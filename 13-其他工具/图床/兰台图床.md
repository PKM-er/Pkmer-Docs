# 兰台图床

兰台是一款管理云端图片的服务，旨在简化并管理图片，俗称图床。

## 解决的问题

其一，以 Obsidian，Typora 等本地软件，在有大量文件数量时（大于一万个文件）文件树会出现较为明显的卡顿，并且文件数量过多难以管理。将图片放到图床，能聚焦到仅管理 Markdown 文件，降低心智压力。

其二，传统对象存储如腾讯云 COS、阿里云 OSS、AWS S3、Cloudflare R2 等，虽然对于个人用户来说很便宜，但有很多需要配置和运维的地方，比如：

- 开通对象存储服务：该服务存储和下载都需要付费，存储价格大约在 0.35元/G，访问和下载按量付费价格不定
- 购买 CDN：单纯的对象存储没有稳定的防盗刷服务，需要 CDN 做防护，有了 CDN 服务，下载走 CDN，对象存储无下行流量费用
- 购买域名：每年大约 10 元以上，上不封顶，好且短的域名往往更贵
- 域名备案：国内的域名需要备案，国外域名无需备案
- 域名 SSL/TLS 证书：域名保障访问内容安全，域名免费 SSL/TLS 证书目前每三个月需要申请一次，未来会缩减到 48 天，需要稳定的自动化工具避免域名 ssl 失效
- 客户端配置：[Typora 文档](https://support.typora.io/Upload-Image/)指出依赖 PicGo、PicList 等外部服务，Obsidian 则还依赖一些插件
- 较难管理：由于对象存储是按桶和key等概念构建的，如果要管理需要自己实现一套服务端和客户端，无法给图片分类，打标签等操作
- ......

对于国外的服务往往不需要备案和自动化证书配置，但支付，访问速度等存在一定的要求。当然也可以使用一些免费图床绕过这些配置，但 Gitee 禁止用户图床，某些图床倒闭等，不能保证稳定。

其三，使得文件易于备份和管理。通过 Git 备份 Obsidian、Logseq、Typora 文件是常见方式，但是 Git 天然对二进制文件不友好，使用图床能保持纯文本文件纯粹，用户能够本地文件大小从几十 G 缩减到数十 MB，能显著减小备份压力。兰台同时提供管理端，支持打标签，修改图片元数据，丰富搜索和查询。进一步的，亦可通过 API 查询图片给 agent 使用。

当然，有利必有弊，解决的问题同时也引入了新的问题。使用图床主要缺点包括无网环境加载不了第一次加载的图片（已加载过的图片有缓存时间），有敏感图片审查（国内对象存储服务严格要求），需要持续付费这三个较大缺点。

## 使用方式

1. 访问 [兰台图床官网](https://lantai.pkmer.cn/)，申请账号。
2. 个人中心确认绑定邮箱（用于过期提醒通知），会在到期前七天，过期时，过期后七天通知，并保留用户图片一月，过期一月后会删除。
3. 在 [兰台图床设置页](https://lantai.pkmer.cn/settings) 根据需要的客户端按照步骤配置使用即可
