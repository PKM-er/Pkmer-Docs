## 概述

**1. 主要功能**
Terminal Commands 是一款仅限桌面端（Windows/macOS/Linux）的 Obsidian 插件。它允许用户通过命令面板或侧边栏菜单，在终端中打开当前 Vault 并执行可配置的 Shell 命令。支持自定义终端应用、命令名称、工作目录及执行行为。

**2. 适用场景**
适合需要频繁在 Obsidian 与终端间切换的开发者或高级用户。例如，快速启动 AI 编程助手（如 Claude Code、Codex CLI）、执行 Git 操作、打开 VS Code 或文件资源管理器，实现笔记管理与代码开发工作流的无缝衔接。

**3. 核心特色**
*   **高度可定制**：支持配置多个命名终端，每条命令可独立设置终端、命令内容和工作目录（Vault 根目录或当前笔记文件夹）。
*   **直观管理**：提供紧凑的列表视图，支持拖拽排序、可视化插入预览及 Obsidian 原生确认删除对话框。
*   **预置实用命令**：内置 Claude Code、Git pull、VS Code 等常用命令，开箱即用。
*   **跨平台适配**：针对 Windows、macOS 和 Linux 提供特定的启动行为，macOS 还支持复用现有终端实例。

**4. 使用建议**
建议根据日常开发习惯，将高频使用的终端命令（如启动特定 AI 工具或 Git 操作）置顶或保留，删除不需要的默认项。利用“工作目录”设置，可精准控制命令执行位置，避免路径错误。注意该插件需 Obsidian 1.13.1 及以上版本。
