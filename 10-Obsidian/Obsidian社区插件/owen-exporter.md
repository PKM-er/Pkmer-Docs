## 概述

### 插件名称
Owen Exporter

### 主要功能
- 右键点击嵌入的 SVG 图像，可将其导出为 PNG 或 JPEG 格式。
- 选中 Markdown 内容，能将其以渲染后的 HTML 格式复制，或保存为 HTML 文件。

### 适用场景
适用于需要将 Obsidian 笔记中的 SVG 图像转换为常见图片格式，以及将 Markdown 内容转换为 HTML 格式的场景。

### 核心特色
- 支持多种 SVG 导出设置，如默认输出格式、保存位置、文件名模板等。
- 可批量导出当前笔记中的所有 SVG 图像。
- 支持选择将 Markdown 内容复制为 HTML 或保存为 HTML 文件。

### 使用建议
- 在设置中根据需求调整 SVG 导出的各项参数，如输出格式、保存位置等。
- 若需批量导出 SVG 图像，可使用命令面板中的“Export all SVG embeds in current note”操作。
- 若遇到导出问题，可使用“Diagnose SVG embeds in current note”进行检查。
