## 概述

### Explorer Order Editor插件总结
1. **主要功能**：可通过在文件资源管理器中拖动文件夹和笔记，或在对话框里操作，将它们手动排序，排序信息以纯文本形式存储在保险库内。
2. **适用场景**：适用于需要对笔记和文件夹按自定义顺序排列的场景，方便整理和查看文件。
3. **核心特色**：无需重命名或添加数字前缀；排序信息存储在保险库而非`.obsidian/`文件夹，可避免因同步设置问题丢失排序；可通过四种方式排序，且这些方式可自由混用；排序信息存储在纯文本笔记中，便于同步、版本控制和手动编辑。
4. **使用建议**：可直接在文件资源管理器中拖动行进行排序，注意拖动到其他行的顶部或底部边缘可精准定位；也可右键文件夹选择“Explorer order → Set order”在对话框中对整个文件夹排序；还能通过右键菜单中的“Move up”“Move down”等选项微调单个项目位置。
