## 概述

**1. 主要功能**
该插件将 Markdown 转换为兼容微信公众号的 HTML 格式。所有样式（标题、引用、列表、表格、代码块）均内联处理，确保粘贴后格式不丢失。支持代码高亮、Obsidian 内部链接图片及本地图片自动 Base64 内联。提供手机框架预览功能，并支持一键复制富文本。

**2. 适用场景**
适用于使用 Obsidian 撰写内容并需发布至微信公众号的用户。特别推荐给个人订阅号或未通过微信认证的账号，因为它采用“本地渲染-预览-复制”的工作流，无需配置 API 密钥或服务器，即可直接粘贴到微信后台编辑器。

**3. 核心特色**
*   **零配置即用**：无需微信认证或 API 权限，解决个人号无法调用草稿接口的问题。
*   **样式保真**：通过内联样式和 Base64 图片技术，完美保留 Markdown 排版细节。
*   **所见即所得**：内置手机框架预览，确保最终呈现效果符合预期。

**4. 使用建议**
安装后，打开任意 Markdown 文件，通过左侧边栏图标或命令面板（`Ctrl/Cmd+P`）执行“预览并复制微信文章”。在弹窗中检查手机预览效果，点击“复制”后，切换至微信公众号后台直接 `Ctrl+V` 粘贴即可。注意：本地图片默认转为 Base64 以支持粘贴，若文件过大可在设置中关闭此功能。
