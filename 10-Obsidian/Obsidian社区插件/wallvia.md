## 概述

**1. 主要功能**
Wallvia 是一款跨平台壁纸插件，旨在将 Wallpaper Engine 的动态壁纸引入 VS Code、Obsidian 和 Codex 桌面应用。它通过本地共享壁纸库，为工作区提供沉浸式视觉体验。

**2. 适用场景**
适用于追求个性化工作环境、希望消除软件界面单调感的开发者及知识工作者。特别适合需要在长时间编码或笔记记录中保持视觉愉悦感的用户。

**3. 核心特色**
*   **多平台统一**：VS Code、Obsidian 和 Codex 共享同一本地壁纸库，一次配置，多端生效。
*   **毛玻璃美学**：在 Obsidian 中通过 CSS 变量在 `.workspace-leaf-content` 上绘制玻璃层，实现通透的磨砂玻璃效果。
*   **安全无侵入**：Codex 端采用 CDP 运行时注入，不修改应用文件且无需管理员权限；VS Code 端自动同步校验和，确保稳定性。

**4. 使用建议**
*   **Obsidian 用户**：可通过 BRAT 安装，或直接将三个文件放入插件文件夹。
*   **环境要求**：确保 Node.js 版本 ≥ 22。
*   **注意**：该插件未经 Obsidian 官方人工审查，建议先在非核心数据区测试，确认兼容性与稳定性后再全面使用。
