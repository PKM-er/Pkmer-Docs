## 概述

**Book Lookup** 是一款用于在 Obsidian 中快速创建书籍笔记的插件，支持从 Open Library 或 Google Books 获取数据。

1. **主要功能**：通过书名、作者或 ISBN 搜索书籍，自动生成包含封面、属性（如标题、作者、出版社）和描述的结构化笔记。支持将元数据插入现有笔记，且默认不覆盖已有属性。
2. **适用场景**：适合需要建立个人图书馆、整理阅读记录或管理书籍元数据的用户，特别是从旧版 Book Search 插件迁移的用户。
3. **核心特色**：
   - **双数据源**：默认使用 Open Library（无需 API Key），也可配置 Google Books（建议申请免费 Key 以避免配额限制）。
   - **精准搜索**：ISBN 搜索直接定位特定版本，避免模糊匹配。
   - **无缝迁移**：完全兼容 Book Search 的模板变量和设置，可一键导入旧配置。
   - **封面管理**：支持将封面图片保存至本地 Vault，并在笔记中引用。
4. **使用建议**：
   - 若使用 Google Books 源，请在设置中填入免费 API Key 以确保稳定性。
   - 建议在设置中配置封面保存路径，以便长期归档。
   - 若已有 Book Search 笔记，可直接导入设置以保持一致性。
