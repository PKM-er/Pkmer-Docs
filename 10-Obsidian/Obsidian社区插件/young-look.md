## 概述

YoungLook Japanese 将电脑中已有的动漫视频和字幕转化为可拆解、可查词、可练习的日语学习素材。它允许你在任意句子处暂停，反复听读，并点击单词即时查询含义与读音。新词会自动存入词汇本，你还能录制自己的朗读并与原声对比，甚至为每句话添加笔记。视频和字幕文件无需移动，插件仅记录其路径，不复制、不上传，确保本地文件安全。

典型场景如：观看《进击的巨人》时，遇到生词“調査”可点击查询，系统自动将其加入复习列表；或在学习《鬼灭之刃》时，对某句台词进行跟读练习，通过对比原声纠正发音。这些操作无需离开 Obsidian，直接利用现有媒体资源，让碎片化时间转化为高效学习时段。

相比同类插件，其特色在于完全本地化处理媒体文件，不依赖云端存储视频内容，仅同步学习记录。首次查词需下载约 17MB 的日语分词词典，之后完全离线可用。AI 功能支持自带 API Key 或内置模型，请求直连服务商，不经过插件服务器，保护隐私。

注意：该插件仅限 Windows、macOS 和 Linux 桌面端使用，移动端无法读取本地视频文件。基础功能免费，但 AI 分析、跟读反馈等高级功能需配置 API Key 或购买内置模型额度。若你希望完全离线且不使用 AI 功能，或主要使用移动设备，此插件可能不适合。
