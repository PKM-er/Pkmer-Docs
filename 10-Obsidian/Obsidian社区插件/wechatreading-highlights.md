# Obsidian 插件：Wechat Reading

> [!Note] 插件名片
> - 插件名称：Wechat Reading

## 概述

### 主要功能
将微信读书的书架、划线、想法、书评、阅读进度和统计等数据同步到本地 Markdown 笔记。生成汇总文件，按阅读状态分组展示；为每本书生成独立笔记并按类别分类；下载图书封面；保留用户手写内容；支持增量同步等多种同步方式，还能自定义同步目录、文件名和模板。

### 适用场景
适合微信读书用户整理阅读笔记，将线上阅读记录转化为本地可编辑的 Markdown 文件。

### 核心特色
本地运行，保护隐私，仅本地存储 API Key；保留手写总结感悟；支持多种同步操作和自定义设置。

### 使用建议
安装可从社区插件搜索或手动下载文件配置。获取 API Key 需在微信读书 App 内操作。首次使用时，按顺序填写 API Key 并测试连接，确认同步目录和汇总页文件名，先关闭自动同步手动操作一次，再按需调整筛选条件和模板。
