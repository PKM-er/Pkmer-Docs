## 概述

Komaki Furigana 是一款专为 Obsidian 设计的日语假名标注工具，核心功能是利用标准 HTML Ruby 标记手动为日文汉字添加、编辑或移除注音。它无需依赖 Templater、网络连接或 API 密钥，所有操作均离线完成，直接将注音数据写入 Markdown 笔记中。插件支持在保存前预览效果，并允许用户自定义注音的大小与位置，确保标注过程直观且可控。

典型使用场景包括日常日语笔记整理与词汇学习。例如，在记录日语文章时，选中“日本語”一词，通过命令面板输入读音“にほんご”，即可快速生成带注音的文本；若需批量处理，可使用“批量标注”功能，按“文字｜读音”格式输入多行数据，一次性为整段文本添加注音。此外，用户还可利用“显示/隐藏注音”功能进行自我测试，模拟听力或阅读练习。

相比其他依赖外部服务或自动生成的插件，Komaki Furigana 的最大特色在于其纯手动、无依赖的特性，彻底避免了隐私泄露风险。它支持平假名与片假名的自动或手动转换，并能兼容已有的 Ruby 标注格式。插件还允许用户选择是否插入回退括号，以兼容不支持 Ruby 渲染的阅读器，同时保留复杂 HTML 结构不被破坏，确保笔记的长期可维护性。

需要注意的是，该插件并非自动注音生成器，不包含日语词典或发音服务，所有读音需用户手动输入。它仅支持单行文本标注，且不支持多光标同时编辑。若笔记中包含代码块、Frontmatter 或复杂 Markdown 结构，这些区域会被排除在标注处理之外。对于希望一键自动识别汉字读音或需要在线发音辅助的用户，此插件可能无法满足需求。
