## 概述

### Canvas Layer Order 插件总结
1. **主要功能**：为 Obsidian Canvas 增添类似 PowerPoint 的图层控制功能，可将卡片置于最前、最后，向前或向后移动一层，还能在聚焦卡片时保留图层顺序。
2. **适用场景**：适用于处理 Obsidian Canvas 中存在重叠卡片的场景，帮助用户更好地管理卡片显示顺序。
3. **核心特色**：通过移动 `.canvas` JSON 文件 `nodes` 数组里的选中卡片来改变图层顺序；可在命令面板使用命令或设置快捷键；在支持的 Obsidian 版本中，卡片右键菜单也可操作；能在插件设置中开启聚焦时保留图层顺序功能。
4. **使用建议**：使用命令可从命令面板调用或设置热键，也能在支持版本中通过卡片右键菜单操作。若不想聚焦卡片时改变显示顺序，可在插件设置里开启“Preserve layer order when focusing cards”。手动安装需复制相关文件到指定插件文件夹。
