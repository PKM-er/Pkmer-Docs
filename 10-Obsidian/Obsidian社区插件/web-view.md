> [!Note] 插件名片

## 概述

### Web View插件总结
1. **主要功能**：借助嵌入式浏览器，在Obsidian新标签页中打开HTTP/HTTPS链接，可从命令面板打开URL、从剪贴板打开有效HTTP(S)链接，还能进行后退、前进、重新加载等操作，也可在默认浏览器中打开当前页面。
2. **适用场景**：适用于在Obsidian内快速访问网页内容，无需在浏览器和笔记软件间频繁切换，方便在记录笔记时随时查看网页资料。
3. **核心特色**：在Obsidian内部嵌入浏览器功能，实现网页的直接访问，操作便捷，提供了类似浏览器的导航和地址栏控制。
4. **使用建议**：将插件文件夹复制到保险库的`.obsidian/plugins`目录，从社区插件设置中启用。使用时，可从命令面板运行“Open URL in Web View”输入URL，或在剪贴板有HTTP/HTTPS链接时，运行“Open clipboard URL in Web View”。需注意该插件仅支持桌面端。
