## 概述

### Mind Map Visual 插件总结
1. **主要功能**：在 Obsidian 内创建和编辑思维导图，可对节点进行添加、重命名、移动等操作，能为节点添加注释或创建关联 Markdown 笔记，支持地图平移、缩放，自动将地图保存为带 YAML 前置元数据的 Markdown 文件，还能将地图导出为 PNG、JPEG 或 PDF 格式。
2. **适用场景**：适用于头脑风暴、知识整理、项目规划等场景，方便用户以可视化方式梳理思路。
3. **核心特色**：具备自动布局，支持以键盘操作为主的编辑方式，可处理关联笔记和节点连接、分组，能本地工作无需网络请求和外部服务。 
4. **使用建议**：可通过命令面板运行“Mind map: Create new mind map”等命令操作，也能点击侧边栏图标创建新思维导图。使用时可借助丰富的键盘快捷键提高效率，如 `Tab` 添加子节点、`Enter` 添加同级节点等。
