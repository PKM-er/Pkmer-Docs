## 概述

### GitHub Updater插件总结
1. **主要功能**：可直接从GitHub仓库安装、跟踪和更新Obsidian插件，无需手动下载文件和离开应用。内置的保险库扫描器能自动发现已安装的非官方插件并开始跟踪。
2. **适用场景**：适用于使用大量非官方Obsidian插件，这些插件仅以GitHub版本发布，未进入社区商店的用户。
3. **核心特色**：免去手动下载`main.js`和`manifest.json`文件并放入`.obsidian/plugins/`文件夹的繁琐操作，还能自动提醒新版本。
4. **使用建议**：通过点击功能区图标或使用命令面板打开模态框，输入`用户名/仓库名`或粘贴GitHub URL即可安装插件。使用前需注意该插件未经Obsidian官方人员手动审核。
