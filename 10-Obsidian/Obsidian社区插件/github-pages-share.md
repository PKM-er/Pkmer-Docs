## 概述

### GitHub Pages share 插件总结

#### 主要功能
将 Obsidian 中的 Markdown 笔记发布到 GitHub 仓库，通过 GitHub Pages（Jekyll）展示，并复制可分享链接到剪贴板。支持单笔记发布、批量发布文件夹内笔记，支持取消发布。

#### 适用场景
适合需要将 Obsidian 笔记分享到网络，供他人查看的场景，如知识分享、项目文档展示等。

#### 核心特色
- 操作便捷：有一键发布、右键菜单和 ribbon 图标，支持移动设备。
- 链接处理：转换 Obsidian 内部链接，未发布目标显示为纯文本。
- 资源处理：上传嵌入图片，重写引用；渲染 callouts 和 mermaid 代码块。
- 自动更新：开启选项后，保存修改约 15 秒自动重新发布。
- 初始化设置：“Set up pages repo” 命令可快速搭建仓库。

#### 使用建议
目前插件待审核，审核通过后可在社区插件中安装启用；也可手动从 Releases 页面下载文件安装。
