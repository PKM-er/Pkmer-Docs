## 概述

Vault Code 将 Obsidian 从单纯的笔记工具转变为集笔记、代码与文件管理于一体的综合工作区。它突破了传统笔记应用的限制，允许用户直接查看和编辑隐藏文件、无扩展名文件以及各类代码脚本。插件内置了功能完善的代码编辑器，支持 170 多种文件类型的语法高亮、折叠和正则查找替换，让你无需切换外部应用，即可在熟悉的界面中处理 Python、JavaScript、HTML 等代码文件，实现文档与代码的无缝协作。

典型场景包括在撰写技术文档时，直接打开并修改同目录下的配置文件或脚本，确保文档与代码同步更新；或者在维护个人博客时，利用内置预览功能实时查看 HTML、SVG 图表及 Mermaid 流程图的效果，无需启动浏览器即可确认渲染结果。此外，你还可以在侧边栏通过 AI 助手针对当前笔记或代码片段提问，获取即时建议或执行修改指令，大幅提升开发效率。

相比同类插件，Vault Code 的特色在于其深度的文件系统集成与多模态预览能力。它不仅支持通过符号链接将外部磁盘文件夹引入库中，还允许通过忽略规则保持文件树整洁。在桌面端，它提供了原生的 Git 差异审查功能，可直接在编辑器内对比、保留或回退代码变更，并支持单文件提交。同时，其 AI 连接方式极为灵活，既支持本地模型服务器，也兼容各类云端 API 及命令行编码代理，满足了不同隐私偏好和技术栈用户的需求。

使用前需注意，Git 操作、AI 交互及外部文件夹链接功能仅限桌面端使用，移动端仅支持基础的文件管理与代码编辑。该插件不适合仅用于纯文本记录、无需处理代码或复杂文件结构的用户。此外，虽然插件本身不收集遥测数据，但使用 AI 功能时，相关上下文会发送至你配置的端点，请根据隐私需求谨慎选择连接方式。
