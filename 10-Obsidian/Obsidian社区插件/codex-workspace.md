## 概述

**1. 主要功能**
Codex Workspace 允许用户在 Obsidian 侧边栏直接调用本地已安装的 Codex CLI，将知识库转化为对话式工作区。无需配置 API 密钥或嵌入网页，即可利用现有的 Codex 会话对笔记进行组织、编辑和探索。

**2. 适用场景**
适用于需要深度整理 Markdown 笔记库的用户，如整理会议记录、建立索引、跨文件关联想法、总结研究文件夹、重构 Frontmatter 及链接规范，或协助制定计划与解决复杂问题。

**3. 核心特色**
*   **零配置接入**：直接复用用户已登录的 Codex CLI 环境，无需额外 API Key。
*   **本地化安全**：数据保留在本地，通过 CLI 交互，不依赖外部嵌入式网站。
*   **生态兼容**：支持调用 Codex 现有的 Skills、插件及 MCP 集成，扩展性强。
*   **持久化面板**：在右侧边栏提供常驻对话界面，实现“边看笔记边对话”的高效工作流。

**4. 使用建议**
*   仅支持 Obsidian 桌面版，移动端不可用。
*   使用前请确保已正确安装并登录 Codex CLI。
*   作为社区独立项目，非官方产品，建议定期更新以获取最佳兼容性。
