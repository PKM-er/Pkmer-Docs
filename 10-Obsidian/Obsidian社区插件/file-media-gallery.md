## 概述

### File Media Gallery 插件总结
1. **主要功能**：右键点击笔记，可查看其引用的所有媒体（图片、视频、音频、PDF 等），支持来自库附件和外部 URL 的媒体，将不同类型媒体分类展示在不同标签页，支持全屏灯箱查看。
2. **适用场景**：适用于媒体文件存于库外，需要集中查看笔记引用媒体的场景。
3. **核心特色**：能查找笔记引用的所有媒体，包括嵌入、库链接和外部 URL；有按类型分类的标签页；支持全屏灯箱查看，可通过快捷键切换；每种媒体类型展示合适的缩略图；有刷新按钮可重新扫描笔记。
4. **使用建议**：在笔记上右键，选择“Show all media from the file”，即可浏览各类型媒体标签页，点击缩略图可在灯箱中查看。插件通过社区插件市场安装，路径为“Settings → Community plugins → Browse”，搜索安装并启用。
