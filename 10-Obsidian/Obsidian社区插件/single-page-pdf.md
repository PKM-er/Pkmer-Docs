## 概述

### Single Page PDF Export插件总结
1. **主要功能**：将Obsidian笔记导出为无分页的单页PDF，页面高度根据内容自动计算，无需手动配置。支持预览、使用用户字体设置，有中英文界面。
2. **适用场景**：适用于需要将笔记完整呈现在一页PDF上，避免分页影响阅读体验的场景，如制作报告、文档等。
3. **核心特色**：单页输出无分页；高度自动计算；可预览；尊重用户字体设置；支持中英文；可通过右键菜单直接导出。
4. **使用建议**：可通过社区插件或手动方式安装。使用时，可通过命令面板（Ctrl+P搜索“Single Page PDF”）或在文件资源管理器中右键点击.md文件选择“Export to single - page PDF”进行导出。若需开发，可使用“npm run dev”自动监听文件变化并重建。
