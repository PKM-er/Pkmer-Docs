## 概述

**主要功能**
SessionReviewer 是一款 Obsidian 插件，能将本地 Codex 会话历史转化为简洁、可编辑的项目回顾。它自动扫描项目相关的所有 Codex 会话，无需调用 Agent 或消耗 Token，即可确定性地将分散的日志聚合为统一的项目视图，涵盖项目目标、当前阶段、下一步行动、风险、关键决策及演变时间线。

**适用场景**
适用于使用 Codex 进行开发的项目管理者或开发者。特别适合需要长期追踪项目演进、复盘历史决策、评估模型使用成本，且希望避免将原始冗长日志直接复制到笔记中的场景。

**核心特色**
1. **零成本聚合**：本地处理，不修改原始 JSONL 文件，无需额外 OpenAI API Key。
2. **结构化输出**：生成人类可读的 `项目回顾.md` 和 `项目历史.md`，隐藏机器生成的元数据。
3. **安全同步**：采用确定性三方合并机制，将可编辑笔记与配置库同步，支持桌面端浏览器查看演变、决策及定价来源。
4. **隐私安全**：原始会话文件保留在本地，不上传云端。

**使用建议**
确保系统满足要求（macOS 13+/Windows 10+，Obsidian 1.8.7+）。安装后，通过桌面端插件启动扫描，利用其五页工作流查看项目全貌。建议定期同步笔记以保持项目状态最新，并利用其“可选语义细化”功能仅在需要深度分析时启用，以保持日常操作的高效与低成本。
