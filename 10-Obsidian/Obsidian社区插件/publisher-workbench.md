## 概述

**Publisher Workbench** 是一款专为 Obsidian 设计的桌面端开源插件，旨在将 Markdown 笔记转化为风格化、可预览的发布草稿。

**主要功能**：支持生成微信公众号和 X Articles 的排版草稿。微信端提供主题预设、实时 HTML 预览及富文本复制功能，支持本地图片；X 端通过配套的 Chrome 扩展（X Bridge）实现 Markdown 移交及文章创建。

**适用场景**：适合在 Obsidian 中撰写内容，并需同步发布至微信公众号或 X 平台的博客作者、内容创作者及自媒体运营者。

**核心特色**：
1. **草稿优先**：仅生成待审核草稿，不直接点击最终发布，确保内容安全可控。
2. **精细排版**：提供字体大小、行高、颜色及多种章节样式（如下划线、左侧栏等）的自定义选项。
3. **工作流整合**：保持 Markdown 为唯一事实来源，通过 Ribbon 图标或命令面板快速启动工作台。

**使用建议**：
- 需保持微信编辑器登录状态；若需自动化草稿移交，需额外安装 Wechatsync。
- 使用 X 功能需安装独立的 X Bridge 扩展并拥有支持 Articles 的 X 账号。
- 发布前务必在目标平台手动核对内容与格式，插件不替代最终发布操作。
