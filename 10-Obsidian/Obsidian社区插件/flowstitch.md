## 概述

**主要功能**
Flowstitch 是一款原生 Obsidian 插件，通过 Todoist 统一 API v1 将笔记与任务无缝连接。它提供实时仪表盘，支持任务的捕获、编辑、完成、重排及标签管理，并实现双向同步。

**适用场景**
适合需要高效管理个人工作流、日程安排及项目进度的用户。特别适用于希望将 Markdown 笔记中的待办事项直接转化为 Todoist 任务，并在多设备间保持状态一致的场景。

**核心特色**
1. **原生集成**：无需其他社区插件，直接对接 Todoist API，支持桌面与移动端。
2. **灵活同步**：采用“选择加入”机制，用户可指定特定文件夹或命令（如 `#todoist`）同步复选框，普通笔记保持本地独立。
3. **实时仪表盘**：提供今日、即将到期、项目视图及最近七天完成历史，支持离线缓存搜索。
4. **安全存储**：API 令牌仅存储在设备本地的 Obsidian 秘密存储中。

**使用建议**
1. **分阶段启用**：初始阶段建议仅在一台设备上启用写入权限，其他设备保持只读，以验证同步稳定性。
2. **手动构建**：需使用 Node 24+ 自行编译安装，安装后需手动配置 Work 项目或选择现有项目。
3. **明确范围**：谨慎设置文件夹同步范围，避免非任务类复选框被意外同步至 Todoist。
