## 概述

**主要功能**
Habitude Checklist 是一款基于 Markdown 原生数据的 7 天习惯追踪插件。它提供可视化的习惯打卡网格，支持连续记录（Streaks）统计、每周完成率分析及周回顾视图。数据直接存储在 Vault 中，人类可读且可手动编辑。

**适用场景**
适合希望以轻量、无依赖方式记录日常习惯（如运动、阅读）的用户。特别适合重视数据隐私、偏好纯文本管理，或需要定期复盘习惯养成进度的 Obsidian 用户。

**核心特色**
1. **Markdown 原生**：数据以纯文本形式存在，不锁定在数据库，随时可迁移或手动修改。
2. **本地可视化**：内置 30 天历史条和 8 周完成柱状图，纯本地 SVG 渲染，无需联网。
3. **AI 教练（BYOK）**：支持接入 Gemini、OpenAI 或本地模型（Ollama/LM Studio），利用用户自有 API Key 提供个性化的习惯建议与对话。
4. **实时同步**：插件自动监听文件变更，手动编辑笔记后界面即时更新。

**使用建议**
建议用户熟悉 Vault 中 `Habitude/` 目录结构，以便在插件故障时直接编辑 Markdown 文件恢复数据。若使用 AI 功能，请确保 API Key 安全，并优先选择本地模型以保护隐私。定期利用“周回顾”功能复盘，结合连续记录激励保持动力。
