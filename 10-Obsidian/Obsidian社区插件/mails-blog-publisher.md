## 概述

### Mails Blog Publisher插件总结
1. **主要功能**：可将Obsidian中的笔记保存为草稿、发布笔记，从Mails Blog同步关联笔记，查看关联笔记的版本历史，从保险库上传图片并插入Markdown格式链接，还能自动将博客绑定元数据写入前置元数据。
2. **适用场景**：适用于已使用Mails Blog，希望在Obsidian内完成草稿撰写、发布、同步及图片上传，无需切换应用的用户。
3. **核心特色**：实现Obsidian与Mails Blog的无缝衔接，让用户在Obsidian单一环境下完成博客创作与发布的一系列操作。
4. **使用建议**：使用前需有Mails Blog账户，通过Mails iOS应用生成`Obsidian Plugin Token`，并获取可达的`Blog API Base URL`。插件可在Obsidian社区插件目录安装，也能手动安装。若从源码构建，运行`npm run release:package`创建可复制文件夹。发布新版本时按相应命令操作，还可使用`--minor`或`--major`自动更新版本号。
