## 概述

Columns Callout 允许你在笔记中通过简单的 Callout 语法创建多栏布局。它解决了 Obsidian 原生 Markdown 缺乏灵活分栏排版的问题，让你无需编写复杂的 HTML 或 CSS 代码，仅使用 `[!cols]` 标记即可将内容划分为多个垂直列。列与列之间通过 `+++` 符号进行分隔，极大地降低了多栏排版的门槛，使文档结构更加清晰直观。

典型场景包括制作对比表格或并排展示不同维度的信息。例如，在撰写产品评测时，你可以将“优点”和“缺点”分别放在左右两栏，利用视觉隔离增强对比效果；或者在整理学习笔记时，将“核心概念”与“相关案例”并列展示，帮助读者快速建立知识关联。这种布局方式特别适合需要横向对比或空间紧凑排版的文档结构。

相比其他排版插件，Columns Callout 的最大特色在于其高度的可配置性与轻量级。它支持在 Callout 标题中直接定义列宽比例（如 `r=2:1`）和列间距（如 `g=2rem`），默认采用等宽布局，但能轻松调整为非对称结构。这种基于文本参数的控制方式比拖拽式编辑器更易于版本控制和协作，同时保持了 Markdown 的纯文本特性，避免了因插件依赖导致的格式丢失风险。

需要注意的是，该插件主要服务于视觉排版需求，并不改变内容的逻辑层级。如果你的笔记内容以线性阅读为主，或者需要复杂的网格嵌套（如行内再分栏），此插件可能无法满足需求。此外，由于列宽是相对比例，在极窄的移动端屏幕上，多栏内容可能会显得拥挤，建议根据目标阅读设备调整列数或比例，以确保最佳的可读性体验。
