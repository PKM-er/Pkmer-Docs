## 概述

Banana Studio 是一款专为 Obsidian 桌面端设计的发布辅助工具，核心功能是从 Markdown 笔记中直接生成封面与正文插图，并支持预览及一键发布到微信公众号和 X（Twitter）。它允许用户独立配置规划与图像生成服务，支持 Codex CLI 或 OpenAI、Anthropic 等主流 API 接口，实现了从内容创作到多平台分发的完整工作流闭环。

典型场景包括：当你完成一篇技术博客后，无需切换软件，直接在插件工作区选择模板生成匹配文章风格的封面图，并预览微信公众号的富文本排版效果，确认无误后直接推送草稿；或者将长文自动拆分为 X 平台的线程格式，利用 AI 重写或确定性分割功能，快速完成跨平台的内容分发。

相比同类插件，其特色在于“规划”与“生成”服务的解耦配置，以及精细化的图像控制能力。用户可以在生成前对画布文本进行内联编辑，甚至通过区域编辑功能仅修改生成图片的特定标记区域，而非重新生成整张图。此外，插图插入采用段落标记机制，确保图片精准定位，避免静默追加导致的排版混乱，且界面语言自动跟随 Obsidian 设置，对中文用户友好。

使用前需注意，该插件仅支持桌面端，且 AI 生成与发布功能依赖你自行配置的 API 密钥或平台账号，相关费用需自行承担。它不替代 Markdown 编辑器，也不作为通用自主智能体运行。如果你只需要简单的图片插入功能，或希望完全离线、不依赖任何外部 AI 服务的工作流，这款插件可能并不适合你的需求。
