## 概述

### Canvas Branch Chat 插件总结
1. **主要功能**：在 Obsidian Canvas 上实现 Flowith 式分叉对话，可从任意节点拉线分叉、标注方向，支持多方向分支、上下文继承、多模型配置等，还具备导出 Markdown/HTML、节点自动命名、流式刷新等功能。
2. **适用场景**：适用于在 Obsidian 中进行思考和记录，将对话转化为可浏览的思维地图，方便回溯、整理和嵌入笔记体系。
3. **核心特色**：把对话变成可回溯的思维地形图，每个分支独立对话且自动继承上下文；多模型配置可从不同视角分析；节点和分支有视觉区分，便于识别；支持多语言和跨平台 API Key。
4. **使用建议**：可利用快捷模板快速插入常用方向，提高分叉效率；使用连通性测试确保 API 正常；导出 Markdown 或 HTML 文件用于分享和离线查看；通过回放对话功能回顾思考过程。
