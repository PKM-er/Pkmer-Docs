## 概述

**1. 主要功能**
Mobile-Translate 是一款基于 Google Translate 的文本翻译插件。用户只需选中文字并点击按钮，即可获取即时翻译结果。支持桌面端与移动端，无需默认配置 API 即可使用。

**2. 适用场景**
适用于日常阅读外文笔记、文献或网页内容时的快速查词与段落翻译。特别适合在移动设备上随时查阅，或作为桌面端轻量级翻译工具，无需频繁切换浏览器标签页。

**3. 核心特色**
*   **零配置启动**：默认无需 API Key，开箱即用，利用 Google Translate 的稳定性和一致性。
*   **跨平台支持**：完美适配 Obsidian 移动端与桌面端，并支持自定义移动端工具栏按钮。
*   **高级扩展**：若遇网络限制，可手动配置 Google Cloud API Key；支持接入 Gemini API 生成上下文例句，增强翻译准确度。

**4. 使用建议**
*   **移动端优化**：务必在设置中启用“移动端工具栏”并添加翻译按钮，以提升操作效率。
*   **网络问题处理**：若移动端因 VPN 等原因无法直连，建议按文档指引申请免费的 Google Cloud Translation API Key。
*   **进阶体验**：强烈建议探索“输出构建器（Output Builder）”功能，并尝试配置 Gemini API 以获取更丰富的语境解释，从而最大化插件价值。
