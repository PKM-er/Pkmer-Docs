## 概述

### 主要功能
Todoist - Plug 实现了 Todoist 与 Obsidian 的深度集成，可在知识库内管理任务。具备快速添加任务模态框，能自动填充任务标题、添加 Obsidian 笔记深层链接；支持配置新任务默认值；采用安全认证存储 Todoist API 令牌。

### 适用场景
适用于习惯在 Obsidian 中记录知识，同时需要借助 Todoist 管理任务的用户，可在知识记录过程中便捷创建任务。

### 核心特色
- 快速添加任务模态框功能丰富，上下文感知，能自动填充标题，还可同步项目和标签颜色。
- 提供可配置的默认设置，方便用户按习惯设置新任务参数。
- 安全认证保障 API 令牌本地存储，防止明文同步。

### 使用建议
可通过 Obsidian 命令面板（`Cmd/Ctrl + P`）调用相关命令。如使用“Todoist - Plug: Add quick task”快速打开添加任务界面，利用其可视化配置任务属性；使用“Todoist - Plug: Create task from current line”从当前行快速创建任务。
