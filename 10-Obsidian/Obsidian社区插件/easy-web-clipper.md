## 概述

### Easy Web Clipper 插件总结
1. **主要功能**：在 Obsidian 内粘贴网页链接，一键将网页内容剪藏为干净的 Markdown 笔记，自动提取正文，去除广告等噪音，生成 YAML 元数据。
2. **适用场景**：适用于需要在 Obsidian 中快速收集和整理网页信息，将网页内容转化为笔记的场景。
3. **核心特色**：零外部依赖，无需浏览器扩展、服务器和 API Key；基于 Mozilla Readability.js 智能提取内容；输出高质量 Markdown，保留多种格式；支持自动 Front Matter；具备剪贴板感知功能；可灵活配置保存路径等。
4. **使用建议**：推荐通过社区插件商店安装。使用时，可通过点击 Ribbon 图标或使用命令面板，粘贴网页链接进行剪藏。若需个性化设置，可在插件配置中自定义保存路径、文件名模板和 Front Matter 字段。
