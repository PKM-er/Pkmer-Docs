## 概述

**1. 主要功能**
Git Sync Desktop 是一款跨平台（macOS/Windows/Linux）Obsidian 插件，用于将 Vault 与 Git 仓库同步。它提供一键同步功能，自动执行本地提交、拉取服务器更新、合并（非变基）及上传，并验证两端提交一致性。

**2. 适用场景**
适用于需要跨设备同步笔记的用户，特别是同时使用桌面端和 iPhone（配合 VaultBridge 插件）的场景。支持 GitHub、Forgejo/Gitea 等任意 Git 托管服务，无需依赖特定云服务。

**3. 核心特色**
- **直观操作**：提供独立的“提交”、“拉取”、“合并”、“推送”按钮，附带通俗解释，降低 Git 使用门槛。
- **稳健同步**：支持 Git LFS 处理大文件，具备冲突检查点和明确确认机制，防止数据丢失。
- **透明反馈**：实时显示同步进度、状态及错误信息，确保操作可控。
- **生态互补**：作为 VaultBridge 的桌面伴侣，共享同一仓库，实现移动端与桌面端无缝衔接。

**4. 使用建议**
- 安装前确保系统已配置 Git 和 Git LFS，并重启 Obsidian。
- 从 GitHub Releases 手动下载插件文件至 `.obsidian/plugins/git-sync-desktop/` 目录并启用。
- 建议先通过 Ribbon 图标或命令面板测试同步，熟悉各步骤含义后再进行日常使用。
- 注意该插件未通过 Obsidian 官方人工审核，请自行评估安全性。
