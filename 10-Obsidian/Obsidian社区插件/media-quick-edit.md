## 概述

**1. 主要功能**
该插件将 Obsidian Bases 转化为可编辑的媒体库。支持表格视图和书架封面视图，允许用户管理评分、双状态（如阅读/观看中）及自动保存评论。集成 TMDB 电影/剧集搜索与 Open Library 图书搜索，支持状态历史记录。

**2. 适用场景**
适合需要系统化整理个人影视、书籍收藏的用户。适用于希望利用 Obsidian 本地数据库功能，替代传统媒体管理软件，实现笔记与媒体库联动管理的场景。

**3. 核心特色**
- **双视图体验**：提供直观的表格快速编辑与美观的书架封面展示。
- **多源集成**：无缝对接 TMDB（需 API Key）和 Open Library（无需 Key），自动填充元数据。
- **状态追踪**：内置双状态切换与历史日志，配合自动保存，确保数据不丢失。
- **本地化安全**：API Key 仅存储于本地 Vault，保障隐私。

**4. 使用建议**
- 需启用 Obsidian 1.10.2+ 及 Bases 核心功能。
- 电影/剧集搜索需自行申请 TMDB v3 API Key 并在设置中测试连接。
- 建议在设置中预设“默认 Base”及媒体文件夹路径，以便通过侧边栏快捷键快速访问。
- 安装后请配置好状态标签（如“在读”、“已看”），以符合个人习惯。
