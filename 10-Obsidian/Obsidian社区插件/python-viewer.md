## 概述

### Python Viewer插件总结
1. **主要功能**：以只读模式打开 `.py` 文件，提供源码和结构大纲视图。可展示导入项、类、函数等结构信息，具备源码行号和轻量级语法高亮，支持按多种条件过滤符号和源码行，能从符号跳转到对应源码行，报告解析诊断信息。
2. **适用场景**：适用于快速检查脚本、生成的代码、迁移工具和代理输出等，无需将库转换为 IDE。
3. **核心特色**：只读设计，不执行代码、不保存更改，保障安全性；结构解析不完整时仍可查看源码；对大文件设置 10000 行渲染上限，保证响应速度。
4. **使用建议**：该插件主要用于查看和检查 Python 代码，若需编辑代码、执行代码等操作，建议使用专业的代码编辑器或终端。
