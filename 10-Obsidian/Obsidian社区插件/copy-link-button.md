# Obsidian 插件：Copy Link Button

> [!Note] 插件名片
> - 插件名称：Copy Link Button
> - 插件作者：ChekTek
> - 插件说明：在 Markdown 链接和纯文本 URL 旁边添加一个复制按钮，这样你只需点击一下就能复制 URL。——此插件尚未经过 Obsidian 官方人员的手动审核。

## 概述

### Copy Link Button插件总结
1. **主要功能**：在Obsidian中，为Markdown链接、纯文本URL、维基链接、内部嵌入和Markdown图片添加复制按钮，点击按钮可将链接或图片目标复制到剪贴板。
2. **适用场景**：适用于在编辑或阅读笔记时，需要快速复制链接或图片地址的场景。
3. **核心特色**：
    - 支持多种链接和图片格式。
    - 编辑、实时预览和阅读视图均可使用。
    - 点击复制后会短暂显示对勾。
    - 按钮默认始终可见，也可设置为按住Ctrl、Cmd、Alt或Shift时显示。
    - 样式与Obsidian主题匹配。
4. **使用建议**：可从社区插件商店搜索“Copy Link Button”安装启用；也可手动下载`main.js`、`manifest.json`和`styles.css`文件放入指定目录后启用。开发时可按文档命令操作，便于实时测试和构建发布。
