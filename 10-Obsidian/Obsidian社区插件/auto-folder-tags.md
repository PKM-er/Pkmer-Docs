## 概述

### 1. 主要功能
自动为新笔记应用配置好的标签，并为当前文件夹内的文件补充标签。可监听新创建的 Markdown 文件并注入配置的前置标签，也能通过命令面板为当前文件夹内所有 Markdown 文件应用相同配置标签，同时避免重复添加已有标签。

### 2. 适用场景
适用于需要对笔记进行批量标签管理，希望提高标签添加效率的用户，尤其是笔记分类较多、结构复杂的情况。

### 3. 核心特色
采用最长匹配文件夹规则，精准应用标签；在本地库内运行，无需联网，不向外部发送笔记内容、文件名或遥测数据，保障隐私。

### 4. 使用建议
可通过手动或社区插件方式安装。安装后，在设置中添加规则，设置相对库根的文件夹路径和以逗号分隔的标签。使用命令“Apply configured tags to files in the current folder”可对当前文件夹文件应用标签，“Open auto folder tags settings”可打开配置页面。
