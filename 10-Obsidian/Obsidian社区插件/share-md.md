## 概述

**Share MD** 是一款将 Obsidian 笔记一键发布为自托管网页的插件。

1. **主要功能**：支持通过工具栏、右键菜单或命令面板快速分享笔记，自动上传文中引用的图片，并允许对已分享链接进行内容同步更新。
2. **适用场景**：适用于需要快速向他人展示 Markdown 笔记、分享技术文档或临时协作的场景，无需搭建复杂的前端环境。
3. **核心特色**：
   - **便捷操作**：一键发布，支持同步更新且保持 URL 不变。
   - **隐私安全**：链接私密不收录于搜索引擎，Token 本地存储。
   - **体验优化**：支持深色模式，可设置 1 天或 7 天自动过期。
4. **使用建议**：
   - **获取 Token**：目前不开放公开注册，需通过微信或邮件联系作者获取 API Token。
   - **配置设置**：安装后需在设置中填入指定的 API URL 及 Token。
   - **注意时效**：分享链接有有效期，长期分享需定期同步或重新发布。
