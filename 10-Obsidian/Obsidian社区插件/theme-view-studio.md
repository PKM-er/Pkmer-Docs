## 概述

Theme View Studio 允许你在保持全库统一默认外观的同时，为特定文件夹设置独立的视觉风格。它支持精细控制阅读宽度、字体排版、背景图片与透明度，甚至提供专门的墨水屏模式。通过文件夹规则机制，你可以让深层目录覆盖父级设置，实现“一处默认，多处定制”的灵活布局，无需手动切换主题。

想象一下，你的“工作”文件夹需要宽屏阅读和深色背景以减少夜间眩光，而“阅读”文件夹则偏好窄栏排版和纸质纹理背景。只需为这两个文件夹分别绑定预设主题，打开对应笔记时界面会自动适配。此外，你还可以利用自定义主页功能，将库内统计、笔记属性或 Dataview 查询拼成个人仪表盘，作为打开 Obsidian 后的第一屏。

相比仅能全局换肤的插件，它的核心优势在于“文件夹级”的隔离与继承逻辑，且通过 CSS 变量生效，不动态生成样式表，性能更稳定。其内置的墨水屏模式能一键灰度化界面并移除动画，适合长时间阅读。状态栏还会实时显示当前生效的主题名，方便你确认当前处于哪种视觉环境中，避免混淆。

需要注意的是，该插件仅改变外观，不会移动或修改笔记内容。主页中的 GitHub 文件块若使用 Token，会以明文存储在本地配置文件中，建议仅使用细粒度只读 Token。如果你需要的是复杂的主题引擎或跨库同步，此插件可能不够；它更适合希望在不同知识领域间快速切换视觉氛围，且对隐私安全有基本认知的用户。
