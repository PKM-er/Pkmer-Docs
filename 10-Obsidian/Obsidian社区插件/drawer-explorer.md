# Obsidian 插件：Drawer Explorer

> [!Note] 插件名片
> - 插件名称：Drawer Explorer
> - 插件作者：Dylan Zhang
> - 插件说明：一个带有模态Vim风格导航的弹出式抽屉文件树：用hjkl键移动，a/r/d键进行文件操作，i键过滤，Esc键返回正常模式。 - 此插件尚未经过Obsidian官方人员的人工审核。

## 概述

### 主要功能
提供弹出式文件和标签浏览器，支持模态、Vim 风格导航及实时预览，可通过快捷键操作文件、移动复制、筛选标签等。

### 适用场景
适合习惯使用 Vim 快捷键、偏好键盘操作的 Obsidian 用户进行文件和标签浏览管理。

### 核心特色
1. 模态导航：使用 `hjkl` 等快捷键在树状结构中导航，无需鼠标。
2. 筛选功能：按 `i` 进行模糊筛选，不同模式下 `Esc` 操作有不同效果。
3. 标签浏览：按 `t` 浏览嵌套标签，可聚焦虚拟集合并细化。
4. 预览窗格：支持多种文件类型预览，还提供 API 供插件扩展。
5. 与 Vim 插件兼容：可与如 Vim Motions 等 Vim 插件协同工作。

### 使用建议
该插件尚处发展阶段，可能存在不足。安装可从 Obsidian 社区插件目录搜索“Drawer Explorer”，使用中遇到问题可提交 issue 或 PR 反馈。
