## 概述

### MCP Notes Tools 插件总结
1. **主要功能**：该插件可让 MCP 客户端在项目库中搜索笔记、读取所选笔记，并请求追加确认的仅追加更改笔记。具体功能有搜索笔记标题、路径和正文，获取所选 Markdown 笔记的完整内容，在“Change notes”部分追加带时间戳的文本。
2. **适用场景**：适用于在 Obsidian 桌面端对项目库中的笔记进行管理和操作的场景。
3. **核心特色**：仅在本地活动的 Obsidian 库中操作，不向外部服务发送笔记内容等信息；追加操作需每次确认，保证数据安全；保留现有笔记内容。
4. **使用建议**：此插件仅支持桌面端。需在“设置 -> MCP Notes Tools”中启用本地 MCP 服务器，默认端点为 `http://127.0.0.1:39399/mcp`，可配置 MCP 客户端连接该端点。同时，插件提供特定库别名，但不支持跨库查询。开发时可按文档执行 `npm` 相关命令。
