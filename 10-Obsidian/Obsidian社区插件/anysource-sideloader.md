## 概述

**1. 主要功能**
AnySource Sideloader 允许用户从任意 Git 托管平台（如 GitHub、Forgejo、Gitea）或直接通过原始 URL 安装和更新 Obsidian 插件。它支持订阅插件目录，并能像官方社区商店一样管理插件的生命周期，包括版本检查、查看发布说明及更新确认。

**2. 适用场景**
适用于需要安装个人开发插件、组织内部私有仓库插件，或托管在自托管平台（如 Forgejo/Gitea）上的插件。特别适合那些未上架 Obsidian 官方社区商店，或希望降低对单一平台依赖的用户。

**3. 核心特色**
*   **多源支持**：打破官方商店限制，兼容多种 Git 服务。
*   **高可用性**：消除单点故障风险，避免因地主账号被标记导致插件无法安装。
*   **安全更新**：提供可视化的更新检查、发布说明展示及更新前确认机制。
*   **互补设计**：作为官方商店的补充而非替代，不干扰已安装的商店插件。

**4. 使用建议**
建议将其作为官方商店的补充工具使用。对于非商店插件，配置好对应的 Git 源地址即可自动管理更新。注意该插件未经 Obsidian 官方人工审核，使用时请确保信任插件来源的安全性。
