## 概述

### “Link As”插件总结
1. **主要功能**：将选中文本链接到任意笔记，并保留其作为显示文本；若未选中文本，可手动输入显示文本或留空使用笔记标题。
2. **适用场景**：适用于希望保留原文表述，又能灵活链接笔记的场景，搭配“Property Over File Name”插件使用效果更佳。
3. **核心特色**：不修改目标笔记属性，仅创建内联链接；遵循用户的链接格式（维基链接或 Markdown 链接），避免重复文件名作为别名；与“Property Over File Name”兼容，笔记选择器按标题属性列出笔记。
4. **使用建议**：可通过社区插件搜索（搜索“Link As david”）或手动下载安装。使用时运行“Link As: link text to a note”命令，建议设置快捷键 `Ctrl/Cmd+Shift+K` 以提高操作效率。
