## 概述

**主要功能**
Task Vault 是一款基于“每任务一文件”的结构化任务管理器。它通过 Frontmatter 中的 UUID 确保任务身份稳定，支持 8 状态机（从收件箱到完成/取消），并具备追加式执行日志，可记录决策与状态变更。

**适用场景**
适用于需要长期追踪复杂项目、记录决策逻辑或频繁使用 AI 辅助编码的开发者及知识工作者。特别适合对数据持久性和 Markdown 兼容性有高要求的用户。

**核心特色**
1. **数据稳健**：UUID 身份标识防止因文本编辑导致的 ID 丢失，数据独立于插件存在。
2. **结构化流程**：严格的 8 状态流转机制，UI 仅允许合法状态转换，避免混乱。
3. **AI 原生支持**：提供委派章节与钩子，让 AI Agent 将任务文件视为规范（Spec）进行精准执行。
4. **全景视图**：侧边栏驾驶舱提供倒计时、逾期提醒及按项目折叠视图，无需复杂查询即可掌握进度。

**使用建议**
建议将任务描述与执行记录分别置于正文指定标题下，保持 Frontmatter 字段规范。利用其 AI 委派功能时，确保任务文件内容清晰完整，以便 Agent 准确理解上下文。
