## 概述

### Typing Interface Hider插件总结
1. **主要功能**：在打字或滚动时隐藏Obsidian界面的选定部分，停止操作或移动鼠标后恢复界面。可选择隐藏侧边栏、左功能区、标签页标题等多个界面区域。
2. **适用场景**：适用于需要轻量级专注或禅意打字模式的场景，且无需改变笔记布局。
3. **核心特色**：可选择在滚动时隐藏界面；滚动隐藏时，界面保持隐藏直至有主动鼠标移动、点击或窗口失焦；支持多种恢复界面的方式，如鼠标移动、点击、滚动等；可设置自动恢复延迟、鼠标移动距离、淡入淡出时长等；有仅鼠标恢复模式。
4. **使用建议**：若想避免在搜索、设置等非笔记区域打字时隐藏界面，可开启“Only in Markdown notes”；若要避免滚动时因小幅度鼠标移动误恢复界面，可增大“Mouse movement needed to restore, px”的值；根据个人喜好调整“Idle return delay, ms”和“Fade duration, ms”。
