## 概述

**Routine Heatmap (Gagans)** 是一款用于 Obsidian 的年度习惯热力图插件。

1. **主要功能**：通过扫描每日笔记中带有特定 `{id}` 标签的已完成任务，生成年度热力图。当日完成的任务 ID 种类越多，热力图颜色越深。支持可选的日历视图颜色同步。
2. **适用场景**：适合希望可视化长期习惯养成进度、追踪每日例行任务（如运动、阅读）完成情况的笔记用户。
3. **核心特色**：
   - **灵活定义**：无内置任务列表，任意 `{id}` 均被识别，自定义程度高。
   - **简洁标记**：仅需在任务前添加如 `{wk}` 的 ID 即可。
   - **配置丰富**：支持自定义每日笔记文件夹、日期格式（YYYYMMDD 或 YYYY-MM-DD）、周起始日、语言及今日高亮等。
4. **使用建议**：
   - 安装需从 GitHub Releases 下载文件至插件目录并手动启用。
   - 建议在每日笔记中统一使用简短且唯一的 `{id}` 标记例行任务。
   - 若笔记分散，可在设置中指定“每日笔记文件夹”以提高扫描效率。
