## 概述

**1. 主要功能**
该插件为 Obsidian 提供轻量级原生 Git 集成，直接调用系统 Git 执行仓库管理。支持查看状态、拉取（Pull）、推送（Push）、同步（Sync）及提交所有更改。状态栏实时显示分支、变更数及远程同步状态，并支持定期自动 Fetch 和 Sync。

**2. 适用场景**
适用于希望将 Obsidian 笔记库作为 Git 仓库进行版本控制、多设备同步或备份的用户。特别适合需要频繁更新且追求高性能、原生 Git 语义的桌面端用户（Linux/Windows/macOS）。

**3. 核心特色**
- **原生轻量**：不依赖 JS/Wasm 重实现，直接调用系统 Git，确保最佳性能与安全性。
- **实时反馈**：状态栏直观展示分支及变更统计，点击可快速操作。
- **自动化**：支持可配置的后台定期 Fetch 和自动 Sync 间隔。
- **灵活配置**：支持自定义提交信息模板（含时间戳替换）及 Git 可执行文件路径。

**4. 使用建议**
- 确保系统已安装 Git 并配置好环境变量。
- 初始设置时建议检查“可执行文件发现”路径是否正确。
- 根据需求调整自动 Fetch/Sync 间隔，避免频繁网络请求。
- 利用提交模板规范备份记录，便于历史追踪。
