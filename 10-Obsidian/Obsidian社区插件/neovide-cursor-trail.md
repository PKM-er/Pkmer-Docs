## 概述

**Neovide Cursor Trail** 是一款为 Obsidian 桌面端 Markdown 编辑器添加平滑光标拖尾效果的插件，灵感源自 Neovide 编辑器。

**主要功能**：在源码模式和实时预览中，为光标移动提供基于四角弹簧物理算法的流畅拖尾动画。每个编辑器面板独立动画，避免跨文件跳动。

**适用场景**：适用于桌面端 Obsidian 用户的日常 Markdown 编辑，特别是追求极致视觉流畅度和个性化体验的开发者或笔记爱好者。

**核心特色**：
1. **独立动画**：各面板光标互不干扰，体验自然。
2. **高度可定制**：支持调整动画时长、拖尾强度、透明度、辉光及颜色（默认跟随主题，支持自定义 HEX 色值）。
3. **智能适配**：自动检测系统“减少动态效果”设置并暂停动画；仅动画化主光标，选中文本、多光标或输入时保持原生光标可见，确保操作清晰。
4. **轻量独立**：无需依赖 VS Code 或 CSS Loader 插件。

**使用建议**：建议从 GitHub 手动安装最新版（放入 `.obsidian/plugins/neovide-cursor-trail/` 目录）。初次使用建议保持默认设置以匹配主题，随后根据个人喜好微调拖尾强度与颜色。注意该插件不支持移动端、阅读视图及 Canvas 中的光标动画。
