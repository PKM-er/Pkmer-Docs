## 概述

**1. 主要功能**
Covault 是一款面向团队的 Obsidian 知识库客户端。它通过后台静默同步 GitHub 仓库，实现团队共享文件夹与个人笔记的无缝备份。核心亮点在于由 LLM 智能体自动处理所有 Git 底层操作（如提交、分支、合并），用户无需接触任何代码或版本控制概念。

**2. 适用场景**
专为非工程背景的团队设计，适用于需要共享知识、协作编辑文档，但成员缺乏 Git 使用经验的场景。适合希望建立企业级知识库，同时保持个人笔记隐私可控的用户。

**3. 核心特色**
*   **零门槛协作**：界面仅使用“分享/更新”等知识库语言，彻底隐藏 Git 复杂性。
*   **AI 冲突解决**：当多人编辑同一内容时，LLM 自动合并版本；高置信度静默应用，低置信度提供三栏审阅界面供人工选择。
*   **隐私可控**：个人笔记默认私有，需手动标记“分享”才进入团队库；凭据存储于系统目录，不随笔记同步。
*   **完整追溯**：支持查看同步笔记的历史记录、变更者信息及行内差异对比。

**4. 使用建议**
仅限桌面端使用。初次使用需连接 GitHub 并添加共享库。建议配置 AI 提供商（如 Anthropic、OpenAI 等）以启用智能冲突合并。注意该插件未经 Obsidian 官方人工审核，请自行评估安全性。
