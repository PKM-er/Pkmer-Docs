## 概述

**1. 主要功能**
Table Width 允许用户通过拖拽边框来调整 Obsidian 中 Markdown 表格的列宽，或双击边框使列宽自动适配最长文本。未调整的表格保持原有布局，仅在被操作后启用固定宽度。

**2. 适用场景**
适用于需要精确控制表格列宽以提升阅读体验的场景，特别是在 Live Preview（实时预览）和 Reading View（阅读视图）模式下。适合处理包含长 URL、内联代码等不易换行内容的表格，防止内容溢出。

**3. 核心特色**
- **非侵入性**：不修改 Markdown 源码，宽度设置按笔记和表头独立保存。
- **智能适配**：拖拽时保持表格总宽不变，双击可自动消除换行。
- **灵活控制**：支持重置命令，一键恢复笔记内所有表格至默认布局。

**4. 使用建议**
安装后启用插件即可使用。建议仅在需要精细排版时手动调整列宽，平时保持表格默认状态以节省空间。若发现列宽混乱，可使用“Reset column widths in this note”命令快速恢复。
