## 概述

**dot-sync** 是一款为 Obsidian 提供点对点实时 Markdown 协作的插件。

1.  **主要功能**：允许用户通过本地 `deepika-sync` 守护进程，在局域网或互联网上共享文件夹，实现多人同时编辑笔记，并支持实时光标显示。
2.  **适用场景**：适用于需要无服务器依赖、端到端加密的桌面端协作场景，如团队文档共同编辑或远程结对编程。
3.  **核心特色**：
    *   **P2P 架构**：无需中心服务器，数据直接对等传输。
    *   **加密安全**：全程端到端加密，文件保持标准 Markdown 格式。
    *   **多端接入**：除 Obsidian 外，还可通过生成的 Web 链接在浏览器中直接加入会话，无需安装额外软件。
    *   **易部署**：插件可一键安装并管理 Linux/macOS 下的守护进程。
4.  **使用建议**：仅限桌面端使用。首次使用需在设置中安装 Daemon，配置用户名及是否使用公共中继（用于远程协作）。右键点击文件夹启动会话，复制邀请码或 Web 链接发送给协作者即可开始。
