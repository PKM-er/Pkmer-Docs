## 概述

### GitHub Assignments 插件总结
1. **主要功能**：将分配的 GitHub 问题和拉取请求追加到 Obsidian 笔记中。可获取当前分配的项目，避免笔记内重复，支持添加可选前缀、后缀和创建日期标签。
2. **适用场景**：适用于日常笔记、项目笔记等各种笔记结构，方便开发者在 Obsidian 中集中管理 GitHub 任务。
3. **核心特色**：轻量级，配置灵活，可自定义问题和拉取请求的前缀、后缀；若文件末尾为空白行，能在光标位置插入任务，避免有序列表出现间隙；添加的创建日期标签可配合 Tasks 插件使用。
4. **使用建议**：先从 Obsidian 社区插件目录安装该插件，在设置中启用并配置 GitHub 令牌和用户名。使用时，打开笔记，运行“Fetch GitHub assignments”命令，即可将分配的任务以复选框形式追加到笔记中。
