## 概述

### Scan to Markdown 插件总结
1. **主要功能**：通过手机扫码拍照，利用视觉大模型将书本、公式、表格等内容转换为结构化 Markdown，可插入当前笔记光标处或新建独立笔记；也支持直接插入图片。
2. **适用场景**：适用于桌面端 Obsidian 用户，需手机和电脑连同一 WiFi，用于将纸质资料快速转为电子 Markdown 笔记。
3. **核心特色**：
    - 扫码即拍，可连续拍摄或选图。
    - 有识别后插入和直接插入图片两种模式。
    - 拍前可对图片进行基础调整。
    - 支持多种写入方式。
    - 公式用 LaTeX 表示，排版结构化。
    - 支持多 LLM 服务商。
    - 本地运行，保障隐私。
4. **使用建议**：
    - 仅在桌面端使用，确保手机和电脑连同一 WiFi。
    - 不建议在公共/不可信网络下开启，可在防火墙关闭默认 43112 端口的外部访问。
    - 填入 API Key 后可选择合适的模型进行识别。
