## 概述

**1. 主要功能**
Poppy 是一款 Obsidian 本地插件注册表管理工具。它允许用户将插件同步到 S3 兼容的存储服务中，并支持在其他 Vault（库）中快速恢复这些插件，实现插件配置的跨库迁移与备份。

**2. 适用场景**
适用于拥有多个 Obsidian 库且希望保持插件环境一致的用户。特别推荐给需要频繁在不同设备或项目间切换，且希望避免重复手动安装和配置插件的高级用户。

**3. 核心特色**
*   **S3 兼容同步**：利用 S3 兼容存储作为中间层，实现插件的高效同步与备份。
*   **跨库恢复**：一键在新库中还原插件列表及配置，极大提升迁移效率。
*   **本地化管理**：作为本地注册表管理器，提供比社区插件市场更灵活的自定义管理体验。

**4. 使用建议**
*   **注意安全性**：该插件未经 Obsidian 官方人工审核，使用前请自行评估风险，建议先备份重要数据。
*   **配置存储**：需确保 S3 存储桶的访问权限正确配置，并注意数据隐私保护。
*   **版本控制**：插件通过 Git 标签发布，开发者可参考 README 中的 `npm run build` 等命令进行本地构建或版本更新。
