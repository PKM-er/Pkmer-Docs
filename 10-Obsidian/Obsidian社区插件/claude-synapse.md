## 概述

**主要功能**
Claude Synapse 是一款基于 Claude Agent SDK 的 Obsidian 插件，将 Claude 智能体直接引入笔记库。它支持读取笔记、追踪链接、重写文件、运行工具及记录对话历史，让笔记库成为智能体的工作区。

**适用场景**
适用于需要深度处理本地笔记、希望避免在聊天窗口与笔记间反复复制粘贴的用户。特别适合对隐私敏感（使用本地模型）或需处理复杂逻辑（使用 Claude）的混合工作流。

**核心特色**
1. **原生智能体架构**：非简单聊天封装，具备真实会话、子智能体、技能、MCP 工具及权限控制。
2. **灵活模型切换**：同一智能体框架下支持 Claude 与 Ollama 本地模型无缝切换，兼顾隐私与性能。
3. **深度集成**：智能体直接操作 Vault 文件，实现笔记的自动化重组与增强。

**使用建议**
需预先安装 Claude CLI。若仅使用本地模型，需运行 Ollama；若使用 Claude，需登录订阅或配置 API Key。建议在隐私要求高的场景绑定本地模型，复杂任务调用 Claude，以实现最佳体验。
