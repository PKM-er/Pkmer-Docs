## 概述

**1. 主要功能**
Markdown Chat Blocks 插件允许用户在 Obsidian 笔记中创建仿聊天界面的对话块。它支持自定义聊天标题、动态头像，并渲染左右两侧的气泡样式，将普通 Markdown 文本转化为可视化的对话记录。

**2. 适用场景**
主要适用于创意写作（如小说对话）、剧本创作或需要清晰展示多方交流内容的文档。通过模拟真实聊天界面，能增强叙事沉浸感，使对话内容更直观易读。

**3. 核心特色**
- **极简语法**：使用代码块包裹，自动交替左右对齐，降低排版难度。
- **灵活控制**：默认自动交替，也可通过 `l:` 或 `r:` 前缀手动指定气泡位置。
- **高度定制**：支持设置联系人名称（Title）和头像（Profile picture），支持内部 Markdown 格式（如加粗、斜体、代码）。

**4. 使用建议**
在笔记中插入 ```chat 代码块，首行设置 `title` 和 `pfp` 参数。对话行直接输入文本，系统会自动交替排列；若需强制某方发言，请在行首添加 `l: ` 或 `r: `。该插件适合快速构建对话场景，无需复杂 CSS 配置即可实现美观的聊天效果。
