## 概述

**主要功能**：Style Tuner 是一款外观精细调校插件，允许用户通过可视化界面调整主题、插件及 CSS 片段的变量。它提供颜色选择器、数值滑块、下拉菜单等控件，支持独立标签页视图、CSS 片段启停管理及文件夹直达。此外，还集成 Markdown 美化与 Lint 功能，支持 YAML 属性配置及列表拖拽排序。

**适用场景**：适用于希望深度定制 Obsidian 界面风格的用户，特别是需要精细调整主题配色、字体大小或布局细节，以及管理大量 CSS 片段和插件设置项的场景。

**核心特色**：
1. **可视化调校**：像调音台一样直观操作，支持亮/暗双模式颜色选择及已修改值高亮。
2. **高效管理**：支持按变量名搜索、一键复制、区块级导入/导出，以及 24 种界面语言。
3. **生态兼容**：完美兼容 `@settings` 生态，可与 Obsidian Linter 共存，支持 YAML 键属性类型定义及顺序继承。

**使用建议**：建议先浏览内置外观面板熟悉基础切换，再利用搜索功能快速定位特定 CSS 变量进行微调。对于复杂配置，可利用“按区块导出”功能备份设置，方便在不同设备间同步或回滚。
