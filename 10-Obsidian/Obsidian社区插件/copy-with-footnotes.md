## 概述

**Copy with Footnotes** 是一款专为 Obsidian 设计的实用插件，旨在解决 Markdown 脚注复制时的完整性问题。

1. **主要功能**：当用户复制选中的 Markdown 文本时，插件会自动检测并附带该文本中引用的所有脚注定义，确保复制内容包含完整的引用信息，避免丢失参考文献。
2. **适用场景**：适用于学术写作、笔记分享或跨平台迁移。当你需要将包含脚注的段落从 Obsidian 复制到邮件、其他笔记软件或网页时，能极大提升效率，无需手动查找和补充脚注。
3. **核心特色**：
   - **智能关联**：自动识别选中范围内的脚注标记并提取对应定义。
   - **实验性粘贴**：支持“带脚注粘贴”，可智能处理 ID 冲突（重用或重命名），并允许选择插入位置（块前/后、笔记末尾等）。
   - **兼容性强**：支持源码模式和实时预览模式，需 Obsidian 1.8.7+。
4. **使用建议**：
   - 通过命令面板执行“Copy selection”或右键菜单选择“Copy with footnotes”进行复制。
   - 若需粘贴，建议在设置中开启“Enable paste with footnotes”，利用“Paste with footnotes”功能实现智能合并，避免脚注 ID 冲突。
   - 本地开发者需使用 LTS 版 Node.js 进行构建。
