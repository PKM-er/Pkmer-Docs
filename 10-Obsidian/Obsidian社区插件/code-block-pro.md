## 概述

Code Block Pro 旨在解决 Obsidian 中代码块阅读体验不佳的问题，通过为围栏代码块添加紧凑且适配主题的工具栏，提升代码的可读性与交互性。其核心功能包括显示语言标识与可选标题、提供一键复制或下载纯净代码文件的能力，以及通过行号、垂直滚动和折叠机制，帮助用户轻松掌控长代码块的浏览体验。

在撰写技术文档或整理学习笔记时，该插件能显著提高效率。例如，当笔记中包含大段 TypeScript 代码时，你可以直接点击头部按钮将代码保存为 `.ts` 文件，无需手动全选复制；或者在快速浏览时，利用折叠功能将冗长的代码块压缩至指定行数，既保留了头部操作入口，又避免了页面被长代码占据，让重点内容更清晰。

相比其他代码增强插件，Code Block Pro 的轻量化设计是其显著特色，它没有运行时依赖，完全基于 Obsidian 原生 CSS 变量构建，确保与各种主题完美融合。此外，它具备极高的自定义灵活性，允许用户独立开关行号、复制、下载、语言标签等各个组件，并可根据个人习惯调整折叠与滚动的触发阈值，同时自动处理主题切换时的行号对齐问题。

需要注意的是，该插件主要优化阅读视图和实时预览中的代码块展示，并不改变代码本身的语法高亮逻辑。如果你需要复杂的代码执行、在线运行或深度语法分析功能，此插件无法满足需求。此外，Mermaid、Dataview 等特殊代码块会被自动忽略，交由其原生处理器管理，因此不适合用于增强这些特定类型的图表或数据块。
