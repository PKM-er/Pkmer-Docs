# Mengshi Cockpit: An Enterprise-Grade Obsidian Workbench Plugin

> [!Note] 插件名片
> - 插件名称：Mengshi Cockpit（猛士驾驶舱）
> - 插件版本：v0.6.10
> - 插件作者：Spenf710
> - 插件说明：一站式 Obsidian 工作台，把日志、项目、待办、排期、飞书、AI 会话收进一个画面，碎片化的工作一目了然
> - 插件项目地址：[点我跳转](https://github.com/Spenf710/obsidian-mengshi-cockpit)
> - 已通过 Obsidian 官方社区审核并上架，社区插件库搜索「Mengshi Cockpit」即可安装

> **猛士驾驶舱** —— 你的 Obsidian 私人工作台。把日志、项目、待办、排期、飞书、AI 会话全部收进一个画面，让碎片化的工作一目了然。

## 驾驶舱是什么

它不是又一个"效率工具"，也不是一个普通的面板——**它是一架战机的座舱**：

- 📅 **日历**是你的**导航仪**——这个月哪天写了日志、哪天状态爆表，一眼扫清
- 📂 **项目**是你的**武器挂载**——十几个项目谁在推进、卡在哪，卡片化尽收眼底
- ✅ **待办**是你的**任务清单**——散落各处的 `- [ ]` 自动聚齐，勾选即回写
- 📊 **排期**是你的**作战地图**——拖拽即同步改期，红色今日线标出谁在延期
- 📡 **飞书**是你的**云端军械库**——云盘文件自动归类到项目名下，链接状态一眼可验
- 💬 **会话**是你的**黑匣子**——和 AI 的每次交锋都完整记录，随时翻旧账、一键续接

**坐进驾驶舱，一切尽在掌控。**

| 📊 排期 | 甘特图、拖拽排期、多阶段、里程碑编辑、README 同步 | 🔴 今日线 / ◆ 里程碑 / 🧩 阶段条 |

## 📅 日历 —— 一眼看完这个月

- **哪天写了没写**：有日志的日期格有底色，空白格说明那天没记
- **写了什么**：格子里直接显示「一句话」摘要 + 🟢🟡🔴 状态点（从日志自动提取）
- **点击空格子** → 弹出日记编辑窗，日期自动填好：自动读模板、自动建月份文件夹、创建或改已有日记，一个弹窗搞定
- **点击状态标签** → 三选一，选中自动写回日记文件，格子立即更新
- hover 的 📄 按钮打开全文、🔗 按钮弹出双链图谱（绿=日记链出去的笔记，橙=谁引用了这篇）
- 顶部 ◀ ▶ 切换月份，格子自动撑满面板

## 📂 项目 —— 项目不再靠脑子记

自动扫描设置里配置的「项目根目录」，每个项目变成一张卡片：

- 卡片内容：**项目名 + 一句话描述 + 文档数量 + 排期区间 + 最近更新时间**
- **三维分组**：按领域（来源目录）/ 按标签（车型）/ 按类别（多维表/RPA/AI 智能体/工具开发）
- 三个一键入口：**README 索引**、**文件列表**（点击直接打开）、**飞书多维表**（浏览器打开）
- 卡片可直接编辑：**点 emoji** 换图标（20+ 选项）、**点标签** 改车型/类别（自定义值自动进全局下拉）、**右键链接** 编辑多维表 URL、**点子分组图标** 换领域图标
- 所有修改持久保存；**未登录或没配项目根目录时显示引导提示**；`+` 一键新建项目（自动按序号命名目录 + 生成完整 README + 骨架文档）

## ✅ 待办 —— 不用再一个一个文件翻

- **扫描范围**：只扫 `工作日志`、`工作周报`、项目 `README` 三类文件，归不上的进「📋 无归属」组
- **自动归组**：通过 Wiki-link / 文件夹名模糊 / 关键词把待办归到对应项目
- **勾选回写源文件**：面板点一下 ○，源文件里的 `- [ ]` 变 `- [x]`，完全同步
- **按项目筛选**、**折叠已完成**、每条待办显示修改时间 + 来源文件
- **智能跳过**：日志里「今天搞哪个项目」「明天要做」这类计划区块不会被误扫描成待办
- 兼容 Tasks 插件格式（🛫 📅 ⏫）

## 📊 排期 —— 甘特图长在笔记里

- **拖拽即同步**：鼠标按住阶段条两端拖到新日期，松手后两件事自动发生：日期存入 `data.json` + **该项目 README 的「预计周期」字段和「开发阶段」表格同步刷新**
- **🔴 今日线**贯穿全图，一眼看出谁延期了；**⚠️ 已延期筛选**一键过滤
- **◆ 里程碑编辑**：点击弹窗改日期/文字/图标，hover × 删除
- **🧩 多阶段**：一个项目多条阶段条（如「V1 多维表」「V2 机器人」），每条独立拖拽，空隙表示中断期
- **🎯 聚焦模式**只看进行中项目；类别筛选 + 月/周时间切片 + ◀ ▶ 导航

## 📡 飞书 —— 云盘和知识库装进 Obsidian

*前置：`npm install -g lark-cli` 后 `lark-cli auth login` 登录一次；插件自动检测，装不到则 `npx` 兜底，未安装/未登录不卡死。*

- **三栏模式**：📁 原始（文件夹树+面包屑，Drive 实时）/ 📂 项目（vault 扫描+深度扫描缓存）/ 📋 通用（按类型：多维表/纪要/图片/MD/云文档）
- **自动归类**：从项目名提取关键词（中文自动拆 2~3 字片段、通用词屏蔽、多命中取最长匹配）匹配云盘文件名，支持 `PROJECT_META` 自定义，匹配不到归「其他」
- **📚 Wiki 知识库**：选空间 → 文档树 → 点击跳飞书
- **🔗 链接状态检查**：批量验证云文档 URL 有效性
- **👁 访问人数统计**：每文件 uv/pv
- **↗ 文件移动**：手动归类到某项目，或移回「待分配」重新走自动匹配
- **文件夹排除**（⊘，不参与扫描）、扫描缓存秒开、上限 100 文件夹

## 💬 会话 —— 把和 AI 每次对话装进驾驶舱

- **🤖 双 Agent 支持**：同时扫描 **Claude Code** 与 **CodeM** 两类 CLI 会话（CodeM 为只读模式），不会误混
- **自动归类**：按当前知识库项目目录树语义匹配归属，分组按会话数倒序、可折叠
- **详情回看**：完整 Markdown 渲染对话，工具调用自动折叠，**🔢 轮次统计**清晰
- **✅ 收割状态标记**：harvested / none 两态徽标，识别会话是否已沉淀进知识库（技能名可配置）
- **状态双维筛选**（v0.6.10）：存档/已收割可选 × 任意切片组合筛选
- **📦 归档与仅存档补齐**：不常用会话归档到 `_archived`；源文件被清理的会话仍可见并继承原项目分组
- **📁 日常抽屉**：日志/周报等零散会话收进 `__daily__` 抽屉，主列表清爽
- **🔁 一键续接**：「在 Claude 中打开」，直接接上上次的对话上下文继续聊；存档会话可「恢复并续接」

## 为什么值得你关注

- **数据主权在 markdown**：插件只读 markdown、画出来、再写回 markdown，离开插件知识库依然完整
- 技术栈干净：TypeScript + React 18 + esbuild，源码开源可自行 fork 改造

## 如何安装

已上架 Obsidian 社区插件库：

1. Obsidian 设置 → 第三方插件 → 浏览
2. 搜索 **Mengshi Cockpit** → 安装并启用
3. 打开工作台（左侧边栏 logo / `Ctrl+P` 输入「打开工作台」）

或手动安装最新 Release（v0.6.10）：

1. 前往 [GitHub Releases](https://github.com/Spenf710/obsidian-mengshi-cockpit/releases) 下载最新 `main.js` + `manifest.json` + `styles.css`
2. 放入 `<vault>/.obsidian/plugins/mengshi-workbench/`
3. Obsidian 设置 → 第三方插件 → 启用

> 系统要求：Obsidian **1.7.2 及以上**，桌面端（Windows / macOS）。飞书面板需另装 lark-cli（见上文）。
