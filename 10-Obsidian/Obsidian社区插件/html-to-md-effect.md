## 概述

### HTML to MD Effectiveness 插件总结
1. **主要功能**：在 Obsidian 中将 HTML 文件转换为干净的 Markdown 文件，支持单个 HTML 文件转换及当前文件夹内所有 HTML 文件的批量转换，能完整转换标题、粗斜体、代码块、链接、列表、表格等元素，还可添加可选的 YAML 元数据，具备覆盖保护功能。
2. **适用场景**：适用于有将 HTML 文件批量或单个转换为 Markdown 文件需求的 Obsidian 用户。
3. **核心特色**：转换功能全面，涵盖多种 HTML 元素；支持批量转换提高效率；有覆盖保护，可避免误覆盖已存在的 MD 文件；能保留代码块语言信息。
4. **使用建议**：可从 Obsidian 社区插件搜索安装该插件，也可通过 BRAT 手动安装。使用时，若要转换单个 HTML 文件，打开文件后运行对应命令；若要批量转换，运行批量转换命令即可。
