## 概述

### 插件名称
Paste ASCII Table

### 主要功能
该插件可在粘贴时将框线绘制或 ASCII 艺术表格转换为真正的 Markdown 表格，还能将终端换行的单元格重新合并为一个 Markdown 单元格。

### 适用场景
适用于粘贴终端输出（如 `mysql`、`psql` 等）、Claude Code 等场景下的表格数据，将其转换为 Markdown 格式。

### 核心特色
- 支持多种样式的表格，包括不同变体的 Unicode 框线绘制、`+---+` ASCII 边框和无边界的 `psql` 输出。
- 能处理终端换行的单元格，避免出现半句话在多余行的问题。
- 可去除表格的前导缩进。

### 使用建议
该插件为纯 JavaScript，无需构建步骤。使用 `./install.sh ~/path/to/vault` 安装，然后在 Obsidian 的社区插件中启用。若未显示，可点击已安装插件旁的重新加载图标，因为 Obsidian 仅在启动时扫描插件文件夹。
