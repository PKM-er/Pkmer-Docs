## 概述

### Code Viewer插件总结
1. **主要功能**：用于查看和编辑代码文件，支持50多种文件扩展名，具备原生语法高亮显示，可选择显示行号，支持代码编辑，有保存和查看控制。
2. **适用场景**：适用于Obsidian用户查看和修改代码文件，在编辑代码笔记、查看代码示例等场景中发挥作用。
3. **核心特色**：采用Obsidian内置 `MarkdownRenderer` 实现语法高亮，颜色与当前主题匹配；自动注册文件扩展名；零依赖，仅使用Obsidian API；设计为只读模式防止误编辑；支持多语言UI，包括中文、英文、俄文；使用Obsidian 1.13+设置API实现声明式设置。
4. **使用建议**：先安装并启用该插件，之后在文件资源管理器中点击支持的文件（如 `.py`、`.ts`、`.sh` 等），文件会以只读代码视图打开并带有语法高亮。若需编辑，可通过临时Markdown文件进行。
