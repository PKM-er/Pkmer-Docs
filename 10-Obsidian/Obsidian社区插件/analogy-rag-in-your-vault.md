## 概述

### Analogy - RAG in your vault 插件总结
1. **主要功能**：为 Obsidian 增加本地语义搜索功能，将索引库暴露给 MCP 客户端用于检索增强生成。可将 Markdown 笔记索引为本地向量块，在侧边栏进行语义搜索，在本地语义画布中探索相关索引块，排除特定文件夹或文件，本地运行 ChromaDB，借助 MCP 服务器让 Claude Code 等工具搜索授权库内容。
2. **适用场景**：适用于需要在 Obsidian 中进行高效语义搜索，以及希望借助外部工具利用笔记库内容进行生成的场景。
3. **核心特色**：使用本地向量嵌入进行语义搜索，支持本地运行 ChromaDB，可与 MCP 客户端集成。
4. **使用建议**：从 GitHub 下载发布资产并复制到指定目录，在 Obsidian 中启用插件。通过本地 RAG 运行时安装器安装嵌入运行时。首次启动时，按引导流程完成环境检测、下载和安装。该插件仅支持桌面端，目前运行时下载支持特定系统。
