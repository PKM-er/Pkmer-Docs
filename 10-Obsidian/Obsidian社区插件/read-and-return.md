## 概述

Read and Return 专为解决长文档阅读时“跳走难回”的痛点而设计。它允许你在笔记中快速跳转至顶部、底部或任意章节，并在需要时一键返回之前的阅读位置。插件通过记录临时返回点和导航历史，让你无需手动搜索或记忆行号，即可在探索不同部分后精准回到原处，极大提升了长文阅读与查阅的效率。

想象一下，你正在阅读一篇数千字的长笔记，突然需要查看开头的目录或结尾的参考文献。此时只需点击悬浮按钮即可瞬间跳转，处理完事务后再次点击，便能无缝回到刚才中断的段落。若你想深入中间某个特定章节，也可以先手动设置返回点，利用大纲导航过去，阅读完毕后直接返回，整个过程流畅且无需打断阅读心流。

与常见的书签插件不同，Read and Return 不修改 Markdown 源文件，不生成任何 HTML 注释或 Frontmatter，确保笔记内容的纯净性。它采用会话级存储机制，所有返回点和历史仅在 Obsidian 运行期间有效，重启后自动清除，仅保留外观偏好设置。此外，它支持移动端优先的悬浮控制与桌面端快捷键，且完全本地运行，无网络请求或数据上传，隐私安全。

需要注意的是，该插件目前处于早期阶段，尚未通过官方人工审核，且真机测试仍在进行中，可能存在兼容性波动。它不提供持久化书签功能，重启 Obsidian 后所有阅读位置记录将丢失。如果你需要跨会话保存固定书签，或依赖复杂的嵌入内容精确恢复视觉位置，此插件可能无法满足需求。此外，大幅编辑笔记后，返回位置可能仅能近似恢复，需留意提示。
