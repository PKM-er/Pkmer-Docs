## 概述

### 主要功能
- 在 Obsidian 笔记中渲染空间化 HTML 内容。
- 提供专用 HTML 文件查看器，可在 Obsidian 中浏览独立 HTML 文件。
- 自动重写 HTML 文件中图片的相对路径，使其能在 Obsidian 中正常显示。

### 适用场景
适用于需要在 Obsidian 中处理对比、时间线、仪表盘等需空间布局信息，以及查看 AI 生成的 HTML 报告（如行业周报、分析报告等）的场景。

### 核心特色
基于 html - effectiveness 方法论，通过 `html - effect` 代码块在笔记中直接渲染特定结构；能正确渲染包含图片、样式和交互元素的 HTML 文件。

### 使用建议
若需在笔记里呈现空间布局信息，可使用 `html - effect` 代码块；若要查看独立 HTML 文件，利用插件的 HTML 文件查看器；遇到相对路径图片无法显示的情况，插件会自动处理，保证图片正常展示。
