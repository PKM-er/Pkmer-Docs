## 概述

**Adjustable Media** 是一款让 Obsidian 笔记具备现代画布式媒体排版能力的插件。

1. **主要功能**：支持将图片和视频并排或网格化排列（每行最多4个），提供直观的鼠标拖拽交互，包括调整列宽、行高及整体缩放。还具备文本环绕、手动分栏、可移动布局及带编号的图表等高级排版功能。
2. **适用场景**：适用于需要制作图文并茂的读书笔记、技术文档、演示文稿或任何需要复杂视觉布局的场景，特别适合对排版美观度有较高要求的用户。
3. **核心特色**：采用“轻量级 HTML 注释”存储布局数据，确保笔记保持 100% 原生 Markdown 格式，无格式锁定，即使卸载插件内容依然可读。支持单图磁性吸附对齐及自动高度均衡，操作流畅且直观。
4. **使用建议**：当前版本（0.7.3）主要优化了桌面端体验，移动端适配将在后续大版本中统一交付。建议用户通过插件内的“功能示例”命令预览效果，并定期关注 GitHub 发布页以获取最新修复与功能更新。
