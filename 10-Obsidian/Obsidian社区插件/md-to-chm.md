## 概述

**Markdown to CHM** 是一款专为 Windows 设计的 Obsidian 插件，主要功能是将单篇或多篇笔记及其附件，编译打包为单一的离线 Compiled HTML Help (.chm) 文件。

**适用场景**：非常适合制作用户指南、API 参考文档或内部操作手册。由于 CHM 格式自带目录、关键词索引和全文搜索功能，且无需浏览器或服务器支持，是分发离线技术文档的理想选择。

**核心特色**：
1. **高度集成**：支持自动包含附件，生成标准的目录结构和索引。
2. **智能配置**：设置界面可自动检测系统安装的 HTML Help Workshop 编译器，并提供默认标题、输出路径及语言选项。
3. **灵活构建**：支持自定义构建行为，如是否保留中间调试文件、构建后自动打开等。

**使用建议**：
1. **环境依赖**：仅限 Windows 系统使用，且必须预先安装 Microsoft HTML Help Workshop（`hhc.exe`）。注意微软已停止官方分发该工具，需自行寻找合法来源下载。
2. **安装方式**：该插件未收录于社区插件目录，需手动下载 `main.js` 等文件至 `.obsidian/plugins/md-to-chm/` 目录并重启 Obsidian 启用。
3. **调试技巧**：若导出失败，建议在设置中开启“保留中间构建文件”选项以便排查问题。
