## 概述

### Reflow 插件总结
1. **主要功能**：可在本地将 PDF 转换为清晰易读的 Markdown 文件，还能将笔记导出为 EPUB 格式用于电子阅读器阅读。转换时能保留图片、表格和数学公式。
2. **适用场景**：适用于处理本地 PDF 文件，将其转换为方便在 Obsidian 中编辑和管理的 Markdown 格式，以及生成可在电子阅读器上阅读的 EPUB 文件。
3. **核心特色**：无需 API 密钥、账号，无页数限制，且文档转换全程在本地进行，保障隐私。转换后以文档标题命名文件夹，方便管理。
4. **使用建议**：在 Obsidian 库中右键点击 PDF 文件，选择“Convert to Markdown”进行转换；右键点击笔记，选择“Export to EPUB”导出 EPUB 文件。若想通过文件夹一键打开笔记，可安装“Folder Notes”社区插件。若不希望按文档标题命名文件夹，可关闭“Name folders by document title”选项。
