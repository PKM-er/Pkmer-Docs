## 概述

**1. 主要功能**
Project Manager Insights 是一款专为 Obsidian 的 Project Manager 插件设计的只读分析层。它不修改原始任务数据，而是基于现有的项目、任务、层级、标签及状态，提供跨项目的工作负载分析、交付进度追踪、数据质量检查及进度风险评估视图。

**2. 适用场景**
适用于使用 Project Manager 进行任务管理，但需要更高维度团队交付洞察的用户。特别适合项目经理或团队负责人，用于监控多项目并行时的资源分配、识别潜在进度风险以及评估整体交付健康度。

**3. 核心特色**
*   **只读安全**：严格遵循只读原则，确保不干扰 Project Manager 的原始任务笔记和执行流程。
*   **宏观视角**：将分散的单项目执行数据转化为可追溯的团队交付洞察，实现从“个人执行”到“团队交付”的视角转换。
*   **风险预警**：专门提供进度风险（Schedule Risk）和数据质量（Data Quality）分析，帮助提前发现管理盲区。

**4. 使用建议**
建议将其作为 Project Manager 的互补工具使用。在 Project Manager 中维护任务细节和依赖关系，同时利用本插件生成的仪表盘查看全局工作负载和风险指标。由于该插件未经过 Obsidian 官方人工审核，建议定期更新并关注其 GitHub 仓库以获取最新修复和安全补丁。
