## 概述

### Granola API Sync插件总结
1. **主要功能**：借助Granola官方API，将Granola中的会议记录和完整文字稿同步至Obsidian库中。
2. **适用场景**：适用于使用Granola进行会议记录，且希望将这些记录整合到Obsidian进行管理和查看的用户。
3. **核心特色**：
    - **稳定**：基于官方文档化、版本化的API，而非逆向工程的内部机制。
    - **私密**：仅在本地库中存储API密钥。
    - **便携**：纯API调用，支持桌面和移动设备。
    - **完整**：能同步会议总结和带时间戳的完整文字稿。
4. **使用建议**：
    - 需要Granola商业或企业版计划，可在Granola桌面应用创建API密钥。
    - 在Obsidian设置中粘贴密钥，设置笔记文件夹和同步间隔。
    - 可通过命令面板手动同步，也可等待自动同步。
    - 可设置个人邮箱，将自己从参会者列表排除，并标记自己的发言。
