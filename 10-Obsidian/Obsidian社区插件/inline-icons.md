## 概述

**主要功能**
Inline Icons 插件允许用户通过简短的代码片段（如 `` `icon:sun` ``）在笔记正文中直接渲染图标。图标会随周围文本的行内显示，并自动匹配当前的字体大小和颜色，无需复杂的 或 HTML 代码。

**适用场景**
适用于需要在笔记中快速添加视觉标记的场景，如任务清单、状态指示、情绪记录或装饰性排版。特别适合喜欢极简风格、希望保持 Markdown 源码纯净且可读性的用户。

**核心特色**
1. **多源支持**：兼容 Obsidian 内置图标、Custom Icons 插件注册的图标包及用户导入的 SVG。
2. **智能解析**：支持简写（如 `sun` 自动匹配 `lucide-sun`）及来源限定（如 `ci:` 仅匹配自定义图标）。
3. **优雅降级**：若图标未找到，保留原始文本并加下划线提示，而非显示空白；插件禁用时源码仍清晰可读。
4. **灵活定制**：支持通过逗号后缀自定义图标大小（如 `1.5em`）和颜色（如 `#e5a50a`）。

**使用建议**
建议配合 Custom Icons 插件使用以获取更丰富的图标库。编写时注意使用单反引号包裹图标代码，若需显示代码本身请使用双反引号。利用简写功能可大幅提升输入效率，但需确保图标 ID 准确以避免解析失败。
