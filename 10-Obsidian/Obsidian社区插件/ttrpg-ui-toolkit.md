## 概述

**TTRPG UI Toolkit** 是一款专为桌面角色扮演游戏（如 D&D）设计的 Obsidian 插件，旨在通过 Markdown 构建交互式角色卡。

**主要功能**：提供现代化的 UI 组件，支持创建生命值追踪器、属性评分、技能列表及法术位管理。它允许用户在笔记中直接定义和管理角色状态，无需依赖外部 PDF 或在线工具。

**适用场景**：适合希望在本地知识库中统一管理 TTRPG 角色数据、法术书及游戏进度的玩家。特别适合厌倦了分散在多个平台管理角色信息的用户，实现“笔记即角色卡”。

**核心特色**：
1. **Markdown 驱动**：通过 YAML 代码块定义组件，简洁且易于维护。
2. **状态持久化**：HP、法术位等动态状态自动保存至 Vault 内的 JSON 文件，跨会话保留。
3. **模块化构建**：组件间可相互引用（如技能读取属性评分），灵活组合成完整角色卡。

**使用建议**：
- 该插件处于早期开发阶段，功能可能变动，建议定期备份数据。
- 新手请优先阅读官方文档中的“快速入门指南”。
- 注意区分静态数据（如属性）与动态状态（如 HP），后者依赖状态存储机制。
