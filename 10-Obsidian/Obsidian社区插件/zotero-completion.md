## 概述

### Zotero Completion 插件总结
1. **主要功能**：在 Obsidian 中搜索 Zotero 的 PDF 附件和批注，在光标处插入 Markdown 链接。可按批注内容、高亮文本搜索批注，按引用和文件名搜索 PDF，插入含批注页码的 Zotero 链接，还能持久化缓存，提供刷新和清除缓存命令以及配置本地 API URL 和检索限制。
2. **适用场景**：适用于使用 Obsidian 做笔记，同时使用 Zotero 管理文献的用户，在笔记中快速引用 Zotero 里的文献和批注。
3. **核心特色**：直接与本地 Zotero 桌面版通信，数据搜索和链接插入方便；缓存持久化，后续使用无需重复从 Zotero 获取数据，提高效率；仅向本地回环地址发送 HTTP 请求，保障隐私。
4. **使用建议**：首次使用从命令面板运行“Zotero Completion: Insert annotation or PDF link”，可在设置中为其分配热键；Zotero 文献库更新后，运行刷新缓存命令；若需重新获取数据，可清除缓存。
