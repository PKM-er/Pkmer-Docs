## 概述

### MarkTex 插件总结
1. **主要功能**：实现实时的 Markdown 到 LaTeX 预览，支持本地 latexmk 进行 PDF 编译，可下载 LaTeX 源码文件、复制到剪贴板，还支持多种配置选项。
2. **适用场景**：适用于需要将 Markdown 文档转换为 LaTeX 格式，进而生成专业 PDF 文件的场景，如学术写作、技术文档编写等。
3. **核心特色**：
    - 智能表格处理，能自动选择最优 LaTeX 环境、计算列宽、处理换行，支持专业样式。
    - 完整支持 Markdown 各种元素，包括标题、列表、代码块、数学公式等。
    - 实时预览有 300ms 防抖优化，支持长文档处理，纯前端 PDF 编译，支持中文和 Unicode，可离线使用。
4. **使用建议**：在左侧编辑器输入 Markdown 内容，右侧实时查看 LaTeX 代码，点击“复制”或“下载”获取文件。可通过右上角“设置”按钮调整文档类、字体大小、中文支持等配置选项。
