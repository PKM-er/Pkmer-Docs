## 概述

### 《Auto Sort Checked Items插件总结》
1. **主要功能**：自动将已勾选的待办事项移至列表底部，实现自动重新排序，支持嵌套列表，能让带子项的事项成组移动，缩进项在自身层级内重新排序，且有平滑的动画效果，还支持一键撤销勾选和移动操作。
2. **适用场景**：适用于使用Obsidian记录待办事项的场景，帮助用户将注意力集中在未完成的事项上。
3. **核心特色**：模仿苹果笔记“自动排序已勾选项目”的行为，具有嵌套感知能力，能处理复杂的列表结构，动画效果让操作更直观，撤销操作简洁方便。
4. **使用建议**：可通过手动下载文件或从源码构建的方式安装插件。手动安装需从最新版本下载文件并放置在指定目录；从源码构建则需进行克隆仓库、安装依赖和构建等操作。开发时可使用`npm run dev`进行文件变更监控，使用`npm run build`进行生产构建。
