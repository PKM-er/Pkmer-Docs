## 概述

### Community Install Manager 插件总结
1. **主要功能**：可从 JSON 文件安装、启用和配置 Obsidian 社区插件，能自动安装缺失插件并应用配置。
2. **适用场景**：适用于多设备间同步保险库插件设置、与团队共享保险库配置，以及用已知插件集快速搭建新保险库。
3. **核心特色**：通过读取保险库 `.obsidian` 文件夹中的 JSON 文件操作插件，无需手动逐个安装和配置；安装过程仅针对 `community-plugins-list.json` 中的插件 ID，且不发送遥测数据。
4. **使用建议**：该插件可下载并安装其他社区插件，存在一定风险。仅在信任 `community-plugins-list.json` 文件来源的保险库中使用；启用自动安装前仔细审查该文件；注意安装的插件可能访问保险库数据和文件系统；因安装的是最新版本插件，可能包含重大变更，需自行承担使用风险。
