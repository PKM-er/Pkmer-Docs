## 概述

### Tetromino插件总结
1. **主要功能**：将Are.na的频道、块、元数据和附件单向导入到Obsidian库中，以稳定的Markdown笔记形式呈现。
2. **适用场景**：适用于需要从Are.na获取资料并整理到Obsidian进行知识管理的用户。
3. **核心特色**：
    - 单向导入，仅从Are.na到Obsidian，不会反向操作。
    - 手动运行，可进行预演预览，输出由用户控制。
    - 输入相同则输出相同，无自动导入，确保数据稳定。
    - 有可选的启动同步或间隔同步设置，默认关闭。
    - API 与当前 Are.na REST API v3 兼容。
4. **使用建议**：初次使用可参考用户指南（[https://frostmute.github.io/Tetromino/docs/USER_GUIDE.md](https://frostmute.github.io/Tetromino/docs/USER_GUIDE.md) ），遇到问题可查看常见问题解答和故障排除文档。若要进行开发，可参考开发者指南。
