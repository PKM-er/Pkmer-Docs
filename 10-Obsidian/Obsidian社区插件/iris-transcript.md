## 概述

### IRIS - Transcript插件总结
1. **主要功能**：将YouTube视频URL转换为Markdown笔记，包含转录、生成思维导图和总结。转录利用YouTube字幕，思维导图可交互，还能通过LLM（如Fantasy Cloud）生成可选总结。
2. **适用场景**：适用于需要从YouTube视频提取文字信息、整理内容结构以及获取视频总结的场景，如学习、研究等。
3. **核心特色**：转录无需API密钥，免费使用；自带交互式思维导图渲染，无需第三方插件；支持多种免费LLM服务，可替代Fantasy Cloud；笔记含可被Dataview索引的元数据。
4. **使用建议**：若想获得主题结构化的思维导图和区分发言者，推荐使用LLM功能。可在“URL API Fantasy Cloud”填入兼容OpenAI的端点，如Groq、Google AI Studio、OpenRouter等免费服务的URL，获取免费API密钥填入“Clé API Fantasy Cloud”，其免费配额足以处理单个视频。
