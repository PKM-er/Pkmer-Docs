## 概述

**1. 主要功能**
DGS Toolkit 是一款用于渲染 Obsidian 中由 `:::` 分隔符定义的“编辑块”插件。它支持多种预设类型（如 lead、epigraph、poem、aside 等），允许通过 `key=value` 语法自定义宽度、对齐方式及 CSS 类名。此外，插件提供阅读与编辑视图的独立排版，以及仅限桌面端的文件夹发布功能，并附带侧边栏差异对比（Diff）视图。

**2. 适用场景**
适用于追求专业排版效果的写作场景，如撰写长文、书籍章节、诗歌或需要精细控制版面结构的文档。特别适合需要区分编辑态与阅读态视觉体验，以及进行内容版本对比的用户。

**3. 核心特色**
*   **灵活语法**：支持嵌套块、自定义 CSS 属性及动态类名生成。
*   **视觉辅助**：Live Preview 模式下高亮显示块结构，未闭合块会有标记提示。
*   **专业排版**：内置符合写作风格指南的编辑样式，支持 `data-type` 属性以便自定义样式片段。
*   **发布工具**：桌面端独有的文件夹发布功能，配合 Diff 视图便于审阅修改。

**4. 使用建议**
建议在块开始和结束的分隔符后保留空行，以确保 Obsidian 正确解析内部 Markdown 结构。利用 `center` 类型居中内容，或使用空的 `spacer` 块增加垂直间距。对于未知类型，插件会应用通用强调容器样式，用户可通过 CSS 片段进一步定制。
