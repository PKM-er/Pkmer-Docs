## 概述

### URL File Preview插件总结
1. **主要功能**：在Obsidian中预览和编辑Windows的`.url`快捷方式文件，可内联编辑URL、在默认应用或网页查看器中打开文件，还能将其转换为Markdown笔记。
2. **适用场景**：适用于包含从Windows同步或从浏览器拖入的`.url`快捷方式文件的Obsidian库。
3. **核心特色**：为`.url`文件提供专用视图，将其渲染为带有可内联编辑URL字段和一键操作的小卡片；解析`.url`文件格式并保留未知键/部分；不进行网络请求，仅本地处理，除用户明确触发的操作外；“在网页查看器中打开”功能依赖Obsidian的“网页查看器”核心插件（仅桌面端，默认禁用）。
4. **使用建议**：可通过社区插件浏览器或手动方式安装。使用时，若要使用“在网页查看器中打开”功能，需在“设置→核心插件”中启用“网页查看器”插件。
