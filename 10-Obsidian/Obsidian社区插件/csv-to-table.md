## 概述

### Csv to table 插件总结
1. **主要功能**：将选中的类 CSV 文本转换为 Markdown 表格。
2. **适用场景**：适用于需要将逗号分隔的文本快速转换为 Markdown 表格的场景，如整理数据、记录信息等。
3. **核心特色**：操作简单，专注于 CSV 文本到 Markdown 表格的转换。与其他类似插件相比，它针对逗号分隔文本，有独立的转换命令，不依赖粘贴操作。
4. **使用建议**：
    - 先选中文本，确保文本每行内容为逗号分隔的值。
    - 通过快捷键 Ctrl/Cmd + P 打开命令面板。
    - 运行“CSV to table: Convert CSV selection to Markdown table”命令完成转换。

例如，选中文本 “fruit,color\napple,red\nbanana,yellow” 后，经插件转换可得到标准的 Markdown 表格。
