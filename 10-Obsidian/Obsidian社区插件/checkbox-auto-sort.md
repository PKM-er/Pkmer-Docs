## 概述

### 1. 主要功能
自动将已勾选的复选框排序到列表底部，勾选复选框时，插件会重新排列周围的列表块，使未勾选项在上，已勾选项在下，并在两组之间显示分隔线。

### 2. 适用场景
适用于使用 Obsidian 管理任务列表、待办事项等场景，能帮助用户清晰区分已完成和未完成事项。

### 3. 核心特色
 - 支持阅读和编辑模式。
 - 仅对包含更改项的连续复选框块重新排序，不影响笔记中的其他列表。
 - 子项（缩进项）会跟随其父项。
 - 在用户编辑时进行排序。

### 4. 使用建议
推荐通过 Obsidian 社区插件浏览器安装。若要进行开发，需 Node.js ≥ 16 和 npm，可使用 `npm install` 进行设置，`npm run dev` 开启开发模式，`npm run build` 进行生产构建，`npx eslint main.ts` 进行代码检查。每次重新编译后，可通过重新加载应用或在设置中切换插件开关来应用最新构建。
