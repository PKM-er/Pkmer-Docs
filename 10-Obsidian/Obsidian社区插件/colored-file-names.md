## 概述

**Colored File Names** 是一款用于 Obsidian 的文件管理插件，旨在通过视觉色彩优化笔记库的组织体验。

**主要功能**：允许用户通过右键菜单为文件资源管理器中的文件和文件夹添加颜色。支持定义可复用的颜色调色板，修改调色板颜色时会自动更新所有引用该颜色的项目。此外，支持将颜色配置导出为 JSON 文件进行备份或跨设备迁移，并可从其他插件（如 File Color）导入数据。

**适用场景**：适合拥有大量笔记、需要直观区分不同主题或项目类型的用户。特别适用于希望快速定位特定文档、或希望通过颜色编码（如按状态、优先级、类别）来管理复杂知识库的场景。

**核心特色**：
1. **智能适配**：自动调整颜色亮度以确保在浅色和深色主题下均清晰可读。
2. **灵活样式**：可自定义着色名称、背景或两者，并支持文件夹递归着色（子项继承父文件夹颜色）。
3. **动态跟随**：颜色标记会随文件或文件夹的重命名、移动而自动保留，无需重新设置。
4. **批量操作**：支持多选文件一次性着色，提高效率。

**使用建议**：建议在设置中预先定义一套固定的“调色板”（如红色代表紧急，蓝色代表参考），以便统一风格。利用“递归”功能为大型项目文件夹整体着色，能快速建立视觉层级。定期导出 JSON 备份，以防数据丢失或便于在新设备同步。
