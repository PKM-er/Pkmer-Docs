## 概述

**1. 主要功能**
该插件在 Obsidian 笔记的代码块右下角自动显示字符数量统计徽章（如“32 字符”）。它仅统计可见字符，自动排除空格、制表符和换行符，且支持实时预览与阅读视图。

**2. 适用场景**
适用于需要严格控制代码片段长度的场景，例如编写 API 请求、SQL 查询或受字符限制的平台代码提交。特别适合在实时编辑时快速确认代码规模，无需手动计算。

**3. 核心特色**
*   **零配置即用**：无需任何设置，启用插件后立即生效。
*   **全场景覆盖**：完美兼容阅读视图、实时预览以及嵌入渲染（如 Canvas）。
*   **实时精准**：基于 CodeMirror 6 和 Markdown 后处理钩子，输入时数字实时刷新，统计逻辑准确排除不可见字符。

**4. 使用建议**
推荐通过 BRAT 插件安装以获取最新测试版，或手动下载 release 文件至插件目录。启用后无需额外操作，打开含代码块的笔记即可在右下角看到统计角标。注意该插件未经 Obsidian 官方人工审核，建议从可信来源获取。
