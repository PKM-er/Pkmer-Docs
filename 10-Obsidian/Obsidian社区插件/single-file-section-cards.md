## 概述

### Single File Section Cards插件总结
1. **主要功能**：将单个笔记的各部分以卡片墙形式展示，每个标题对应一张卡片，可直接在卡片上编辑内容并保存到源 `.md` 文件。支持多种布局和排序方式，能标记任务完成日期，还可固定卡片、快速添加内容。
2. **适用场景**：适用于日常笔记管理、临时仪表盘搭建、便签记录、任务管理和头脑风暴等场景。与 Single File Daily Notes 插件搭配使用，能更好地管理每日笔记。
3. **核心特色**：提供六种布局和三种排序顺序，每个笔记可保留自己的视图；支持直接在卡片上编辑原始 Markdown 内容；可固定卡片在顶部，且固定区域在滚动时保持显示。
4. **使用建议**：可根据实际需求选择合适的标题级别生成卡片；在编辑卡片内容时，利用快捷键（如 `Ctrl/⌘+Enter` 保存、`Esc` 取消、`Tab` 缩进）提高效率；搭配 Single File Daily Notes 插件，提升每日笔记管理体验。
