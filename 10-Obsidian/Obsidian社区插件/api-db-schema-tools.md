## 概述

**主要功能**
API Database Schema Tools 是一款用于管理 API 接口与数据库字段 Schema 的 Obsidian 插件。它基于 Markdown、YAML 和 Wikilink，提供可编辑网格视图，支持 JSON 和 DDL 文件/字符串导入，实现字段的高效维护与精准引用。

**适用场景**
适用于需要同时维护 API 接口文档与数据库结构的技术团队或个人开发者，特别是涉及复杂嵌套对象、多层级引用及多数据源（如 MySQL/Oracle）管理的场景。

**核心特色**
1. **一键体验样例**：提供可逆的中文 Demo 流程，安装前展示完整影响范围，不覆盖现有文件，结束后可一键恢复配置，极大降低上手门槛。
2. **精准引用与导入**：支持 `[[@` 分层引用，兼容 JSON/DDL 导入及 Diff 对比，便于版本管理。
3. **灵活工作流**：集成 Fileclass 属性定义，支持 Excel/WPS 多单元格粘贴，具备强大的排序、筛选与搜索功能。

**使用建议**
首次安装后，建议先运行“安装/打开体验样例”命令，在隔离的 `_SchemaTools-Demo/` 目录中熟悉网格编辑、导入及引用功能。体验结束后执行恢复命令，再正式应用于业务文档。注意该插件需配合 Fileclass 使用以获得最佳属性定义体验。
