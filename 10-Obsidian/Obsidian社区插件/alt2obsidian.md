## 概述

**1. 主要功能**
Alt2Obs 是一款专为使用 Alt (altalt.io) 记录课堂的学生设计的 Obsidian 插件。它能直接读取本地 Alt 桌面应用中的讲座数据，将每节课转化为结构化的 Obsidian 笔记。利用 LLM（如 Claude Code 或 Codex CLI）从幻灯片和录音中提取概念，自动生成带有 `[[wikilinks]]` 的概念笔记和考试摘要，实现知识点的自动关联。

**2. 适用场景**
适用于依赖 Alt 进行课堂录音和截图的学生，特别是需要高效整理大量课程资料、构建个人知识网络，并希望通过 AI 辅助提取核心概念以应对考试的学习者。

**3. 核心特色**
*   **AI 驱动提取**：自动从幻灯片和对应录音片段中生成注释和概念链接，无需手动整理。
*   **同步查看器**：提供 PDF 幻灯片与笔记并排滚动的视图，方便对照学习。
*   **数据本地化**：直接从本地 Alt 文件夹读取，无需分享链接，保护隐私。
*   **增量更新**：支持重新导入，且保留用户原有的个人笔记（Memos），仅更新 AI 生成的部分。
*   **韩英混合界面**：界面及生成笔记主要为韩语，学术术语保留英文。

**4. 使用建议**
*   确保已安装 Alt 桌面应用并登录，插件才能识别本地讲座列表。
*   需配置好本地的 LLM 环境（如 Claude Code 或 Codex CLI）以启用智能提取功能。
*   建议定期使用“重新导入”功能同步最新幻灯片，同时注意备份个人笔记以防意外覆盖。
*   注意该插件目前主要面向韩语用户，非韩语用户可能需自行调整语言设置或翻译生成内容。
