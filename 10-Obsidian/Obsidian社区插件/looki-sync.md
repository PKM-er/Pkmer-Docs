## 概述

### Looki Sync 插件总结
1. **主要功能**：将 Looki 的日常数据（Moments）和即时提示（For You）同步到 Obsidian，合并为按日期的「每日记忆」笔记。支持设置 API、指定目标文件夹、选择是否同步图片/视频，提供增量同步和全量重同步命令。
2. **适用场景**：适用于使用 Looki 记录日常，希望将数据整合到 Obsidian 进行统一管理和回顾的用户。
3. **核心特色**：设计参照成熟插件，有设置页、命令面板、功能栏图标和增量同步历史；支持测试连接；目标和媒体文件夹自动创建；图片按真实格式保存；笔记幂等/自愈，不重复堆积；自动解析地点，剥离视频抽帧外链。
4. **使用建议**：在设置页填好 API Key 和 Base URL 后先测试连接；根据需求选择是否同步图片/视频；可按需设置回填天数和自动同步间隔；若数据有较大变动，可使用全量重同步命令。
