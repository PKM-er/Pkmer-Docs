## 概述

**1. 主要功能**
Syncidian 是一款基于自托管服务器的 Obsidian 同步插件。它允许用户通过私有服务器在多台设备间同步笔记库（Vault），支持将 GitHub 私有仓库作为数据的持久化版本控制源，并可选集成 MCP 协议以连接 AI 工具。

**2. 适用场景**
适用于重视数据隐私、希望完全掌控数据主权的用户；需要跨设备无缝同步且不想依赖 Obsidian 官方付费同步服务的场景；以及希望将笔记库纳入 Git 版本管理，并利用 AI 工具辅助知识管理的进阶用户。

**3. 核心特色**
*   **自托管与隐私优先**：数据存储在用户自己的服务器上，不经过第三方云同步。
*   **GitHub 版本控制**：每个用户可绑定一个私有 GitHub 仓库，实现笔记的版本追踪与持久备份。
*   **AI 桥梁**：内置 MCP 支持，便于将笔记内容直接对接各类 AI 助手。
*   **开源免费**：MIT 协议开源，社区驱动，无强制付费墙。

**4. 使用建议**
*   需自行部署 Syncidian 服务器（如通过 Docker），并配置好访问令牌（`sk_sync_…`）。
*   确保已配置好私有 GitHub 仓库权限，以便启用版本备份功能。
*   建议定期验证 GitHub 同步状态，利用其版本控制特性作为最终数据恢复手段。
*   注意该插件未经过 Obsidian 官方人工审核，使用前请确认服务器安全性。
