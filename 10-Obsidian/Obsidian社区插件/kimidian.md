## 概述

### Kimi Assistant插件总结
1. **主要功能**：将Kimi Code CLI嵌入Obsidian右侧边栏，实现与Kimi的聊天交互，可读取、搜索和编辑笔记。具备侧边栏聊天、权限审批、会话历史记录、知识库集成、状态栏显示及取消生成等功能。
2. **适用场景**：适用于Obsidian用户在知识管理过程中，借助AI辅助进行笔记的查询、编辑和知识整合。
3. **核心特色**：采用ACP协议驱动会话；聊天界面有用户/助手气泡、流式Markdown渲染等；权限审批有多种选择，还可设置自动批准；能查看和恢复历史会话；知识库集成方便引用笔记；状态栏可切换模型、查看连接状态。
4. **使用建议**：先安装Kimi Code CLI并登录，按步骤构建和复制插件文件到指定位置，在Obsidian中启用插件并确认CLI路径。通过点击左侧丝带图标或运行命令打开聊天侧边栏，输入问题发送，用`@`引用笔记，生成时可点击“停止”中断，“New Chat”开启新会话。
