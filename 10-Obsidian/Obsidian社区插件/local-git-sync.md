## 概述

### Local Git Sync插件总结
1. **主要功能**：利用Git同步和备份Obsidian库的更改，支持提交、拉取、推送操作，能自动同步库的变更。
2. **适用场景**：适用于使用Git管理Obsidian库的桌面用户，可在不离开Obsidian的情况下完成库的版本控制操作。
3. **核心特色**：自动提交本地库更改；可从配置的远程仓库拉取、推送本地提交；库打开时自动同步；拉取冲突时给出警告；支持GitHub、GitLab、Gitee等远程服务；可选择添加空文件夹占位文件用于Git跟踪。
4. **使用建议**：安装前需确保本地安装了Git，且库已在Git仓库中。可通过社区插件目录（待审核通过后）或手动方式安装。手动安装时，需在库文件夹中创建对应插件目录，复制相关文件，重启Obsidian并在设置中启用该插件。
