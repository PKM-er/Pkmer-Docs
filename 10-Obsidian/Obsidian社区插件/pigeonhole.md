## 概述

**1. 主要功能**
Pigeonhole 是一款基于 TypeSafe Jev AI 的笔记自动分类插件。它能分析笔记内容，根据预设属性或现有文件夹结构，自动将笔记归档至对应目录，并写入 Frontmatter 标签。

**2. 适用场景**
适用于希望实现知识库自动化整理、减少手动移动文件负担的用户。特别适合笔记量大、分类维度复杂（如工作、项目、会议等）且拥有 TypeSafe API Key 的场景。

**3. 核心特色**
*   **智能归档**：利用 AI 判断笔记属性，自动匹配 Vault 中已有的文件夹结构。
*   **灵活配置**：支持自定义属性（名称、描述、目标文件夹），描述越具体，分类越精准。
*   **低门槛设置**：仅需配置 API Key 即可运行，无需复杂代码。
*   **属性优先**：自定义属性的优先级高于同名文件夹，支持更细粒度的分类逻辑。

**4. 使用建议**
*   务必在 TypeSafe 控制台获取有效的 API Key 并填入插件设置。
*   初期可保留默认的 `meeting`、`idea`、`reference` 属性，后续根据实际文件夹结构调整或新增。
*   编写属性描述时，请具体说明该类别包含的笔记类型，以提升 AI 判断的准确性。
*   若目标文件夹留空，插件仅添加标签而不移动文件，适合仅做标记的场景。
