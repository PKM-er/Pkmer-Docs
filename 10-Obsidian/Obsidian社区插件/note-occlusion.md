## 概述

**1. 主要功能**
Note Occlusion 允许用户在 Markdown 笔记的任意区域绘制彩色遮盖层，点击即可揭示隐藏内容。遮盖层与笔记绑定，支持移动、缩放及自定义颜色，且具备持久化存储特性。

**2. 适用场景**
适用于需要自我测试记忆、制作互动式学习笔记或隐藏敏感信息的场景。特别适合希望将笔记转化为“闪卡”式复习工具的用户，或用于在共享笔记中隐藏答案。

**3. 核心特色**
- **六种模式**：提供绘制、自由画笔、文本锚定、快速删除、揭示及透传模式，操作灵活。
- **高稳定性**：遮盖层随文本滚动，重启软件后保留，并跟随笔记重命名或移动自动更新。
- **纯 Markdown 支持**：仅适用于 Markdown 笔记，不支持 PDF 或 Canvas。

**4. 使用建议**
- 安装需手动将插件文件放入 `.obsidian/plugins/note-occlusion/` 目录并启用。
- 在“绘制”模式下笔记不可编辑，但可正常滚动；建议使用“文本”模式隐藏特定词汇，以便在阅读/编辑模式切换时自动重算位置。
- 注意该插件仅针对 Markdown 文件，若需处理 PDF 请寻找其他专用插件。
