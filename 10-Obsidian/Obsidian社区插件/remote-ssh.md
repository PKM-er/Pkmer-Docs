## 概述

### Remote SSH 插件总结
1. **主要功能**：可通过 SSH/SFTP 协议远程编辑存储在服务器上的 Obsidian 保险库，如同 VS Code 的 Remote - SSH 功能。能实现文件、附件操作、搜索及实时更新，数据直连远程服务器。
2. **适用场景**：适用于需要从不同设备访问和编辑存储在家庭服务器、VPS、工作机或集群上的 Obsidian 保险库的场景。
3. **核心特色**：无需云服务和同步工具，不将完整数据复制到本地，仅保留当前查看内容，保障笔记存储在用户可控设备上。
4. **使用建议**：安装时，在 Obsidian 的社区插件中搜索“Remote SSH”进行安装和启用。首次使用推荐的 RPC 传输方式时，插件会从 GitHub 下载匹配的辅助守护程序，需一次性确认；若不想在远程端使用二进制文件，可选择 SFTP 传输方式。也可通过 BRAT 安装预发布版本或手动下载安装。
