## 概述

### 插件名称
File Explorer Size

### 主要功能
在Obsidian文件管理器中显示文件和递归文件夹大小，并提供一个排名视图，可计算笔记及其附件的组大小。

### 适用场景
适用于想要了解Obsidian库中哪些文件或文件夹占用大量空间的用户。

### 核心特色
1. 在文件管理器显示文件和递归文件夹大小，可通过工具栏开关。
2. 能根据可配置的阈值突出显示大文件和文件夹。
3. 提供排名视图，含文件、笔记组、文件夹三个标签页。
4. 计算笔记组大小仅考虑笔记及其直接附件。
5. 可选支持MAKE.md Navigator。

### 使用建议
- 若想查看库中最大的项目，可打开排名视图。
- 若要切换文件浏览器大小显示，使用“Toggle File Browser sizes”命令。
- 当对文件或文件夹有更改后，使用“Recalculate all sizes”命令重新计算大小。
