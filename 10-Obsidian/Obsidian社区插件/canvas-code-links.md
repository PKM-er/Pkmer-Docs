## 概述

**Canvas Code Links** 是一款 Obsidian 插件，允许用户在 Canvas 卡片或 Markdown 笔记中直接链接到源代码文件的特定行。

**主要功能**：支持通过相对路径（如 `../src/Player.cs#L105`）创建代码链接，点击即可在 VS Code、Cursor、Rider 或 Obsidian 中打开指定行列。

**适用场景**：适合将代码库与笔记库并存的开发者，特别是用于游戏开发或需要详细记录代码逻辑的项目文档化。

**核心特色**：
1. **跨平台便携**：使用相对路径，兼容 Windows/macOS/Linux。
2. **多编辑器支持**：可配置多种编辑器或自定义 URI 模板。
3. **精准定位**：支持行号及列号定位。
4. **移动端友好**：iOS/Android 支持内置只读查看器或跳转至 GitHub/GitLab 网页版。
5. **辅助功能**：提供剪贴板生成链接命令、代码链接图标徽章及悬停提示。

**使用建议**：目前需手动安装（下载 Release 文件至插件目录）。建议配置好默认编辑器，利用“Insert Code Link”命令快速从剪贴板生成链接，并确保文件扩展名在配置中被识别为代码文件。
