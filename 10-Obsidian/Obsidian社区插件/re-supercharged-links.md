## 概述

**1. 主要功能**
Re-Supercharged Links 是一款专为 Obsidian 设计的高级链接样式插件。它允许用户根据笔记标签（Tags）、Frontmatter 属性、Dataview 内联字段以及笔记路径，动态定制内部链接的视觉样式（如颜色、字体等），支持阅读模式、实时预览及多种 UI 视图。

**2. 适用场景**
适用于拥有大量笔记的大型知识库（Vault），特别是需要建立复杂知识网络、通过视觉区分不同项目或状态（如“待办”、“进行中”）的用户，以及追求界面整洁与高效导航的知识工作者。

**3. 核心特色**
作为 Supercharged Links 的深度重构版本，其核心优势在于**高性能与稳定性**。规则在内存中评估，无需生成额外 CSS 文件；采用批量 DOM 更新和元数据缓存机制，有效减少 UI 卡顿；优化了观察器设置，避免布局变更时的重复绑定，确保在大型库中依然流畅响应。

**4. 使用建议**
建议大型库用户优先尝试此插件以替代旧版样式方案，以获得更稳定的性能。配置时，可结合标签和路径规则建立清晰的视觉层级。注意该插件为社区插件，未经官方人工审核，使用前建议备份数据，并关注其 GitHub 仓库以获取最新集成支持（如 myBrain）。
