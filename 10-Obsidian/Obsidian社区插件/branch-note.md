## 概述

**1. 主要功能**
Branch Note 允许笔记像树一样生长。它利用普通文件夹和匹配的 Markdown 首页文件，将笔记转化为父页面，子笔记则存储在对应的文件夹中。右键点击笔记即可创建子笔记，实现层级化管理。

**2. 适用场景**
适用于需要结构化组织复杂信息的场景，如旅行计划（主笔记为行程，子笔记为行李清单）、项目文档或长篇内容拆解。特别适合希望在不改变现有文件结构的前提下，建立清晰层级关系的用户。

**3. 核心特色**
*   **原生兼容**：笔记仍为普通 Markdown 文件，无需特殊格式或关联数据，保留 Obsidian 原生编辑、链接和主题功能。
*   **自动关联**：文件夹自动匹配同名 Markdown 文件作为首页，若缺失可一键创建。
*   **简洁视图**：文件浏览器中首页显示为文件夹，避免文件重复，仅在有子项时显示展开箭头，保持界面整洁。
*   **低配置**：设置极简，仅包含语言选择，无复杂配置负担。

**4. 使用建议**
*   从简单开始：先创建主笔记，再通过右键菜单逐步添加子笔记，避免一次性过度规划。
*   利用“Start writing”功能快速为现有文件夹生成首页，完善知识结构。
*   由于依赖文件夹结构，重命名文件夹和首页时会同步更新，操作前请确认备份，以防链接断裂。
