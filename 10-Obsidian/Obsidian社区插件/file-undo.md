## 概述

### 插件名称
File Undo

### 主要功能
允许在Obsidian内直接撤销近期文件删除和移动（重命名）操作，支持恢复删除文件到原路径、撤销跨文件夹移动或重命名，还具备重做功能。

### 适用场景
适用于误删文件、误移动文件或误重命名文件后，需快速恢复文件原始状态的场景，可作为系统回收站、文件历史记录或本地备份功能的本地替代方案。

### 核心特色
- 可配置操作历史数量，默认记录200条。
- 提供“撤销上次文件移动或删除”和“重做上次撤销的文件移动或删除”专用命令。

### 使用建议
1. 在设置中启用该插件。
2. 误删或误移动文件时，打开命令面板，运行“撤销上次文件移动或删除”命令。
3. 若要设置历史记录保存数量，可前往“A1 File Undo Settings”选项卡进行配置。
