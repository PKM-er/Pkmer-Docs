## 概述

### Native Git Bridge插件总结
1. **主要功能**：在安卓设备上，通过Termux中的真实`git`二进制文件执行Git操作，如状态查看、拉取、推送、提交、同步等，还支持按文件或文件夹暂存、取消暂存，丢弃本地更改等。有状态面板展示冲突、暂存更改等信息。
2. **适用场景**：适用于在桌面端和安卓设备间共享的Obsidian库，桌面端可使用普通Git或其他Git工具，安卓端则用此插件。
3. **核心特色**：仅适用于安卓，利用真实`git`二进制文件，提供一流的稀疏检出支持，无需isomorphic - git、HTTP服务器，不开放端口，无后台运行程序。
4. **使用建议**：此插件尚在开发中，使用前需安装Termux和配套小应用。在桌面端建议使用普通Git或[obsidian - git](https://github.com/Vinzent03/obsidian - git) 。
