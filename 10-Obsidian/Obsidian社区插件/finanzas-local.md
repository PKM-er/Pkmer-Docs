## 概述

**Finanzas 插件中文总结**

1. **主要功能**：基于 Python (Flask/SQLite) 的本地个人财务管理应用，集成于 Obsidian 桌面端。支持债务管理、还款记录、收入导入（CFDI 格式）及支付日历查看。
2. **适用场景**：适用于需要管理个人债务、跟踪月度还款计划及记录墨西哥比索（MXN）收支的用户，特别是希望数据完全本地化、不依赖云端服务的隐私敏感用户。
3. **核心特色**：
   - **完全本地化**：无遥测，数据不上传外部服务，仅通过本地端口通信。
   - **深度集成**：在 Obsidian 标签页中运行，支持拖拽操作编辑支付日期。
   - **灵活配置**：需手动安装 Python 环境及依赖，支持自定义 Python 路径，界面为西班牙语。
4. **使用建议**：
   - 仅限 Obsidian 桌面版使用。
   - 需手动在库中 `.finanzas/` 目录安装应用，并在插件设置中正确配置 Python 可执行文件路径。
   - 默认关闭启动时自动运行服务器，可在设置中开启；关闭视图后服务器仍保持运行，需注意资源占用。
   - 注意该插件未通过 Obsidian 官方人工审核，使用前请自行评估安全性。
