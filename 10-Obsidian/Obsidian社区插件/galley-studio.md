## 概述

### Galley Studio 插件总结
1. **主要功能**：将 Markdown 文章借助 OpenAI-compatible 模型、Codex CLI 或 Claude CLI，结合内置排版 Skill 生成适合微信公众号等场景的 HTML。支持在 Obsidian 中预览、可视化编辑、源码编辑和复制导出。
2. **适用场景**：适用于需要将 Markdown 文章排版并发布到微信公众号等平台的用户，也可用于普通 HTML 文件的编辑。
3. **核心特色**：AI 生成功能强大，支持多种模型和本地 CLI，能自动提取可用 HTML，生成对话展示详细信息且可后台运行；HTML 工作台可在同一页面切换预览、编辑和源码模式，支持自动保存等操作；控制台可管理主题和 Skill，有多种界面语言模式。
4. **使用建议**：可手动安装或从源码构建插件。配置生成方式时，若用插件内模型需填写相关信息并保存 API Key；Desktop 端也可选择本地 CLI。
