## 概述

**1. 主要功能**
AI Session Atlas 是一款专为 macOS 设计的 Obsidian 插件，旨在统一管理 Claude Code 和 Codex 的 AI 会话。它提供全量文本搜索、实时会话监控、Token 及成本统计，并支持在 Obsidian 内部终端标签页中直接运行和恢复会话。

**2. 适用场景**
适用于日常高频使用 Claude Code 或 Codex 进行代码开发、自动化任务处理的 macOS 用户，特别是需要跨 Agent 协作或管理大量历史会话记录的场景。

**3. 核心特色**
*   **统一检索与恢复**：索引本地会话记录，支持按项目、日期等筛选，可一键在 Obsidian 内恢复会话，甚至支持在 Claude 与 Codex 之间交叉“接力”继续任务。
*   **实时交互卡片**：以卡片形式展示运行中会话的状态，支持直接在 Obsidian 内回答权限请求、审批计划、发送指令或停止任务，无需切换窗口。
*   **本地隐私安全**：所有数据通过本地 Python 服务器处理，默认不上传任何数据，可选开启 AI 增强功能。

**4. 使用建议**
建议定期利用搜索功能回顾历史会话以复用代码片段或解决思路；对于长任务，可利用“实时卡片”功能在 Obsidian 内直接响应 Agent 的询问，保持工作流连贯性；注意该插件仅限 macOS 使用，且需确保本地环境支持 Python 服务运行。
