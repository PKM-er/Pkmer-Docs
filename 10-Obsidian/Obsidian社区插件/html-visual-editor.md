## 概述

### HTML Visual Editor插件总结
1. **主要功能**：可在Obsidian中打开并可视化编辑`.html`和`.htm`文件，能对页面元素进行拖动、调整大小、选择、复制、删除和样式设置等操作，还可插入文本、图片等元素，编辑后能直接保存到原Vault文件。
2. **适用场景**：适用于需要在Obsidian中可视化编辑HTML文件的场景，可避免直接编写代码的繁琐。
3. **核心特色**：支持从文件菜单或命令面板打开文件；保存操作简单，可通过Obsidian工具栏按钮、页面内保存按钮或快捷键完成；保存时直接覆盖原文件，无需系统文件选择器；能临时映射相对图像和样式表链接，粘贴的Base64图像可保存到指定文件夹。
4. **使用建议**：安装并启用插件后，右键点击HTML文件选择“Open in HTML Visual Editor”进行编辑，编辑完成后点击“Save”或按快捷键保存。需注意该插件仅编辑本地Vault文件，保存会覆盖原文件，重要文档要做好备份或使用版本控制。
