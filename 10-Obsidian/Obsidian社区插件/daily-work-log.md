## 概述

### Daily Work Log 插件总结
1. **主要功能**：直接从每日 Markdown 笔记中可视化每日时间跟踪（事件）和待办事项列表，无需 YAML 前置元数据。具备网格时间轴、分类标签、可折叠待办面板、PDF/HTML 导出等功能，还有工作洞察的库总结信息。
2. **适用场景**：适合需要记录每日工作、学习、休息等活动时间，以及管理待办事项的用户，可用于日常办公、学习计划安排。
3. **核心特色**：采用最少元数据，从三个普通 Markdown 标题读取信息；支持多语言和向后兼容标记；可自动检测 UI 语言；有独立的侧边栏明暗主题切换；工作洞察功能提供丰富的库统计信息。
4. **使用建议**：每日笔记命名需遵循 `YYYY-MM-DD.md` 格式；可在设置中配置每日笔记文件夹，利用文件夹自动补全功能；首次运行时插件会自动根据 Obsidian 语言设置 UI 语言，也可在设置中修改。
