## 概述

**主要功能**
Speak Selection 是一款基于 Web Speech API 的文本朗读插件。用户只需选中文字并右键点击或调用命令，即可将选中文本转换为语音播放。它无需联网或 API 密钥，直接调用系统内置语音引擎，支持离线使用。

**适用场景**
适用于语言学习、听力训练、阅读辅助及无障碍访问场景。特别适合需要多语言阅读支持的用户，如学习中文、日文、德文等外语时，通过听读结合加深理解。

**核心特色**
1. **智能语言检测**：自动识别中、日、韩、德、英等 23 种语言。针对德语和英语等相似语言，采用功能词、前后缀及名词大写等评分机制进行精准区分。
2. **零配置体验**：无需手动设置语言，自动根据字符集检测。
3. **灵活控制**：提供设置面板，可调整语速（0.5x-2.0x）、选择默认语言或关闭自动检测。
4. **多种触发方式**：支持右键菜单、命令面板及自定义快捷键。

**使用建议**
建议用户在设置中根据系统语音质量调整默认语速，以获得最佳听感。若系统缺乏特定语言语音包，朗读效果可能受限，需确保操作系统已安装相应语言的 TTS 语音组件。对于混合语言文本，可手动指定默认语言以确保准确性。
