# Obsidian 插件：Git History Reviewer

> [!Note] 插件名片
> - 插件名称：Git History Reviewer
> - 插件作者：timdommett
> - 插件说明：在你仓库的Git历史记录里，用暗黑模式的差异视图查看每一次提交，还能追踪你已经查看并批准过哪些提交。查看状态是本地保存的，所以不会产生新的提交记录。——Obsidian官方人员尚未手动审核此插件。

## 概述

### Git History Reviewer插件总结
1. **主要功能**：可查看仓库中每个提交，提供暗黑模式的差异视图，能标记已审查和批准的提交，支持按日期批量批准提交，有过滤和搜索功能。
2. **适用场景**：适用于使用Obsidian Git自动提交功能，提交堆积较快，希望仔细审查仓库提交历史的用户。
3. **核心特色**：从仓库直接加载完整提交历史；暗黑模式差异视图功能丰富，支持文件折叠、显示行号等；有逐文件审查标记，显示审查进度；可隐藏已审查文件；支持自动前进到下一个待审查提交；合并提交自动展开显示变更。
4. **使用建议**：若想快速清理旧的自动提交，可使用“按日期批量批准”功能；默认隐藏已审查文件可让审查更高效，若想查看已审查文件，可在详情面板或设置中关闭该功能；利用过滤功能可快速定位待审查或已批准的提交。
