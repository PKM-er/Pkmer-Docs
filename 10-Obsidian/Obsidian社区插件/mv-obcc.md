## 概述

### 插件主要信息
- **名称**：mv-AIDE
- **适用版本**：Obsidian 1.7.2 及以上桌面端

### 主要功能
将 Claude Code、Codex CLI 等 Agent 桥接到本地知识库，提供划词调用 LLM、行内补全、系统终端、源码编写辅助、默认文件打开器等功能。

### 适用场景
适合需要在 Obsidian 内进行代码编写、知识管理，且希望借助 AI 提升效率的用户。

### 核心特色
- 具备 IDE 桥接功能，可提供 Obsidian 上下文并支持 Diff 审核。
- 划词助手能流式调用 LLM，结果展示在悬浮窗。
- 行内补全支持多种操作。
- 全功能系统终端支持主题和字体自定义。

### 使用建议
- 推荐通过社区插件市场安装，操作简单。
- 开启所需功能，如 IDE 桥接中的 Claude Code 或 Codex IDE 功能。
- 根据自身需求，在设置页对各功能进行详细配置。
