## 概述

**1. 主要功能**
Simple One 是一款集成化插件，涵盖写作格式化、链接与网页捕获、日历日记管理、阅读显示优化、附件整理、Git 同步及笔记公开分享（GitHub Pages/EdgeOne）。

**2. 适用场景**
适合希望在一个插件内解决笔记格式、日常记录、文件管理及多端同步需求的用户，特别是需要定期备份、整理无用附件或将笔记发布为静态网站的用户。

**3. 核心特色**
*   **高度集成**：将写作、同步、分享等分散功能合一，支持按需启用。
*   **灵活同步**：支持桌面 Git 备份及无 Git 环境的轻量级多端同步，具备冲突解决机制。
*   **便捷分享**：一键发布笔记至 GitHub Pages，支持自定义 HTML 模板，移动端亦可操作。
*   **智能整理**：自动清理网页标题、查找未使用附件、配置化格式规则。

**4. 使用建议**
*   设置界面目前仅支持中文，建议中文用户直接配置。
*   使用 Token 分享或 EdgeOne 授权需确保 Obsidian 版本在 1.11.4 及以上。
*   桌面与移动端的显示选项可独立配置，建议根据设备习惯分别调整。
*   定期利用“查找未使用附件”功能保持库整洁，并善用 Git 备份以防数据丢失。
