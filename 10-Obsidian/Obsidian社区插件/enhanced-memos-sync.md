## 概述

### 插件名称
Enhanced Memos Sync

### 主要功能
将 Memos 服务器上的备忘录同步到 Obsidian 中，每个备忘录保存为独立的 Markdown 文件，当天备忘录会链接到每日笔记里。

### 适用场景
适合使用 Memos 进行记录，同时习惯用 Obsidian 管理笔记和日记的用户。

### 核心特色
1. 多种同步模式：支持智能、增量和强制同步。
2. 保留对话结构：回复内容会保留，可折叠到父备忘录。
3. 处理附件：可下载图片到指定文件夹或跳过。
4. 安全可靠：增量同步仅添加新笔记，API 令牌安全存储。
5. 自动化：可在启动或按计划自动同步。
6. 保持整洁：可设置同步天数限制。

### 使用建议
1. 确保桌面版 Obsidian 为 1.6.6 及以上版本。
2. 准备好可通过 HTTP 或 HTTPS 访问的 Memos 服务器及 API 令牌。
3. 若要将备忘录链接到每日笔记，需启用内置的 Daily Notes 或 Periodic Notes 插件。可从社区插件目录安装该插件。
