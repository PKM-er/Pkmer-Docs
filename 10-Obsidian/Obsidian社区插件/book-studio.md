## 概述

Book Studio 将你的 Markdown 笔记文件夹转化为可直接印刷的平装书 PDF 和通用 EPUB 3 电子书。它内置了专业的排版引擎，无需安装 Pandoc 或 LaTeX 等外部依赖，所有解析、排版及文件生成过程均在本地设备完成。这意味着你的手稿数据不会上传至任何服务器，彻底解决了隐私顾虑，同时支持桌面端与移动端使用。

典型场景适用于独立作者或知识创作者。例如，你可以将一系列关于历史研究的笔记整理成书，通过清单笔记定义章节顺序，插件会自动生成包含版权页、目录及“作者其他作品”的前后辅文。另一个例子是小说创作，利用其“实时分页预览”功能，你可以像翻阅实体书一样检查每一页的排版效果，确保最终成品符合出版标准。

相比同类工具，Book Studio 的核心优势在于其“出版级”的排版细节与 KDP 适配性。它采用 Knuth–Plass 断行算法，支持智能引号、连字符及首字下沉等高级排版特性，并自动处理孤行寡行。针对亚马逊 KDP，它内置了 6"×9" 标准尺寸，能根据页数动态调整内边距，并报告书脊宽度供封面设计参考。此外，其导出的 EPUB 文件能通过官方校验，确保在各大电子书商店的兼容性。

使用前需注意，当前版本仅支持 6"×9" 开本及 Classic、Modern 两种主题，且要求笔记结构符合特定的清单格式。如果你需要自定义复杂的 CSS 样式、非标准开本，或希望将笔记转换为网页而非书籍格式，此插件可能无法满足需求。它专为“从笔记到成品书”的线性流程设计，不适合需要频繁调整底层排版代码的高级用户。
