## 概述

### Git Viewer插件总结
1. **主要功能**：这是一款轻量级的Obsidian插件，可展示Git状态、历史记录，支持对选定文件进行提交。能在侧边栏紧凑显示Git状态，提供“Changes”和“History” 标签页，分组显示不同状态的文件，展示最近50条提交记录及详情。
2. **适用场景**：适用于想在Obsidian内操作，查看仓库文件变更、打开文件、进行有目的的提交以及查看提交历史，而无需启动更复杂Git客户端或Visual Studio Code的用户。
3. **核心特色**：仅提交明确选定的文件，使用临时Git索引避免无关文件混入；省略Obsidian无法打开的隐藏/内部Git路径；通过`git` CLI使用本地Git输出，不进行网络请求。
4. **使用建议**：手动刷新或在仓库文件事件后自动刷新，提交时需填写必要的提交信息。该插件不包含拉取、克隆、合并等功能，若有这些需求需借助其他工具。
