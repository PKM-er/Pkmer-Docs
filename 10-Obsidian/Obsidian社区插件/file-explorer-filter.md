## 概述

### File Explorer Filter插件总结
1. **主要功能**：为Obsidian的文件资源管理器添加过滤功能，可在所有文件夹和特定顶级文件夹视图间切换，还能按自定义文本隐藏匹配的文件和文件夹。
2. **适用场景**：适用于在同一笔记簿中需要快速切换不同文件夹上下文查看内容，以及想要隐藏已完成笔记的场景。
3. **核心特色**：一是能在同一笔记簿内轻松切换文件夹上下文；二是可自定义模式隐藏已完成笔记；三是基于CSS，能与其他文件资源管理器插件配合使用；四是隐藏操作无损，可通过搜索、链接等方式找到隐藏项。
4. **使用建议**：可通过社区插件安装或手动安装。使用时点击文件资源管理器工具栏的过滤图标，选择显示的文件夹，还能独立切换是否隐藏包含特定文本的文件和文件夹。可在设置中启用或禁用名称过滤选项，并修改过滤文本。也可通过命令面板操作。
