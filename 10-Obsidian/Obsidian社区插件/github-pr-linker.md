## 概述

### GitHub PR Linker插件总结
1. **主要功能**：将GitHub拉取请求（PR）引用转换为Markdown链接。支持多种格式，如`repo#123`、`owner/repo#123`等。
2. **适用场景**：适用于在Obsidian笔记中记录GitHub PR相关信息时，需要快速将引用转换为可点击链接的场景，方便开发者查阅PR详情。
3. **核心特色**：
    - 支持多种PR引用格式，能满足不同的书写习惯。
    - 可配置默认GitHub所有者，方便处理无所有者的引用。
    - 提供“Owner in link label”设置，灵活控制链接标签是否显示所有者信息。
4. **使用建议**：
    - 先在插件设置中配置默认GitHub所有者。
    - 书写PR引用后，选中该引用，运行“Link GitHub pull request”命令进行转换。
    - 若未选中内容、选中内容格式不支持或无默认所有者配置，插件会给出提示且不改变文本。
