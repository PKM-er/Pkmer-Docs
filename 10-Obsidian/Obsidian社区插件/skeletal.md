## 概述

### 插件名称
Skeletal

### 主要功能
作为可搜索的 Markdown 模式库，提供 47 个可配置模板，涵盖 12 个类别。支持模板搜索、分类筛选，有收藏和最近使用功能。可对模板进行数据驱动式配置，提供原始 Markdown 和渲染后预览。能在光标处插入内容、复制 Markdown 或创建新笔记，还具备可管理的任务进度条，支持手动和自动更新。

### 适用场景
适用于需要快速生成各类 Markdown 内容结构的用户，如撰写笔记、文档等场景。

### 核心特色
模板丰富且可配置，无需构建新 UI 即可添加新模板；有多种预览和操作方式；进度条管理方便，能根据任务复选框自动重新计算。

### 使用建议
可通过手动从 GitHub 发布版下载文件安装，或从源代码构建安装。使用时，可先在模板浏览器中搜索合适模板，利用表单控件自定义结构，预览满意后插入到笔记中。
