## 概述

**主要功能**
CardHomeTab 将单个 Markdown 笔记转化为 Obsidian 的起始页。它通过标题自动拆分笔记内容，利用 Obsidian 原生渲染器将各部分渲染为独立卡片，支持模糊搜索、书签及最近文件访问。

**适用场景**
适用于希望打造高度个性化、模块化个人仪表盘的用户，特别是需要整合 Dataview、Base 块、代码块及图片等多类型内容，并追求视觉统一性的知识库管理者。

**核心特色**
1. **原生渲染**：内容基于真实笔记，支持相对路径链接及嵌入资源，兼容 Dataview 等插件。
2. **灵活定制**：每张卡片可通过 `%%card: %%` 注释独立配置 CSS、图标及列宽；全局支持表格斑马纹等样式。
3. **交互体验**：支持拖拽排序卡片，编辑笔记时卡片实时同步更新；界面支持深浅色模式及背景模糊效果。
4. **跨平台**：基于公共 API 开发，兼容移动端与桌面端。

**使用建议**
建议将仪表盘内容集中存放在单一笔记中，通过不同级别的标题划分卡片区域。利用原生注释语法为特定卡片添加个性化 CSS 片段以增强视觉效果。注意该插件界面目前仅支持中文，且移动端因触摸限制无法直接操作卡片的设置、编辑或删除功能，建议主要在桌面端进行卡片管理。
