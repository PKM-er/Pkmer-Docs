## 概述

**1. 主要功能**
该插件在 Obsidian 侧边栏添加图标，提供手动触发的 Pull（拉取）和 Push（推送）菜单，实现笔记与 GitHub 仓库的同步。

**2. 适用场景**
适用于希望将 Obsidian 笔记备份至 GitHub 的用户，特别是需要在一个 Git 仓库中管理多个 Vault，或偏好手动控制同步时机、避免自动同步干扰的用户。

**3. 核心特色**
*   **手动控制**：非自动同步，用户完全掌控拉取和推送的时机。
*   **灵活仓库定位**：自动向上查找最近的 `.git` 目录，支持单仓库管理多 Vault。
*   **文件筛选**：提供简洁 UI，允许用户选择具体哪些文件进行提交和推送。
*   **简化流程**：仅使用 `main` 分支，降低操作复杂度。

**4. 使用建议**
*   确保本地目录结构正确，插件能定位到 `.git` 文件。
*   初次使用建议通过设置向导配置。
*   由于是手动同步，养成定期点击图标检查更新或推送的习惯，以防数据丢失。
*   注意该插件未经 Obsidian 官方人工审核，使用前请自行备份重要数据。
