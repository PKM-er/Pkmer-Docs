## 概述

**Mercurio Git Sync** 是一款专为 Obsidian 桌面端设计的 Git 同步插件，旨在让用户无需在终端中输入凭据即可管理 Vault 的版本控制。

**主要功能**：提供 Commit、Pull、Push 及一键 Sync 等核心命令，支持自定义提交信息、中止合并及初始化仓库。

**适用场景**：适用于需要在 Windows、macOS 或 Linux 环境下对 Obsidian 笔记库进行多设备同步、自动备份及版本管理的用户。

**核心特色**：
1. **零交互凭据**：依赖 SSH 或系统凭据助手，全程无需手动输入密码。
2. **可视化面板**：右侧边栏显示修改文件列表及操作按钮，状态栏实时显示变更数量。
3. **安全机制**：拉取冲突时明确提示并停止操作，不自动解决冲突；支持可选的启动时拉取及定时自动备份。
4. **配置简便**：远程 URL 和作者信息直接在设置中配置，无需终端操作。

**使用建议**：
1. 确保已安装 Git（推荐 2.28+）并配置好 SSH 密钥或凭据助手。
2. 首次使用建议通过“Initialize repository”初始化仓库，并在设置中配置远程地址。
3. 建议开启“自动备份”功能以增强数据安全，注意该插件仅支持桌面端，移动端无法使用。
