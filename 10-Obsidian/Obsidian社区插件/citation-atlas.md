## 概述

**插件名称**：Citation Atlas

**主要功能**
该插件将 Zotero 文献库导出为 Obsidian 原生的 `.canvas` 可视化文献地图。用户可选择特定条目、集合或作者，插件会生成包含论文节点、引用连线及集合容器的画布文件。

**适用场景**
适用于需要梳理文献脉络、构建知识图谱的研究者。特别适合在 Zotero 中管理大量文献，并希望以直观图形方式回顾阅读进度、发现引用关系或进行文献聚类分析的场景。

**核心特色**
1. **原生兼容**：生成的 JSON Canvas 文件完全兼容 Obsidian，支持手动拖拽、标注和重新布局。
2. **智能映射**：自动将论文转化为时间排序的卡片，引用关系转化为带方向的箭头（新引旧），集合转化为可嵌套的容器框。
3. **状态可视化**：通过颜色区分“已读”、“未读”和“已标注”状态，直观反映阅读进度。
4. **安全离线**：仅通过 Zotero 本地 API 读取数据，无需 API 密钥，不修改数据库，确保数据安全。

**使用建议**
需确保 Zotero 7+ 正在运行。建议先整理好 Zotero 中的集合结构，以便导出时生成清晰的容器分组。导出后，可直接在 Obsidian 中对画布进行二次编辑，如添加个人笔记或调整布局，以深化文献管理体验。
