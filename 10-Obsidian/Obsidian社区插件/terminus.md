## 概述

### Terminus 插件总结
1. **主要功能**：在 Obsidian 内提供真实终端，支持 shell 集成，有新手友好的命令帮助。可与 Claude Code 协作，编辑文件后能展示详细变更，支持立即保存文件并后续审查修改，还可选择撤销。
2. **适用场景**：适用于需要在 Obsidian 中使用终端执行命令、借助 Claude Code 进行文件编辑及审查的场景。
3. **核心特色**：一是命令执行失败时，无需离开终端处理，点击失败命令旁的徽章，Claude 会结合上下文解释原因并提供修复建议；二是编辑完成后，所有变更文件集中在待处理变更面板，显示逐行差异，可直接接受、拒绝或打开文件。此外，支持真实的 PTY 终端、多终端并发，可对终端重命名和配色。
4. **使用建议**：可充分利用命令帮助功能解决执行问题，借助待处理变更面板高效审查文件修改，根据需求打开多个终端并进行个性化设置。
