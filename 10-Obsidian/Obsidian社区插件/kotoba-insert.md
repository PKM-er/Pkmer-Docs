## 概述

**1. 主要功能**
Kotoba Insert 允许用户在 Obsidian 中本地查询日语词汇（基于 JMdict 离线词典），并将选定的词义、释义及振假名以可配置的 Markdown 模板形式插入笔记。此外，它支持通过 OpenAI 兼容的 AI API 生成并插入自定义内容。

**2. 适用场景**
适用于日语学习者或语言爱好者，需要在笔记中快速记录生词、构建词汇库，或利用 AI 辅助生成特定格式的语言学习材料时。

**3. 核心特色**
- **本地离线查询**：无需联网即可快速搜索完整或部分日语形式、读音及变体。
- **智能振假名渲染**：内置振假名渲染功能，无需额外插件。若词典提供精确对齐，则显示分段振假名（如 `{食|た}べる`），否则自动回退至整体读音。
- **灵活模板与 AI 集成**：支持自定义 Markdown 模板插入，并可配置任意兼容 Chat Completions API 的 AI 服务，API 密钥通过 Obsidian SecretStorage 安全存储。

**4. 使用建议**
首先需在设置中安装词典数据。建议将命令添加到移动设备工具栏或命令面板以便快速调用。使用时，搜索目标词汇，选择具体义项和模板，即可在光标处插入结果。若使用 AI 功能，请预先配置好 API 地址、模型及提示词文件夹。
