## 概述

Planning Dashboard 允许你在 Obsidian 笔记中直接创建可编辑的项目阶段、季节性时间线和规划看板。它通过嵌入代码块的方式，将原本分散的日程安排整合为可视化的本地规划界面，无需依赖外部网页服务即可在库内完成时间管理。

典型场景包括制定年度学习计划或管理多阶段项目。例如，你可以使用 `planning-overview` 代码块在笔记中生成一个总览面板，直观展示当前所处的项目阶段；或者利用 `planning-season-map` 来映射不同季节的任务分布，帮助理清长期规划与短期执行的节奏。

该插件的一个显著特色是支持可选的 TickTick 同步功能。通过配置 API 令牌，它能读取 TickTick 中的日程数据，实现任务管理工具与笔记库的联动。此外，它提供了多种代码块类型，如 `planning-nearest-phases`，能自动聚焦于临近的阶段，减少手动筛选信息的负担，让规划视图更贴合当前工作重心。

需要注意的是，TickTick 同步功能需要用户自行提供 API 令牌，且该插件目前未经过 Obsidian 官方人工审核。如果你主要依赖复杂的甘特图依赖关系分析，或者需要多人实时协作编辑同一份规划文档，此插件可能无法满足需求，因为它侧重于个人本地的静态或半动态展示，而非复杂的工程级项目管理。
