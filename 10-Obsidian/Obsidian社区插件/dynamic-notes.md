## 概述

### 《Dynamic Notes插件总结》
1. **主要功能**：可在任意笔记中按小的本地工作流程移动结构化 Markdown 块，支持将块在“Now -> Done”“Later -> Now”区域间移动。提供“验证当前笔记”“推进”功能，“推进”可将当前 Now 块移至 Done 并提升首个 Later 块。
2. **适用场景**：适用于项目工作流、流程和清单、学习序列、维护例程、每日笔记等场景，能引导任务推进。
3. **核心特色**：以 Markdown 为唯一依据，无隐藏状态和网络依赖；改动后的 Markdown 可读、可同步、可版本管理；“推进”命令在阅读和编辑视图可用，编辑视图操作可一键撤销；使用官方 API，无 Node.js 或 Electron 运行时依赖，支持移动端。
4. **使用建议**：笔记采用特定 Markdown 格式，通过前置元数据开启功能，并按顺序设置 Now、Later 和 Done 区域。
