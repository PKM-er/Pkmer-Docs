## 概述

### 插件名称
aulycKanban

### 主要功能
支持动态创建、重命名和删除任务类型与象限；可对任务进行编辑、归档、恢复、排序、批量删除等操作；具备全局搜索和归档筛选功能；自动为每个任务类型和存档生成 Markdown 镜像；能自动保存插件数据；支持选择界面语言。

### 适用场景
适用于需要管理多类型任务，且希望在 Obsidian 中以看板形式清晰组织任务的用户，如办公场景管理工作任务、个人生活管理日常事务等。

### 核心特色
轻量且清晰地管理多任务类型，所有任务类型共享一套象限结构，同时各任务类型保存独立任务内容；支持 Markdown 同步；可选择界面语言。

### 使用建议
经社区审核后，可从 Obsidian 社区插件目录安装和更新。手动安装需从匹配的 GitHub Release 下载相应文件，放入指定文件夹。该插件无自动更新检查等功能，运行时不与发布服务通信，数据都保留在当前库中。
