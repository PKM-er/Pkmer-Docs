## 概述

**1. 主要功能**
该插件将 Markdown 中的 `ugougo` 代码块渲染为具有90年代复古电视风格（类似《ウゴウゴルーガ》）的抖动文字动画。支持自定义字体、大小、颜色及代码高亮，实现纯视觉特效。

**2. 适用场景**
适用于在 Obsidian 笔记中制作趣味标题、动态强调文本，或用于生成 HTML 幻灯片、Marp 演示文稿以及 VS Code 预览中的动态视觉元素。

**3. 核心特色**
- **零 JS 依赖**：仅使用 SVG 和 CSS 实现动画，无需 JavaScript，因此兼容性强，可轻松导出至多种环境。
- **多端通用**：同一套代码可在 Obsidian、HTML 导出、Marp 及 VS Code 中一致运行。
- **手动安装**：目前未上架官方插件商店，需通过 Node.js 构建后手动部署文件。

**4. 使用建议**
- 需具备 Node.js 环境以执行 `npm run build` 生成插件文件。
- 安装后需关闭 Obsidian 的“受限模式”并重启应用。
- 建议在代码块中指定等宽字体（如 Courier New）以获得最佳的代码动画效果。
- 注意：此为个人非官方项目，与富士电视台无关联。
