## 概述

**主要功能**
该插件在 Obsidian 文件浏览器中为文件夹、笔记及其他文件添加可视化图标。它区分打开与关闭的文件夹，为 Markdown 笔记显示折角页面图标，并为 PDF、画布、图片等其他文件显示代码符号图标。

**适用场景**
适用于希望提升文件浏览效率、快速通过视觉识别文件类型及状态（如文件夹是否展开）的用户，特别适合拥有大量不同格式文件的知识库管理。

**核心特色**
1. **轻量级实现**：仅通过 CSS 绘制图标，不修改文件浏览器核心结构，性能开销极低。
2. **灵活配色**：支持跟随主题（深色/浅色）、使用强调色或自定义颜色，并能自动随主题切换。
3. **插件兼容**：可与“Colored File Names”插件联动，使文件夹图标继承其颜色设置，保持视觉一致性。

**使用建议**
建议开启“Open folders”选项以区分展开状态，提升导航直观性。若使用深色主题，推荐选择“Match theme”模式以获得最佳对比度；若追求个性化，可尝试自定义颜色。该插件无需复杂配置，安装后即可生效，适合追求简洁高效工作流的笔记用户。
