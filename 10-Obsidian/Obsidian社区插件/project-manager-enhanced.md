## 概述

**Project Manager Enhanced** 是一款基于 Project Manager 1.8.0 的 Obsidian 增强版项目管理插件，支持 ZenTao 字段、虚拟化视图及可组合过滤器。

**主要功能**：在 Obsidian 库内提供完整的项目管理功能，包括表格、甘特图、看板三种视图，支持自定义字段、状态、优先级、时间追踪、依赖关系、里程碑及智能调度。

**适用场景**：适合希望在本地 Markdown 文件中管理个人项目、任务列表或团队轻量级协作的用户，尤其适合注重数据隐私、离线工作且不愿依赖云服务的人群。

**核心特色**：
1. **纯文本存储**：数据以带 YAML 前置信息的 `.md` 文件形式保存，便携、可搜索、支持版本控制，无供应商锁定。
2. **多视图切换**：同一数据源支持表格、甘特图、看板自由切换，满足不同管理视角需求。
3. **高度可定制**：支持保存自定义筛选/排序组合为命名视图，灵活适配个人工作流。
4. **完全离线**：无需账号、API 或云端同步，数据完全掌握在用户手中。

**使用建议**：建议先熟悉基础表格视图进行任务录入，再根据需求启用甘特图查看时间线或看板管理状态流转。利用“保存视图”功能预设常用筛选条件，提升日常操作效率。注意该插件为社区 Fork 版本，未通过 Obsidian 官方人工审核，使用前建议备份数据。
