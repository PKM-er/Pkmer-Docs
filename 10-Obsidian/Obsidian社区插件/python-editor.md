## 概述

**主要功能**
Python Editor 是一款基于 CodeMirror 6 的 Obsidian 插件，专为查看和编辑 `.py` 及 `.pyi` 文件设计。它提供行号显示、Python 语法高亮、代码折叠、括号匹配以及撤销/重做功能。插件内置可导航的代码大纲，支持快速定位类、函数、方法及 `__main__` 入口点。此外，它兼容 Obsidian 的搜索（Ctrl/Cmd+F）和替换（Ctrl/Cmd+H）快捷键，并支持自动保存。

**适用场景**
适合需要在 Obsidian 笔记库中直接阅读、修改或维护 Python 源代码的用户，特别是那些希望将代码片段与文档笔记整合在同一工作流中的开发者。

**核心特色**
1. **结构导航**：提供可配置的代码大纲（左/右/隐藏），便于快速浏览代码结构。
2. **原生体验**：深度集成 Obsidian 的保存生命周期，操作流畅且符合 Obsidian 界面风格。
3. **跨平台兼容**：纯文本编辑实现，不依赖 Node.js 或 Electron API，完美支持移动端。
4. **安全性**：仅作为文本编辑器运行，绝不执行 Python 代码，确保环境安全。

**使用建议**
安装后，建议根据屏幕大小调整大纲位置（右侧或左侧）以提升浏览效率。由于插件不执行代码，若需运行脚本，请配合外部终端使用。注意该插件尚未经过 Obsidian 官方人工审查，建议在非关键数据备份后尝试。
