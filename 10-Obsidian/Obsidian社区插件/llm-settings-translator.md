## 概述

**LLM Settings Translator** 是一款利用 OpenAI 兼容大语言模型自动翻译 Obsidian 插件设置界面文本的工具。

**主要功能**：自动将设置弹窗内的标签、描述及按钮等英文文本实时翻译为目标语言（默认简体中文），支持自定义端点、模型及 API Key，并提供连接测试功能。

**适用场景**：适用于希望以母语阅读英文插件设置项的用户，支持桌面端及 iOS/Android 移动端，兼容本地模型（如 Ollama）及各类云端服务。

**核心特色**：
1. **全自动无感**：打开设置约 2 秒后自动生效，无需手动点击。
2. **零侵入性**：仅修改当前 UI 会话显示，绝不改动插件源码或笔记内容。
3. **高效缓存**：翻译结果持久化存储，重复打开不消耗 Token，支持多语言独立缓存。
4. **透明可控**：实时显示 Token 用量，支持手动触发重新翻译及弹出窗口模式。

**使用建议**：请配置有效的 OpenAI 兼容 API 端点（如 DeepSeek、Kimi 或本地 Ollama）。若需即时刷新，可点击左侧丝带图标或设置中的“测试翻译”按钮。注意该插件未通过官方人工审查，请确保 API 密钥安全。
