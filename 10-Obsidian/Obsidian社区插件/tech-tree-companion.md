## 概述

**主要功能**
Tech Tree Companion 是一款 Excalidraw 的独立伴侣插件，用于在 Obsidian 中创建和管理 SVG 技术卡片。它支持卡片模板管理、节点间连线绘制，以及直接编辑与卡片关联的 Markdown 笔记详情。

**适用场景**
适用于需要构建技术树、知识图谱或项目依赖关系的用户。特别适合在 Excalidraw 画布中，将可视化节点与具体的 Markdown 文档内容深度绑定，实现“图-文”一体化的知识管理。

**核心特色**
1. **深度集成**：直接嵌入 Excalidraw 环境，支持在画布内实时编辑关联笔记，双击阅读文本可进入原位编辑器。
2. **模板化**：提供卡片模板功能，快速统一节点样式。
3. **强关联性**：支持链接特定 Markdown 标题，实现精准的内容映射。
4. **轻量化**：无需额外 runtime 目录，依赖项嵌入主文件，安装简单。

**使用建议**
1. **环境要求**：仅支持桌面端（Windows 11 已测试），需 Obsidian 1.13.7+ 及 Excalidraw 2.25.3+。
2. **安装注意**：手动安装时需将 `main.js` 等三个文件放入插件目录。
3. **数据备份**：升级插件前，务必备份 `data.json`、字体缓存及生成的卡片附件，以防数据丢失。
4. **版本监控**：由于依赖 Excalidraw 运行时 API，上游更新可能导致兼容性问题，需关注插件更新。
