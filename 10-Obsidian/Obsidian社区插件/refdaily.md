## 概述

**1. 主要功能**
RefDaily 插件可将 RefDaily 服务中的学术论文、每日摘要及研究报告同步至 Obsidian 库，并自动转换为标准的 Markdown 笔记。每篇论文生成独立笔记，包含标题、作者、摘要、AI 总结及来源链接。

**2. 适用场景**
适合需要持续追踪特定研究主题最新文献的科研人员、研究生或知识工作者，尤其是希望将外部文献管理与个人笔记体系无缝整合的用户。

**3. 核心特色**
*   **数据主权**：笔记为纯 Markdown 格式并附带 YAML 元数据，不依赖插件即可使用，兼容 Dataview、图谱视图及自定义模板。
*   **智能去重**：基于 DOI 或 ID 匹配，重复同步时仅更新内容而非创建副本，手动重命名笔记也不会导致链接失效。
*   **灵活配置**：支持自定义各类笔记的存储文件夹，提供手动同步与自动定时同步选项。

**4. 使用建议**
需先在 RefDaily 官网生成 API Token 并在插件设置中填入。建议根据研究习惯规划文件夹结构，利用 YAML 字段配合 Dataview 插件构建动态文献看板。免费账户即可使用，无需付费功能。
