## 概述

**1. 主要功能**
该插件允许用户在 Obsidian 笔记中插入自定义样式的按钮。支持上传动态图标（GIF、APNG、WebP），并可独立控制按钮的背景色、文字色、边框、圆角、字体大小及图标尺寸。按钮可触发 Obsidian 内部命令或打开指定 URL。

**2. 适用场景**
适用于需要快速导航、执行常用操作或美化文档交互的场景。例如，在个人主页或知识库首页创建“快速访问”面板，或在特定笔记中嵌入操作指南按钮，提升笔记的交互性和视觉吸引力。

**3. 核心特色**
*   **高度自定义**：通过 JSON 代码块定义样式，灵活调整颜色、动画（如脉冲、弹跳、发光等）及布局。
*   **样式隔离**：图标样式紧密作用域，防止被主题默认的边框、阴影或内边距干扰，确保视觉一致性。
*   **动态支持**：原生支持动画图标，无需额外 CSS 即可保留动画效果。
*   **按钮行功能**：内置 CSS 支持将多个按钮排列成行，无需额外安装 CSS 片段。

**4. 使用建议**
*   安装后需在设置中上传图标文件，再通过命令面板插入按钮。
*   插入的按钮本质是 JSON 代码块，可直接手动编辑以批量修改或复用配置。
*   建议在阅读视图或实时预览模式下查看最终渲染效果，以确保样式符合预期。
