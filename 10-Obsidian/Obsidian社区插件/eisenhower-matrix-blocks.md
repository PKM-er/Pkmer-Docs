## 概述

### Eisenhower Matrix Blocks 插件总结
1. **主要功能**：可在 Markdown 笔记中嵌入独立、可编辑的艾森豪威尔矩阵任务板，能插入四象限任务板，就地完成任务，并保存可过滤的任务历史记录。
2. **适用场景**：适用于使用 Obsidian 做笔记，且需要对任务进行优先级管理和规划的场景，能帮助用户清晰区分任务的重要性和紧急程度。
3. **核心特色**：
    - 每个笔记内的矩阵独立，拥有自己的任务和完成历史，一个笔记可包含多个矩阵。
    - 基于 Markdown，任务、象限、排序和完成时间可通过 Obsidian Sync、Remotely Save 或 Git 同步。
    - 具备完整工作流，无需离开矩阵即可添加、编辑、移动、完成、恢复、删除和过滤任务。
4. **使用建议**：安装插件后，在编辑器光标处插入矩阵，即可开始使用，利用其功能对任务进行有效管理。
