## 概述

**1. 主要功能**
Activity Timeline 插件将 Vault 中的所有活动转化为可视化时间线。它自动记录笔记的创建与编辑、任务的完成与废弃、剪藏（Capture）及 Canvas 文件变更。支持按日、周、月、年切换视图，并提供基于 Git 的历史数据重建功能，确保即使 Obsidian 未运行期间的修改也能被追溯。

**2. 适用场景**
适用于需要回顾工作流、追踪知识积累过程的用户。特别适合重度 Git 用户，用于审计 Vault 的长期变化；也适合希望量化每日产出、通过热力图分析活跃规律的知识管理者。

**3. 核心特色**
*   **Git 深度集成**：从提交记录重建完整历史，覆盖所有设备与工具的操作。
*   **智能聚合**：30分钟内的同一笔记编辑合并为单一事件，避免信息噪音。
*   **精准定位**：点击事件卡片可直接跳转至笔记中具体修改的行，支持分屏打开。
*   **多维筛选**：支持按文件类型（笔记、任务、Canvas等）和文件夹过滤，并附带类型统计计数。

**4. 使用建议**
建议开启 Git 版本控制以解锁完整历史回溯功能。利用“热力图”检查每日点击习惯，优化工作节奏。通过“类型统计”定期复盘，平衡笔记编写与任务管理的比例。注意该插件尚未经过官方人工审核，使用前请确认 Vault 已纳入 Git 管理。
