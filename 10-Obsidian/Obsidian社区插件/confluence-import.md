## 概述

### Confluence Page Import 插件总结
1. **主要功能**：将 Confluence 页面导入为 Obsidian 本地 Markdown 笔记，手动单向导入，内容仅从 Confluence 流向本地库，不向 Confluence 写入。导入前有只读差异预览，可选择“拉取并替换”或“取消（保留本地）”。插件内部完成从 Confluence 存储格式到 Markdown 的转换，无需外部工具。
2. **适用场景**：适用于在 Obsidian 记工作笔记但团队文档存于 Confluence 的技术团队；需要本地可搜索、离线可读的常用 Confluence 页面 Markdown 副本的知识工作者；需要验证安全工具的企业评估人员。
3. **核心特色**：手动从 Confluence 导入，用户触发同步，不自动后台同步；单向拉取，不修改 Confluence 页面；能检测 Confluence 页面与本地笔记的差异。
4. **使用建议**：若需将笔记发布到 Confluence，该插件不适用，可参考 [docs/COMPARISON.md] 寻找替代工作流。
