## 概述

### Siltflow Importer插件总结
1. **主要功能**：将Siltflow语言学习的SQLite数据库导入到Obsidian库中，转化为带有双语AI注释卡片的Markdown笔记。支持增量同步，仅更新有变化的注释，还能按类型过滤，如只包含单词、短语或句子。
2. **适用场景**：适合使用Siltflow进行语言学习，且希望将学习数据整合到Obsidian进行管理和查看的用户。
3. **核心特色**：可通过点击丝带图标或运行命令实现同步，生成结构化笔记，每个文档对应一条笔记，每条注释都配有AI总结和标注卡片；数据处理完全本地进行，不上传数据，保障隐私。
4. **使用建议**：可从社区市场安装，也可从发布页面复制相关文件到指定目录；需Obsidian 1.13+桌面版；若要本地构建，可执行 `npm install && npm run build`。
