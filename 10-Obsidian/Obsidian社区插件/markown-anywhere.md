## 概述

**Markown Anywhere** 是一款专为 Windows 用户设计的 Obsidian 插件，旨在实现从系统任意位置直接通过 Obsidian 打开 Markdown 文件。

1. **主要功能**：通过 Go 编写的 Windows 伴侣程序处理文件关联，将外部 Markdown 文件以符号链接形式映射至 Vault 内的 `_external-open/` 目录，实现无缝路由与打开，同时支持链接清理与 URI 启动。
2. **适用场景**：适用于需要在 Windows 系统中频繁处理散落在各处的 Markdown 文件，并希望统一在 Obsidian 中管理和编辑的用户。
3. **核心特色**：采用“插件+伴侣程序”架构，插件仅负责设置管理，核心逻辑由独立可执行文件处理，避免性能瓶颈；严格遵循隐私原则，不复制文件内容、不上传数据、无遥测收集。
4. **使用建议**：需手动安装 Windows 伴侣程序并配置路径；建议通过 BRAT 进行 Beta 测试或从 GitHub Release 获取最新资源；注意同步更新 `manifest.json` 等配置文件以确保版本一致。
