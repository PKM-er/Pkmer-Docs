## 概述

**1. 主要功能**
Web Search Menu 允许用户通过右键菜单或命令面板，直接对选中的文本或笔记标题发起网络搜索。它支持自定义搜索引擎，并能自动清理 Markdown 语法（如链接、加粗、高亮等），确保搜索内容纯净。

**2. 适用场景**
适用于需要在笔记中快速验证信息、查找参考资料或进行学术研究的场景。特别适合在写作过程中，针对特定术语或概念即时搜索外部资料，无需手动复制粘贴到浏览器。

**3. 核心特色**
*   **高度可定制**：内置 Google、DuckDuckGo、Wikipedia 等引擎，支持通过设置添加任意自定义搜索 URL（如 GitHub、地图等）。
*   **智能文本清洗**：自动提取 `[[Note|alias]]` 中的别名，并移除格式标记，提升搜索准确率。
*   **隐私安全**：插件本身不传输数据，仅在浏览器中打开搜索链接，由所选搜索引擎处理查询。
*   **操作灵活**：支持右键菜单、命令面板及快捷键触发，可配置默认引擎及菜单显示数量。

**4. 使用建议**
建议在设置中配置常用的 2-3 个引擎，并将第一个设为默认引擎以提高效率。对于阅读视图，由于无右键菜单，请优先使用命令面板进行搜索。自定义引擎时，务必在 URL 中使用 `{query}` 占位符以正确传递搜索词。
