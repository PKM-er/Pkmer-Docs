## 概述

**1. 主要功能**
该插件利用 TypeSafe 的 Jev AI 模型，对当前活跃的 Obsidian 笔记进行智能分类，并自动将其移动至用户预设的指定文件夹。支持“撤销”最近一次移动操作，并将模糊分类结果自动归入“待审核”文件夹。

**2. 适用场景**
适用于桌面端 Obsidian 用户，特别是那些拥有 TypeSafe API 密钥、希望利用 AI 辅助管理大量 Markdown 笔记结构，实现自动化归档和知识库整理的场景。

**3. 核心特色**
*   **自定义分类体系**：通过复选框选择目标文件夹并自定义描述，Jev 仅从该封闭列表中分类。
*   **安全机制**：保留原文件名，绝不故意覆盖现有文件；支持会话内撤销。
*   **隐私与成本**：插件本身免费（MIT协议），但需自备 TypeSafe API 密钥，API 调用可能产生额外费用。
*   **局限性**：目前仅支持桌面端，界面暂为西班牙语，无后台批量处理或自动打标签功能。

**4. 使用建议**
*   确保 Obsidian 版本在 1.11.4 以上，并配置好有效的 TypeSafe API 密钥。
*   首次使用时，建议仔细编写各文件夹的描述，以提高 AI 分类的准确性。
*   鉴于早期发布且界面为西班牙语，建议熟悉基本西班牙语或参考英文文档操作。
*   注意 API 调用成本，避免频繁对无关笔记执行分类操作。
