## 概述

### Resojot 应声记插件总结
1. **主要功能**：支持在 Obsidian 中快捷录音，可自动保存音频与笔记；能将音频转写为文本，支持本地或云端 ASR；可对转写文本进行 AI 润色，自动提取标题与待办事项，还支持录音实时转写。
2. **适用场景**：适用于需要快速记录灵感、会议内容、学习资料等场景，可将语音内容快速转化为结构化的 Markdown 笔记。
3. **核心特色**：具备自动处理流程，从录音到转写、润色等可按设置自动完成；支持多种录音启动方式，如快捷键、命令、URL 快捷指令等；可自动结构化存储，音频与笔记位置、命名等可灵活设置；支持多服务配置，当前服务失败可尝试其他服务。
4. **使用建议**：先在知识库了解部署和免费 API 指南；遇到问题可在 GitHub Issues 反馈；获取授权码等可在小红书搜索“焦应行”。
