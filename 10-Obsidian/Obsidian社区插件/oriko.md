## 概述

**Oriko 插件中文总结**

**1. 主要功能**
Oriko 将网页剪藏转化为可视化的“图片墙”。它自动下载网页中的图片和视频至本地附件文件夹，并生成 Markdown 笔记，确保即使源网页失效（链接腐烂），内容依然永久保存。

**2. 适用场景**
适合需要大量保存网页灵感、文章、漫画或视频素材的用户。特别适用于构建个人知识库、收集设计灵感、归档参考图片，或管理大量多媒体剪藏内容的场景。

**3. 核心特色**
*   **可视化布局**：提供可平移、缩放的瀑布流（Masonry）视图，直观浏览所有剪藏。
*   **本地化存储**：自动下载媒体文件，解决外链失效问题，数据完全本地化。
*   **纯 Markdown 兼容**：剪藏本质为普通 Markdown 笔记，不依赖插件也能正常阅读和编辑。
*   **便捷操作**：支持在墙上直接粘贴链接、拖拽图片/视频，或通过命令面板从剪贴板快速剪藏。

**4. 使用建议**
建议指定专用的剪藏文件夹和附件文件夹，以便插件自动管理文件结构。利用其可视化特性定期回顾灵感墙，发现内容关联。由于插件免费且由个人开发，若觉得有用，可考虑通过 GitHub 赞助支持作者持续维护。
