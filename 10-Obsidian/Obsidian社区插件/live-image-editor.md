## 概述

**主要功能**
Live Image Editor 是一款非破坏性图像编辑插件。支持裁剪、旋转、翻转、缩放及应用 CSS 滤镜（如亮度、对比度、模糊等）。所有编辑仅通过修改 Markdown 属性块实现，原始图片文件保持不变，且支持将编辑结果导出为新文件。

**适用场景**
适用于需要在 Obsidian 笔记中快速调整图片布局、美化视觉效果或统一图片尺寸的场景。特别适合经常处理照片、截图或图表，且希望保持源文件纯净的用户。

**核心特色**
1. **非破坏性编辑**：编辑数据以标准 Markdown 属性形式存储，兼容 MkDocs 等外部工具，移除插件后图片仍正常显示。
2. **实时交互**：点击图片即唤起工具栏，支持自由旋转裁剪、实时直方图反馈及一键滤镜预设（如复古、黑白）。
3. **灵活集成**：自动识别 Vault 中的 CSS 类，支持行内/块级切换，并可集成 Editing Toolbar 插件。

**使用建议**
建议用户在调整图片时优先使用该插件而非外部编辑器，以保留原始画质。利用“导出”功能可将最终效果固化为新图片，便于分享或归档。注意该插件未经官方人工审核，使用前请备份重要数据。
