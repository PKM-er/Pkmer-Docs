## 概述

**1. 主要功能**
该插件为 Obsidian 的 Base（数据库视图）功能提供“源码模式”。用户无需离开 Obsidian，即可直接以纯文本 YAML 格式编辑 Base 的底层配置，支持完整的搜索与替换功能（含大小写敏感），并具备主题感知的 YAML 语法高亮。

**2. 适用场景**
适用于需要精细调整 Base 配置、进行批量修改或修复 Base 视图错误的场景。特别适合高级用户或开发者，当图形界面无法满足复杂逻辑配置需求时，可直接操作底层数据。

**3. 核心特色**
*   **无缝集成**：在 Obsidian 内部直接编辑，无需外部编辑器。
*   **原生体验**：搜索/替换操作与原生 Markdown 笔记一致，支持命令面板调用。
*   **视觉友好**：利用 Obsidian CSS 变量实现语法高亮，适配当前主题。
*   **全平台支持**：完美兼容移动端。

**4. 使用建议**
通过命令面板执行“Toggle source mode”或点击 Base 视图中的切换按钮进入源码模式。建议在修改前备份数据，因为直接编辑 YAML 可能导致格式错误。安装后可参考 Roadmap 了解后续功能规划。
