## 概述

Bases View Tabs 旨在解决 Obsidian Bases 核心插件中视图切换不够直观的问题。它会在 Base 文件工具栏下方生成一个可视化的标签页条，将已保存的视图名称直接展示出来。用户只需点击对应的标签，即可一键切换当前视图，无需反复打开原生菜单查找。该插件仅负责视图的选中与展示，不会修改 Base 文件本身，也不会创建额外的表格副本，确保数据管理的纯粹性。

典型场景适用于需要频繁对比不同状态的任务管理。例如，在一个任务 Base 中，你可以同时看到“所有任务”、“进行中”和“已完成”三个视图。通过标签页，你能快速在“进行中”和“已完成”之间切换，直观地检查任务流转情况。此外，如果你习惯使用键盘操作，该插件支持完整的键盘导航：通过 Tab 键聚焦标签条，使用左右方向键移动焦点，按 Enter 或 Space 确认选择，极大提升了纯键盘工作流的效率。

相比同类插件，Bases View Tabs 的最大特色在于“零配置”的自动识别。打开 Base 文件后，所有已保存视图会自动按顺序显示，无需像其他插件那样预先在设置中手动配置每个 Base 的按钮或图标。此外，它提供了免费的标签换行功能，当视图名称过长或面板较窄时，标签可以自动折行显示，避免横向滚动带来的不便。Pro 版本则额外提供视图置顶和自定义图标功能，但免费版已能满足绝大多数日常导航需求。

使用前请注意，该插件仅支持独立的 Base 面板，嵌入在笔记中的 Base 代码块不会显示标签条。如果你的 Base 文件存在无效的 YAML 格式或重复的视图名称，标签条将自动隐藏以防止误操作，此时需使用原生菜单修正。此外，该插件不包含移动端的外观编辑器，且视图重命名后需重新设置置顶或图标偏好。如果你需要高度自定义的按钮样式或拖拽排序功能，可能需要考虑其他替代插件。
