## 概述

### Lens OCR插件总结
1. **主要功能**：借助原生 macOS 和 Windows 系统的 OCR 功能，直接从屏幕上捕获区域并将手写笔记数字化，提取的文本会粘贴到当前活动笔记中。
2. **适用场景**：适用于 macOS Catalina（10.15）及以上版本和 Windows 10 及以上版本系统，用户需要将手写笔记快速录入到 Obsidian 笔记库时可使用。
3. **核心特色**：100% 离线使用，不依赖 AI API 或云订阅，不向外部服务器发送数据，无需联网；无额外依赖，不捆绑重型 OCR 模型和外部运行时依赖，利用现有系统库；提取的文本可直接粘贴到当前光标位置。
4. **使用建议**：先在设置的热键部分搜索 “Obsidian Lens OCR”，为 “Capture screen region and run OCR” 命令分配热键。分配完成后，按下热键，选择要进行 OCR 的屏幕区域，稍等片刻，提取的文本就会自动粘贴到活动页面。
