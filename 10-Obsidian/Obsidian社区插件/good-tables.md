## 概述

Good Tables 旨在解决 Obsidian 原生 Markdown 表格在视觉呈现上的局限性，通过增强原生表格编辑器，提供颜色标记、数值格式化、对角线表头及可逆合并单元格等核心功能。它允许用户在保持 Markdown 源码纯净的前提下，直接对表格内容进行样式化展示，无需手动编写复杂的 HTML 或 CSS 代码，让数据表格从枯燥的文本列表转变为直观、易读的可视化图表。

典型使用场景包括制作项目进度表或财务预算表。例如，你可以将日期字段自动格式化为“2026-10-24”样式，将百分比数值显示为进度条，或者利用对角线表头清晰区分行与列的维度。在需要强调重点时，你可以选中特定单元格设置背景色，或合并多个单元格以创建跨行的标题，所有操作均通过右键菜单或命令面板快速完成，极大提升了笔记中数据展示的清晰度。

相比其他仅支持基础 Markdown 的插件，Good Tables 的特色在于其“可逆性”与“原生集成”。合并单元格后，原始数据依然保留在 Markdown 源码中，取消合并即可完整恢复，不会丢失任何信息。此外，它深度融入 Obsidian 的原生编辑体验，支持标准的撤销/重做、行/列拖拽移动，且样式会随行列调整自动适配。其内置的颜色选择器支持 HEX/RGB 同步及六色收藏，方便统一文档风格，同时支持自定义前后缀格式，满足个性化展示需求。

需要注意的是，该插件目前仅支持 Obsidian 桌面端，移动端用户无法使用。它主要服务于静态展示和轻量级数据整理，不具备复杂的数据计算或数据库功能。如果你需要处理大规模动态数据、执行复杂公式运算，或者依赖移动端同步编辑，Good Tables 可能不是最佳选择。此外，虽然它支持多种数值格式，但所有格式化仅改变显示效果，不改变底层数值，适合用于阅读和汇报，而非作为专业数据分析工具。
