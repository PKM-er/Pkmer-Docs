## 概述

**1. 主要功能**
RA Search 是一款 Obsidian 插件，用于将 RetroAchievements (RA) 的游戏库导入笔记系统。它支持自动批量导入用户 RA 账号下的所有游戏，或手动添加特定游戏及子集。插件会自动生成包含游戏元数据（如封面图、成就信息等）的笔记，并创建 Obsidian Base 视图以直观展示游戏库。

**2. 适用场景**
适用于 RetroAchievements 玩家或复古游戏爱好者，希望利用 Obsidian 管理游戏收藏、追踪成就进度，或探索游戏之间的关联与主题。适合希望将分散的游戏数据整合进个人知识管理体系的用户。

**3. 核心特色**
*   **自动化导入**：一键同步 RA 账号下的全部游戏，支持跳过已存在项，避免重复。
*   **元数据丰富**：自动抓取并插入游戏封面（托管于 RA 官方媒体服务器）及相关元数据。
*   **可视化视图**：自动生成 Obsidian Base，提供类似数据库的直观浏览体验，且支持自定义。
*   **灵活管理**：支持导入子集（Subsets），并可随时取消正在进行的自动导入任务。

**4. 使用建议**
使用前需在插件设置中配置有效的 RA 用户名和 Web API Key（可在 RA 个人设置页获取）。建议先通过“Auto import”批量导入基础库，再利用“Add game”补充未游玩但感兴趣的作品。注意该插件由社区独立开发，非 RA 官方支持，请确保 API Key 安全。
