## 概述

**Canvas Sync Bridge** 是一款将 Canvas LMS 数据同步至 Obsidian 的知识管理插件。

1.  **主要功能**：自动抓取并同步 Canvas 课程、模块、作业、讨论、成绩、文件及日历，将其转化为结构清晰、相互链接的 Markdown 笔记。
2.  **适用场景**：适用于使用 Canvas 作为学习管理系统的高校师生，特别是希望将在线课程资料整合进个人知识库进行长期复习或研究的用户。
3.  **核心特色**：
    *   **双模式同步**：支持通过 Canvas REST API 直接连接（兼容移动端），或配合浏览器扩展（Chrome/Firefox）使用。
    *   **智能调度**：提供 15 分钟至 24 小时不等的后台自动同步间隔，支持多课程批量处理。
    *   **隐私安全**：零遥测设计，数据本地化处理，确保隐私安全。
4.  **使用建议**：若需移动端支持，优先配置 API Token 使用直接连接模式；若机构限制 API 访问，可安装配套浏览器扩展。建议根据课程更新频率设置合理的自动同步间隔，以保持笔记时效性。
