## 概述

**1. 主要功能**
该插件将 `:::` 围栏语法转化为可视化的 Markdown 块，使其成为 Obsidian 中粗体、高亮等行内样式的块级对应物。用户可在块内使用常规 Markdown（如列表、代码、数学公式），并支持嵌套。

**2. 适用场景**
适用于需要结构化笔记、强调特定内容（如定义、警告、示例）或制作美观 PDF 导出的场景。特别适合希望在不编写 CSS 的情况下，快速定制笔记视觉风格的进阶用户。

**3. 核心特色**
*   **样式即对象**：无需编写 CSS，直接通过界面创建、导入、导出和复用视觉风格。
*   **高度一致**：在实时预览、阅读视图、打印及 PDF 导出中保持样式统一。
*   **便捷操作**：提供 Tab 自动补全、右键菜单操作及全局应用命令，支持嵌套和 Vault 级重命名。
*   **隐私安全**：完全离线运行，无遥测、无网络请求。

**4. 使用建议**
目前为 Alpha 版本，核心语法稳定但视觉细节仍在开发中。建议先使用内置的六个预设（如 Definition, Warning）体验，再通过界面自定义颜色、边框和间距。如需复杂效果，可利用其 JSON 导入导出功能备份样式，或使用受限的高级 CSS 声明作为补充。
