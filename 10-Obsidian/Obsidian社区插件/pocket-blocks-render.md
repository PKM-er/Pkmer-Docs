## 概述

**Pocket Blocks Render** 是一款离线运行的 Obsidian 插件，主要用于在笔记中渲染 Pocket 格式的时间线、图表和流程图。

**主要功能**：支持渲染带阶段描述的时间线、柱状/折线/饼状图、带标签箭头的 SVG 流程图及决策树。它具备循环感知能力，支持全屏控制、缩放和平移，并能正确处理未知块类型。

**适用场景**：适用于需要离线查看结构化数据可视化的场景，如项目发布计划、数据分析展示或逻辑流程梳理。适合桌面端及移动端（Android 测试中）用户，要求 Obsidian 1.4.0 及以上版本。

**核心特色**：完全离线运行（内置 Chart.js），无需网络连接。渲染器处理阅读视图和 Markdown 预览中的 `<pocket:TYPE>` 标签，保持周围 Markdown 格式不变。采用确定性分层布局，清晰区分循环路径。

**使用建议**：目前需从 GitHub Releases 手动安装。请将 `main.js`、`manifest.json` 和 `styles.css` 放入 `.obsidian/plugins/pocket-blocks-render` 目录后启用。注意该插件不提供实时预览编辑器扩展，源码模式保留原始文本，建议在阅读视图或预览模式下查看渲染效果。
