## 概述

### 主要功能
Tasks Timeline 用于在 Obsidian 库中展示和管理任务项，内置 Model Context Protocol (MCP) 服务器，支持 AI 代理读写库中的任务。提供了查询、创建、更新、删除、完成、取消任务等多种操作工具，还能获取任务统计信息和今日计划。

### 适用场景
适合需要在 Obsidian 中管理任务，且希望借助 AI 辅助进行任务管理的用户。

### 核心特色
延续了 obsidian - tasks - calendar - wrapper，基于 tasks - timeline - components 构建；内置 MCP 服务器，方便 AI 接入；提供丰富的任务操作工具。

### 使用建议
先在设置中开启 MCP 服务器，可按需配置端口。将服务器地址添加到 MCP 客户端配置中，使用时注意默认开启了 bearer - token 认证，需复制令牌并在支持 HTTP MCP 头的客户端中配置认证头。
