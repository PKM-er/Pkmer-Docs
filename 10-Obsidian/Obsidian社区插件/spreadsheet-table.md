## 概述

### Spreadsheet Table 插件总结
1. **主要功能**：为 Markdown 表格提供类电子表格的编辑、公式计算和渲染功能。包括检测与编辑表格、格式化表格、导航单元格、插入或删除行列、行列移动与排序、导出表格为 CSV 等。支持实时预览和阅读模式下公式结果的渲染。
2. **适用场景**：适用于在 Obsidian 中使用 Markdown 表格进行数据记录、整理和计算的场景，如制作清单、统计数据等。
3. **核心特色**：保留 Markdown 源格式，公式在笔记中仍以公式形式存在，预览和阅读时显示计算结果；提供命令面板、右侧边栏工具栏和 Ribbon 图标操作；支持 Excel 风格的列字母和行号显示；移动端友好。
4. **使用建议**：打开含 Markdown 表格的笔记并选中单元格，可通过命令面板、右侧边栏工具栏或配置的热键执行操作。实时预览模式下，先点击渲染的单元格；源码模式下，将光标置于单元格内再使用工具栏操作。
