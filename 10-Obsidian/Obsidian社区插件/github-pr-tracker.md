## 概述

### Github PR Tracker插件总结
1. **主要功能**：在Obsidian侧边栏面板跟踪和管理GitHub拉取请求（PR），展示PR详细信息、状态、评论情况、CI状态等，支持搜索、排序、分组、固定PR等操作。
2. **适用场景**：适用于开发者在使用Obsidian记录笔记时，无需切换界面就能随时关注GitHub上的PR审查情况。
3. **核心特色**：有专门的侧边栏展示PR，按状态或仓库分组；能快速查看PR关键信息；标题前缀生成彩色标签；显示主导评论状态；支持自定义CI状态显示；操作选择会在会话间保存。
4. **使用建议**：先在Obsidian中安全存储GitHub个人访问令牌，利用搜索、排序和分组功能快速定位所需PR；对于重要PR可进行固定，方便随时查看；定期通过快速操作刷新PR信息，确保数据及时更新。
