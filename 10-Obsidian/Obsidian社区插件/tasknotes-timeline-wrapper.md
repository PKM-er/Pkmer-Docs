## 概述

**主要功能**
TaskNotes Timeline Wrapper 是 TaskNotes 的配套插件，提供“今日时间线”视图。它通过 Runtime API 读取和写入任务，展示按日期分组的未完成任务、可选的日历事件（支持 ICS/Google/Microsoft）以及快速任务录入功能。

**适用场景**
适用于已安装 TaskNotes 4.10.0+ 版本的用户。适合需要在侧边栏或笔记嵌入中快速查看当日议程、管理每日待办事项，并需要结合日历事件进行日程规划的场景。

**核心特色**
1. **可视化统计**：提供待办、逾期、未计划任务的统计瓷砖，点击即可筛选。
2. **灵活交互**：支持拖拽任务至其他日期以重新调度，无需打开弹窗即可内联编辑优先级和日期。
3. **智能过滤**：支持自由文本结合状态、标签、截止日期等多维度组合搜索。
4. **系统提醒**：可选的操作系统级通知，在定时任务或日历事件开始前提醒。
5. **数据一致**：完全依赖 TaskNotes API，确保与主插件的设置（如模板、重复规则）保持同步。

**使用建议**
请确保 TaskNotes 版本不低于 4.10.0 且启用了 Runtime API v1 及读写权限。若主插件缺失或 API 不兼容，插件将显示错误提示而非扫描库。建议利用其侧边栏模式作为每日工作台，并开启“今日已完成”回顾功能以优化每日复盘流程。
