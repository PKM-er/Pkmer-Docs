## 概述

**1. 主要功能**
DataSinking 是一款 Obsidian 插件，能将全球主要市场（美、英、中、日、韩、台）上市公司的完整财务报告（如年报、季报、10-K）抓取并转换为格式整洁的 Markdown 笔记。它保留标题、表格及单位注释，支持通过股票代码（如 `600519.SS`）获取最新报告，也支持批量下载。

**2. 适用场景**
适用于金融分析师、投资者及研究人员，需要快速查阅、归档或建立多家公司财务数据链接网络时。特别适合在 Obsidian 中构建个人财务知识库，进行跨公司对比分析或长期趋势追踪。

**3. 核心特色**
*   **多市场覆盖**：支持 SEC EDGAR（美）、A股、日股、韩股、台股及英股。
*   **格式友好**：自动清洗 HTML，保留结构化内容，直接可读可链接。
*   **灵活配额**：提供无需注册的免费共享额度；获取免费 API Key 后可解锁 7 天内 8,191 篇文档的高额度。

**4. 使用建议**
*   **获取 Key**：建议访问 datasink.ing 获取免费 API Key 并在插件设置中填入，以突破共享配额限制，提升下载稳定性。
*   **批量操作**：利用批量下载功能，一次性导入关注列表中的多家公司报告，便于后续批量处理。
*   **手动安装**：若社区插件列表未更新，可手动将 `main.js` 等文件放入插件目录完成安装。
