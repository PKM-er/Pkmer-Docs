## 概述

### RephraseThis 插件总结
1. **主要功能**：在 Obsidian 编辑器内直接优化所选文本，提供改写建议，可在接受建议后原地替换文本。支持使用 Ollama、OpenAI 等多种 OpenAI 兼容的聊天 API。
2. **适用场景**：适用于在 Obsidian 中撰写文章、笔记等场景，当需要优化语句表达时使用。
3. **核心特色**：无需离开编辑器即可改写文本；改写前可查看建议；能用键盘切换替代建议；支持多种 API 且可通过 Obsidian 秘密存储保存 API 密钥；可调整附近文本的包含量以结合风格和上下文。
4. **使用建议**：使用前在设置中配置好 API 基础 URL 和 API 密钥，根据需求调整写作上下文设置。注意不同 API 提供商有各自的数据保留、隐私和计费规则，使用时需查看相关规定。仅在明确运行改写操作时，插件才会发送笔记内容。
