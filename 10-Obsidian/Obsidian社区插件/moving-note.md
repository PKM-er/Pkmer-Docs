## 概述

### Moving Note 插件总结
1. **主要功能**：实现 Obsidian 笔记的跨设备同步。桌面端借助系统 Git 自动提交和推送；安卓端通过 GitHub API 拉取和推送更改，无需本地 Git。支持一键同步、自动同步，具备冲突处理能力，还能灵活配置。
2. **适用场景**：适用于需要在不同设备（桌面和安卓）间同步 Obsidian 笔记的用户，确保笔记在各设备上保持一致。
3. **核心特色**：配置简单，一键完成拉取、检测本地更改和推送操作；桌面端自动提交推送，安卓端无需本地 Git；有冲突处理机制，桌面生成报告，移动端以远程为准；可自定义仓库 URL、分支名和提交消息模板。
4. **使用建议**：安装时下载相关文件并放入指定文件夹，在社区插件中启用。配置时，桌面端需输入仓库 URL、分支名，确保 Git 安装和凭证配置；安卓端输入 URL，创建并粘贴 GitHub 令牌，设置分支名要与桌面端一致。
