## 概述

Lets Hear It 是一款专为 Obsidian 打造的本地神经文本转语音插件，旨在解决传统 TTS 工具依赖云端 API 或复杂环境配置的问题。它直接将优化后的语音引擎嵌入 Obsidian 运行时，利用设备的 WebGPU 或 CPU 算力即时合成自然流畅的英语语音。用户无需配置 API 密钥或安装外部依赖，安装后即可在笔记中直接播放，实现了零设置、零延迟且完全私有的语音体验。

在日常使用中，你可以开启“聆听模式”，插件会自动将笔记切换至阅读视图，并实时高亮当前朗读的单词与句子，帮助你在听读中快速发现文字中的节奏问题或拼写错误。此外，若只需回顾长文档中的特定段落，只需选中文字并右键选择“朗读选区”，引擎便会仅合成该部分内容。对于需要离线收听的需求，你还可以一键将笔记或选段导出为高质量 MP3 文件，直接保存在库文件夹中，方便在通勤或散步时通过手机收听。

相比同类插件，Lets Hear It 的核心优势在于其“即插即用”的极简体验与绝对的数据隐私。它不向任何第三方服务器发送数据，避免了云服务的订阅费用与网络延迟。同时，插件采用非破坏性高亮技术，利用浏览器原生 API 追踪语音进度，不会修改 Markdown 源码或产生文件同步噪音。其内置的智能 Markdown 清理器还能自动忽略代码块、链接及格式符号，确保你听到的是纯净自然的英文散文，而非生硬的标点符号。

需要注意的是，该插件目前仅支持英语笔记，提供 28 种美式和英式神经语音，暂不支持中文或其他语言。如果你主要使用非英语内容，或需要多语言混合朗读，此插件可能无法满足需求。此外，虽然它支持 CPU 回退机制，但在硬件性能极低的设备上，合成速度可能会受到一定影响。对于追求极致隐私且以英语为主要笔记语言的用户，这是一个高效且免费的替代方案。
