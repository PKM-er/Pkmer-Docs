## 概述

**1. 主要功能**
Mengshi Cockpit 是一款集成式 Obsidian 工作台插件，将日历、项目管理、待办事项、甘特图、飞书文档及 Claude Code 会话整合于单一仪表板中，提供一站式工作流管理。

**2. 适用场景**
适用于需要高效管理个人日程、项目进度及多源任务的知识工作者。特别适合重度使用飞书进行团队协作，且依赖 Claude Code 等 AI 工具辅助开发或内容创作的用户。

**3. 核心特色**
- **多视图日历**：提供“日新”与“月异”双视图，支持一键生成日报/周报骨架。
- **智能任务聚合**：自动扫描项目文件夹，聚合多源待办事项，勾选即回写源文件。
- **深度集成**：支持飞书 Wiki/Drive 深度扫描与自动分类，可视化展示并管理 AI 代码会话。
- **动态甘特图**：支持拖拽调度、里程碑标记及与 README 双向同步。

**4. 使用建议**
建议先配置好项目文件夹结构以启用自动扫描；利用底部悬浮按钮快速捕获日记或待办；定期使用“Harvest”功能整理归档 AI 会话，保持工作区整洁。
