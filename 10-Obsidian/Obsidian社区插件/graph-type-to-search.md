# Obsidian 插件：Graph Type to Search

> [!Note] 插件名片
> - 插件名称：Graph Type to Search
> - 插件作者：Jeonghyeon Park
> - 插件说明：图谱视图中的预输入功能：当图谱处于聚焦状态时，开始输入内容进行筛选，会在标题匹配的节点周围绘制高亮圆环。你也可以选择让所有节点都显示，仅给匹配的节点加圆环标记。 - 此插件尚未经过Obsidian官方人员的手动审核。

## 概述

### 主要功能
为Obsidian的图谱视图带来预输入搜索功能，在图谱视图聚焦时直接输入即可过滤节点，匹配的节点会有高亮环，默认保留全量节点，也可切换为过滤模式。

### 适用场景
适用于在Obsidian图谱视图中快速查找特定节点，且希望保留上下文信息的场景。

### 核心特色
- 无需按 `Cmd/Ctrl+F` 或点击搜索框，直接输入即可搜索。
- 匹配节点有高亮环，可选择是否闪烁，还能放大标题，非匹配节点会变暗。
- 高亮环绘制在图谱渲染器中，随图谱的平移、缩放自动调整。
- 支持韩语及CJK等输入法。

### 使用建议
当图谱窗口激活时，插件会在左上角显示一个输入框并保持聚焦，直接输入关键词即可搜索。若想保留上下文信息，可开启“Keep all nodes visible”；若只需查看匹配节点，关闭该选项。
