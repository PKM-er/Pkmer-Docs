## 概述

### XU File Catalog 插件总结
1. **主要功能**：读取 Markdown 文件标题，生成带层级缩进的可点击目录树，支持代码块动态渲染、命令插入、标题层级与样式自定义、快捷键配置及冲突检测。
2. **适用场景**：适用于需要在 Obsidian 中为 Markdown 文件快速生成目录，且希望对目录样式、显示层级等进行个性化设置的场景。
3. **核心特色**：无需 Dataview 依赖，替代 DataviewJS 的 filecatalog 脚本；支持 `[[]]` 链接格式，可利用 Obsidian 自动补全；命令有双模式，操作灵活；可自定义标题层级、样式、快捷键，且能即时检测快捷键冲突；含链接与不含链接标题颜色有区别。
4. **使用建议**：推荐从 Obsidian 社区目录安装该插件，操作更便捷。使用时可根据需求在插件设置面板自定义标题层级、样式和快捷键，利用代码块动态渲染功能快速生成目录。
