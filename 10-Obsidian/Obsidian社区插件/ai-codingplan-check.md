## 概述

**1. 主要功能**
在 Obsidian 侧栏聚合查询多家 AI 编程服务的订阅套餐剩余额度或按量余额，支持多账号、多套餐管理，无需频繁切换官网控制台。

**2. 适用场景**
适合同时订阅多家 AI 编程服务（如 OpenCode、火山方舟、智谱、Kimi 等）或拥有多个账号的用户，用于快速监控额度消耗与重置倒计时。

**3. 核心特色**
*   **广泛兼容**：支持 API Key 与控制台 Cookie 两种接入方式，覆盖 OpenCode、火山方舟、DeepSeek 等十余款主流服务。
*   **智能展示**：订阅类服务显示用量窗口（百分比+倒计时），按量类服务拆分充值/赠送/代金券明细。
*   **灵活凭证**：针对无开放 API 的服务，支持通过浏览器 Cookie 登录态查询，并支持凭证导出以便多端同步。

**4. 使用建议**
*   优先使用 API Key 接入，安全性更高；仅当服务不支持 API 查询时，再使用 Cookie 方式。
*   **安全警示**：会话 Cookie 等同于登录权限，严禁外传；若 Cookie 泄露，请立即在官网重置密码或登出。
*   手机端 iOS 无法直接读取 Cookie，建议先在电脑端配置账号，通过“凭证导出”功能同步至手机使用。
