## 概述

### HTML Table Toolbar插件总结
1. **主要功能**：为Obsidian笔记中的HTML表格提供类似Word的工具栏，可进行行与列操作、合并与拆分单元格、设置表头行、调整对齐方式、设置每行每列边框及单元格底纹等。
2. **适用场景**：当需要创建和编辑具有复杂样式（如合并单元格、设置单个单元格样式等）的表格，而Markdown管道表格无法满足需求时使用。
3. **核心特色**：与HTML Font Toolbar为姊妹插件，由同一作者开发。二者可独立安装使用，也能协同工作，不相互依赖且代码不相互导入。它们能合理堆叠，不重叠，会自适应窗口大小，不会在CSS上冲突，分工明确。此外，二者都有独立的 ribbon 图标，可独立显示或隐藏。
4. **使用建议**：若仅需处理表格，安装此插件即可；若还需进行字体格式设置，可同时安装HTML Font Toolbar插件，以获得更全面的编辑体验。
