## 概述

Pocket Markwhen 专为移动端用户设计，让你能在手机或平板上直接阅读和编辑 Markwhen 时间线。它支持打开 `.mw` 文件或在笔记中嵌入 `mw` 代码块，将事件日期、范围、标签及标题分组以垂直时间线形式直观呈现。插件严格保留原始文件格式，编辑时仅修改文本内容，不会将计划转换为数据库，确保数据始终处于你熟悉的纯文本状态。

典型场景包括快速查看旅行计划或项目进度。例如，你可以打开一份包含“罗马 #italy”标签的行程文件，通过时间线清晰看到日期范围和标签芯片；或者在周回顾笔记中嵌入时间线，直接查看本周待办事项。若需聚焦特定任务，可使用“Today”功能快速定位当前日期后的首个事件，并自动展开相关分组，方便随时掌握下一步行动。

相比其他插件，Pocket Markwhen 的特色在于对源文件的无损编辑和灵活的过滤能力。它支持按日期范围和标签筛选事件，且过滤仅影响当前视图，不改变磁盘文件。Pro 版本还允许合并多个 `.mw` 文件进行对比查看，或导出为 Markdown 列表，适合需要跨文件整合信息或生成报告的用户。此外，它内置了 Markwhen 解析器，能正确处理包含时区设置的复杂日期逻辑。

使用前请注意，该插件主要面向移动端阅读体验，桌面端功能未做深度优化。它不支持将重复事件展开为日历视图，也不渲染事件文本中的 HTML 或交互式 Markdown 元素，这些细节需在源码模式下编辑。如果你需要复杂的数据库式管理、自动同步或跨平台实时协作，此插件可能无法满足需求。此外，Pro 功能需 GitHub 账号，且部分高级功能如文件合并和导出仅对 Pro 用户开放。
