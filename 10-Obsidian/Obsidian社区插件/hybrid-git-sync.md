## 概述

### 主要功能
Hybrid Git Sync 是一款跨平台的 Obsidian Git 同步插件，采用自适应同步引擎，在桌面端调用本地原生 Git 客户端进行同步，在移动端通过与云 REST API（GitHub / GitLab / Gitea）交互实现同步。

### 适用场景
适用于需要在不同操作系统（如桌面端的 Windows、Mac、Linux，移动端的 iOS、Android）使用 Obsidian 并进行 Git 同步的场景。

### 核心特色
1. 自适应混合引擎：根据设备智能切换同步方式，桌面端用原生命令，移动端用 API 请求。
2. 注重隐私：个人访问令牌本地安全存储，数据不离开设备。
3. 冲突解决：内置智能同步逻辑，降低多设备同时编辑时文件覆盖风险。
4. 免费开源：可自定义、自托管，用于通用知识库备份。

### 使用建议
鉴于插件未经过 Obsidian 官方人工审核，使用前可充分了解其开源代码确保安全性。配置个人访问令牌时注意保管，避免泄露。
