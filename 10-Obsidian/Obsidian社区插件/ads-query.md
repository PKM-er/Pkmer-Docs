## 概述

**1. 主要功能**
该插件允许用户在 Obsidian 笔记中直接运行 NASA ADS（天体物理数据系统）搜索。它通过代码块发送查询请求，并将结果以 Markdown 表格形式写入笔记，支持生成 ADS 记录链接及 DOI 链接。

**2. 适用场景**
主要适用于从事天文学或相关科学研究，且习惯使用 Obsidian 管理研究笔记的用户。适合需要频繁检索文献、且不希望频繁切换浏览器进行数据查询的研究人员。

**3. 核心特色**
*   **无缝集成**：无需离开 Obsidian 即可完成文献检索，提升工作流效率。
*   **原生存储**：结果直接以 Markdown 表格形式保存在笔记中，便于后续编辑和引用。
*   **安全存储**：利用 SecretStorage 加密存储 API Token，保障账户安全（需 Obsidian 1.11.5+）。
*   **链接支持**：自动附带 ADS 和 DOI 链接，方便快速溯源。

**4. 使用建议**
*   **前置准备**：需先在 NASA ADS 官网申请 API Token，并在插件设置中配置。
*   **版本要求**：确保 Obsidian 版本不低于 1.11.5，以支持加密存储功能。
*   **合规注意**：使用本插件即表示同意 NASA ADS API 的使用条款，请合理控制查询频率，避免违规。
