## 概述

### Claude Code Sync插件总结
1. **主要功能**：将本地Claude Code的会话以Markdown笔记形式同步到Obsidian库中，每次会话生成一个笔记，笔记名为`<日期> <会话标题>.md`，按项目分类存放。
2. **适用场景**：适用于使用Claude Code进行代码相关会话交流，希望在Obsidian中整理、查看和搜索这些会话记录的用户。
3. **核心特色**：
    - 一次设置，自动同步过往和未来的所有Claude Code会话，方便快捷。
    - 工具调用和Claude的思考内容折叠在可展开的标注块中，保持对话可读性。
    - 笔记为只读镜像，源会话更新时自动重新生成，保证数据一致性。
4. **使用建议**：
    - 推荐通过BRAT安装该插件，步骤为安装BRAT插件，添加`mattbirchler/claude-code-obsidian`，在社区插件设置中启用。
    - 不要直接编辑同步的笔记，若需添加评论，可在单独笔记中进行并链接到同步笔记。
