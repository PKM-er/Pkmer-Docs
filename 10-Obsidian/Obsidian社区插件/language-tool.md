## 概述

Language Tool Advanced 为 Obsidian 笔记提供实时的拼写、语法及西班牙语风格检查。它基于 LanguageTool 引擎，能在你输入时自动识别错误，并通过点击下划线快速应用修正。该插件的核心价值在于弥补了原生 LanguageTool 的不足，特别针对混合语言笔记、遵循西班牙皇家语言学院（RAE）规范的西班牙语写作，以及经过复制粘贴后格式混乱的 Markdown 文本进行了深度优化。

典型场景包括撰写多语言混合笔记或处理复杂的 Markdown 格式。例如，当一篇笔记中同时包含英语和西班牙语段落时，插件能自动识别每个段落所属的语言并分别检查，避免将短段落误判为斯洛文尼亚语等小语种。此外，对于包含加粗、斜体、链接或脚注的复杂文本，插件能确保修正错误时保留原有的格式标记，防止因自动替换导致排版破坏。

相比同类插件，其特色在于对西班牙语 RAE 规则的深度支持，如对话标点、角引号及常见语法错误的精准识别。同时，它具备强大的 Markdown 容错能力，能正确处理跨格式单词、软连字符及字符引用等“脏”数据。若注重隐私，用户可部署本地 LanguageTool 服务器，确保笔记内容永不离开个人电脑，实现完全离线检查。

需要注意的是，该插件目前仅支持 macOS、Windows 和 Linux 桌面端，不支持手机或平板设备。此外，若使用公共服务器，存在请求频率限制；若需使用高级规则或每段独立语言检测功能，则必须部署本地服务器或购买 Premium 服务。对于仅需基础英文拼写检查且对隐私无特殊要求的用户，原生功能或更简单的插件可能已足够。
