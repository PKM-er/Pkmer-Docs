## 概述

**Zotero Deep Linker** 是一款专为 Obsidian 设计的桌面插件，旨在通过可视化搜索本地 Zotero 库，将文献条目、PDF 附件或具体标注以 Markdown 链接形式插入笔记。

**适用场景**：适用于学术写作、文献管理及知识整理，特别适合需要在笔记中精准引用特定文献段落或页面内容的研究者。

**核心特色**：
1. **深度链接**：支持生成指向 Zotero 条目、PDF 文件及具体页码/标注的深层链接（`zotero://` 协议）。
2. **双模搜索**：支持按标题、作者、DOI 或关键词搜索，也可直接浏览 Zotero 集合树。
3. **只读安全**：仅读取本地 API，绝不修改 Zotero 数据，确保文献库安全。
4. **零依赖**：无需安装其他 Obsidian 或 Zotero 插件，只需启用 Zotero 本地 API 即可。

**使用建议**：
1. 确保 Zotero 桌面版正在运行，并在其设置中启用“本地 API”（默认端口 23119）。
2. 在 Obsidian 中通过命令面板运行“Add Zotero Deep Link”或点击丝带图标。
3. 若 Zotero 使用非默认地址，请在插件设置中更新 API 地址。
4. 界面语言跟随 Obsidian 设置，支持中文显示。
