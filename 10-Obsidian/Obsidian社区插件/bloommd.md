## 概述

**BloomMD 插件中文总结**

**1. 主要功能**
BloomMD 将 Markdown 笔记转化为交互式思维导图。它自动解析标题层级（`#`为根节点，`##`为子节点），将标题作为节点，正文作为内容。支持在可视化界面上直接编辑结构（如重命名、增删子节点、复制粘贴分支、重新归类），所有修改会实时写回原始 `.md` 文件，保持 Markdown 为唯一数据源。

**2. 适用场景**
适用于需要快速梳理复杂文档结构、进行知识梳理或大纲设计的用户。特别适合在 Obsidian 中处理长篇笔记、项目规划或需要直观查看层级关系的场景，无需切换格式即可实现“所见即所得”的结构编辑。

**3. 核心特色**
*   **非侵入式**：不创建专有格式，完全兼容标准 Markdown，确保数据可移植性。
*   **双向同步**：视觉编辑与文本文件实时同步，通过 Obsidian Vault API 安全写入。
*   **本地优先**：强调本地文件控制，未来可能支持同步与团队协作，但当前以本地工作流为主。

**4. 使用建议**
*   目前仅支持桌面端（iOS/Android 未启用），请在电脑上使用。
*   该插件处于公开 Beta 阶段，建议定期备份重要数据。
*   若遇到兼容性问题，请在 GitHub Issues 反馈；代码开发主要在 Monorepo 进行。
*   适合喜欢结构化思维的用户，但需注意它主要优化标题层级结构，而非全文内容编辑。
