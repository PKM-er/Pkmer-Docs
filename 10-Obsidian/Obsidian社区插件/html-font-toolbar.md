## 概述

### HTML Font Toolbar插件总结
1. **主要功能**：提供一个浮动的、类似Word的格式化工具栏，使用简洁的内联HTML为选中文本设置样式，如颜色、高亮、大小、字体、加粗、倾斜、下划线、删除线等，还支持表格内文本对齐。
2. **适用场景**：适用于Obsidian用户在撰写笔记时需要对文本进行多样化样式设置的场景，尤其在处理包含表格的笔记时，能方便地设置表格内文本样式。
3. **核心特色**：生成的内容为一个简洁的内联HTML span，避免了不同语法混用导致的嵌套冲突问题；与姐妹插件HTML Table Toolbar可协同工作，两者不重叠、分工明确且不冲突CSS。
4. **使用建议**：可单独安装使用，若有处理HTML表格的需求，也可同时安装HTML Table Toolbar，两者会自动协调工作，无需额外配置。
