## 概述

**1. 主要功能**
Zen UI 是一款旨在极简化的 Obsidian 插件。它允许用户隐藏侧边栏、工具栏及多余间距，提供“禅模式”一键全屏专注，并支持自定义侧边栏标签页、快速打开每日笔记及调整文件浏览器布局。

**2. 适用场景**
适合追求极致简洁界面、希望减少视觉干扰以深度阅读或写作的用户。也适用于需要频繁切换 Git 同步状态且希望操作界面更清爽的场景。

**3. 核心特色**
*   **极致极简**：通过简单开关隐藏所有非必要 UI 元素，增加“呼吸感”。
*   **安全集成**：Git 同步功能仅读取状态，所有实际 Git 操作（如 pull/push）均由 Git 插件处理，Zen UI 本身不执行 Shell 命令或网络请求，确保数据安全。
*   **专注模式**：提供专门的 Zen 模式，一键隐藏所有干扰项，实现全屏沉浸。

**4. 使用建议**
建议在设置中根据习惯逐步隐藏不常用的侧边栏和工具栏。若需使用 Git 同步功能，请确保已安装并配置好 Obsidian Git 插件。开启 Zen 模式前，可先调整文件浏览器间距以获得最佳视觉体验。
