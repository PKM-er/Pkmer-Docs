## 概述

**Daily Note Flow** 是一款将日常任务、待办事项及时间分类记录转化为纯 Markdown 笔记的 Obsidian 插件。

**主要功能**
该插件支持在单一面板中快速添加、编辑和删除记录，并自动按早、午、晚时段分类及重新排序。它能基于每日笔记自动生成周报和月报，支持预览后应用，并可选集成 DeepSeek AI 对日、周、月总结进行润色优化。

**适用场景**
适合需要结构化记录日常事务、进行周期性复盘（周/月回顾）的用户，尤其适合偏好纯文本存储、注重数据隐私及希望利用 AI 辅助总结效率的个人知识管理者。

**核心特色**
1. **纯 Markdown 存储**：数据直接写入 Vault 内的指定文件夹（Daily/Weekly/Monthly），无隐藏数据库，便于同步与迁移。
2. **智能时间管理**：自动识别时段并调整记录顺序，保持笔记整洁。
3. **AI 增强**：可选配置 DeepSeek API，自动优化总结内容的表达与逻辑。

**使用建议**
- 默认存储路径为 `Daliy_Note/`，建议根据习惯自定义根目录。
- 若启用 AI 润色，需配置 API Key，请注意隐私数据会发送至 AI 端点，切勿将密钥提交至版本控制系统。
- 插件处于活跃开发阶段，建议从社区插件浏览器或 GitHub Release 获取最新稳定版。
