## 概述

### Code Import插件总结
1. **主要功能**：支持在Obsidian笔记里使用`@import`语法导入外部代码文件，兼容Markdown Preview Enhanced。可在阅读视图直接导入代码，支持选择行范围，能根据文件扩展名自动实现语法高亮，支持相对路径。
2. **适用场景**：适用于需要在笔记中引用代码文件的场景，例如程序员记录代码示例、技术文档编写等。
3. **核心特色**：提供全量和部分代码导入功能；支持0和1两种行索引模式；在桌面和移动端（iOS）都能正常使用。
4. **使用建议**：插件可通过Obsidian社区插件市场安装。使用时，利用`@import`语法导入文件，可通过`line_begin`和`line_end`参数选择行范围。注意两种行索引模式的差异，默认采用0基索引模式。
