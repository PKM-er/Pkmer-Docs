## 概述

**插件名称**：Dynamic Views

**1. 主要功能**
该插件为 Obsidian 的 Bases 功能提供优雅的网格和瀑布流卡片视图。它支持将笔记图片显示为缩略图、封面或背景，具备图片滑动浏览、全屏查看功能，并展示笔记文本预览。此外，还包含长标题换行、属性横向滚动及移动端菜单隐藏等优化。

**2. 适用场景**
非常适合制作情绪板（Mood boards）、媒体库、图片画廊，以及日常笔记管理。与 Web Clipper 和网页查看器配合使用时，能显著提升信息收集与整理效率。

**3. 核心特色**
*   **高度自定义**：支持调整图片位置（上下左右）、属性名称显示方式及布局，可应用 CSS 片段微调样式。
*   **丰富交互**：支持键盘导航、复选框切换、文本选择，以及“打开随机文件”和“洗牌视图”等便捷按钮。
*   **生态集成**：无缝集成 Notebook Navigator、YouTube 缩略图显示及 Link Embed 等插件，增强多模态内容展示。

**4. 使用建议**
建议用于需要视觉化展示内容的场景，如项目灵感收集或媒体资源管理。利用其“默认设置配置”功能可统一新视图风格，保持库内一致性。若需深度定制外观，可结合 CSS 片段进行精细调整。
