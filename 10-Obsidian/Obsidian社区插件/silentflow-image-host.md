## 概述

**SilentFlow Image Host** 是一款专为 Obsidian 设计的图片托管插件，旨在简化笔记中的图片管理流程。

**主要功能**
该插件支持将直接粘贴或拖入编辑器的图片自动上传至 SilentFlow 云服务，并即时替换为公共 Markdown 链接。它保留了纯文本粘贴功能，不会干扰其他插件的操作，且支持并发上传多张图片。

**适用场景**
适用于需要频繁在笔记中插入截图、图表或照片的用户，特别是那些希望摆脱本地文件依赖、实现笔记跨设备同步或公开分享时，无需担心图片丢失或路径错误的场景。

**核心特色**
1. **智能占位符**：上传过程中显示临时占位符，即使编辑周围文本也能准确替换，确保链接稳定。
2. **灵活配置**：可独立开启/关闭粘贴或拖放上传功能；支持可选的文件名作为 Alt 文本，提升无障碍访问性。
3. **用量监控**：内置命令可检查存储和流量使用情况，便于管理配额。
4. **全平台支持**：基于 Obsidian 原生 API，完美兼容桌面端和移动端。

**使用建议**
1. 首先前往 SilentFlow 官网获取免费 API Key。
2. 在插件设置中填入密钥，保持默认 API 地址即可。
3. 建议开启“检查用量”功能以监控存储状态。
4. 若需优化图片描述，可启用“使用文件名作为 Alt 文本”选项，但需注意通用文件名（如 image.png）会被自动优化为 pasted-image。
