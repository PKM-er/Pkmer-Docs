## 概述

### Code Playground插件总结
1. **主要功能**：可在Obsidian笔记中嵌入实时、可编辑的[Sandpack](https://sandpack.codesandbox.io/)代码游乐场，支持HTML/CSS、React、Vue等多种代码类型。
2. **适用场景**：适合开发者在Obsidian笔记中实时编写、测试代码，如学习新框架、验证代码逻辑等。
3. **核心特色**：能在笔记内直接运行代码并即时预览效果，无需切换到其他开发环境；支持多种主流前端框架和语言。
4. **使用建议**：
    - 该插件依赖CodeSandbox的托管服务，运行代码需联网，无完全离线模式。
    - 若代码涉及敏感信息，请勿使用，因代码编译会传输到CodeSandbox。
    - 可在设置中配置自托管打包器URL，避免将代码发送到CodeSandbox。
    - “Open in CodeSandbox”按钮默认关闭，开启后点击会将代码上传到codesandbox.io。
    - 移动端支持处于实验阶段。
