## 概述

TreeTable 旨在解决原生 Markdown 表格在层级展示和复杂内容编辑上的局限。它通过简单的标记符号，让普通表格具备可折叠的行组功能，并支持在单元格内直接编辑列表、任务、图片及代码块等富文本内容。此外，插件允许用户通过拖拽调整列宽，或切换为单行紧凑视图，从而在保持 Markdown 纯文本兼容性的同时，大幅提升表格的信息承载能力与视觉清晰度。

典型场景包括整理旅行计划或项目任务清单。例如，你可以用 `#` 标记“旅行”和“工作”作为顶级分组，用 `>` 和 `>>` 标记“住宿”或“东京”作为子项，点击箭头即可快速折叠或展开特定分支。在单元格中，你可以直接插入待办事项列表或嵌入外部笔记，无需跳出表格界面，让信息整理过程更加连贯高效。

相比同类插件，TreeTable 的特色在于对富 Markdown 内容的原生支持以及灵活的列宽控制。它不仅能处理文本，还能在单元格内保留其他插件提供的交互式代码块显示，同时支持通过元数据或拖拽精确设定列宽。这种设计使得表格既能作为结构化的数据容器，又能容纳复杂的富媒体内容，且在不启用插件时仍保持为标准的 Markdown 表格，便于长期归档。

使用前需注意，目前尚不支持直接拖拽移动记录或整个分组，需切换至源码模式调整。此外，若同时使用 Advanced Tables 等会重写表格行的插件，可能会干扰树状标记或宽度元数据，建议先在副本中测试兼容性。该插件不适合需要频繁拖拽排序或依赖复杂表格交互逻辑的场景，更适合用于静态展示或层级化信息梳理。
