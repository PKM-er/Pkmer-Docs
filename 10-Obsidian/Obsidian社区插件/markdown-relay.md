## 概述

### Markdown Relay 插件总结
1. **主要功能**：将 Obsidian 中的 Markdown 笔记单向发布到飞书/Lark、Notion 和 ima，本地 Markdown 是唯一内容源，远端修改不合并回 Vault。
2. **适用场景**：适用于需要将 Obsidian 里的 Markdown 笔记分享到飞书、Notion、ima 等平台的用户。
3. **核心特色**：支持多平台发布，可一次选择一篇或多篇 Markdown 发布到一个或多个平台；有多种发布入口，使用同一任务协调器；进度面板支持取消未开始任务，完成报告支持仅重试失败项；发布前重新验证目标，避免权限、重复等问题；不提供反向同步等功能，不调用猜测或私有 API。
4. **使用建议**：可通过 Obsidian 社区插件市场、BRAT 或手动安装 Release 进行安装。观看 B 站视频教程了解安装、配置和发布流程。选择目标时，各平台有不同规则，需按要求设置。新安装默认不发布用户 YAML。
