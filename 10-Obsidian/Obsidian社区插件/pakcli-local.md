## 概述

**PakCLI Local** 是一款专为 Windows 用户打造的 Obsidian 桌面系统桥接与效率工具插件，旨在将操作系统能力直接融入笔记工作流。

**主要功能**：
1. **链接管理**：创建并管理 Windows 目录联接（Junction）及文件符号链接，支持可视化树状徽章。
2. **脚本执行**：内置 PowerShell 运行器，可在库内直接同步、执行和监控自动化脚本。
3. **媒体捕获**：集成 `yt-dlp`，支持下载视频片段、高清缩略图及字幕，并自动生成 Markdown 笔记。
4. **系统诊断**：提供实时健康检查，监控 PowerShell 版本、开发者模式及二进制路径状态。

**适用场景**：
适合需要高度自动化、希望将笔记库与本地文件系统深度联动，或经常处理视频素材的技术型用户。

**核心特色**：
- **OS 深度集成**：打破 Obsidian 与 Windows 系统的壁垒，实现文件级操作。
- **模块化设计**：通过事件总线解耦通信，支持配置持久化，卸载后重装可自动恢复设置。
- **直观界面**：双栏响应式设置中心，支持即时搜索与未安装模块的透明预览。

**使用建议**：
安装前请确保已启用 Windows 开发者模式并配置好 `yt-dlp` 路径。建议先运行“系统向导”进行环境自检，再逐步启用脚本或媒体功能，以确保持久化配置正常生效。
