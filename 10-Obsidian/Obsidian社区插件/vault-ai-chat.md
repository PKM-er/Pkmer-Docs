## 概述

**AI Vault Memory** 是一款为 Obsidian 提供本地知识库记忆与上下文感知 AI 聊天的插件。

**主要功能**：插件在本地索引 Markdown 笔记，无需外部数据库即可实现语义检索。当用户提问时，系统自动提取相关笔记片段作为上下文，仅将提示词与选中内容发送至配置的 OpenAI 兼容 API 进行处理。

**适用场景**：适用于需要基于个人笔记库进行问答、知识检索或内容分析的 Obsidian 用户，特别是希望结合本地数据与 AI 能力进行高效信息管理的场景。

**核心特色**：
1. **完全本地化索引**：笔记索引、设置及聊天记录均存储在本地，保障数据隐私。
2. **广泛的 API 兼容性**：支持 OpenAI、OpenRouter、Groq、LM Studio 及自托管服务等任意 OpenAI 兼容接口。
3. **灵活交互**：支持附加特定文件、发送选中文本至聊天，并具备索引重建、更新及清除功能。
4. **多语言支持**：提供英文和波斯语界面，并支持保存聊天会话。

**使用建议**：安装后，请在设置中配置 API 地址、密钥及模型，务必先执行“重建索引”操作以确保检索准确。日常使用中，可通过命令面板使用“分析当前文件”或“发送选区至聊天”功能，快速利用 AI 辅助笔记处理。
