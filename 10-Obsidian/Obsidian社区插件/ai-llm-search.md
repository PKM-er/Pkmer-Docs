## 概述

### 插件名称
AI LLM Search

### 主要功能
借助自身的模型 API，可与选中文本、当前笔记、知识库相关笔记及网页搜索结果进行对话。支持就当前笔记提问、选中编辑或阅读视图文本右键问 AI 或搜索整个库等。

### 适用场景
适用于在 Obsidian 中进行知识查询、文本内容理解等场景，用户可在阅读或编辑过程中随时与 AI 交互。

### 核心特色
- 以中文为主的侧边栏界面，适配窄桌面窗格和移动布局。
- 本地搜索 Markdown 笔记采用 BM25 算法，无需嵌入服务。
- 可将当前笔记、整个库和网页上下文结合在一次对话中，展示发送给模型的内容来源。
- 支持 DuckDuckGo 无 API 密钥搜索，可配置 Tavily。
- API 密钥存储在 Obsidian SecretStorage 中。

### 使用建议
可通过社区插件或手动方式安装。安装后在设置中配置 OpenAI 兼容的 API 基础 URL、模型 ID、API 密钥等信息，还可按需限制本地库搜索文件夹、选择网页搜索工具。
