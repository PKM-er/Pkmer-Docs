## 概述

**1. 主要功能**
PARA Navigator 是一款基于 PARA 方法论的侧边栏导航插件。它将 Inbox、Projects、Areas、Resources 和 Archives 文件夹转化为可交互的笔记树。每个节点均为 Markdown 笔记，支持在侧边栏直接创建、编辑层级结构，并自动生成统计仪表盘和 Bases 数据表。

**2. 适用场景**
适用于采用 PARA 体系管理知识库的用户，特别是需要频繁在层级间切换、整理大量笔记及任务，且希望保持纯 Markdown 结构不脱离文件系统的场景。

**3. 核心特色**
*   **纯 Markdown 层级**：文件夹由同名笔记（如 `X/X.md`）代表，支持将普通笔记一键转换为文件夹笔记并自动更新全库链接。
*   **智能捕获与排序**：新建笔记默认存入 Inbox；支持拖拽自定义子节点顺序，重启后保留。
*   **数据可视化**：按需生成各文件夹的 Bases 表格及统计面板（含字数、任务状态、标签等），且绝不覆盖现有文件。
*   **高度可定制**：自动识别中英文及数字前缀文件夹，支持自定义图标、颜色及路径映射。

**4. 使用建议**
安装后通过图标或命令面板打开。若自动检测失败，请在设置中手动调整路径或点击“重新检测”。建议利用右键菜单进行节点操作，并善用统计仪表盘定期回顾项目进度与笔记分布。
