## 概述

**主要功能**
Ambient Backlinks 插件利用 LLM 生成单行摘要，精准解释每个反向链接笔记与当前笔记之间的具体关系（如“提供反例”或“前置步骤”），而非简单总结笔记内容。

**适用场景**
适用于构建大型知识库、进行文献综述或复杂项目管理的用户，特别适合需要快速理清笔记间逻辑脉络、理解引用上下文及梳理知识关联的场景。

**核心特色**
1. **关系导向**：聚焦于链接上下文，解释“为何链接”而非“链接内容”。
2. **智能缓存**：基于笔记修改时间键值缓存，避免重复调用 API，节省成本。
3. **灵活模式**：支持自动模式（防抖后自动解释）和手动模式（按需触发），用户可完全掌控 API 支出。
4. **直观交互**：侧边栏按修改时间排序，支持点击跳转原文或展开查看包含链接的具体段落。

**使用建议**
1. 通过丝带图标或命令面板打开侧边栏，确保当前笔记存在入站链接。
2. 根据预算选择模式：频繁浏览建议用自动模式提升效率；注重成本建议用手动模式。
3. 配置好 API 密钥与模型后，点击行标题可快速跳转源笔记，点击展开箭头可查看原始引用段落以验证 AI 解释的准确性。
