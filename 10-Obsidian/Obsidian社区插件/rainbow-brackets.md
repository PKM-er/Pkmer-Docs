## 概述

**Rainbow Brackets 插件总结**

1. **主要功能**：在 Obsidian 中实现类似 VS Code 的彩虹括号效果。根据嵌套深度为圆括号、方括号和花括号着色（4色循环），高亮显示光标处的括号及其配对项，并将未匹配的括号标记为红色虚线。
2. **适用场景**：适用于在纯 Markdown 文本中处理复杂嵌套结构（如代码片段、数学公式或逻辑结构）的场景，帮助用户快速识别括号层级和配对关系。
3. **核心特色**：
   - **智能忽略**：自动忽略行内代码、代码块、数学公式、Frontmatter 及转义括号，避免误判。
   - **全模式支持**：兼容实时预览和源码模式，支持桌面端和移动端。
   - **高度可定制**：通过 CSS 变量轻松自定义各层级颜色及高亮样式，适配深色/浅色主题。
4. **使用建议**：安装后无需额外配置即可生效。若对默认颜色不满意，建议在“外观”设置中创建 CSS 片段，修改 `--rb-0` 至 `--rb-3` 变量以匹配个人审美或主题风格。
