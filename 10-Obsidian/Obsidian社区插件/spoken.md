## 概述

**Spoken 插件中文总结**

**主要功能**
Spoken 是一款语音转文字插件，支持在手机或桌面端使用。它利用用户自有的 Gemini API Key，将语音实时转录为整洁文本并插入光标处。插件具备智能清洗能力，自动去除“嗯”、“啊”等无意义填充词及口误，确保最终文本干净流畅。

**适用场景**
适用于需要快速记录灵感、会议笔记或日常备忘的场景。特别适合在移动端（手机）进行碎片化记录，或在桌面端进行长篇幅语音输入。对于经常涉及特定人名、术语且对拼写准确性要求高的用户尤为适用。

**核心特色**
1. **跨平台支持**：无缝衔接手机与桌面端，随时随地记录。
2. **智能清洗**：自动过滤口头禅和错误开头，保留核心内容。
3. **专有名词校正**：支持自定义词汇表（每行一个名称），确保特定人名或术语拼写准确。
4. **原子化操作**：转录结果作为单个撤销步骤插入，方便修改。
5. **隐私自主**：使用用户自己的 API Key，数据不经过第三方服务器。

**使用建议**
1. **配置 API**：需自行申请并配置 Gemini API Key。
2. **维护词汇表**：在指定笔记中逐行添加常用专有名词，以提升识别准确度。
3. **注意审查**：虽然插件已清洗文本，但建议插入后快速浏览确认，特别是长段落。
4. **备份数据**：由于依赖外部 API，建议定期备份笔记，以防转录失败或网络波动。
