## 概述

**1. 主要功能**
Vault Sidekick 在 Obsidian 侧边栏集成基于 Claude Code 的聊天助手。它允许用户直接与 AI 对话，AI 可读取、搜索、创建及编辑库内的 Markdown 笔记，并支持通过斜杠命令调用 Jira、Google Drive 等外部连接器及自定义技能。

**2. 适用场景**
适用于需要高效管理笔记、自动化文档处理或跨平台信息整合的知识工作者。特别适合希望在不离开 Obsidian 的情况下，利用 AI 辅助写作、整理资料或执行特定工作流的用户。

**3. 核心特色**
*   **本地安全运行**：复用本地 Claude Code 登录，无需额外 API Key，且严格限制 AI 仅能访问 Vault 内部文件，保护隐私。
*   **可视化编辑控制**：AI 修改笔记前需用户确认，编辑时自动打开对应笔记标签页，实时展示变更过程。
*   **无缝体验**：回复流式显示，链接可点击，界面完全适配 Obsidian 主题，操作流畅自然。

**4. 使用建议**
建议先熟悉 `/` 命令以调用特定技能或连接器。在进行批量修改时，善用“允许本次”或“允许本次会话”选项以平衡效率与安全。注意该插件为独立项目，非 Anthropic 官方出品，使用前请确认本地已正确安装并登录 Claude Code。
