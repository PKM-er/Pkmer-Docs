## 概述

### 插件名称
Vault Script Runner

### 主要功能
这是一款仅适用于桌面端的Obsidian插件，可运行带参数提示的本地脚本。脚本通过目录JSON文件发现，按需下载、跟踪版本，并通过可配置预设运行。

### 适用场景
适用于需要在Obsidian中运行本地脚本的场景，例如将PDF渲染为页面图像和Markdown笔记。

### 核心特色
- 与脚本无关，可处理多种脚本。
- 自动跟踪脚本版本，有新版本时会提示更新。
- 支持自定义脚本目录URL。

### 使用建议
1. 安装：将插件文件夹复制到 `<Vault>/.obsidian/plugins/vault-script-runner`，重启Obsidian并在社区插件中启用。
2. 配置：在 **Settings -> Vault Script Runner** 中设置脚本目录URL（可选）。
3. 运行：点击下载脚本，然后从命令面板选择 **Run configured script** 运行预设。
4. 刷新：可在设置页点击 **Refresh** 按需重新加载目录。
