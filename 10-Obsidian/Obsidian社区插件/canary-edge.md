## 概述

**Canary Edge 插件总结**

1.  **主要功能**：作为 BRAT 的现代替代方案，专注于基于 Git 的插件测试与版本控制。提供版本选择、更新日志审计、兼容性检查及针对单个插件的精细化覆盖设置。
2.  **适用场景**：专为开发者、测试人员及高级用户设计。适合那些熟悉 GitHub PAT 和开发者工具，且对 BRAT 或官方插件管理器感到控制力不足、需要更深层次透明度和配置灵活性的用户。
3.  **核心特色**：定位为“单用途”精准工具，而非全能插件管理器。强调极致的数据粒度、精确的版本控制和调试能力，旨在消除标准工具带来的摩擦，满足“控制狂”对细节的严苛要求。
4.  **使用建议**：严禁新手使用。若未使用过 BRAT 或第三方开发插件管理器，请避免安装，其高密度和细粒度控制可能造成困扰。若无需深度定制，请保持简单，选择官方渠道。
