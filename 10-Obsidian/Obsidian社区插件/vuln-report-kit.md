## 概述

### Vuln Report Kit插件总结
1. **主要功能**：将Obsidian库转变为漏洞研究文档的结构化工作区，可创建漏洞案例、记录相关信息、用仪表盘跟踪案例、使用模板生成最终报告、扫描本地可能存在的机密信息、创建净化后的公开副本以及进行多种形式的导出。
2. **适用场景**：适用于负责任的漏洞披露记录、漏洞赏金报告撰写、CVE研究笔记、公开文章草稿以及净化报告的准备工作。
3. **核心特色**：本地优先，仅需在Obsidian库内使用Markdown文件，无需服务器、账户、云数据库、API密钥、外部AI服务或许可证服务器，简单易用。
4. **使用建议**：可先使用“Vuln Report Kit: Open quick start guide”命令查看快速入门指南，再通过“Vuln Report Kit: Create vulnerability case”创建案例，按核心工作流程逐步完成漏洞研究文档的记录与报告生成，过程中可按需使用模板和扫描机密信息等功能。
