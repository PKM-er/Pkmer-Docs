## 概述

### Joplin Server Sync插件总结
1. **主要功能**：实现Obsidian与Joplin Server的双向同步，涵盖笔记、文件夹和附件。支持端到端加密，可转换链接和标签，处理文件和文件夹的移动、重命名，具备冲突解决机制，还有强制同步、同步历史记录展示及排除特定路径的功能。
2. **适用场景**：适用于需要在多设备间同步笔记，且希望使用Joplin Server进行管理的用户，尤其是注重数据安全、需要处理复杂文件操作和同步冲突的场景。
3. **核心特色**：双向同步基于Joplin Server delta API，端到端加密使用官方协议，多客户端一致性通过稳定的文件ID和变更日志保障，冲突解决有多种策略。
4. **使用建议**：可通过Obsidian社区插件直接安装，也可手动或借助BRAT安装。开启端到端加密时，设置好密码并妥善保管；在同步中遇到问题，可根据冲突解决策略选择合适的处理方式；如需跳过特定路径，可在设置中添加排除模式。
