## 概述

### Git Revision Tracker插件总结
1. **主要功能**：基于Git追踪写作项目各阶段的进度，分析Git提交，识别新写作、删除和修改内容，提供净词差异、总工作量、纯修改工作量等丰富进度指标。
2. **适用场景**：适用于使用Git管理的写作项目，帮助写作者准确掌握自己的工作进度。
3. **核心特色**：能精准检测修订，采用基于Levenshtein的词级差异计算；提供类似GitHub的热力图展示每日进度；有三种视图呈现数据；可自定义新单词、删除单词和修改单词的权重；支持自动追踪每日目标；能灵活过滤文件和作者。
4. **使用建议**：Obsidian库需为Git仓库或其子文件夹，Git要安装并配置好路径。该插件不管理Git，需使用自己喜欢的Git客户端。可根据个人对“进度”的定义调整权重，利用文件和作者过滤功能聚焦关键内容。
