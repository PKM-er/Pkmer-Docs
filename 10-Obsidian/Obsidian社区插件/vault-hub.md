## 概述

### 1. 主要功能
Vault Hub 是一款用于发布和安装 Vault Hub 资源的 Obsidian 插件。可将笔记、代码片段、完整保险库发布到 GitHub，生成 `hub.md` 元数据和 `README.md` 文件，检测所需社区插件，附加 CSS 代码片段，上传截图；能在 Obsidian 内浏览 Vault Hub 目录并直接安装笔记包和 CSS 代码片段，还可在侧边栏管理已安装的 CSS 代码片段。

### 2. 适用场景
适合需要在社区分享笔记、代码片段，或从社区获取资源丰富自己 Obsidian 保险库的用户。

### 3. 核心特色
支持多种资源发布，能自动生成相关文件，可直接在 Obsidian 内完成资源的浏览与安装。

### 4. 使用建议
- 手动安装，将相关文件放入保险库插件目录。
- 设置时需粘贴有 repo 访问权限的 GitHub 个人访问令牌。
- 利用插件命令进行资源的发布、更新和浏览。注意该插件仅支持桌面端，发布和更新需 GitHub 账户和令牌。
