## 概述

**主要功能**
PDF Translator 是一款专为 Obsidian 设计的学术 PDF 阅读插件。它支持读取 PDF 文件并生成布局感知的精准翻译，同时内置 AI 助手，允许用户在阅读工作区内直接对论文进行摘要或提问，无需切换工具。

**适用场景**
主要适用于科研人员、学生及专业人士阅读英文学术论文。特别适合需要处理包含复杂公式、图表或特殊符号的文档，以及希望在一个统一环境中完成“阅读-翻译-讨论”全流程的用户。

**核心特色**
1. **视觉增强翻译**：结合 PDF 文本层与页面渲染图像，利用多模态模型的视觉理解能力，在文本提取丢失数学结构时，能准确重构公式、符号及阅读顺序。
2. **双向对齐高亮**：源文与译文保留段落映射关系，鼠标悬停任意一侧即可高亮显示对应内容，便于对照阅读。
3. **上下文感知助手**：AI 助手共享文档上下文，可基于整篇论文内容提供精准问答和总结。

**使用建议**
配置 API 时，务必选择支持**视觉/图像输入**的 OpenAI 兼容模型，纯文本模型无法可靠处理公式和布局。建议确保 API 支持长上下文及流式响应，以优化页面翻译速度和体验。
