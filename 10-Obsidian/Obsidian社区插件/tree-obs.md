# Obsidian 插件：Tree Obs

> [!Note] 插件名片
> - 插件名称：Tree Obs
> - 插件作者：Yuyang
> - 插件说明：把标记好的TreeChat导出内容转化为可供图谱视图查看的关联树形笔记。——此插件尚未经过Obsidian官方人员的人工审核。

## 概述

### 主要功能
Tree Obs 可将标记的 Tree Chat 导出的 Markdown 文件转换为每个节点一个 Obsidian 笔记，并通过维基链接连接父子笔记，也支持符合相同格式的手动标记 Markdown 文件。

### 适用场景
适用于需要将 Tree Chat 中的数据以树形笔记形式导入 Obsidian 进行可视化展示和管理的用户，可在 Obsidian 的图视图中查看笔记关系。

### 核心特色
独立于 Tree Chat 运行，不捆绑或运行 Tree Chat，仅读取用户放在 Obsidian 库中的 Markdown 文件，不提供自动或双向同步。转换后会保留源导出文件，在以根节点命名的文件夹中生成节点笔记。

### 使用建议
可从 Obsidian 社区插件安装（待审核通过），也可从 GitHub Release 手动安装。快速开始时，先在 Tree Chat 中导出含节点标记的 Markdown 文件，再将其放入 Obsidian 库，使用 Tree Obs 进行转换。
