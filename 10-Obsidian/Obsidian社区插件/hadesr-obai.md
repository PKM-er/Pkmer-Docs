## 概述

Hadesr AI 旨在解决 Obsidian 写作过程中频繁切换侧边栏或打断心流的问题。它通过“选中即胶囊”的交互设计，让 AI 辅助直接嵌入编辑区：选中文字后浮出操作菜单，支持润色、纠错、扩写等 16 种内置动作；停手片刻则自动触发行内补全，以灰色文字预测后续内容。这种无侵入式的设计让你无需离开键盘，即可在光标处完成改写、续写或格式转换，保持写作节奏的连贯性。

典型场景如撰写技术文档时，选中一段晦涩的描述，点击“简化语言”或“转列表”，瞬间获得更清晰的表达；或在长文写作中，利用“AI 划范围”功能，让 AI 自动标记出所有提及特定关键词的段落，仅做高亮而不修改正文，待你确认后再批量处理。此外，对于多段落的统一调整，可先标记多段，再在浮动对话面板中发送指令，一次性完成所有标记内容的改写，失败项还能单独重试。

相比同类插件，Hadesr AI 的特色在于其精细的控制力与效率优化。它提供“差异预览”功能，在替换前逐行展示改动，支持仅复制变化部分，避免误操作。针对大文档，其“两段式”定位机制能显著减少 Token 消耗并加快首字响应。同时，插件支持 OpenAI、Anthropic 及 Google 等多种接口，允许为不同动作单独指定模型，且所有内置提示词均可自定义，兼顾了灵活性与专业性。

使用前需注意，行内补全依赖 Obsidian 编辑器特定能力，在部分移动端或旧版本中可能自动关闭，但不影响其他功能。该插件不适合需要完全离线且无本地模型支持的用户，因为所有 AI 功能均依赖你配置的 API 接口。此外，虽然 API Key 经过混淆存储，但本质仍是明文保存于本地，若对隐私有极高要求，需自行评估风险。插件不包含数据统计或第三方上报，唯一的网络行为是向你的 API 发送文本。
