## 概述

**AXXA Agent** 是一款移动优先的 Obsidian AI 助手插件，支持桌面与移动端无缝使用。

1. **主要功能**：提供聊天、基于 RAG 的库问答（Vault Q&A）及智能体（Agent）笔记编辑三大模式。支持 OpenAI、Claude、Gemini、Ollama 等六种主流模型，用户需自备 API 密钥，所有对话记录均保存为 Markdown 文件。
2. **适用场景**：适合需要在手机或电脑上随时查阅笔记、基于个人知识库提问，或希望让 AI 直接辅助修改、整理笔记内容的用户。
3. **核心特色**：移动优先设计，界面适配手机布局；回答具备溯源能力，能引用具体笔记来源；支持本地模型（Ollama），保障数据隐私；多模型兼容，灵活度高。
4. **使用建议**：安装后需在设置中配置对应的 API 密钥。建议先使用“库问答”模式测试检索准确性，再尝试“智能体”模式进行自动编辑。注意该插件未经 Obsidian 官方人工审核，使用前请备份重要数据，并留意 GPL-3.0 许可证要求。
