## 概述

**插件名称**：Markdown Heading Links

**主要功能**
该插件旨在弥补 Obsidian 原生对标准 Markdown 标题链接（如 `[文本](#slug)`）支持不足的缺陷。它提供了标准的悬停预览和点击导航功能，支持在编辑模式下通过输入 `#` 自动补全标题，并在阅读视图中提供复制标题 Slug 或完整 Markdown 链接的便捷按钮及命令。

**适用场景**
适用于需要频繁创建指向文档内部特定章节或跨笔记标题链接的场景。特别适合那些偏好使用标准 Markdown 语法而非 Obsidian 专有双链语法（`[[...]]`）进行笔记写作和知识管理的用户。

**核心特色**
1. **原生体验增强**：为普通 Markdown 标题链接增加 Ctrl/Cmd 悬停预览和点击跳转能力。
2. **智能辅助**：输入 `#` 后触发标题自动补全，极大提升链接创建效率。
3. **便捷复制**：在阅读视图和编辑模式下均提供一键复制 Slug 或完整链接的功能。
4. **去重处理**：自动为重复标题添加 `-1`、`-2` 等后缀以确保链接唯一性。

**使用建议**
在编辑模式下，输入 `[链接文本](# ` 后务必添加一个**空格**以激活自动补全建议。若需快速获取链接，可直接在阅读视图悬停标题使用复制按钮，或通过命令面板（Ctrl/Cmd+P）搜索“Copy Markdown link to heading”执行操作。
