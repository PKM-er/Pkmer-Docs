## 概述

**DeepSeek Harness** 是一款专为 Obsidian 桌面版设计的插件，旨在将 DeepSeek Harness (DSH) 的原生 Web GUI 无缝嵌入到笔记库中，实现 AI 工具与知识管理的深度整合。

**主要功能**
该插件通过官方扩展接口连接 DSH，在本地运行服务，无需修改 DSH 源码。它支持一键安装 DSH 及缺失依赖（如 Git、Node.js），并自动启动后台服务。用户可直接在 Obsidian 内通过 iframe 访问完整的 DSH 界面，实现笔记内容与 AI 交互的双向桥接。

**适用场景**
适用于 Windows 和 macOS 桌面用户，特别是那些希望在不离开 Obsidian 环境的情况下，利用 DeepSeek Harness 进行代码辅助、逻辑推理或复杂任务处理，同时保持笔记与 AI 工作流紧密相连的高级用户。

**核心特色**
1. **极简部署**：一键配置，自动检测并安装依赖，全程无需命令行操作。
2. **静默运行**：后台静默启动，无控制台窗口干扰，崩溃后可一键重连。
3. **原生体验**：嵌入真实 DSH Web UI，支持 0.5×–2.0× 缩放及主题自适应，随 DSH 版本更新持续兼容。

**使用建议**
安装后建议先运行“一键设置”完成环境初始化。使用时注意插件仅通过 localhost 通信，确保本地网络环境正常。由于涉及外部 AI API 请求，请根据实际使用场景配置好相应的 API 密钥。
