## 概述

**1. 主要功能**
该插件是 TTRPG Tools 生态系统的可配置控制中心。它提供专用侧边栏，允许用户自由创建分组、排列按钮并自定义外观。此外，它包含一个独立的 GM（主持人）界面导航面板，支持嵌套页面和 Markdown 笔记预览，并支持布局的 JSON 备份与导入。

**2. 适用场景**
主要适用于使用 Obsidian 进行桌面角色扮演游戏（TTRPG）的 GM 或玩家。特别适合需要频繁切换地图、声音、时间线等工具，希望实现“一键操作”以简化游戏流程的用户。

**3. 核心特色**
*   **高度自定义**：支持按组设置强调色、按钮图标及颜色，全局调整间距与圆角。
*   **生态整合**：无缝集成 Maps、Soundboard、Time 等多个 TTRPG 子插件。
*   **稳健性**：即使提供者插件被禁用，按钮仍保留在布局中并自动置灰，配置不丢失。
*   **GM 专属**：提供专门的 GM 导航面板，支持笔记预览和原生悬停预览。

**4. 使用建议**
建议根据游戏频率将常用动作（如切换地图、播放音效）置顶分组。利用“点击折叠”功能保持界面整洁。定期使用 JSON 功能备份布局，以防插件更新或重装导致配置丢失。注意该插件需配合其他 TTRPG Tools 系列插件使用才能发挥完整功能。
