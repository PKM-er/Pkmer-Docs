## 概述

**Sidecar AI 插件总结**

1. **主要功能**
在 Obsidian 侧边栏提供原生 AI 聊天界面，直接调用本地已认证的 CLI 工具（如 Google Antigravity、GitHub Copilot、Pi Coding Agent 或自定义 CLI）进行交互，无需配置额外的 API 密钥或代理。

2. **适用场景**
适合已拥有 Google AI 或 GitHub Copilot 订阅，且希望避免额外 API 费用、注重数据隐私的用户。适用于在笔记中快速提问、总结内容或基于选中文字进行上下文查询。

3. **核心特色**
*   **零额外成本**：复用现有订阅，无需支付按 token 计费的 API 费用。
*   **隐私优先**：数据通过本地 CLI 处理，避免向第三方服务器发送敏感密钥。
*   **原生体验**：界面与 Obsidian 风格完美融合，支持多种主流模型（Gemini、Claude、GPT 等）。

4. **使用建议**
*   确保终端中已安装并登录对应的 CLI 工具（如运行 `agy` 或 `copilot login`）。
*   通过左侧丝带图标或命令面板（`Ctrl/Cmd + P`）打开侧边栏。
*   建议在笔记中选中特定文本后提问，以获得更精准的上下文回答。
