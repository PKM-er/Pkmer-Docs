## 概述

### Code Workbench插件总结
1. **主要功能**：提供Claude代码IDE功能，含语法高亮、代码格式化等编辑功能；能通过Claude维护Obsidian知识库，包括文件整理、链接修复；支持与Claude Code CLI一键连接。
2. **适用场景**：适用于在Obsidian中管理笔记、项目、研究等知识内容，希望借助AI工具整理知识库，以及有代码编辑需求的用户。
3. **核心特色**：免费使用；一键连接Claude，无需额外设置，使用用户已有Claude订阅，避免API费用；支持多种Claude兼容模型；Claude维护知识库时基于内部链接图操作，变更需用户批准，保障数据安全；具备真正的代码编辑器。
4. **使用建议**：开启知识库维护功能前，明确自身笔记组织体系；使用Claude进行操作时，仔细审核变更内容，确保符合需求。
