## 概述

### Smart List Input 插件总结
1. **主要功能**：实现智能 Markdown 列表输入，可将中文标点（如 1、1。等）自动转换为标准序号，支持有序、无序列表和待办列表的快速切换，确保子项类型与所在层级一致。
2. **适用场景**：适用于使用 Obsidian 进行 Markdown 文档编写，需要频繁创建和编辑列表的场景。
3. **核心特色**：
    - 自动将中文序号标点转换为标准 Markdown 序号。
    - 通过简单输入（如 `-`、`【`）或按键操作（`Tab`、`Shift+Tab`）快速切换列表类型。
    - 子项类型自动适配上级列表，避免嵌套有序列表。
    - 支持标准和非标准的待办标记。
    - 按 `Backspace` 可删除标记保留内容。
4. **使用建议**：在输入列表时，若使用中文序号标点，按空格即可自动转换；需创建子列表时，在有序列表下一行输入 `-` 或 `【` ；使用 `Tab` 和 `Shift+Tab` 灵活调整列表层级和类型。
