# Obsidian 插件：Vault File Refresh

> [!Note] 插件名片
> - 插件名称：Vault File Refresh
> - 插件作者：Labtopia
> - 插件说明：会递归地检查从Obsidian外部添加到仓库里的新文件，并自动对这些文件进行处理。——此插件尚未经过Obsidian官方人员的手动审核。

## 概述

### Vault File Refresh插件总结
1. **主要功能**：自动识别从Obsidian外部添加到保险库的文件，无需手动重启。每8秒递归扫描整个保险库，将磁盘上存在但Obsidian未知的文件进行同步，也会对已存在但内容有更新的文件进行无声同步。
2. **适用场景**：适用于以Flatpak方式安装Obsidian、将保险库存储在网络驱动器、通过脚本或AI工具同步文件、从外部应用写入保险库的场景。
3. **核心特色**：完全递归，覆盖整个保险库及所有嵌套子文件夹；自动跟踪新创建的文件夹；相比社区Auto Refresh插件，无需手动列出要监视的文件夹，且能递归操作。
4. **使用建议**：若遇到新文件或文件夹无法及时在文件资源管理器显示，或打开文件内容未更新的问题，可安装此插件解决，让文件同步更便捷。
