## 概述

**1. 主要功能**
该插件在 Obsidian 库内集成 Claude 聊天窗口。它能直接读取当前打开的笔记及选中的文本，将对话上下文无缝融入 AI 回答中，并将会话自动归档为笔记。

**2. 适用场景**
适用于需要基于特定笔记内容、项目背景或关联文档进行深度问答的场景。特别适合避免将笔记内容复制到外部聊天窗口时丢失关键上下文的痛点，仅限桌面端（Obsidian 1.8.7+）使用。

**3. 核心特色**
*   **原生上下文感知**：AI 直接访问库内文件，无需手动粘贴内容，保留完整项目与人物背景。
*   **库内指令驱动**：行为规则由用户库内的指令文件定义，而非插件预设，确保 AI 符合个人工作流。
*   **ICOR 卡片输出**：回答以结构化的 ICOR 卡片呈现，提升可读性。
*   **本地 CLI 依赖**：依赖本地安装的 Claude Code 命令行工具，无独立 API 密钥字段。

**4. 使用建议**
*   **前置条件**：务必先在本地安装并登录 Claude Code 命令行工具，否则插件无法运行（这是最常见的问题）。
*   **环境限制**：仅支持桌面端，移动端无法运行本地程序。
*   **配置灵活**：行为逻辑存储在库内文件中，用户可自定义 AI 身份与上下文规则。
