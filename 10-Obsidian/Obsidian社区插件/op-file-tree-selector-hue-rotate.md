## 概述

### 插件名称
File Tree Selector Hue Rotate

### 主要功能
使用直接、连续的边框颜色帧，在鼠标悬停或激活的项目周围注入一个颜色旋转的动画边框覆盖框。

### 适用场景
适用于使用Obsidian进行笔记整理、文档编辑等操作时，用户需要快速定位和区分当前鼠标悬停或激活的文件或项目的场景。

### 核心特色
通过颜色旋转的动画边框，为用户提供更直观、动态的视觉反馈，帮助用户在众多文件和项目中迅速聚焦到当前操作的对象。
