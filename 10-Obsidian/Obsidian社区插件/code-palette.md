## 概述

Code Palette 旨在解决 Obsidian 中代码显示风格单一的问题，允许用户为行内代码、表格代码及代码块独立选择配色方案。其核心功能包括按文件或文件夹设置默认语言规则，实现语法高亮，同时支持全局回退配色，确保未匹配规则的笔记也能拥有统一的代码外观，且全程不修改笔记原文。

典型场景如编写技术笔记时，可将特定文件夹设为 Python 默认语言，使其中的行内代码自动获得高亮；若需展示 Markdown 结构，可将 `text` 块规则设为 Markdown 并启用正文预览，在阅读视图中直接显示标题、列表等格式，而非纯代码文本。

相比同类插件，Code Palette 的特色在于“稳定编辑”机制，连续输入时保留已有颜色，减少视觉闪烁；同时提供 10 套离线主题和 24 种语言支持，允许保留或替换已有代码块的语言标记，灵活适配不同工作流。

使用前需注意，该插件仅提供语法高亮，不支持代码执行或语义分析；单段代码超过 20 万字符时将回退至原生显示。它不适合需要实时代码运行、复杂 IDE 级语义提示，或移动端重度使用的用户，因为移动端尚未完成实测。
