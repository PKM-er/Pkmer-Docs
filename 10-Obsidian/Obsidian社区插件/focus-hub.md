## 概述

Focus Hub 旨在将任务管理与项目规划整合于单一界面，核心功能包括带有状态、评论及图片附件的任务列表，以及每日“今日”视图。它允许用户通过甘特图时间线管理项目，支持依赖关系设置、关键路径计算及进度追踪，帮助你在一个地方掌控所有待办事项与项目动态。

典型场景如规划每日工作时，你可以利用“今日”视图查看建议焦点、当前进行中的任务及未来七天的安排，周末还会自动隐藏工作类任务，仅显示个人事项。在项目管理中，你可以直接在笔记中插入甘特图，通过拖拽调整任务时长或开始时间，系统会自动更新依赖任务的排期，并直观展示项目整体进度与计划偏差。

相比同类插件，Focus Hub 的特色在于其强大的时间线交互能力，支持工作日调度、节假日排除及基线对比，并能将图表导出为 PDF 或 PNG。此外，它提供可选的 AI 晨间建议功能，通过调用 Anthropic API 分析未完成任务，生成每日优先事项建议，且该功能完全由用户自主控制，默认关闭。

使用前需注意，所有数据存储在插件专属的 `data.json` 文件中，随库同步。若启用 AI 建议，需自行配置 API 密钥，且任务详情会发送至 Anthropic 服务器，不适合对数据隐私极度敏感或完全离线环境的用户。此外，该插件主要服务于个人任务与项目规划，若你需要复杂的团队协作或企业级权限管理，它可能无法满足需求。
