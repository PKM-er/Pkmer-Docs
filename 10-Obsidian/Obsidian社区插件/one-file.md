## 概述

### One File插件总结
1. **主要功能**：可在Obsidian库内以无干扰的专注模式编辑电脑上的任意Markdown文件，通过创建指向原文件的链接避免文件复制，编辑直接作用于原文件。
2. **适用场景**：适用于在Obsidian中集中编辑电脑上分散的Markdown文件，适合桌面端（macOS、Windows、Linux）用户。
3. **核心特色**：采用链接而非复制文件的方式，无重复文件和同步问题；专注模式可隐藏界面元素；能清理指向已删除文件的链接；链接文件夹可见，便于了解文件来源。
4. **使用建议**：安装时将相关文件复制到指定目录，在Obsidian中启用插件，若编辑受保护位置文件需授予相应权限。可通过“Open file from computer”或“Open file by path”命令打开文件，用“Toggle focus mode”切换专注模式，定期使用“Clean up links to deleted files”清理无效链接，设置可在社区插件中调整。
