## 概述

HandyLearn 将你的 Obsidian 库转化为个人英语词汇笔记本，核心功能是在阅读过程中无缝捕捉生词。它允许你在阅读论文、文档或笔记时，通过右键点击直接创建包含丰富上下文的闪卡，并利用间隔重复算法进行复习。整个过程无需离开 Obsidian，实现了从“遇到生词”到“掌握词汇”的闭环，让英语学习融入日常阅读习惯。

典型场景包括备考和日常阅读。例如，在准备考研或托福时，你可以运行“从当前笔记提取生词”命令，系统会自动扫描当前笔记，按考试词表（如 CET-4/6、考研、GRE 等）或频率分组，让你勾选后批量建卡。或者，在阅读英文技术文档时，遇到不认识的术语直接右键建卡，稍后通过侧边栏的“开始今日学习”进行复习，利用键盘快捷键快速完成记忆测试。

相比同类插件，HandyLearn 的特色在于其上下文关联与批量处理能力。每张卡片都会记录你遇到该单词的具体笔记来源，形成上下文反向链接，帮助记忆。此外，它支持基于 SM2 算法的间隔重复，提供“回忆含义”和“拼写”两种卡片模式，并可选用 DeepSeek 或 Doubao API 生成例句。已收录的单词在阅读视图中会以虚线下划线高亮，点击即可跳转至对应卡片，极大提升了复习效率。

使用前需注意，AI 例句功能需自行配置 DeepSeek 或 Doubao 的 API 密钥，若留空则禁用该功能。该插件主要面向希望系统化积累英语词汇的用户，不适合仅需简单查词或没有长期记忆需求的场景。此外，部分功能如发音和词典处理基于开源项目 obsidian-spaced-repetition，请确保你的网络环境能正常访问相关服务以获取最佳体验。
