## 概述

### User Prompt Optimizer 插件总结
1. **主要功能**：选中提示词后借助大语言模型（LLM）优化，结果流式返回并覆盖原选内容。有流式优化，支持两种优化模式（模板优化和轻量级优化），提供 OpenAI 兼容和 Anthropic 两种调用源，可控制推理与采样参数，具备可见状态反馈，能保留技术细节，还可选择注入角色。
2. **适用场景**：适用于提示工程场景，帮助用户优化提示词以更好与模型交互，不适用于通用写作辅助。
3. **核心特色**：两种优化模式灵活可选，支持多种调用源及兼容服务方言，操作状态可视化，可随时中断，能精准保留技术细节，可自动注入角色。
4. **使用建议**：根据需求选择合适的优化模式；若需特定模型，可一键获取模型列表；优化过程中若想停止，点击状态提示处即可；启用角色注入可让优化后的提示词直接用于其他模型。
