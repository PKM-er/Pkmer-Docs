# Obsidian 插件：Code Block Plus

> [!Note] 插件名片
> - 插件名称：Code Block Plus
> - 插件作者：Patrick
> - 插件说明：类似思源笔记的代码块，带有语言选择标签（点击可下拉选择）、悬停复制按钮、智能的Ctrl/Cmd + A 操作、中文标点触发（输入···即可触发代码块）、外观可定制，还有双语界面（中文/英文）。 - 此插件尚未经过Obsidian官方人员的人工审核。

## 概述

### Code Block Plus插件总结
1. **主要功能**：为Obsidian的代码块添加功能，如带语言标签（可点击选择、搜索、输入自定义语言）的美观标题栏、复制按钮，支持智能Ctrl/Cmd + A选择，能用中文标点 `···` 触发创建代码块，空块可按退格键删除，隐藏代码围栏线，新代码块自动添加空行，外观可自定义，支持双语界面。
2. **适用场景**：适用于Obsidian用户在编辑笔记时需要插入、编辑代码块的场景。
3. **核心特色**：拥有40 + 预设语言的搜索式语言选择器，复制按钮悬停显示，支持手机端操作，且操作控件适配触摸，在手机上始终可见。
4. **使用建议**：可从GitHub手动下载 `main.js`、`styles.css` 和 `manifest.json` 文件安装，也可在Obsidian社区插件浏览器中搜索 “Code Block Plus” 安装。安装后可在设置中自定义外观、切换语言，开启或关闭复制按钮悬停显示等功能。
