## 概述

**ContextFlow** 是一款本地优先的 Obsidian 快速插入插件，旨在通过极简操作提升笔记效率。

**主要功能**：提供统一的“快速插入”菜单，支持在光标处插入日期、时间、任务，或对选中文本进行高亮、转换为任务/引用块、创建内部链接及代码块等格式化操作。

**适用场景**：适用于日常笔记记录、任务管理、文档格式化及需要频繁插入标准 Markdown 元素的工作流，特别适合追求高效输入且不愿配置复杂模板的用户。

**核心特色**：
1. **多入口触发**：支持命令面板、右键菜单、侧边栏按钮、快捷键及 `/` 斜杠菜单，操作灵活。
2. **智能隐藏**：无选中文本时自动隐藏相关操作，避免误触。
3. **零门槛上手**：内置动作无需理解 JSON 或变量即可使用；支持通过 JSON 文件分享自定义动作包。
4. **工作流支持**：可串联多个动作形成工作流，实现批量处理。

**使用建议**：
1. 启用插件后，习惯使用 `/` 斜杠菜单或右键菜单快速调用功能。
2. 利用“选中文本”触发特定格式转换，保持操作意图清晰。
3. 进阶用户可创建自定义动作模板（如 `{{date}}`），并打包为 JSON 以便复用或分享，进一步个性化工作流。
