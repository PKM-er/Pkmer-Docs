## 概述

### CM Code Editor插件总结
1. **主要功能**：这是一款适用于Obsidian的代码文件编辑器，基于CodeMirror 6构建。具备语法高亮（支持25+种语言）、代码折叠、代码自动补全、搜索和替换等功能，还有多种语法主题可选，可配置缩进、行数显示等。
2. **适用场景**：适合在Obsidian中进行代码编辑和记录的用户，如开发者、技术文档撰写者等，能在笔记中便捷地处理代码内容。
3. **核心特色**：支持丰富的语言和语法主题，可继承Obsidian主题；有内置语言自动补全；具备代码折叠的侧边栏控制；有缩进引导和活动行高亮显示。
4. **使用建议**：确保Obsidian版本在1.13.0+。可通过Obsidian社区插件商店搜索“CM Code Editor”安装，也可手动从GitHub下载并解压到指定目录后启用。使用时可根据需求调整各种配置，如主题、缩进大小等。
