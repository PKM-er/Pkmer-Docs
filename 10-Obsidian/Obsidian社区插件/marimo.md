## 概述

**主要功能**
该插件允许用户在 Obsidian 中直接编辑和运行 Marimo 响应式 Python 笔记本。它通过注册 `.py` 文件扩展名，使 Python 笔记本在文件资源管理器中可见，并支持以“编辑器”模式（完整代码编辑）或“应用”模式（仅展示输出和交互组件）两种视图运行。

**适用场景**
适用于需要在 Markdown 笔记环境中进行数据探索、科学计算或构建交互式数据应用的开发者与研究人员。特别适合希望将 Python 分析流程与文档管理整合在一起的用户。

**核心特色**
1. **无缝集成**：将 Marimo 笔记本直接嵌入 Obsidian 工作区，无需切换外部浏览器。
2. **双模式视图**：支持代码编辑与纯应用展示，方便调试与成果分享。
3. **自动化管理**：首次使用时可自动安装缺失的 Marimo 依赖，简化配置流程。
4. **纯文本存储**：笔记本以标准 `.py` 文件形式保存，便于版本控制和跨平台兼容。

**使用建议**
1. **环境准备**：需安装 Python 3 及 Marimo 包，且仅限桌面端使用（不支持移动端）。
2. **操作方式**：可通过侧边栏图标或命令面板新建笔记本，右键点击 `.py` 文件选择打开模式。
3. **注意**：该插件为社区非官方开发，未获 Obsidian 官方审核，使用前请确保了解相关风险。
