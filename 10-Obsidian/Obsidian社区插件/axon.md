## 概述

**1. 主要功能**
Axon 利用用户本地的 Claude Code 实例读取 Obsidian 笔记，自动识别并提取其中隐含的任务，经用户确认后同步至自托管的 Vikunja 任务管理系统。

**2. 适用场景**
适用于习惯在笔记中记录想法、待办事项或复杂计划，但容易遗漏关键行动点的用户。特别适合需要管理个人项目、工作待办，且已有 Vikunja 使用习惯的知识工作者。

**3. 核心特色**
*   **零额外成本**：无需 Anthropic API Key，直接复用用户现有的 Claude Code 登录状态和订阅计划。
*   **智能去重**：自动识别并分离已存在于 Vikunja 中的任务，避免重复添加。
*   **精准提取**：专注于“易被遗忘”的具体行动项，过滤掉日常习惯或时间块；遵循“一目标一任务”原则，将复杂逻辑合并为单一清晰任务。
*   **双向链接**：生成的任务会自动关联回源笔记，方便追溯上下文。

**4. 使用建议**
*   确保已正确配置本地 Claude Code 环境。
*   在笔记中保持自然书写风格，无需刻意格式化任务列表，Axon 能自动从非结构化文本中挖掘任务。
*   利用侧边栏的“Review”阶段，仔细核对提取的“确定任务”与“可能任务”，调整日期、优先级及标签后再同步，以确保任务管理的准确性。
