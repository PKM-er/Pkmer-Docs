## 概述

**1. 主要功能**
Simple Vimeo 允许用户通过标准的 Markdown 图片语法（`![](URL)`）在 Obsidian 笔记中直接嵌入 Vimeo 视频。它在阅读视图和实时预览中显示视频播放器，同时保留原始 Markdown 格式不变，并在播放器下方保留原始链接。

**2. 适用场景**
适用于需要在笔记中引用 Vimeo 视频内容的场景，如课程记录、视频素材整理或项目文档。特别适合希望保持笔记纯文本兼容性，同时获得良好阅读体验的用户。

**3. 核心特色**
*   **极简语法**：无需复杂代码块，仅用一行 Markdown 图片语法即可嵌入。
*   **双视图支持**：在阅读视图和实时预览中均能正常显示播放器。
*   **非侵入性**：不修改原始 Markdown 文本，保持笔记的纯净和可移植性。
*   **隐私友好**：明确说明隐私和网络访问策略。

**4. 使用建议**
*   **安装方式**：该插件尚未上架 Obsidian 社区插件目录，需从 GitHub Releases 手动下载 `main.js`、`manifest.json` 和 `styles.css` 至 `.obsidian/plugins/simple-vimeo/` 文件夹。
*   **更新注意**：更新时仅替换上述三个文件，务必保留 `data.json` 以保存现有设置。
*   **格式规范**：建议将每个视频嵌入单独放在一行，并在前后留空行，以确保布局稳定。
