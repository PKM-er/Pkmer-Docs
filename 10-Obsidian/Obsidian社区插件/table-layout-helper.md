## 概述

### XU Table Layout Helper 插件总结
1. **主要功能**：可自定义 Markdown 表格的布局、列宽、文本换行、对齐方式、溢出控制和表头粘性等，替代手写 CSS 代码。
2. **适用场景**：适用于需要在 Obsidian 中对 Markdown 表格样式进行精细调整的场景，如制作文档、笔记等。
3. **核心特色**：提供丰富的设置选项，包括多种表格布局和宽度模式、列宽控制、文本换行方式等；支持可视化配置和实时预览，修改设置后样式立即生效，无需重启；同时支持阅读视图和实时预览视图。此外，还具备表头粘性、斑马纹、链接不折行等特色功能。
4. **使用建议**：推荐从 Obsidian 社区插件目录安装该插件。使用时，可根据实际需求灵活调整各项设置，如使用固定列宽布局模式和表头粘性功能，以提升表格的可读性和专业性。
