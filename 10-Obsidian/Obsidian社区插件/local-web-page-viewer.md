## 概述

**Local Web Page Viewer** 是一款专为 Obsidian 设计的插件，旨在解决原生无法渲染本地 `.html` 文件的问题。

1.  **主要功能**：将 Vault 中的 `.html` 文件作为真实网页打开，完整支持 CSS 样式、图片及视频播放。提供缩放、书签管理及滚动位置记忆功能，实现桌面端与移动端体验一致。
2.  **适用场景**：适用于在 Obsidian 中直接阅读本地静态网页，如通过 Telegram Desktop 导出的包含复杂资源（CSS/JS/媒体）的频道存档，或其他无法被 Obsidian 原生解析的 HTML 文档。
3.  **核心特色**：
    *   **真实渲染**：突破 Obsidian 内容安全策略限制，确保页面交互、链接跳转及媒体播放正常。
    *   **跨平台一致**：桌面端支持工具栏自定义固定与排序；移动端支持宽度适配及便捷的书签跳转。
    *   **状态记忆**：自动保存滚动位置与书签，方便长文档断点阅读。
4.  **使用建议**：适合需要频繁查阅本地 HTML 导出内容的用户。建议利用工具栏自定义功能，将常用操作（如缩放、书签）固定以便快速访问。注意该插件尚未经过 Obsidian 官方人工审核，使用前请确保来源可信。
