## 概述

### Git History插件总结
1. **主要功能**：以直观界面管理Obsidian库的Git版本控制，无需终端操作。可跟踪编辑的笔记，查看更改历史、撤销后悔的更改，还能备份。提供交互式提交图、源控制面板和差异查看器。
2. **适用场景**：适用于需要对Obsidian笔记库进行版本管理、备份，以及回顾笔记更改历史的场景。
3. **核心特色**：界面直观，将所有版本信息以可视化时间线呈现，操作简单，点选即可完成。涵盖提交、推送、拉取等常见Git操作，方便用户管理笔记库。
4. **使用建议**：若库还不是Git仓库，可从Obsidian命令面板运行“Initialize Git repository”命令初始化。日常使用养成记录更改内容、按“Commit”和“Push”的习惯。源控制面板可查看更改笔记，能按需求选择单个笔记、整个文件夹或全部进行暂存和提交。
