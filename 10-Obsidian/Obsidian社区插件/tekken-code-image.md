## 概述

### Tekken Code Image插件总结
1. **主要功能**：将日本铁拳格斗游戏的指令表示法转换为SVG图像。在Obsidian中，通过创建`tekken`代码块，输入数字方向和攻击按钮组成的指令，即可渲染为SVG图像。
2. **适用场景**：适用于铁拳格斗游戏玩家、爱好者在Obsidian笔记中记录和展示游戏指令，方便指令的直观呈现和分享。
3. **核心特色**：支持多种指令记法，包括方向、攻击按钮、滑动、同时按键、分隔符、任意文本等；可在插件设置中调整图像的形状大小、间距、文本样式和攻击按钮颜色。
4. **使用建议**：安装时在Obsidian社区插件中搜索并安装启用。使用时按照支持的记法在`tekken`代码块输入指令。需注意斜向箭头图形左右间隙较大，不支持部分游戏图标，可用任意文本替代；指令最大长度为200字符，有问题可提Issue反馈。
