## 概述

**Qualitative Query** 是一款基于语义检索的 Obsidian 插件，旨在通过“提问-阅读-连接”的工作流，从现有笔记中挖掘答案并建立知识关联。

**主要功能**：支持保存问题，利用本地搜索与 Jev 评分精准定位能回答该问题的原始段落，并将这些段落通过原生块嵌入（Block Embeds）连接起来。

**适用场景**：适合需要深度整理个人知识库、进行定性研究或从大量笔记中提炼特定观点（如概念辨析、主题归纳）的用户。

**核心特色**：
1. **原汁原味**：直接展示原始笔记段落，而非生成式 AI 的摘要，确保信息溯源准确。
2. **智能筛选**：结合本地关键词检索与 Jev API 语义评分，精准过滤相关度高的内容。
3. **动态连接**：保存结果后自动生成带有反向链接的笔记，在本地图谱中直观展示知识间的关联，且结果随笔记更新实时同步。

**使用建议**：
1. 首次使用需下载约 31MB 的搜索模型以启用语义匹配。
2. 建议配置 TypeSafe 的 Jev API Key 以获得更精准的语义评分；若无 Key，仅使用本地匹配功能。
3. 可通过命令面板启动，选择预设模式（如“相关段落”或“区别辨析”）提问，并定期回顾生成的连接笔记以深化知识网络。
