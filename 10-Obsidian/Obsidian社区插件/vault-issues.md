## 概述

**1. 主要功能**
Vault Issues 是一款仿 GitHub Issues 的任务追踪插件。它将任务存储为带有 YAML 前置信息的 Markdown 文件，支持列表与看板（Kanban）双视图切换。核心功能包括拖拽更新状态（Open/In progress/Closed）、优先级与标签管理、项目分组、截止日期提醒，以及强大的搜索、过滤和排序能力。

**2. 适用场景**
适用于个人知识管理、项目任务管理或待办事项追踪。特别适合需要离线使用、注重数据隐私（无网络、无遥测）且希望数据可移植的用户。

**3. 核心特色**
*   **数据即文件**：任务本质是 Markdown 文件，即使卸载插件，数据依然可读、可搜索、可移植。
*   **双向链接**：建立任务与源笔记的双向关联，便于追溯上下文。
*   **直观交互**：支持拖拽改状态、颜色编码的优先级/标签/截止日期，以及右键上下文菜单。

**4. 使用建议**
*   建议利用“双向链接”功能，在创建任务时关联相关笔记，增强知识关联。
*   善用看板视图进行日常快速流转，列表视图用于批量筛选和回顾。
*   注意该插件目前仅支持桌面端，移动端用户需另行考虑同步方案。
