## 概述

**1. 主要功能**
Claudian Scheduler 是一款 Obsidian 插件，用于定时向 Claudian 插件的指定对话框发送任务。它支持图形化界面排程，能自动切换目标标签页并在目标忙碌时自动等待，确保任务按时执行。

**2. 适用场景**
专为使用 DeepSeek API 的开发者设计。适用于希望利用 DeepSeek“峰谷定价”机制（北京时间 00:30-08:30 低谷时段）来降低 API 成本的用户。适合在白天批量规划数据处理或分析任务，由插件在夜间自动错峰执行。

**3. 核心特色**
*   **成本优化**：通过错峰发送，可节省 50%–75% 的 API 费用。
*   **零依赖**：纯 Obsidian 插件，无需 Python/Node 等外部环境。
*   **智能管理**：提供清晰的待发送列表与历史记录，支持任务取消；若关机期间任务到期，重启后自动补发。
*   **便捷交互**：侧边栏时钟图标一键打开面板，操作直观。

**4. 使用建议**
*   **前置条件**：必须已安装并启用 Claudian 插件。
*   **安装方式**：推荐通过 BRAT 插件安装以实现自动更新，或手动下载 Release 文件放入插件目录。
*   **注意事项**：Obsidian 需保持运行状态（或开机）；建议在低谷时段内（如凌晨 1-2 点）安排任务，以最大化成本效益。
