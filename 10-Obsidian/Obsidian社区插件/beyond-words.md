## 概述

**1. 主要功能**
Beyond Words 是一款利用 LLM 将词汇表转化为分级英语文章的 Obsidian 插件。它支持从文本、TXT 或 PDF 文件导入单词，自动生成包含目标词汇的上下文文章，并自动高亮显示这些词汇（含变形）。此外，插件还提供逐段翻译（中/英/日）及从文章中提取的常用短语库。

**2. 适用场景**
专为英语语言学习者设计，特别是希望摆脱死记硬背、通过真实语境掌握词汇用法的用户。适用于备考雅思（支持 4.0-9.0 分级）或日常英语积累。

**3. 核心特色**
- **i+1 分级生成**：根据用户选择的雅思听力水平生成难度适中的文章，兼顾可理解性与挑战性。
- **本地化验证**：本地检查文章是否包含所有目标词，缺失时自动重试，确保准确性。
- **灵活控制**：支持选择叙事、说明等风格及 100-800 字长度，翻译以引用块形式呈现。
- **兼容性强**：支持 DeepSeek、Kimi、OpenAI 等任意 OpenAI 兼容接口，且提供无需 API Key 的 Mock 模式供免费体验。

**4. 使用建议**
建议用户配置 DeepSeek 或 Kimi 等性价比高的 API 以降低成本。初次使用可先开启 Mock 模式熟悉流程。生成后文章自动保存至 `BeyondWords/` 文件夹，建议定期回顾高亮词汇和短语库，强化记忆。
