## 概述

**Concept Roamer** 是一款基于 DeepSeek API 的 Obsidian 插件，旨在通过对话深化概念理解并构建知识图谱。

**主要功能**：支持流式聊天与中断恢复，可将对话转化为结构化的 Markdown 概念笔记（涵盖定义、机制、案例等）。插件能自动建议链接至现有笔记，生成对话摘要，并支持从新讨论中更新旧笔记，具备版本备份与冲突检查功能。

**适用场景**：适合需要深度探索复杂概念、整理学习笔记或构建个人知识库的用户。特别适用于从特定笔记片段出发进行延伸讨论，或将零散想法系统化。

**核心特色**：
1. **智能记忆**：可编辑的人格设定与共享记忆笔记，保持对话上下文连贯。
2. **上下文管理**：支持手动/自动压缩上下文，保留原始消息，优化长对话体验。
3. **无缝集成**：支持从右键菜单直接讨论选中片段，生成带来源卡片的笔记，并支持桌面弹窗聊天。
4. **灵活编辑**：保存前可预览和编辑生成的 Markdown，确保内容符合预期。

**使用建议**：需自备 DeepSeek API Key（可能涉及费用）。建议定期维护“记忆笔记”以优化对话质量；利用“概念笔记”的结构化模板整理知识；在讨论特定笔记片段时，善用来源卡片功能以追踪知识脉络。
