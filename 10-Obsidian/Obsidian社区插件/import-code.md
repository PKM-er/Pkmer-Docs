## 概述

**1. 主要功能**
Import Code 允许在 Obsidian 笔记中通过 `![[file.ext]]` 语法嵌入本地或远程代码文件。支持自动语法高亮、提取特定符号（如函数/类）、指定行范围及高亮显示。兼容 GitHub、GitLab、Gitea、WebDAV 等多平台远程源，并支持从剪贴板创建代码文件并自动上传至指定位置。

**2. 适用场景**
适用于开发者在技术文档、学习笔记或项目 Wiki 中直接展示代码片段。特别适合需要引用远程仓库代码、对比不同版本代码或无需复制粘贴即可嵌入复杂代码结构的场景。

**3. 核心特色**
*   **智能提取**：支持基于符号（函数/类）和行号的精准代码片段提取，适应缩进和括号语言。
*   **多源支持**：零配置引用多平台远程代码，支持别名管理。
*   **增强渲染**：提供行号显示、代码折叠、长行换行及加载骨架屏，提升阅读体验。
*   **双向同步**：支持本地文件嵌入及远程内容自动刷新。

**4. 使用建议**
建议在设置中预先配置常用远程仓库别名，以简化引用路径。对于大型代码文件，利用符号提取功能仅嵌入核心逻辑，保持笔记整洁。注意远程内容获取依赖网络连接，离线时仅本地文件可用。
