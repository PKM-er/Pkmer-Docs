## 概述

**Prompt Shelf** 是一款 Obsidian AI 助手插件，旨在统一管理 AI 服务商、API 密钥及可复用提示词。

1. **主要功能**：集中管理多家 AI 提供商（如 OpenAI、Anthropic、Gemini 及本地模型）的配置与密钥。用户可定义“动作”（如摘要、翻译），并通过右键菜单、命令面板或脚本在任意文本上执行这些预设提示词。
2. **适用场景**：适合需要频繁调用 AI 进行文本处理（如会议记录清洗、文章摘要、多语言翻译）的知识工作者，以及希望将 AI 能力嵌入 Dataview 脚本或自定义插件的高级用户。
3. **核心特色**：支持流式输出，实时显示 AI 回答并允许中途停止；提供模型浏览与测试功能，便于快速验证连接；暴露 API 接口，允许通过代码在笔记内嵌入交互式 AI 面板，实现高度自动化。
4. **使用建议**：建议在设置中预先配置好常用服务商的 API 密钥，并创建几个高频使用的“动作”模板。对于批量处理需求，可利用其 API 结合 Dataview 编写脚本，实现笔记内容的自动化分析与生成，提升工作流效率。
