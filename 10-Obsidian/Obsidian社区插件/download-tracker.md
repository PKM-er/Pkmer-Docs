## 概述

**1. 主要功能**
该插件专为发布社区插件或主题的用户设计，用于在 Obsidian 内部实时展示其作品的下载量、历史变化趋势及发布时间。它支持追踪 GitHub 用户名下的所有相关仓库，并可单独统计非 Obsidian 项目的数据。

**2. 适用场景**
适用于 Obsidian 插件或主题开发者，用于监控作品在社区的受欢迎程度、分析发布后的流量增长，以及管理多个开源项目的整体表现。

**3. 核心特色**
*   **多维度数据**：除下载量外，可选显示 GitHub Stars、Issues、PR 及版本历史。
*   **历史快照与图表**：支持手动或每日自动保存数据快照，内置三种原生 HTML/SVG 图表（项目分布、周期新增、总趋势），无需额外图表库。
*   **灵活筛选**：支持按时间范围、类型或名称过滤图表，并在图表中标记每次发布节点。
*   **可视化区分**：为每个项目分配专属颜色和形状，适配明暗模式。

**4. 使用建议**
建议定期开启自动快照功能以积累长期趋势数据；利用可选列监控 GitHub 反馈（如 Issues）以优化开发优先级；通过图表的时间筛选功能，重点分析特定发布周期内的用户增长情况。
