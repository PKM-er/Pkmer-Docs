## 概述

**1. 主要功能**
该插件允许用户在 Obsidian 笔记中通过输入 `gh#` 快速搜索并插入 GitHub 项目看板中的 Issue 链接。支持按 Issue 编号或标题关键词搜索，并提供鼠标悬停预览功能。

**2. 适用场景**
适用于使用 GitHub 进行项目管理、且习惯在 Obsidian 中记录开发进度、技术调研或会议笔记的开发者。特别适合需要频繁引用特定 Issue 进行上下文关联的场景。

**3. 核心特色**
*   **智能排序**：优先显示用户历史链接过的 Issue，提升检索效率。
*   **跨仓库支持**：支持包含多个仓库的 GitHub 项目看板。
*   **安全轻量**：仅需只读权限的细粒度令牌，数据仅用于读取，令牌存储在本地 Vault 中。
*   **体验优化**：提供悬停预览，无需跳转即可快速查看 Issue 详情。

**4. 使用建议**
*   **配置令牌**：务必创建具有“Issues”和“Projects”只读权限的细粒度个人访问令牌（PAT），并授权给对应组织。
*   **版本要求**：确保 Obsidian 版本在 1.13 及以上，支持桌面端和移动端。
*   **安装方式**：推荐通过社区插件市场搜索安装，或手动下载 Release 文件至插件目录。
*   **操作习惯**：在笔记中养成使用 `gh#` 触发搜索的习惯，结合历史链接记录，可极大提升 Issue 追踪效率。
