## 概述

**主要功能**
WeChat Format 是一款 Obsidian 插件，能将 Markdown 笔记一键转换为微信公众号文章格式。支持生成兼容 HTML、导出独立文件或直接发送至公众号草稿箱，实现从本地笔记到线上发布的无缝衔接。

**适用场景**
专为使用 Obsidian 撰写公众号内容的创作者设计，适用于需要频繁将技术文档、博客文章或日常记录发布至微信平台的用户，特别适合希望省去手动排版繁琐步骤的场景。

**核心特色**
1. **多主题与智能排版**：内置 6 种精美主题，自动优化标题、代码块、表格及图片样式，支持正文两端对齐。
2. **高效工作流**：提供实时预览面板，支持一键复制 HTML 或直发草稿箱，极大提升发布效率。
3. **灵活定制**：允许自定义字号、行高、CSS 等细节，并支持底部关注引导区。
4. **图片处理**：配置 API 后自动上传本地图片至微信素材库，未配置则自动内联，确保图片正常显示。

**使用建议**
建议用户遵循推荐的 Markdown 规范书写，以充分利用自动排版效果。初次使用可先通过“打开预览”检查视觉效果，确认无误后再选择“复制”或“发草稿”。若需保持品牌一致性，建议在设置中调整自定义 CSS 以匹配个人风格。
