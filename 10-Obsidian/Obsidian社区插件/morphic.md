## 概述

**Morphic** 是一款将 Markdown 笔记转化为快速、可编程视图的 Obsidian 插件。

1. **主要功能**：允许用户通过规则、模板及 Bases 集成，将普通 Markdown 笔记渲染为自定义 HTML 界面。支持表达式求值、作用域 CSS、本地 JavaScript 执行及实时编辑，同时保持底层文件为纯 Markdown 格式。
2. **适用场景**：适用于需要动态数据展示、复杂交互界面或跨文件数据联动的知识库。特别适合那些静态模板无法满足需求，且对视图刷新性能有较高要求的用户。
3. **核心特色**：采用“精确失效”机制，仅更新实际变化的数据部分，避免全量刷新；具备响应式数据流，能实时追踪文件、元数据及链接笔记的变化；支持 Live Preview，未保存内容即可参与渲染；原生集成 Obsidian Bases 数据源。
4. **使用建议**：适合进阶用户构建复杂仪表盘或动态列表。建议利用其依赖追踪特性优化大型 Vault 的性能，注意配置可信的本地脚本以确保安全，并充分利用其跨文件反应能力实现数据联动。
