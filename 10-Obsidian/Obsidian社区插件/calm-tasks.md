## 概述

**1. 主要功能**
Calm Tasks 是一个简洁的任务工作区插件，能自动收集 Obsidian 库中所有 Markdown 文件里的任务。它支持嵌套任务、议程视图、自定义分组及保存的智能过滤器，允许用户创建、编辑、排序及批量管理任务，并可选同步至 Microsoft To Do。

**2. 适用场景**
适合偏好纯文本精神、希望以 Markdown 文件为唯一数据源的用户。适用于需要跨笔记统一视图、进行每日议程回顾、项目优先级管理及日常任务归档的个人知识管理或轻量级项目管理场景。

**3. 核心特色**
- **极简语法**：兼容标准 Markdown 复选框，支持紧凑的日期与优先级（A-D）标记，同时识别 Obsidian Tasks 的常见元数据。
- **灵活交互**：支持拖拽、右键菜单及快捷键操作，提供底部或侧边详情面板进行快速编辑。
- **智能过滤**：可按状态、日期、标签等即时搜索，支持韩文输入法优化，并将过滤条件保存为智能过滤器。
- **视觉增强**：在普通笔记和工作区中自动高亮日期和优先级，支持自定义间距与元数据颜色。

**4. 使用建议**
建议在普通 Markdown 中直接使用标准复选框，按需添加 `| 日期 | 优先级` 格式以启用高级功能。利用“智能过滤器”预设常用视图以提升效率。注意，删除自定义分组不会删除任务，它们将回归收件箱。若需同步，请确保已配置 Microsoft To Do 权限。
