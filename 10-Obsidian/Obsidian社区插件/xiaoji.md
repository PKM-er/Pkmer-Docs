## 概述

小记（xiaoji）旨在解决灵感碎片化与记录工具割裂的问题，提供一个简洁、本地优先的 Markdown 小记空间。它允许用户将日常灵感、待办事项和临时想法直接保存在自己的 Markdown 文件中，支持标签、待办、附件、代码块、表格及公式等原生语法。通过列表与瀑布流布局、置顶、归档及层级标签功能，用户可以在不依赖云端服务的情况下，对大量碎片化信息进行高效检索与批量整理，确保数据始终掌握在自己手中。

典型场景包括快速捕捉稍纵即逝的灵感或会议要点。例如，在桌面端，你可以设置全局快捷键，即使 Obsidian 处于最小化状态，也能唤起独立的快速记录小窗，输入内容后通过 Shift+Enter 保存，随后返回主页面继续编辑，光标会自动定位在草稿末尾，实现无缝续写。另一个场景是整理长期积累的任务清单，利用插件的搜索与批量操作功能，快速筛选特定标签下的待办事项，进行归档或状态更新，保持工作流的清晰有序。

相比其他笔记插件，小记的特色在于其极致的本地化与隐私保护，以及灵活的 AI 集成能力。它支持接入 API 或本机 Codex，提供基于小记内容的检索、来源引用及临时对话功能，且 AI 默认关闭，确保普通记录与搜索完全离线可用。此外，插件提供 Markdown 回收站与格式备份机制，在整理历史格式时先预览并备份，避免误操作导致数据丢失，这种对数据安全的细致考量是其显著优势。

使用前需注意，独立快速记录小窗仅限桌面端使用，移动端体验可能受限。若使用 AI 功能，需自行配置 API 密钥或安装 Codex CLI，且推理过程需要联网，数据保留策略取决于服务商。该插件不适合需要复杂双向链接图谱、实时多人协作或高度依赖云端同步的用户。如果你追求的是纯粹、可控且基于本地文件的轻量级记录体验，小记是一个值得考虑的选择。
