## 概述

### Para - ZK插件总结
1. **主要功能**：这是一个用于Obsidian的插件，可实现PARA、Zettelkasten和LLM - Wiki工作流。能将用户提供的信息源整合进相互关联的笔记中，保持前置元数据、引用和反向链接的一致性，避免每次查询时重复推导知识。还可通过原生CLI暴露完整工作流，借助MCP服务器提供编辑工具。
2. **适用场景**：适用于需要构建知识体系、管理知识笔记的用户，尤其是对AI相关知识进行整理和关联的场景。
3. **核心特色**：以LLM维护知识维基，提供GUI命令和 ribbon 快捷方式，运行时可通过CLI访问。能生成相互关联的概念页面，如AI论文相关的知识页面。
4. **使用建议**：需Obsidian 1.12.3及以上版本。可从Obsidian社区插件浏览器安装，安装后使用“PARA - ZK: Set up PARA - ZK vault”命令搭建库，该操作支持安装所需或可选的社区插件。Claude Code和Codex用户在Obsidian运行且相关命令在PATH中时，可按对应指令安装。
