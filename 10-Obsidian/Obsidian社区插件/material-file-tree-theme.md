## 概述

### Material File Tree Theme插件总结
1. **主要功能**：为Obsidian文件树添加Material Icon Theme风格的文件和文件夹图标，适配多种视觉主题。提供图标大小、透明度、灰度等设置选项，还有主题兼容操作。
2. **适用场景**：适合拥有大型库且经常对文件树进行展开/折叠操作的用户，可优化文件树图标展示体验。
3. **核心特色**：无需构建步骤和npm依赖；专为大型库设计，文件树装饰稳定；主题兼容性强，能适配多种视觉主题；采用Material风格的SVG图标；图标匹配基于`dist/material-icons.json`映射文件，匹配方式多样。
4. **使用建议**：本地安装需在库中创建指定文件夹并复制相关文件，然后在社区插件中启用。若设置页面提示缺少图标资源，可在插件设置中打开下载页面，下载并解压`material-icon-souce.zip`，再导入包含`icons/`和`dist/material-icons.json`的文件夹。
