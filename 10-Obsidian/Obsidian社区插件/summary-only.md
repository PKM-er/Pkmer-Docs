## 概述

**1. 主要功能**
SummaryOnly 插件为 Obsidian 的 Bases 功能新增了一个“仅摘要”视图。该视图会隐藏数据行，仅以卡片形式展示记录的摘要信息，从而提供比传统表格更直观的视觉呈现。

**2. 适用场景**
适用于需要快速浏览大量笔记或数据概览的场景。当用户不希望被详细的表格数据干扰，只想快速抓取核心摘要信息时，该插件能显著提升信息获取效率。

**3. 核心特色**
*   **卡片式展示**：将枯燥的数据行转化为视觉友好的摘要卡片。
*   **专注核心**：通过隐藏冗余的行数据，帮助用户聚焦于关键摘要内容。
*   **开发友好**：提供完整的开发文档，支持 `npm run dev` 监听模式，并附带演示 Vault 便于快速测试。

**4. 使用建议**
*   **安装**：建议直接从社区插件市场安装；若需开发，请遵循 README 指引，执行 `npm install` 和 `npm run build`，并将构建文件复制到插件目录。
*   **配置**：在 Obsidian 设置中启用该插件后，在 Bases 视图中切换至“Summary only”即可生效。
*   **注意**：该插件未经 Obsidian 官方手动审核，使用前请确认兼容性。
