## 概述

Desktop Stickies 将 Obsidian 笔记转化为独立的桌面便签窗口，核心在于结合原生 Live Preview 引擎与拟物化设计。它允许你在桌面上直接编辑 Markdown，支持标题、清单、公式等即时渲染，并配备富文本工具栏。所有笔记均保存为本地 .md 文件，位置、尺寸及皮肤等元数据记录在 YAML 中，确保数据完全本地化且兼容 Obsidian Sync 或 Git 同步，无需依赖云端服务。

典型场景包括会议记录与跨应用参考。例如，在开会时可将便签设为“置顶模式”，悬浮于所有窗口之上，方便快速查阅要点；或在编写代码时，将笔记嵌入 Windows 桌面底层（Progman），使其免疫 Win+D 最小化操作，始终停留在壁纸上，既不打断工作流，又能随时瞥见关键信息。此外，你可以通过右键菜单将库中任意笔记直接转为桌面便签，实现从深度阅读到快速备忘的无缝切换。

相比普通便签应用，该插件的特色在于其独特的三态窗口管理：通过工具栏图标一键循环切换“浮动”、“置顶”和“桌面挂件”模式，灵活适应不同专注需求。同时，它提供 7 种拟物化纸张皮肤，包括经典黄、樱花粉及专为深色模式优化的炭黑主题，后者具备高对比度光标与语法渲染优化。内置的“便签中心”以瀑布流卡片展示所有笔记，支持实时搜索与预览，方便管理分散在桌面的多个便签，避免视觉混乱。

使用前需注意，该插件主要面向 Windows 系统，其“桌面挂件”模式依赖 Windows 桌面壳集成，其他操作系统可能无法实现完全嵌入壁纸的效果。此外，虽然支持多显示器，但断连时会自动恢复可见性，若你追求极致的跨平台一致性或需要复杂的协作功能，此插件可能不是最佳选择。它更适合个人知识管理、临时备忘及需要视觉隔离的专注场景，而非团队实时协同编辑。
