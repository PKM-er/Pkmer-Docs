## 概述

### Auto Scroll插件总结
1. **主要功能**：在写作和浏览时，让Obsidian编辑器自动滚动。可在打字时光标到达设定点、按下向下箭头键或鼠标指针进入设定边缘区域时触发滚动。
2. **适用场景**：适用于长时间写作、浏览长文档时，避免频繁手动滚动页面，提高操作效率。
3. **核心特色**：提供丰富的设置选项，可灵活配置滚动触发条件、滚动量、滚动冷却时间等；支持通过命令面板快速开启或关闭；具备平滑滚动动画效果。
4. **使用建议**：根据自身使用习惯调整触发点、滚动量等参数，以达到最佳使用体验。若希望减少不必要的滚动，可开启“Only near document bottom”并设置合适的文档深度。开发时，可按提示使用`npm install`安装依赖，`npm run build`构建插件，`npm run dev`开启开发监听模式。
