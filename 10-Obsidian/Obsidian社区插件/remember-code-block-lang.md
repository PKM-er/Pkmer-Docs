## 概述

### 《Remember Code Block Language插件总结》
1. **主要功能**：该插件能记住你上一次使用的代码块语言，下次创建代码块时自动添加该语言。还提供插入带有记忆语言代码块的命令，且可在设置中自定义默认语言。
2. **适用场景**：适用于在Obsidian中频繁编写代码块的用户，尤其是经常使用同一种或几种特定编程语言的场景，可提高代码块输入的效率。
3. **核心特色**：自动记忆上次使用的代码块语言，无需每次手动输入；支持设置默认语言，满足不同用户习惯。
4. **使用建议**：安装可通过Obsidian社区插件浏览器，或手动复制`main.js`、`manifest.json`到指定文件夹。使用时，输入代码块起始符（```），插件会自动插入上次使用的语言。若常用某一特定语言，可在设置中设为默认，进一步提升使用体验。
