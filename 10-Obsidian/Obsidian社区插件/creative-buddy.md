## 概述

**Creative Buddy** 是一款基于 Claude Code 的 Obsidian 插件，通过对话式访谈辅助项目构思。

1. **主要功能**：插件扮演“访谈者”角色，针对你描述的故事、游戏或产品创意，逐一提问并引导思考。它会将你的回答整理为相互链接的 Markdown 笔记存入库中，并在侧边栏实时生成动态思维导图，直观展示项目结构与待解决疑问。
2. **适用场景**：适合在 Obsidian 中进行创意构思、世界观构建、游戏设计或产品原型梳理的用户，特别是喜欢通过“口述”方式逐步完善细节的思考者。
3. **核心特色**：
   - **思维主权**：只记录用户明确表达的内容，未决事项仅提问不代填，确保笔记完全属于用户。
   - **可视化**：提供树状或径向思维导图，支持折叠分支和点击跳转笔记。
   - **成本透明**：利用现有 Claude Code 订阅，每次回复显示 API 估算成本，无额外账单。
4. **使用建议**：建议将其作为创意初期的“思维脚手架”，通过回答访谈问题来梳理逻辑漏洞。注意隐私问题，对话内容会发送至 Anthropic；它不自动撰写正文或检索资料，需用户主动驱动思考。
