## 概述

**1. 主要功能**
Refwright 是一款 AI 原生的文献管理插件，旨在替代 Zotero 或 EndNote。它支持直接在 Obsidian 中搜索 PubMed 数据库，利用 LLM 生成文献摘要，自动添加 MeSH 标签，并生成符合 CSL 标准的多种期刊格式引用。此外，它还提供了 MCP 接口，允许 Claude Code 或 Codex 直接访问你的实时 Vault。

**2. 适用场景**
专为在 Obsidian 中进行学术研究、文献综述和论文写作的用户设计。适合希望将笔记库直接作为参考文献库使用，并需要高效检索、总结及格式化引用的科研人员和学生。

**3. 核心特色**
- **原生集成**：Markdown 笔记即参考文献库，无需外部数据库同步。
- **AI 增强**：结合 LLM 实现智能摘要与标签化，提升文献处理效率。
- **灵活引用**：支持多种学术引用格式，满足不同期刊要求。
- **MCP 扩展**：通过 MCP 协议实现 AI 编码助手对本地文献库的实时访问，增强自动化能力。

**4. 使用建议**
建议先配置好 PubMed API 密钥及 LLM 模型以启用核心功能。若需与 Claude Code 或 Codex 联动，请阅读 MCP 相关文档进行设置。注意该插件目前未通过 Obsidian 官方人工审核，使用前建议备份数据。
