## 概述

Mind Map Canvas 允许你在 Obsidian 中直接创建和编辑思维导图，核心在于将思维结构存储为标准的 Markdown 嵌套列表。这种设计确保了数据始终是纯文本，不仅便于长期归档，还能与库中的其他笔记无缝协作。插件提供了一个可缩放、可拖拽的无限画布，支持滚轮缩放、平移以及一键自适应视图，让你能自由地组织复杂的层级关系，同时保持底层数据的简洁与透明。

典型的使用场景包括快速梳理会议要点或构建知识体系。例如，当你整理一篇长文的核心观点时，可以新建一个思维导图，通过双击节点输入中心主题，利用 `Tab` 键快速添加子分支，用 `Enter` 键补充同级内容。另一个场景是复习已有笔记，你可以直接打开包含嵌套列表的 Markdown 文件，插件会自动将其渲染为可视化的导图，方便你直观地检查逻辑结构或补充遗漏的分支。

相比许多依赖专有格式或外部服务的思维导图工具，该插件最大的特色是双向同步能力。任何符合规范的 Markdown 嵌套列表都能被识别并渲染，这意味着你既可以在画布上拖拽节点调整布局，也可以随时切回编辑器直接修改文本，两者实时保持一致。此外，它支持自由拖拽任意节点到画布上的任意位置，连接线会实时跟随，提供了比固定布局更灵活的视觉呈现方式，适合需要个性化排版的需求。

需要注意的是，该插件主要服务于基于列表结构的层级思维，不适合处理非层级关系的复杂网络图或需要大量图形装饰的场景。由于数据严格依赖 Markdown 列表格式，如果你习惯使用表格、代码块或其他复杂 Markdown 元素来组织信息，可能无法直接转换为导图。此外，虽然它提供了基础的编辑快捷键，但缺乏高级的样式定制功能，对于追求极致视觉美感的用户来说，可能需要配合其他插件或手动调整 CSS 来满足需求。
