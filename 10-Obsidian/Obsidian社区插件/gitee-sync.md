## 概述

### Gitee Sync 插件总结
1. **主要功能**：将 Obsidian 库同步到 Gitee 或 GitHub 私有仓库，支持增量双向同步、删除传播、冲突解决、预演预览和诊断日志记录。
2. **适用场景**：适用于多设备使用 Obsidian 的用户，可确保不同设备间笔记数据实时一致；也适合需要对笔记进行版本管理的用户。
3. **核心特色**：直接连接平台 API，无需服务器或本地安装 Git，支持桌面、iOS 和 Android 设备；同步引擎采用 Git blob 哈希和三方比较；界面自动跟随 Obsidian 语言，支持中英双语。
4. **使用建议**：安装时在 Obsidian 社区插件中搜索安装并启用；创建 Gitee 或 GitHub 私有仓库并获取对应权限的个人访问令牌；配置存储后端、仓库所有者、仓库名、分支、令牌等信息；可按需设置自动同步间隔、启动时同步和排除同步的文件夹。
