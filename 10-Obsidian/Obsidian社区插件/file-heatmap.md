## 概述

### File Heatmap插件总结
1. **主要功能**：在Obsidian文件资源管理器中生成实时的文件热力图覆盖层，直观展示近期修改文件情况。
2. **适用场景**：适用于需要快速查看近期文件修改状态，不想通过打开新标签、按热键或排序等方式查看的场景。
3. **核心特色**：
    - 始终可见，一瞥侧边栏就能看到活跃工作区域。
    - 零摩擦，无需热键、弹窗和上下文切换。
    - 美学极简，设计简洁且融入界面。
    - 颜色、样式和宽度等可配置。
4. **使用建议**：该插件通过颜色、条宽度和智能数字覆盖展示文件修改时间。颜色按0-5天（高活跃）到>30天（隐藏）动态变化；条宽度按周区分，越近越宽；仅对15天内修改的文件显示具体天数。用户可根据自身需求调整颜色和样式等属性，以更好地利用热力图查看文件修改情况。
