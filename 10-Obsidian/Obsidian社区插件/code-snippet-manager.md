## 概述

### code - snippet - manager插件总结
1. **主要功能**：这是一款Obsidian的代码片段管理器，支持从当前编辑器选中文本、剪贴板内容创建代码片段，也能直接从仪表板创建。可将多个代码片段存于一个Markdown文件中，能按关键字、语言、标签搜索，支持复制和插入代码片段，还能预览匹配代码。
2. **适用场景**：适合开发者在Obsidian中收集、整理和使用代码片段，无需将数据转移到私有数据库，以Markdown文件为核心管理。
3. **核心特色**：以Markdown为核心，代码片段存储于Markdown文件，保证数据的开放性；使用Obsidian块ID作为稳定跳转目标，方便定位；搜索结果按Markdown文件分组，便于查找。
4. **使用建议**：此插件为早期稳定版本，仅支持手动安装和社区测试。安装时需先执行`npm install`安装依赖，再执行`npm run build`构建插件。目前不支持向量搜索、云同步、在线代码执行等功能。
