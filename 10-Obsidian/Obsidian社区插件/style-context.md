## 概述

### 样式上下文（Style Context）插件总结
1. **主要功能**：将运行时上下文发布为 CSS 类和变量，可把本地图片注册为 CSS 变量，设置保险库背景，将当前主题暴露在主体上以进行特定主题样式设置，还能按文件夹自动添加 CSS 类。
2. **适用场景**：适用于需要使用本地图片作为背景、对特定主题进行样式微调的场景。比如想让笔记背景使用本地图片，或者对某个主题的细节进行优化。
3. **核心特色**：解决了 Obsidian 中保险库资源 URL 会在重新加载时改变，导致直接使用 `url()` 不可靠的问题，提供稳定的变量引用；可在不编辑主题原始 CSS 的情况下对特定主题进行样式调整。
4. **使用建议**：在插件设置中对视觉选项进行自定义配置；利用稳定的 CSS 变量引用本地图片，对特定主题添加 CSS 时，谨慎操作以避免影响主题整体效果。
