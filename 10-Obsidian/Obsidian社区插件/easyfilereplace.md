## 概述

### 《Easy File Replace插件总结》
1. **主要功能**：在Obsidian中轻松替换附件内容，且不会破坏内部链接。用户可选择新文件覆盖原文件内容，同时保留原文件名和路径。
2. **适用场景**：适用于需要更新附件（如音频、图片）的场景，避免手动删除旧文件、导入新文件并重新命名的繁琐操作。
3. **核心特色**：操作简便，可通过右键菜单或命令面板触发替换操作；严格的格式保护，要求新文件与被替换文件扩展名完全相同，防止数据损坏或出现意外行为。
4. **使用建议**：安装时，先关闭安全模式，在社区插件中搜索安装并启用。替换文件时，右键点击文件资源管理器中的附件，选择“Replace file (Easy File Replace)”，或在文件打开时使用命令面板。注意选择的新文件格式需与原文件一致，否则操作将被自动阻止。
