## 概述

**Knowledge Inbox（知识收件箱）** 是一款旨在优化信息捕捉与整理流程的 Obsidian 插件。

**主要功能**：支持语音或文本的快速捕捉，利用用户配置的 AI 服务（STT 和 LLM）进行转录、分类及结构化整理，并将笔记自动路由至指定文件夹。

**适用场景**：适合需要高效记录灵感、会议内容或语音备忘，并希望借助 AI 实现从“原始素材”到“结构化知识”自动转化的用户。

**核心特色**：
1. **原始保留**：严格保留原始音频和文本，确保数据可追溯。
2. **AI 驱动**：通过可配置的 API 实现智能转录与内容分类。
3. **安全机制**：AI 生成的草稿以独立区块形式存在，重新处理时仅更新草稿，不破坏用户原有内容。
4. **灵活配置**：支持自定义模板、文件夹映射及多种音频格式（推荐 M4A/MP3/WAV）。

**使用建议**：
1. 需自行配置有效的 STT 和 LLM API 密钥。
2. 建议优先使用 M4A、MP3 或 WAV 格式音频以保证兼容性。
3. 注意上传文件不超过 50MB 限制。
4. 由于插件处于早期开发阶段（v0.1.0），建议定期备份 Vault，并关注后续版本更新。
