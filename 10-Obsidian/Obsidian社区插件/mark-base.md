## 概述

### MarkBase 插件总结
1. **主要功能**：将 Markdown 与 Obsidian Bases 结合为自由格式视图，把查询结果的可见属性和公式渲染成连续的 Markdown 文档。可渲染选定的笔记属性、文件属性和公式，还能控制渲染内容及其顺序。
2. **适用场景**：适用于需要将 Obsidian Bases 数据以 Markdown 形式呈现和整理的场景，如知识管理、文档编写等。
3. **核心特色**：能通过 Base 属性菜单控制渲染内容和顺序；可添加多行 Markdown 分隔符；能使用可复用的 Markdown 模板覆盖属性布局；无需网络请求，在保险库内即可运行。
4. **使用建议**：需 Obsidian 1.13.0 及以上版本，且启用 Bases 核心插件。使用时，先打开 Base 并将布局改为自由格式，通过 Base 属性菜单选择和排序要渲染的属性与公式，还可在“Configure view”中设置属性和结果间的 Markdown 分隔符。
