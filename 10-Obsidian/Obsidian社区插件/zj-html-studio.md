# Obsidian 插件：ZJ HTML Studio

> [!Note] 插件名片
> - 插件名称：ZJ HTML Studio

## 概述

### 主要功能
ZJ HTML Studio 可让 Obsidian Desktop 在原生标签页打开本地 `.html` 和 `.htm` 文件，支持加载本地资源、实时重载、只读源码查看、页面缩放、页面内搜索、全屏及 Markdown 嵌入等。

### 适用场景
适用于课程页面、分享会、公众号排版、交互演示等生成的 HTML 文件，方便在 Obsidian 内直接查看。

### 核心特色
- 为 HTML 文件注册原生标签页视图，点击即可预览。
- 自动分析依赖，计算最小资源范围，确保父目录资源正常加载。
- 每个预览有独立来源和会话，避免页面间干扰。

### 使用建议
- 从社区插件中安装或从 GitHub 下载文件安装，在设置里启用。
- 对不熟悉的文件用“安全只读”模式；自己创建和检查过的本地页面用“本地交互”模式；审核过且需远程资源或网络 API 的页面用“可信兼容”模式。
- 用 `![[page.html]]` 等语法在 Markdown 中嵌入页面。该插件仅支持桌面端，需 Obsidian 1.12.7 及以上版本。
