## 概述

### GitHub Publish插件总结
1. **主要功能**：可快速免费发布Obsidian笔记库。借助Quartz生成站点，用GitHub Pages托管，自动完成配置。能跟踪已发布站点的变化，一键发布更新后的笔记。
2. **适用场景**：适用于希望轻松将Obsidian笔记免费发布到网络，且不想花费时间进行复杂配置和学习的用户。
3. **核心特色**：
    - 一键设置，用户只需选择内容文件夹、站点名称和仓库，其余由插件处理。
    - 默认使用Quartz，支持Obsidian风格的Markdown、反向链接和图谱视图。
    - 增量发布，首次发布后仅上传有变化的笔记。
    - 支持多站点，可将一个笔记库中的多个文件夹发布到不同仓库。
    - 能跟踪发布进度。
4. **使用建议**：使用前需用GitHub账户认证并授予公共仓库和工作流权限。插件仅在content/文件夹内操作，不会读取其他仓库数据或删除仓库。可参考项目Wiki的实时演示了解效果。
