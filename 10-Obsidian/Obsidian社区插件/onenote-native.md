## 概述

Live note 是一款集 Markdown 笔记本、无限画布以及视频学习与阅读批注功能于一体的综合性插件。它旨在打破传统笔记软件中线性文本与多媒体内容割裂的局限，允许用户在同一个工作区内自由切换文字记录、视觉布局与媒体交互。核心功能在于将静态的笔记转化为动态的知识管理空间，支持在无限画布上自由拖拽笔记卡片，并直接嵌入视频或文档进行实时批注，从而构建起一个灵活且高度互联的个人知识体系。

典型的使用场景包括复杂的课题研究或课程学习。例如，当你在观看一段教学视频时，可以直接在视频旁侧的无限画布上创建笔记卡片，记录关键时间点并添加批注，随后将这些卡片与相关的 Markdown 文档片段通过连线关联起来。另一个场景是整理碎片化信息，你可以将网页摘录、PDF 阅读笔记和思维导图节点混合排列在画布上，通过视觉化的方式梳理逻辑关系，而无需在多个窗口间频繁切换。

相比同类插件，Live note 的特色在于其“无限画布”与“多媒体批注”的深度整合。许多笔记插件仅支持文本或仅支持白板，而 Live note 允许用户在画布中直接操作带有批注的视频和文档对象。这种能力使得它特别适合需要处理大量非结构化媒体资料的用户，能够保留学习过程中的上下文语境，避免传统笔记中常见的“笔记与素材分离”问题，让知识整理过程更加直观和连贯。

在使用前需注意，该插件尚未经过 Obsidian 官方团队的人工审核，建议定期备份数据以防意外。此外，由于无限画布和多媒体嵌入可能占用较多系统资源，在配置较低的电脑上运行大型画布时可能会遇到性能瓶颈。如果你只需要纯粹的纯文本写作环境，或者对视频批注没有需求，仅希望进行简单的 Markdown 编辑，那么这款功能繁复的插件可能显得过于沉重，不适合此类轻量级需求。
