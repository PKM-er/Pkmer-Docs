## 概述

**1. 主要功能**
该插件为 Obsidian 编辑器提供类似 VS Code 的查找与替换功能。支持区分大小写、全词匹配及正则表达式，具备可折叠的替换行，支持“替换”与“全部替换”，并高亮显示所有匹配项及计数。

**2. 适用场景**
适用于需要高效处理长文档、代码笔记或进行批量文本修改的场景。特别适合习惯 VS Code 操作逻辑的用户，以及在阅读视图下快速定位内容的需求。

**3. 核心特色**
*   **悬浮式设计**：控件悬浮于编辑器右上角，不挤压正文布局，且支持自由拖动位置与调整宽度，状态跨笔记及重启后保持。
*   **阅读视图支持**：无需切换模式即可在阅读视图中查找，匹配项直接在渲染页高亮；若执行替换操作，会自动切换至编辑视图。
*   **原生快捷键**：集成 VS Code 风格快捷键（如 Cmd+F），并兼容 Vim 模式逻辑，操作流畅自然。

**4. 使用建议**
建议在设置中绑定 `Cmd+F` 为查找、`Alt+Cmd+F` 为查找替换，以替代默认快捷键。利用双击控件空白处可快速复位至右上角，双击左边缘可切换默认/宽屏模式，提升操作效率。
