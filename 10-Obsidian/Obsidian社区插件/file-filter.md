## 概述

### File Filter插件总结
1. **主要功能**：具备文件面板实时过滤和编辑器段落级过滤两大功能，可隐藏不匹配内容，支持反向过滤，还能识别任务关键字。
2. **适用场景**：适用于在Obsidian中编辑笔记时，快速筛选出所需内容，提高查找和编辑效率。
3. **核心特色**：
    - 实时过滤，输入关键词即可快速隐藏无关内容。
    - 支持反向过滤，可隐藏包含特定词的段落。
    - 能识别任务关键字，如“task”“todo”“done”。
    - 可选择将隐藏段落折叠为省略号，匹配文本会高亮显示。
4. **使用建议**：
    - 点击笔记头部过滤图标或按自定义热键“Cmd + F”开启过滤。
    - 点击省略号或按“Escape”清除过滤，按“Cmd/Ctrl + Z”恢复上一次查询。
    - 若不想显示省略号，可在设置中取消勾选“Show ellipses”。
    - 该过滤器更适合编辑模式，阅读模式使用可能有bug。
