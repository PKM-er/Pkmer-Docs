## 概述

**主要功能**
DocShelf 允许用户在 Obsidian 中集中浏览和管理分散在不同项目中的外部 Markdown 及 HTML 文档。它支持递归发现文件夹内容并自动更新，同时提供类似 GitHub 的“行号链接”功能，可精准定位到文档的具体段落。

**适用场景**
适用于需要频繁查阅跨仓库项目笔记、设计文档或 AI 生成报告的场景。特别适合需要与 AI 代理协作，通过精确引用文档行号来讨论特定内容或调试代码的开发者。

**核心特色**
1. **跨项目书架**：将分散的文件或文件夹统一纳入一个“书架”，在 Obsidian 或本地 Web 应用中同步查看。
2. **精确溯源链接**：选中 Markdown 源码行即可生成指向特定行范围的链接（Obsidian 内部或 Web 端），便于精准沟通。
3. **双端独立或统一**：支持独立使用 Obsidian 插件或本地 Web 应用，也可将两者指向同一数据源，实现无缝切换。

**使用建议**
建议将常用的项目文档目录添加到书架中，利用其自动更新特性保持内容同步。在与 AI 交互时，善用“行号链接”功能直接分享具体段落，能显著提高沟通效率。若需离线快速检索，可优先使用本地 Web 应用，它不会修改原始文件，安全且高效。
