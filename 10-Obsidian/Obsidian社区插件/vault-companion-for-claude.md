## 概述

### 插件主要功能
Vault Companion for Claude 支持在桌面端和移动端的 Obsidian 内与 Claude 聊天，可对笔记进行读取、搜索、创建和更新操作，每次写入有审批卡。打开的笔记自动成为 Claude 上下文，可通过上下文栏固定或移除笔记。

### 适用场景
适用于需要借助 Claude 在 Obsidian 中处理笔记的用户，无论是桌面端还是移动端。

### 核心特色
1. 跨平台运行：不同于其他 Claude 集成插件仅支持桌面端，此插件能在 iPhone、iPad、Android 及桌面端使用。
2. 两种后端：可使用 Anthropic API 密钥直接调用 API，无需服务器；也可通过 Mac 中继，使用 Claude 订阅，费用按订阅套餐而非按令牌计费，且拥有完整 Agent SDK 工具集。

### 使用建议
若注重便捷性和跨平台使用，推荐使用 Anthropic API 密钥方式；若已有 Claude 订阅且想享受更多工具集，可选择 Mac 中继方式。
