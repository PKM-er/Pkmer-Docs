## 概述

X Bookmarks Graph 将你在 X 平台收藏的帖子转化为本地 Obsidian 笔记，并构建出可视化的交互图谱。它通过浏览器扩展捕获你浏览过的书签内容，无需使用 X API 密钥或共享账号密码，所有数据均保存在你的电脑本地。插件会自动将内容整理为推文、作者、话题及外部域名等分类笔记，并生成一个仪表盘供你快速检索，让你能像管理知识库一样管理社交媒体的收藏。

典型场景包括整理长期关注的行业观点或突发新闻线索。例如，当你浏览 X 时看到多篇关于某项新技术的讨论，插件会自动抓取这些帖子及其关联的作者和话题标签。在 Obsidian 中，你可以打开图谱视图，直观地看到这些帖子如何围绕特定话题或作者形成网络，从而快速发现信息间的潜在联系，而无需在浏览器和笔记软件间反复切换。

相比其他依赖官方 API 或云端服务的同类工具，该插件最大的特色是完全离线运行且无需付费。它不依赖 X 的官方接口，避免了 API 配额限制和隐私泄露风险，所有数据仅通过本地端口传输。此外，它具备去重机制，重复发送相同帖子不会生成冗余笔记，确保了知识库的整洁性。这种“本地优先”的设计使其成为注重数据隐私用户的理想选择。

需要注意的是，该插件仅支持 Obsidian 桌面版，且捕获范围仅限于你在浏览器中实际滚动加载过的帖子，无法一次性导入全部历史书签。如果 X 平台更改页面布局，捕获功能可能会暂时失效。此外，若你在 X 上删除了书签，本地笔记不会自动同步删除。因此，它不适合需要全量自动同步或移动端使用的场景，更适合作为手动筛选和深度整理特定兴趣内容的辅助工具。
