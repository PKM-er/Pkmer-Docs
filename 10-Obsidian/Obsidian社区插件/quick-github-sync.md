## 概述

### Quick GitHub Sync插件总结
1. **主要功能**：一键同步Obsidian库与GitHub仓库。先拉取远程更改，再推送本地更改，自动检测当前分支。
2. **适用场景**：适用于希望快速、便捷地将Obsidian笔记库与GitHub仓库同步，进行版本管理和备份的用户。
3. **核心特色**：操作简便，通过侧边栏按钮或命令面板即可一键同步；PAT令牌使用Obsidian本地存储API安全存储，不会提交到git；自动检测分支。
4. **使用建议**：使用前需确保系统安装Git，Obsidian库是git仓库，有可同步的GitHub仓库和带`repo`权限的GitHub个人访问令牌。手动安装插件，在设置中配置仓库URL和个人访问令牌。使用时，点击侧边栏“云上传”图标或通过命令面板运行同步命令。
