## 概述

### md2flomo 插件总结
1. **主要功能**：将 Obsidian 笔记一键发送到 flomo，支持单篇和批量发布，能解析标签、清理内容，还可管理发布后台状态。
2. **适用场景**：适用于习惯在 Obsidian 记录笔记，又希望将内容同步到 flomo 进行整理和回顾的用户。
3. **核心特色**：可在插件设置中配置 flomo API Token 并测试可用性；侧边栏有小图标，点击即可发送当前笔记；能将 frontmatter 中的 `tags` 转换为 flomo 标签；内容样式丰富，包含标题、正文、别名和标签；发布后台可清晰区分已发送和未发送笔记。
4. **使用建议**：可通过手动或插件市场安装插件。安装后，在插件设置中输入 flomo API Token 并测试连接，之后打开笔记，点击右侧栏图标即可发送。可在插件后台查看笔记发送状态。
