## 概述

AI Vault Agent CN 是一款专为国内用户设计的 Obsidian 智能笔记代理插件。它直接对接 DeepSeek、GLM、Kimi、Qwen 等国内可访问的大模型 API，无需安装命令行工具或配置海外代理。核心功能在于赋予 AI 自主操作笔记库的能力，支持搜索、读取、创建和编辑笔记，让你通过自然语言指令即可管理知识库，实现从“问答”到“执行”的跨越。

典型场景包括自动化整理与内容生成。例如，你可以让 AI 搜索库中所有关于“项目管理”的笔记，提取关键信息并创建一份新的总结文档；或者在编辑某篇笔记时，直接指令 AI 根据上下文补充缺失的章节或修正格式。插件具备上下文感知能力，能识别当前打开的笔记，从而更精准地协助你完成正在进行的写作或整理工作。

相比海外同类插件，其最大特色是“零门槛”的本土化适配。内置中文系统提示词与界面，预设了多家国内厂商的 API 配置，只需粘贴密钥即可使用。此外，它支持多智能体即时切换，允许你为不同任务配置不同的模型和提示词，且切换时保留对话历史。独特的“记忆”机制会将对话内容沉淀至单一笔记中，并按遗忘曲线安排回顾，使 AI 交互记录成为可链接、可搜索的长期资产。

使用前需注意，创建或编辑笔记默认需要用户确认，以防误操作，可在设置中改为自动批准。该插件主要面向希望利用国内大模型能力管理个人知识库的用户。如果你依赖海外特定模型（如 Claude 原生 API）且无法通过兼容端点访问，或需要复杂的本地私有化部署而非云端 API 调用，此插件可能不是最佳选择。
