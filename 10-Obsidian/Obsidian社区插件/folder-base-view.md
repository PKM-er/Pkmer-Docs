## 概述

### Folder Base View插件总结
1. **主要功能**：在文件资源管理器中点击文件夹，可将选定的 `.base` 文件作为该文件夹的目录打开，无需配套笔记，文件夹内容会通过 `.base` 的布局呈现。
2. **适用场景**：适用于使用 Obsidian 1.13+ 桌面版且启用了核心 **Bases** 插件的用户，希望以表格目录形式查看文件夹内容。
3. **核心特色**：无需配套笔记即可查看文件夹目录；可设置默认索引 `.base` 文件，还能为特定文件夹指定专属 `.base`；支持多种打开触发方式。
4. **使用建议**：先在设置中创建推荐的索引 `.base` 或选择默认索引 `.base` 文件，然后在文件资源管理器中点击文件夹即可查看。开发时需配置环境变量，可使用 `npm run dev` 进行热更新开发，`npm run deploy` 进行一次性构建部署。发布时要先在 `CHANGELOG.md` 中添加版本信息。
