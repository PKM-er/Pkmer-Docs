## 概述

Media Consumption Calendar 将你的 Obsidian 笔记库变身为可视化的媒体消费日志。它提供月视图日历，让你记录阅读、观看、游玩和收听的内容，涵盖漫画、书籍、电影、剧集、动漫、游戏及播客。每天格子里直接展示对应作品的封面图，直观呈现你当天的娱乐轨迹，无需在多个笔记间切换即可掌握整体进度。

想象一下，你刚看完一部电影或读完一本小说，只需点击日历上的日期，搜索标题并添加条目，封面便会自动出现在当天。或者在回顾上个月时，你可以快速浏览整个月的日历，通过封面墙直观地看到自己消费了哪些内容，甚至可以通过拖拽卡片将未看完的内容移动到新的日期，轻松规划接下来的观看或阅读计划。

与同类插件相比，该插件采用统一的本地 JSON 文件存储所有数据，而非为每个条目创建独立笔记，这极大简化了数据管理。其界面支持卡片堆叠效果，鼠标悬停可提升卡片，视觉体验更佳。此外，它具备完善的数据安全机制，包括自动备份、损坏数据隔离以及防止意外覆盖的保护措施，确保你的记录不会因插件更新或意外操作而丢失。

使用前需注意，部分媒体源（如电影、游戏）需要配置免费的 API 密钥才能自动获取封面和元数据，但手动添加条目无需密钥。该插件主要面向个人娱乐记录，不适合需要复杂项目管理或团队协作的场景。同时，请确保你的同步服务（如 Obsidian Sync）已开启“其他文件类型”同步，以包含 JSON 数据文件，否则数据可能无法跨设备同步。
