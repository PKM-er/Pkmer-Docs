## 概述

**插件名称**：Windows Path Links

**1. 主要功能**
该插件专为 Windows 桌面端设计，旨在优化文件系统路径在 Obsidian 中的处理。核心功能包括：自动将粘贴的 Windows 路径转换为 Markdown 链接；使用系统默认处理器打开文件夹链接；以及基于当前笔记名称快速创建对应文件夹并插入链接。

**2. 适用场景**
适用于需要在 Obsidian 笔记中频繁引用本地 Windows 文件、文件夹或项目目录的用户。特别适合管理本地工作流、归档文件路径，或在笔记中建立与本地文件系统的直接关联。

**3. 核心特色**
*   **无损转换**：粘贴路径时自动转为 Markdown 链接，保留原始路径文本及中文字符，无需确认弹窗。
*   **原生集成**：文件夹链接调用 Windows 默认处理器打开，文件及内部链接则沿用 Obsidian 原生跳转逻辑，体验自然。
*   **灵活配置**：支持设置工作目录根路径，并可通过进程名设置激活特定的文件夹管理器窗口。

**4. 使用建议**
*   在“设置”中正确配置“工作目录”，以便“创建文件夹”命令能在正确位置生成子文件夹。
*   若使用非默认资源管理器（如 Q-Dir），建议配置“文件夹管理器进程名”以实现窗口激活。
*   注意该插件未通过 Obsidian 官方人工审核，使用前请确保信任其安全性。
