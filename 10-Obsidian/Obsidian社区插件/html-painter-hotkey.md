## 概述

**HTML Painter Hotkey** 是一款专为 Obsidian 设计的文本样式插件，允许用户通过自定义快捷键快速切换选中文字的字体颜色或背景高亮颜色。

**适用场景**：适合需要频繁对笔记内容进行视觉标记、重点强调或区分不同类别信息的用户，如学术阅读、会议记录或创意写作。

**核心特色**：
1. **循环切换机制**：无需打开菜单，连续按快捷键即可在预设颜色序列间循环（如黑→红→蓝→清除），极大提升操作效率。
2. **高度可定制**：支持任意 CSS 颜色名称或十六进制代码，用户可在设置中自定义颜色列表，并使用 `null` 作为清除样式的终点。
3. **无侵入性**：仅改变视觉呈现，不破坏 Markdown 源码结构，且选中状态保持，便于连续操作。

**使用建议**：
1. 安装后，务必在“设置 → 快捷键”中为“Cycle HTML Text Color”和“Cycle HTML Highlight”分配顺手的按键。
2. 根据个人习惯在插件设置中精简颜色列表，建议将常用颜色排在前面，并将 `null` 置于末尾以便快速还原。
3. 注意该插件未通过 Obsidian 官方人工审核，建议备份数据后使用。
