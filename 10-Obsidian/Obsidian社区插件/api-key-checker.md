## 概述

### AI API Key Checker插件总结
1. **主要功能**：可一键验证21家AI供应商的API密钥，并检测其速率限制。支持即时验证、速率限制与余额检测、批量检查、智能排序，还能点击复制密钥，同时有统计栏显示验证结果。
2. **适用场景**：适用于在Obsidian中使用多个AI供应商API密钥的用户，方便他们快速验证和管理密钥，及时发现无效或达到速率限制的密钥。
3. **核心特色**：验证基于真实供应商API而非正则表达式；能区分无效密钥和无配额的有效密钥，并显示限制重置时间；可批量处理大量密钥，且结果秒出；智能排序让问题密钥优先显示。
4. **使用建议**：用户可将多个API密钥一次性粘贴进行批量检查，快速定位问题。对于显示有问题的密钥，可根据速率限制提示合理安排使用或及时更换。
