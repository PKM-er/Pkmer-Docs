## 概述

### 插件名称
Mark as Read

### 主要功能
一键将笔记标记为已读或已完成，在文件资源管理器中直观显示状态，完成的笔记会变灰并带有复选标记。支持通过 CSS 片段根据任意前置元数据属性对文件进行样式设置，且能即时更新。

### 适用场景
适用于需要跟踪笔记阅读状态、任务完成情况等场景，方便用户快速了解笔记状态，无需打开笔记查看。

### 核心特色
- 无需配置，安装启用后，为笔记添加 `read` 等属性，即可在文件资源管理器显示状态。
- 提供可选的页脚栏，将复选框固定在笔记底部，无需滚动到属性面板操作。
- 支持通过 CSS 片段自定义文件样式，任何前置元数据属性都可用于样式设置。

### 使用建议
- 安装启用后，先给任意笔记添加 `read` 等属性，即可开始使用。
- 若需自定义样式，可在设置的 CSS 片段中编写代码。
- 在设置中选择要暴露的属性和添加页脚切换按钮的属性。
