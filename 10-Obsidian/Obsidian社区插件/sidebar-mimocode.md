## 概述

### 主要功能
将 MiMo - Code CLI 代理嵌入 Obsidian 侧边栏，以当前库为工作目录，可对库内容进行读写、搜索和运行命令。支持侧边栏聊天，有流式响应、取消、恢复及历史记录重载功能；具备原生构建和计划模式，有自定义权限规则；支持内联编辑与差异预览；可处理图片附件、指令模式、斜杠命令等；有多个聊天标签和自动对话标题。

### 适用场景
适用于需要借助 AI 协作处理 Obsidian 库内文件，进行文件读写、搜索、执行命令及开展多步骤工作流的场景。

### 核心特色
以 Obsidian 库为工作目录，实现 AI 与本地文件的深度交互；本地优先的工作流程，依托 MiMo - Code 原生运行时行为。

### 使用建议
- 确保安装 Obsidian Desktop 1.7.2 或更高版本、MiMo - Code CLI 0.1.1 并配置好 API 凭证。
- 可通过 GitHub 发布版或从源代码安装插件。
- 运行一次 MiMo - Code 并配置模型提供商凭证，在 Obsidian 设置中启用插件并确认可执行文件。可按需添加自定义权限规则。
