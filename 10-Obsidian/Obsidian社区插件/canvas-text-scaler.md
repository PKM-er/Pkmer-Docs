## 概述

### Canvas Text Scaler 插件总结
1. **主要功能**：在调整 Obsidian Canvas 卡片大小时，使卡片内的文本随卡片自身大小缩放，而非仅随画布缩放。
2. **适用场景**：适用于使用 Obsidian Canvas 进行内容创作、知识管理，需要灵活调整卡片大小并让文本适配的场景。
3. **核心特色**：打破了文本仅随画布缩放的限制，实现文本随卡片大小动态缩放。若与主题字体大小设置冲突，有相应开关可供调整。
4. **使用建议**：使用过程中若遇到字体大小与主题冲突，可使用切换开关解决。开发者曾尝试用 CSS 实现此功能但失败，说明该插件在处理 Canvas 节点渲染和虚拟化方面有其独特优势，建议放心使用该插件实现文本缩放需求，避免自行用 CSS 尝试可能遇到的问题。
