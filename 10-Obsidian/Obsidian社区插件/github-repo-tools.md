# Obsidian 插件：GitHub Repo Tools

> [!Note] 插件名片

## 概述

### 主要功能
在Obsidian侧边栏添加GitHub仓库面板，可监控仓库陈旧状态、管理分支、暂存和提交文件、跟踪拉取请求，还能展示本地仓库状态、导航变更文件、处理冲突和合并、管理暂存、进行分支切换及各类Git操作。

### 适用场景
适用于在Obsidian中进行知识管理，同时需要对本地克隆的GitHub仓库进行操作和监控的场景。

### 核心特色
- 无需离开Obsidian即可完成多种GitHub仓库操作。
- 变更文件导航方便，能直接在Obsidian中打开并高亮显示改动。
- 智能处理分支切换和本地变更，避免操作失败。

### 使用建议
- 此插件仅支持桌面端，使用前需安装git并克隆要监控的仓库。
- 操作前确保理解各功能含义，避免误操作影响仓库状态。 
- 若遇到合并冲突，可根据提示一键解决或中止操作。
