## 概述

### Source Mode Image Renderer插件总结
1. **主要功能**：在Obsidian的源码模式下，于图片链接下方直接渲染图片预览。支持`![[image.png]]`格式链接的预览展示，也支持`![[image.png|300]]`这类宽度语法，若图片文件未找到会显示友好提示信息，且不影响实时预览和阅读视图。
2. **适用场景**：适用于习惯使用Obsidian源码模式写作，但又希望能直观看到图片效果的用户，避免因实时预览模式下语法显示导致的文本跳动问题。
3. **核心特色**：专注于源码模式下的图片渲染，让用户在源码模式写作时也能有可视化的图片参考，保持写作专注度，同时不干扰其他视图模式。
4. **使用建议**：可通过Obsidian社区插件搜索“Source Mode Image Renderer”进行安装，也可手动从GitHub下载相关文件并复制到指定文件夹，然后在设置中启用插件。在源码模式下按格式添加图片嵌入即可看到效果。
