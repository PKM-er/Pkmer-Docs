## 概述

**主要功能**
该插件允许用户在 Obsidian Canvas 中直接复制选中的图片或文件节点到系统剪贴板。它通过键盘快捷键（默认 macOS 为 `Cmd + C`）触发，将图像作为真实图像数据、将 Markdown 等文件作为真实文件引用进行复制，而非截图或路径。

**适用场景**
适用于需要频繁在 Canvas 与其他应用间交换素材的场景，例如将 Canvas 中的图片直接粘贴到浏览器上传区、邮件、聊天软件或 Finder 中，无需手动导出或拖拽。

**核心特色**
1. **真实数据复制**：复制的是原始图像数据或文件引用，而非 Canvas 截图或内部路径。
2. **原生兼容**：在 Canvas 内部粘贴时，保持 Obsidian 原生的节点克隆行为，确保新节点引用同一文件，避免重复导入。
3. **零配置即用**：安装后默认启用 `Cmd + C`，无需额外设置；无工具栏按钮或上下文菜单，保持界面简洁。
4. **格式支持**：支持 PNG、JPG、JPEG 和 WebP 格式。

**使用建议**
1. 在 Canvas 中仅选中**一个**图像或文件节点。
2. 按下 `Cmd + C`（macOS）或自定义快捷键进行复制。
3. 在目标应用或 Canvas 中粘贴即可。
4. 若快捷键冲突，可在插件设置中修改，或重置为默认值。
5. 该插件仅在活动 Canvas 中选中单个文件节点时生效，多节点选中无效。
