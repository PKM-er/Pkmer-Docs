## 概述

**1. 主要功能**
Superpowers 是一款通过自然语言对话扩展 Obsidian 能力的插件。它允许用户与笔记库交互（提问、检索、创建或更新笔记），并能根据描述自动生成定制化工具或插件（如健身记录器、阅读日志等），支持在对话中持续迭代优化。

**2. 适用场景**
适用于希望简化工作流、无需编程基础即可定制个人工具的用户。适合需要快速构建特定功能（如数据追踪、自定义视图）并希望在桌面和移动端同步使用的场景。

**3. 核心特色**
- **对话式构建**：用日常语言描述需求，AI 自动生成并激活插件，支持多轮对话修正。
- **多模型支持**：兼容 OpenAI、Claude 和 Gemini，用户需自行配置 API Key。
- **独立运行**：生成的插件独立于 Superpowers 运行，即使关闭主插件，已创建的工具仍可使用。
- **全平台适配**：支持桌面与移动端，具备活动状态指示、对话保存及语音输入功能。

**4. 使用建议**
- 需从社区插件安装 BRAT 并添加 GitHub 链接以获取 Beta 版。
- 每台设备需单独配置 API Key；若使用 Obsidian Sync，需确保插件同步更新。
- 建议先尝试简单需求（如“创建待办清单”），再逐步复杂化，利用对话历史持续优化功能。
