## 概述

Syntax Palette 专为桌面端用户打造，旨在解决 Markdown 围栏代码块缺乏视觉区分度的问题。它通过为代码片段提供丰富的语法高亮，让笔记中的技术内容更加清晰易读。该插件的核心优势在于其高度可定制性，内置了 15 种不同的主题家族，允许用户根据笔记的整体风格或个人偏好，灵活调整代码块的配色方案，从而在保持笔记美观的同时，显著提升代码内容的可读性。

想象一下，当你整理编程学习笔记或记录 API 文档时，Syntax Palette 能让复杂的代码逻辑瞬间变得条理分明。例如，在记录 Python 脚本时，关键字、字符串和注释会以不同颜色呈现，帮助你快速定位关键逻辑；或者在撰写技术博客草稿时，通过切换不同的主题家族，你可以轻松找到与正文背景最协调的代码配色，避免视觉上的突兀感，让阅读体验更加流畅自然。

与许多仅支持单一配色或基础高亮的插件不同，Syntax Palette 提供了更细致的视觉控制能力。除了核心的语法着色外，它还支持可选的背景色设置，使代码块与周围文本形成更明显的层次对比。此外，插件允许用户开启行号显示，这对于需要引用特定代码行或进行代码审查的场景非常实用。同时，它支持编辑器换行功能，确保长代码行不会溢出屏幕，而是自动折行显示，解决了传统代码块在窄屏或移动端预览时常见的截断问题。

需要注意的是，该插件目前仅支持桌面端版本，移动端用户无法使用此功能。此外，由于它主要聚焦于视觉呈现，如果你需要代码执行、实时调试或复杂的代码片段管理功能，Syntax Palette 可能无法满足需求。它更适合那些重视笔记美观度、希望代码块在视觉上更专业、更整洁的用户，而非追求代码交互能力的开发者。
