## 概述

**1. 主要功能**
Universal Text Style Manager 是一款无需编写 CSS 代码即可对 Obsidian 笔记进行视觉美化的插件。它提供直观的图形化界面，允许用户自定义文本、标题、引用块、列表、表格、链接及嵌入内容（如图片、PDF）的样式，并支持实时预览。

**2. 适用场景**
适用于希望提升笔记视觉美观度，但不具备 CSS 编程能力的用户。特别适合需要区分亮/暗模式样式，或希望在不修改原始 Markdown 文件的前提下，对特定元素进行个性化装饰的场景。

**3. 核心特色**
*   **零代码操作**：通过可视化界面直接调整样式，降低使用门槛。
*   **非侵入式**：样式仅作用于显示层，绝不修改原始 Markdown 文件内容。
*   **高度兼容**：完美适配 Live Preview 和 Reading View，且与现有 Obsidian 主题无缝共存。
*   **精细控制**：支持独立设置亮/暗模式样式，内置 12 种预设方案，涵盖从基础文本到复杂表格、嵌入媒体的全方位定制。

**4. 使用建议**
建议新手先尝试内置的 12 种预设以快速上手，熟悉界面后再进行自定义调整。由于插件支持独立配置亮/暗模式，用户可针对两种环境分别优化配色方案，以获得最佳的阅读体验。
