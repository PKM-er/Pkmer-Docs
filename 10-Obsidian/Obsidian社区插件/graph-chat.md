## 概述

### Graph Chat插件总结
1. **主要功能**：提供扩展的图谱视图，笔记可打开为基于本地Claude Code CLI的AI聊天框。具备图谱画布展示笔记、标签和链接；能从任意笔记开启聊天，AI读取笔记及周边关联信息；支持对话分支，新分支继承之前内容后再发散。
2. **适用场景**：适用于在Obsidian中管理知识图谱，希望与笔记进行交互、拓展思路、探索不同观点的用户。
3. **核心特色**：基于本地Claude Code CLI，无需API密钥和单独计费，继承Vault的配置。每个聊天都是真实的Markdown笔记，与来源笔记关联。支持语义缩放，可将Vault折叠为文件夹卡片。
4. **使用建议**：使用前需在本地安装并认证[Claude Code](https://claude.com/claude-code) CLI。未来版本会支持更多CLI，可关注更新。操作时可利用图谱画布的交互功能，如平移、缩放、排列等，还可尝试通过对话分支对比不同模型的回答。
