## 概述

**1. 主要功能**
MindMap Studio 是一款将 Markdown 文件渲染为思维导图的插件。它允许用户直接打开 `.mindmap.md` 文件，将其大纲结构可视化为思维导图进行编辑，并支持双向同步：在导图中的修改会实时写回 Markdown 文件，反之亦然。

**2. 适用场景**
适用于需要以可视化方式整理笔记、梳理知识结构或进行头脑风暴的用户。特别适合希望保持笔记为纯文本格式（便于版本控制、搜索和备份），同时又需要图形化界面来辅助思考的 Obsidian 用户。

**3. 核心特色**
*   **Markdown 原生**：文件本质是标准 Markdown，完全兼容 Obsidian 的链接、反向链接、搜索及 Git 版本控制，无专有格式锁定。
*   **无损往返**：编辑导图后，未修改的行原样写回，保留 Frontmatter 等元数据。
*   **丰富功能**：支持拖拽重排、原生 Wikilinks 和图片嵌入、自动布局、搜索及 PNG 导出。
*   **布局独立**：视图布局与视口状态存储在插件数据中，不污染 Markdown 源文件。

**4. 使用建议**
建议通过命令面板或侧边栏图标创建新的 `.mindmap.md` 文件开始使用。编辑时，可随时切换回 Markdown 视图检查源码。注意该插件目前仅支持桌面端，且未经官方人工审核，建议在重要数据操作前做好备份。
