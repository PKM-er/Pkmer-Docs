## 概述

**插件名称：Evil Org**

1.  **主要功能**：为 Obsidian 的 Vim 模式引入 Org-mode 风格的标题编辑能力。支持通过 `Tab`/`Shift-Tab` 循环切换标题折叠状态，并将折叠后的标题视为单行，从而支持 `V`、`dd`、`p` 及 `>>`/`<<` 等 Vim 命令对完整子树进行移动、复制、提升或降级操作。

2.  **适用场景**：适合习惯 Emacs Org-mode 或 Vim 工作流的用户，特别是在处理长篇结构化笔记、需要频繁调整文档层级结构或进行大块内容重组时。

3.  **核心特色**：
    *   **无缝集成**：基于 Markdown 标题模拟 Org 标题行为，无需改变笔记格式。
    *   **智能折叠**：`Tab` 实现局部折叠循环（折叠→子项→子树），`Shift-Tab` 实现全局视图切换（概览→内容→全部）。
    *   **子树操作**：折叠状态下，Vim 命令可像操作单行一样操作整个标题子树，极大提升结构编辑效率。

4.  **使用建议**：
    *   务必在设置中开启 **Vim key bindings**。
    *   主要在 Vim 普通模式和可视模式下使用快捷键，插入模式不受影响。
    *   建议先熟悉 `Tab` 的三种状态切换逻辑，以便快速定位所需视图。
