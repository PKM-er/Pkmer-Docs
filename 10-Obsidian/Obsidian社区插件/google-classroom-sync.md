## 概述

Google Classroom Sync 将你的谷歌课堂账号直接接入 Obsidian，核心功能是同步课程、作业和材料，并自动生成结构化的 Markdown 学习笔记。它提供了一个专属的工作区标签页，让你无需切换浏览器即可在本地查看所有已注册的课程、最新公告以及即将到来的截止日期，实现了学术信息与个人知识库的无缝整合。

典型使用场景包括：当你需要快速了解本周学习重点时，打开仪表盘即可看到带有“今日截止”或“剩余 X 天”等智能紧急程度徽章的作业列表；当你开始处理某项作业时，插件会自动在指定文件夹下生成一篇包含作业说明、截止日期、相关材料及交付物清单的笔记，省去了手动整理信息的繁琐步骤。

相比其他同类插件，其特色在于通过官方 OAuth 2.0 桌面集成确保数据隐私，所有令牌和凭证仅保留在本地机器，不经过任何第三方服务器。此外，它支持一键隐藏已完成或归档的课程，保持界面整洁，并默认将笔记按“课程名称”自动归类到指定文件夹中，维持了知识库的有序性。

使用前需注意，该插件需要你在 Google Cloud Console 中手动创建项目、启用 API 并配置 OAuth 客户端 ID 和密钥，这一初始设置过程对非技术用户可能有一定门槛。如果你不需要将谷歌课堂数据同步到本地笔记，或者希望完全免配置、开箱即用的体验，这款插件可能不适合你。
