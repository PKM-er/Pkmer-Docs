## 概述

**主要功能**
这是一款可视化的 CSS 片段设计工具，允许用户通过直观的控制面板调整字体排版、颜色、阴影、背景及 UI 元素。插件能实时生成标准的纯 CSS 代码，并支持一键复制，无需手动编写复杂的样式规则。

**适用场景**
适用于希望个性化 Obsidian 界面但不熟悉 CSS 编程的用户。特别适合需要快速定制阅读视图、实时预览视图外观，或希望创建可分享的主题片段的高级用户。仅支持桌面端（Obsidian 1.7.2+）。

**核心特色**
1. **实时预览**：在调整参数时，界面与生成的代码同步更新，所见即所得。
2. **丰富预设**：提供精选样式预设及程序化背景图案。
3. **智能保护**：采用围栏输出机制，保存时保留用户自定义的 CSS 代码，避免覆盖。
4. **内置校验**：写入前进行结构性 CSS 验证，确保代码有效。
5. **无障碍支持**：包含动画效果并支持“减少运动”设置。

**使用建议**
建议初学者先从“预设”标签页入手，快速获得基础美化效果；进阶用户可深入“排版”和“颜色”标签页进行精细调整。由于插件未通过官方人工审查，建议定期备份笔记数据，并在修改前熟悉“围栏输出”机制，以防自定义样式丢失。
