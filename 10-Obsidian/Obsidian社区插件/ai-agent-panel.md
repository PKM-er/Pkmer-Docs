## 概述

**1. 主要功能**
该插件在 Obsidian 中提供原生 AI 代理面板，允许用户直接与已安装的 Anthropic Claude Code CLI 交互。代理以 Vault 为工作目录，可执行搜索笔记、回答内容问题、重构及链接笔记、起草新笔记等任务。

**2. 适用场景**
适用于希望利用 AI 辅助进行知识管理、笔记整理或文档重构的用户。特别适合已拥有 Claude Code 账号并熟悉 CLI 工具的技术型用户，需在本地环境中自行安装并登录代理。

**3. 核心特色**
*   **原生集成**：作为 Obsidian 原生面板运行，操作体验流畅。
*   **权限安全**：所有操作均通过 Obsidian 原生权限提示进行确认，确保用户控制权。
*   **独立非官方**：插件不处理登录或凭证，仅调用用户本地安装的 CLI，不涉及官方背书，安全性由用户自行管理。
*   **单一代理支持**：目前仅支持 Claude Code，OpenAI Codex 等仍在计划中。

**4. 使用建议**
使用前请确保已在本地安装并登录 Claude Code CLI。由于插件未通过 Obsidian 官方人工审核，建议谨慎授予文件操作权限。鉴于其非官方性质，重要数据操作前请做好备份，并关注后续多代理支持的开发进展。
