# Obsidian 插件：Jot

> [!Note] 插件名片
> - 插件名称：Jot

## 概述

### Jot 插件总结
1. **主要功能**：支持使用 Apple Pencil 在 Obsidian 中对 PDF 进行手写批注，批注以 JSON 边车文件形式保存，不修改原 PDF；具备压感墨水、多种工具（笔、荧光笔、橡皮擦）、七种可配置颜色和四种宽度；支持单 PDF 的撤销/重做操作，可将批注合并为扁平化 PDF。
2. **适用场景**：适用于在排练时对乐谱进行批注，标记呼吸点、提醒注意的音符等场景，也可用于日常对 PDF 文件的批注。
3. **核心特色**：批注存储在边车 JSON 文件中，可通过 Git 或 iCloud 与 Vault 同步，实现跨设备编辑查看；长按打开的径向调色板能记住上次设置；书写时忽略触摸输入，可自由放手掌。
4. **使用建议**：先在 Obsidian 社区插件中搜索安装并启用 Jot；打开 PDF 后，用 Apple Pencil 长按页面打开径向调色板选择工具、颜色和宽度进行批注；两指按住可关闭调色板；可通过命令将批注合并到 PDF 或清除批注。
