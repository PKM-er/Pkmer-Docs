# 兰台（LanTai）

**兰台**（拼音 **Lántái**；产品拼写 **LanTai**；英语近似 *lahn-tye*）借自中国历史上收藏图籍与档案的典藏之名。汉代宫廷设有名为「兰台」的中央图籍与档案典藏之所（宫内石室藏书，御史中丞兼领，置兰台令史典校秘书，并有奉诏修史之例）。后世引申指宫廷文献府库、史官或相关职司；今常作档案保管机构与档案工作的雅称。

本插件在本地库与对象存储之间上传、本地化并管理笔记图片，为 Obsidian 提供全流程的图片附件与图床管理方案，面向 **桌面端与移动端**。

## 解决什么痛点

其一，以 Obsidian，Typora 等本地软件，在有大量文件数量时（大于一万个文件）文件树会出现较为明显的卡顿，并且文件数量过多难以管理。将图片放到图床，能聚焦到仅管理 Markdown 文件，降低心智压力。

其二，传统对象存储如腾讯云 COS、阿里云 OSS、AWS S3、Cloudflare R2 等，虽然对于个人用户来说很便宜，但有很多需要配置和运维的地方，比如：

- 开通对象存储服务：该服务存储和下载都需要付费，存储价格大约在 0.35元/G，访问和下载按量付费价格不定
- 购买 CDN：单纯的对象存储没有稳定的防盗刷服务，需要 CDN 做防护，有了 CDN 服务，下载走 CDN，对象存储无下行流量费用
- 购买域名：每年大约 10 元以上，上不封顶，好且短的域名往往更贵
- 域名备案：国内的域名需要备案，国外域名无需备案
- 域名 SSL/TLS 证书：域名保障访问内容安全，域名免费 SSL/TLS 证书目前每三个月需要申请一次，未来会缩减到 48 天，需要稳定的自动化工具避免域名 ssl 失效
- 客户端配置：[Typora 文档](https://support.typora.io/Upload-Image/)指出依赖 PicGo、PicList 等外部服务，Obsidian 则还依赖一些插件
- 较难管理：由于对象存储是按桶和key等概念构建的，如果要管理需要自己实现一套服务端和客户端，无法给图片分类，打标签等操作
- 不少方案不支持移动端，手机上无法完成同一套流程。
- ......

对于国外的服务往往不需要备案和自动化证书配置，但支付，访问速度等存在一定的要求。当然也可以使用一些免费图床绕过这些配置，但 Gitee 禁止用户图床，某些图床倒闭等，不能保证稳定。

其三，使得文件易于备份和管理。通过 Git 备份 Obsidian、Logseq、Typora 文件是常见方式，但是 Git 天然对二进制文件不友好，使用图床能保持纯文本文件纯粹，用户能够本地文件大小从几十 G 缩减到数十 MB，能显著减小备份压力。兰台同时提供管理端，支持打标签，修改图片元数据，丰富搜索和查询。进一步的，亦可通过 API 查询图片给 agent 使用。

当然，有利必有弊，解决的问题同时也引入了新的问题。使用图床主要缺点包括无网环境加载不了第一次加载的图片（已加载过的图片有缓存时间），有敏感图片审查（国内对象存储服务严格要求），持久付费。

兰台把上传、本地化、命名模板与画廊管理放在同一插件里，并覆盖移动端（见下方限制）。

## 要求

- Obsidian **≥ 1.11.4**（访问密钥使用 Secret Storage / `SecretComponent`）

## 快速开始

**兰台云（推荐）**

[兰台云](https://lantai.pkmer.cn)只需注册登录，复制 API Key 即可使用，无需自建对象存储，且能更好管理图片数据，支持排序。

1. 在 [兰台网页控制台](https://lantai.pkmer.cn/settings?tab=api-keys) 注册并登录，签发并复制 API Key。
2. 打开 **设置 → LanTai → 存储**，新建配置档，将提供商选为 **兰台**，粘贴 Key，并设为当前启用。
3. 在 Markdown **编辑**视图中，对图片 **右键**（移动端：**长按**）→ **上传**，或使用命令面板。

**自有 S3 兼容桶**

1. 打开 **设置 → LanTai → 存储**。
2. 新建存储配置档，填写桶、公网访问前缀、区域/端点等，并通过 Secret Storage 绑定访问密钥。
3. 将该配置档设为当前启用，然后按上面的方式上传。

侧边栏 Ribbon 可打开画廊，浏览最近上传、兰台 / S3 与本地图片。
## 主要功能

- **兰台云** — 注册登录后复制 API Key 即可使用。网关生成对象键、压缩图片，并把公网 URL 写入笔记。原始文件名会保存，供画廊显示。
- **图片右键菜单** — 对单张图上传、本地化、下载（另存到库外）。桌面端右键，移动端长按打开菜单。
- **批量命令** — 上传当前笔记中的全部本地图；本地化当前笔记中的全部远程图。
- **迁移向导（桌面端）** — 把选定笔记文件夹内引用的本地图上传到当前启用配置档，改写链接，并可按计划文件续跑。移动端不显示入口。
- **命名模板** — 本地落盘路径与各 S3 配置档的对象键均可模板化。常用变量：`noteFileName`、`noteFolderName`、`noteFilePath`、`noteFolderPath`、`date`、`uuid`、`random`、`originalName`、`ext`。兰台忽略客户端对象键模板（由服务端分配键）。
- **画廊** — 侧边栏 Ribbon 打开画廊，浏览、搜索并管理图片。兰台源支持排序、搜索（`tag:` 按标签）、分页，以及可调宽度的详情侧栏（标题、描述、标签、反向链接）。

另外支持 AWS S3、Cloudflare R2、阿里云 OSS、腾讯云 COS，以及 MinIO 等 S3 兼容端点；可选上传成功后将本地源文件移入回收站；本地链接可选 Wiki / Markdown（远程 http(s) 链接一律为 Markdown）。

## 限制

- 在编辑态会**替换** Obsidian 图片原有的右键菜单。
- **不支持**按自定义规则对 S3 图片排序（这是对象存储本身的限制，不是本插件漏做）。兰台画廊支持排序。
- 兰台删除是**软删除**：公网链接约 **7 天**内仍可访问。插件内**不能恢复**。
- 迁移向导**仅桌面端**；未完成的计划要等到桌面再打开库处理。
- 移动端**仅在 Android 上测试过**；iOS 未充分验证。
- 阅读 / 预览模式不接管图片菜单，仍使用 Obsidian 原生菜单。
