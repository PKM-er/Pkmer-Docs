## 概述

**Grok Notes** 是一款连接 xAI Grok 模型的 Obsidian 插件，旨在让用户直接在笔记应用中与 AI 对话。

**主要功能**：支持对当前笔记或选中内容进行提问、摘要、重写，并将 AI 回复直接插入笔记。提供“Imagine”图像生成功能。

**适用场景**：适用于需要在多设备（笔记本、平板、手机）间无缝切换的知识工作者。桌面端采用侧边栏交互，移动端采用底部弹出面板（Sheet），适合在写作过程中即时获取 AI 辅助。

**核心特色**：
1. **多端适配**：界面根据设备自动调整，无需额外配置。
2. **无 CLI 依赖**：直接调用 xAI API，无需安装命令行工具，配置简单。
3. **快速操作**：提供 3x2 的快捷操作按钮，提升交互效率。
4. **隐私透明**：明确说明数据发送至 xAI 服务器，API 密钥仅存储在本地 `data.json` 中。

**使用建议**：
1. 需自行前往 xAI 控制台申请 API Key 并配置，注意 API 使用费用。
2. 插件尚未进入官方社区商店，需从 GitHub Releases 手动下载安装。
3. 切勿将包含 API 密钥的 `data.json` 提交至版本控制系统，以防泄露。
