## 概述

**主要功能**
该插件允许用户在 Obsidian 的阅读视图中，通过直接拖拽表头边缘来调整 Markdown 表格的列宽。它基于标准 Markdown 管道表格工作，无需嵌入代码块或特殊标记，确保笔记保持纯文本格式。

**适用场景**
适用于需要在阅读模式下优化表格视觉呈现的用户，特别是那些希望保持笔记高度可移植性、避免使用专有格式或代码块包裹表格的场景。

**核心特色**
1. **纯 Markdown 兼容**：不修改文件内容，禁用插件后表格依然有效，无锁定风险。
2. **持久化设置**：列宽调整会自动保存，重启软件后依然生效。
3. **多设备支持**：基于指针事件，支持鼠标、触摸屏及手写笔操作。
4. **主题友好**：样式作用域隔离，不会与现有主题冲突，且可自定义列宽的最小/最大值限制。

**使用建议**
建议从官方插件目录安装以获取自动更新。该插件专注于视觉列宽调整，若需编辑表格内容或导航，建议搭配 Advanced Tables 插件使用，二者互补可提升表格处理效率。目前主要支持阅读视图，实时预览（Live Preview）支持正在规划中。
