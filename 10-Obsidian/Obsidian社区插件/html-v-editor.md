# Obsidian 插件：HTML V Editor

> [!Note] 插件名片

## 概述

### 主要功能
在 Obsidian 桌面端直接预览、编辑和保存 `.html` / `.htm` 文件，支持 Markdown 中 `html-v` 代码块和嵌入 HTML 的可视化编辑，可在三种模式间切换，还能将 HTML 导出复制为 Markdown 或纯文本。

### 适用场景
适用于需要在 Obsidian 内处理 HTML 文件、编写含 HTML 代码块的 Markdown 文档的场景。

### 核心特色
- 本地打包编辑器，不依赖 CDN。
- 提供三档预览安全模式。
- 有内置的 HTML V Tasks / Links 侧栏，可管理任务和发现内部链接，且支持多种过滤。

### 使用建议
可直接在 Obsidian 社区插件市场搜索安装该插件，若手动安装，需将相关文件复制到指定目录，重启或重载社区插件后在设置里启用。使用时可按需切换不同模式及安全等级，利用侧栏的过滤功能高效管理任务和链接。
