## 概述

**Cycle Latest Tab** 是一款旨在优化 Obsidian 标签页导航体验的社区插件。

1. **主要功能**：该插件将默认的标签页切换逻辑替换为“最近使用（MRU）”模式。它模仿 Windows 的 Alt+Tab 或 macOS 的 Cmd+Tab 机制，让用户能按最近访问顺序快速循环切换标签页，而非按物理位置顺序。
2. **适用场景**：特别适合同时打开大量笔记、参考文档或代码文件，且需要在多个非相邻标签页之间频繁跳转的用户。
3. **核心特色**：
   - **MRU 循环**：基于使用频率排序，提升切换效率。
   - **可视化列表**：切换时弹出模态窗口，直观展示当前所有打开的标签页，避免盲选。
   - **高度可定制**：支持在 Obsidian 设置中自由绑定快捷键，并调整行为参数。
4. **使用建议**：
   - 安装后需进入“设置 -> 快捷键”，为“Cycle to next/previous tab”分配快捷键（如 `Ctrl+Tab`）。
   - **注意冲突**：若自定义快捷键与系统默认标签页切换冲突，需先解绑默认的“Go to next/previous tab”快捷键。
   - 目前社区商店待审核，建议通过 GitHub Releases 手动下载并放入 `.obsidian/plugins/` 目录安装。
