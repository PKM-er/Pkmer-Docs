## 概述

### 主要功能
YAML Editor 是为 Obsidian 打造的结构化 YAML 编辑器。提供专注的 YAML 编辑模式，有模式感知的自动补全、结构缩进、折叠、代码片段面板等功能，还能对独立 YAML 文件进行编辑。

### 适用场景
适用于编辑笔记的前置元数据（Frontmatter）、YAML 代码块，以及独立的 `.yaml` 或 `.yml` 文件。

### 核心特色
- 模式感知补全：扫描库中所有笔记的前置元数据、代码块和独立 YAML 文件，根据路径提供已使用的键、示例值和代码片段的补全建议，还支持显式 JSON 模式。
- 保留原文格式：遵循往返保留原则，不会重新排序键、删除注释或修改空格。

### 使用建议
在编辑 YAML 内容时，充分利用自动补全功能提高效率。若需要更精准的补全建议，可使用显式 JSON 模式。对于常用结构，可借助代码片段快速插入。
