## 概述

**1. 主要功能**
在 Obsidian 内提供 UI 设计学习闭环：浏览 13,500+ 真实设计图库、查阅中英双语 UI 词典、探索 44 种视觉风格图鉴，并通过审美测验巩固记忆。支持笔记记录及一键生成“复刻 Prompt”。

**2. 适用场景**
适合 UI/UX 设计师、前端开发者及独立创作者，用于日常灵感积累、组件术语学习、风格识别训练，以及将设计灵感转化为 AI 编程指令（Vibe Coding）。

**3. 核心特色**
*   **闭环学习**：从看图、学名词到测验巩固，形成完整知识体系。
*   **Vibe Coding 集成**：点击“复刻”即可生成包含截图、预览及步骤的 Prompt，甚至可复制 HTML 源码，直接交给 AI 助手。
*   **本地化与隐私**：笔记、评分、标签均保存在个人库中，支持 Markdown 导出；界面自动适配 Obsidian 主题。

**4. 使用建议**
建议结合“灵感图库”浏览与“UI 词典”学习，遇到感兴趣的设计立即使用“复刻”功能生成 Prompt 并保存为笔记。定期完成“审美测验”以强化记忆。注意该插件需 Obsidian ≥ 1.7.2，且数据内置于 `main.js`，无需额外依赖。
