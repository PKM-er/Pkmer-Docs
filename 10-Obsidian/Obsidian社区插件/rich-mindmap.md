## 概述

**Rich Mindmap** 是一款将 Markdown 列表转化为可编辑思维导图的 Obsidian 插件。

1. **主要功能**：在地图上直接编辑节点，支持拖拽重组、设置优先级、进度及标记，并为节点添加悬浮备注。数据始终保存为纯 Markdown 缩进列表，确保数据透明且无专有格式。
2. **适用场景**：适合需要可视化梳理层级结构、进行任务管理（如标记进度和优先级）或整理复杂知识体系的场景。特别适用于希望数据能被 AI 或其他工具直接读取的笔记工作流。
3. **核心特色**：
   - **双向编辑**：区别于只读预览或 Canvas 格式，支持在地图上直接修改并回写至 Markdown 源文件。
   - **纯文本兼容**：节点备注以 Markdown 引用块存储，无需插件即可阅读；兼容 markmap 的层级模型，可打开现有预览文件进行编辑。
   - **数据纯净**：仅执行有限的字节级规范化，避免引入专有坐标或 JSON 数据，保持文件简洁。
4. **使用建议**：建议将笔记结构化为标准的缩进列表以发挥最佳效果。由于插件未通过官方人工审查，重要数据请定期备份。利用其“纯文本”特性，可轻松结合 AI 工具进行内容生成或整理。
