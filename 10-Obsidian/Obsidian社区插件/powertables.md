# Obsidian 插件：Power Tables

> [!Note] 插件名片
> - 插件名称：Power Tables
> - 插件作者：Power Plugins
> - 插件说明：直接在原地对Markdown表格进行颜色设置、计算和排序：可以设置单元格填充颜色和文本颜色，使用实时重新计算的公式，还能进行列排序，所有这些都以纯Markdown格式存储。——此插件尚未经过Obsidian官方人员的人工审核。

## 概述

### Power Tables 插件总结
1. **主要功能**：为笔记中的 Markdown 表格赋予电子表格能力，包括设置单元格颜色、使用实时公式自动重算、排序、筛选，支持 Excel 键盘快捷键，还有数据验证、迷你图等。
2. **适用场景**：适用于需要在笔记中使用表格进行数据记录、计算和分析的场景，如预算记录、数据统计等。
3. **核心特色**：表格以纯 Markdown 形式存储，有无插件笔记都能正常使用；提供丰富的颜色设置和条件规则；支持 49 种 Excel 函数，公式栏可自动补全；实时总计随笔记内容变化自动更新。
4. **使用建议**：新用户可运行“Insert demo table”命令，在十秒内查看大部分功能的运行效果。操作时可利用 Excel 选择键提高效率，还能通过数据验证为列设置可选值，方便数据录入。
