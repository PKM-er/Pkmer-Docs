## 概述

**1. 主要功能**
Chenggao 是一款 Obsidian 桌面端插件，支持在笔记右侧实时预览“推特风格卡片”或“微信公众号文章”。它提供双栏布局，左侧编辑 Markdown，右侧即时刷新预览效果。支持将内容导出为 PNG 图片（自动存入同级`图片/`文件夹）或复制为微信编辑器兼容的富文本/HTML。

**2. 适用场景**
适合需要频繁向社交媒体（如 Twitter/X）发布图文卡片，或撰写微信公众号文章的内容创作者。尤其适用于希望减少“编辑-复制-排版”重复劳动，追求高效工作流的中文用户。

**3. 核心特色**
*   **实时同步**：输入即预览，所见即所得。
*   **双模式支持**：卡片模式自动分页生成 1728×2304 尺寸图片；文章模式提供微信风格长图预览。
*   **一键导出**：支持批量导出 PNG 或保存为 `.wechat.html`，简化发布流程。
*   **本地化友好**：界面语言跟随 Obsidian 设置，中文环境自动显示中文 UI。

**4. 使用建议**
目前未上架社区插件目录，需从 GitHub 克隆仓库，执行 `npm run build` 构建后，将 `manifest.json`、`main.js` 和 `styles.css` 手动复制至 Vault 的 `.obsidian/plugins/chenggao/` 目录并启用。建议先熟悉卡片分页逻辑，再根据平台要求调整 Markdown 结构，以确保导出图片排版美观。
