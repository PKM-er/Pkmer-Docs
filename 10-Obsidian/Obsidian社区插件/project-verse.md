## 概述

### 插件总结
1. **主要功能**：ProjectVerse 是 Obsidian 的虚拟项目空间管理插件。可自由创建、编辑和删除项目空间，关联文件与文件夹；有专属侧边栏项目浏览器，专注当前任务；自动生成美观的项目控制面板，含数据统计、任务扫描、备忘录等功能；支持工作区状态同步，切换项目时保存并还原标签页。
2. **适用场景**：适用于需要在 Obsidian 中对项目进行集中管理，处理多个分散文件，且希望有直观操作界面和便捷任务管理的场景。
3. **核心特色**：以代码和配置化管理项目，非侵入式关联文件；项目浏览器和控制面板设计实用，能提高工作效率；工作区状态同步让工作无缝衔接。
4. **使用建议**：按步骤从 GitHub Releases 下载并安装插件。若要二次开发，可使用 `npm install` 安装依赖，`npm run dev` 启动开发模式，`npm run build` 编译生产版本。
