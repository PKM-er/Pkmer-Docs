## 概述

**Markdown to CV** 是一款专为 Obsidian 设计的简历生成插件，主要功能是将 Markdown 笔记实时转换为标准 A4 版式的 HTML 预览，并支持本地导出为 PDF。

**适用场景**：适合需要在 Obsidian 中管理、编辑并快速生成专业简历的用户，特别是中文环境下的求职者或 HR 从业者。

**核心特色**：
1. **实时预览**：编辑 Markdown 时同步更新 A4 页面效果，支持 50%-200% 缩放及“适应宽度”功能，方便细节检查。
2. **离线中文字体**：内置思源黑体（Source Han Sans CN），无需联网即可保证中英文排版美观。
3. **灵活编辑**：支持自由调整章节顺序，提供起始模板及“回到模板”功能（保留原稿快照，生成修复副本，不覆盖源文件）。
4. **即时导出**：导出 PDF 时捕获当前编辑状态（含未保存内容），操作灵活。

**使用建议**：
1. 仅支持桌面端（macOS 已测试，Windows/Linux 未验证），不支持移动端。
2. 需手动从 GitHub Release 下载文件至插件目录安装，非官方商店插件。
3. 建议先使用内置模板熟悉结构，再自定义内容；导出前确认内容无误，因为导出即定格当前状态。
