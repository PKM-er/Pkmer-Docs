## 概述

### 插件主要功能
Copy Indented Code Blocks 是一款 Obsidian 插件，它能在复制缩进的代码块时自动去除每行的前导缩进，保留代码内部的相对缩进。

### 适用场景
适用于需要将 Obsidian 中缩进的代码块复制到其他地方（如命令行）使用的场景，避免手动删除前导空格的麻烦。同时，也支持在列表中折叠代码块并保持其结构。

### 核心特色
- 自动检测代码块的缩进级别并去除相应前导空格。
- 支持任何缩进样式（空格或制表符）。
- 能处理由超过 3 个反引号界定的代码块，以及嵌套代码块。

### 使用建议
使用 Obsidian 内置的复制功能（点击代码块右上角文本或图标）来复制代码块，插件会自动处理缩进问题。注意，嵌套代码块默认只能复制整个包含块。
