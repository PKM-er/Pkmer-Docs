## 概述

### GitHub Stars Manager插件总结
1. **主要功能**：可在Obsidian内管理和查看GitHub收藏的仓库，支持多账户管理、自定义标签、智能搜索，能实时显示仓库数量和收藏数，支持自动或手动同步收藏仓库，还可添加自定义标签、备注并将仓库与Obsidian笔记文件关联。
2. **适用场景**：适合经常使用GitHub且习惯在Obsidian中记录和管理信息的用户，方便他们集中管理GitHub收藏的仓库。
3. **核心特色**：支持多账户同时管理收藏；有直观的标签芯片组件，便于快速选择已有标签；本地存储注释数据，保护隐私；搜索支持正则表达式和模糊匹配，还能进行多维度排序。
4. **使用建议**：初次使用可先根据使用指南完成账户配置和同步设置；利用智能搜索和多维度排序功能快速定位所需仓库；添加自定义标签和备注，方便对仓库进行个性化管理。
