## 概述

### Quick Capture 插件总结
1. **主要功能**：可将 iPhone 或 Android 设备上的文本、链接和短笔记发送到 macOS 或 Windows 系统的 Obsidian 桌面应用，消息会临时存储在用户的 Cloudflare Worker 和 D1 数据库，待桌面应用可用时写入每日 Markdown 表格。
2. **适用场景**：适用于在移动设备上快速记录信息，并同步到桌面端 Obsidian 进行整理的场景。
3. **核心特色**：支持从 iOS 快捷指令分享表及 Android 自动化工具捕获内容；桌面应用启动和运行时自动同步；电脑离线时可缓存消息；对缓存内容进行 AES - 256 - GCM 加密；可将中继部署到用户自己的 Cloudflare 账户，无需自定义域名、服务器等。
4. **使用建议**：插件被社区目录收录后，可在设置的社区插件中搜索安装；测试阶段需从 GitHub 下载文件手动放置到指定目录。部署需有免费 Cloudflare 账户，可点击按钮部署私有中继。
