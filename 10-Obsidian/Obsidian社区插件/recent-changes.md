## 概述

**Recent Changes** 是一款用于 Obsidian 的侧边栏插件，旨在帮助用户快速浏览最近修改的文件和文件夹。

**主要功能**：提供紧凑的侧边栏视图，支持按时间范围（如1小时、1天、1周等）筛选最近变更的内容，并可切换查看文件列表或文件夹结构。

**适用场景**：特别适用于 Vault 被外部编辑器、脚本、AI 代理或 Git 同步修改的情况，帮助用户迅速定位最新变动的内容，无需手动搜索。

**核心特色**：
1. **高效筛选**：一键选择多种时间范围，文件按时间分组，文件夹按最新修改时间排序。
2. **灵活配置**：可自定义文件扩展名、排除特定文件夹或文件名，并设置显示数量限制。
3. **便捷操作**：支持右键快速排除项目、相对时间显示、高亮当前活动文件，以及通过键盘导航和原生上下文菜单进行操作。
4. **隐私安全**：无网络请求、无遥测数据、无账户要求，且无其他插件依赖，完全本地运行。

**使用建议**：
- 需安装桌面版 Obsidian 1.7.2 或更高版本。
- 若社区插件列表中未显示，可通过 BRAT 插件或手动安装发布文件进行安装。
- 启用后，点击侧边栏的历史图标或运行命令“Recent Changes: Open view”即可使用。
- 建议结合 Git 工作流使用，以便在代码或笔记同步后快速审查变更。
