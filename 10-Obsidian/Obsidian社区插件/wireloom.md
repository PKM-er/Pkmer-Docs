## 概述

**1. 主要功能**
Wireloom 是一款 Obsidian 社区插件，能将纯文本形式的 Wireloom 代码块直接渲染为自包含的 SVG UI 线框图。它无需外部工具或网络请求，实现了“文档即设计”，让界面原型与 Markdown 笔记同源共存。

**2. 适用场景**
适用于产品经理在 PRD 中嵌入 AI 生成的界面原型、开发者在技术文档中维护实时界面示意图、设计师快速迭代低保真概念，以及构建“自然语言 → 线框图”的自动化 AI 文档生成工作流。

**3. 核心特色**
*   **AI 原生**：专为 LLM 生成代码设计，支持文本优先存储，天然兼容 Git 版本控制。
*   **零依赖渲染**：生成的 SVG 完全自包含，无外部字体或脚本依赖，加载性能优异。
*   **深度集成**：完美适配 Obsidian 主题（浅/深色）、设置面板及 Markdown 渲染管线，且具备精确到行列的错误提示功能。

**4. 使用建议**
在笔记中使用 ` ```wireloom ` 代码块包裹线框图代码即可自动渲染。建议利用其文本特性配合 Git 进行版本管理，并借助 AI 工具直接生成 Wireloom 代码以提升原型迭代效率。注意该插件尚未经过官方人工审核，请留意兼容性。
