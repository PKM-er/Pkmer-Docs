## 概述

**主要功能**
SelfGrow 是一款本地优先的 Obsidian 插件，能将链接、文本、图片、PDF、Markdown 文件及 GitHub 仓库转化为可审查的“原始卡片（Raw cards）”。它支持提取文档内容，保留完整源证据，并允许用户将精选内容蒸馏为关联 Wiki。

**适用场景**
适用于知识管理、信息收集及深度阅读场景。特别适合需要长期积累素材、整理网络资源或处理大量文档，并希望通过人工筛选建立结构化知识库的用户。

**核心特色**
1. **本地优先**：数据完全存储在 Vault 中，不依赖云端，支持桌面及移动端。
2. **AI 增强**：可选配 AI 提供商，自动生成标题、预览、分类及推荐评分，但非必需。
3. **严格审查机制**：Wiki 写入需经过显式批准，确保知识入库的质量与准确性。
4. **多源支持**：兼容多种格式，包括解析 GitHub 仓库的 README 及代码块。

**使用建议**
1. 安装后先在设置中指定“原始卡片”根目录。
2. 若需自动摘要或分类功能，请配置 AI API Key；仅本地存储则无需密钥。
3. 建议定期审查原始卡片，仅将高价值内容蒸馏至 Wiki，以保持知识库的精简与高效。
