## 概述

### Copy Note Wikilink插件总结
1. **主要功能**：将所选笔记或搜索结果复制为Obsidian维基链接，如`[[My note]]`。可复制当前活动笔记链接，也能复制搜索模态框中高亮结果的链接。
2. **适用场景**：适用于在Obsidian中需要快速复制笔记维基链接的场景，如在编辑笔记时引用其他笔记，或在搜索结果中获取特定笔记链接。
3. **核心特色**：支持多种搜索模态框结果复制，包括Omnisearch、Quick Switcher和Better Command Palette等；默认提供热键，方便操作。
4. **使用建议**：可通过命令面板运行“Copy current note name as [[wikilink]]”命令，也可使用默认热键（macOS: `Cmd+Shift+C`；Windows/Linux: `Ctrl+Shift+C`）。打开支持的搜索模态框后，高亮所需结果再用热键复制。该插件可在社区插件商店下载，也能手动安装。需注意，搜索结果支持依赖模态框DOM暴露所选结果，若第三方搜索插件改变结果标记，可能需更新插件。
