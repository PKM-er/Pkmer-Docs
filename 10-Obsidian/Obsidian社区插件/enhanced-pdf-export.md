## 概述

### 插件名称
Enhanced PDF Export

### 主要功能
将活动的 Markdown 文件导出为 PDF，能保留渲染后的 Mermaid 图表、内联 HTML、SVG、表格、标注和图片等内容，还可添加可选的封面和目录。

### 适用场景
适用于包含 Mermaid 图表、内联 HTML、SVG、表格、标注和图片等丰富视觉内容的笔记导出。

### 核心特色
- 先通过应用预览渲染器渲染 Markdown 文件，再用 Electron 打印导出为 PDF，能保留默认 PDF 导出器可能遗漏或处理不当的视觉内容。
- 打印前会等待字体、图片、SVG 和 Mermaid 图表加载完成。
- 提供多种操作入口，如 ribbon 操作、命令面板操作和文件上下文菜单操作。

### 使用建议
安装可选择 Git 克隆或手动下载文件到指定目录，然后在社区插件中启用。使用时，打开要导出的 Markdown 文件，点击 ribbon 导出按钮或运行相应命令即可。
