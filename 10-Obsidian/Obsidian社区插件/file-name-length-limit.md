## 概述

### 《File name length limit插件总结》
1. **主要功能**：确保Obsidian库中的文件名在Windows、Linux、Android和iOS等设备上兼容，避免因文件名过长或含系统拒绝字符导致同步失败。
2. **适用场景**：适用于在不同操作系统设备间同步Obsidian库的用户，防止因文件名问题造成文件同步异常。
3. **核心特色**：
    - 自动警告：打开或重命名文件时，若不兼容会提示涉及平台和问题数量。
    - 实时输入警告：输入文件名时，不兼容名称会红色下划线显示，状态栏显示长度并即时提醒。
    - 状态栏提示：显示活动文件长度，不兼容时显示警告，点击可全量扫描。
    - 全量报告：可通过命令扫描整个库并生成兼容性报告。
4. **使用建议**：日常操作中留意状态栏提示和实时警告，定期使用“Check all file names”命令扫描库，确保文件名兼容性，保障文件正常同步。
