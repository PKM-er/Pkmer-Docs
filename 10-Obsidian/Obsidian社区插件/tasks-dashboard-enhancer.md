## 概述

**Tasks Dashboard Enhancer** 是一款将 Obsidian 中 Tasks 插件的查询结果转化为紧急度仪表盘的工具，旨在优化任务管理体验。

**主要功能**：自动将任务重新分组为逾期、今日、未来七天、稍后、未排期及已完成等板块，并提供待办、逾期等状态摘要。支持在不修改原始数据的情况下进行过滤，展示逾期天数，并允许展开子笔记及导航依赖任务。

**适用场景**：适用于需要高效管理复杂项目、依赖关系较多或希望直观掌握任务紧急程度的用户，特别是同时使用 Tasks 插件和 Project Manager Enhanced 插件的场景。

**核心特色**：
1. **紧凑卡片设计**：保留日期与优先级，布局响应式，适配桌面与移动端。
2. **深度集成**：支持依赖链接、笔记内编辑及创建任务，无需离开仪表盘。
3. **数据同步**：可链接项目项至任务，支持标题、截止日期及完成状态的同步。
4. **安全查询**：避免在查询中使用 JavaScript 表达式，提升稳定性。

**使用建议**：
1. 确保已安装并启用 Tasks 插件（Obsidian 1.5.0+）。
2. 在笔记属性中添加 `cssclasses: tasks-dashboard` 和 `tasks-center` 以启用仪表盘。
3. 使用标准 Tasks 状态查询代码块，插件将在渲染后自动进行紧急度重组。
4. 可配置 QuickAdd 命令以快速创建任务，并设置任务中心笔记以实现项目与任务的同步。
