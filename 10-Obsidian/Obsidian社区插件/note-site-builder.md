## 概述

**Note Site Builder** 是一款将 Obsidian 笔记或文件夹转化为精美单页网站及 PDF 的插件，旨在简化文档排版与发布流程。

**主要功能**：自动处理排版，生成带目录栏、编号章节及图片说明的网页，支持 KaTeX 数学公式、Excalidraw 绘图转 SVG，并输出 A4/Letter 标准 PDF。

**适用场景**：制作课程讲义、实验室手册、技术报告或在线文档，适合需要快速生成专业格式文档并分享给他人的用户。

**核心特色**：
1. **实时预览**：浏览器中保存即刷新，所见即所得。
2. **一键发布**：集成 Git，支持一键推送到 GitHub Pages 实现在线托管。
3. **多页联动**：支持文件夹多页模式，页面间 `[[links]]` 有效跳转。
4. **极简配置**：右键即可设置网站，自动处理标题、副标题及输出路径。

**使用建议**：建议将相关笔记整理在同一文件夹中，利用“Set up website”功能统一配置。若需在线分享，请确保已安装 GitHub CLI 或准备好 GitHub 仓库，以便快速启用 Pages 服务。适合追求高效文档交付的用户。
