## 概述

**Handy Toolkit** 是一款旨在优化 Obsidian 阅读与编辑体验的增强工具箱。

**主要功能**：提供属性区一键折叠、首行缩进设置、快速切换器文件夹过滤、重命名时同步 Frontmatter 标题及附件文件夹、修改时自动更新 `updated` 字段、Perlite 发布状态切换、图片按序重命名及生成 `.gitkeep` 文件。

**适用场景**：适合追求高效工作流、需要批量管理笔记属性、注重中文排版（首行缩进）以及使用 Git 或 Perlite 进行同步发布的用户。

**核心特色**：功能模块化且轻量，支持对当前文件或全库笔记进行批量属性折叠，且折叠状态仅保存在本地，不修改 Markdown 内容。此外，它提供了灵活的前置元数据同步机制，能自动处理重命名带来的标题和附件路径变更，极大减少手动维护成本。

**使用建议**：建议优先启用“属性折叠”以提升界面整洁度；若使用中文写作，务必开启“首行缩进”以符合排版习惯；对于依赖 Git 同步的用户，可配置“重命名同步”功能以避免元数据不一致。注意该插件折叠状态不通过 Git 同步，多设备使用时需留意差异。
