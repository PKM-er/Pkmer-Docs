## 概述

### Git Ribbon Sync插件总结
1. **主要功能**：在Obsidian左侧侧边栏添加Git操作按钮，可直接进行拉取、提交、推送操作，还能查看仓库提交历史，无需打开终端。
2. **适用场景**：适用于使用Obsidian且需要同步vault更改，借助Git管理笔记库的用户。
3. **核心特色**：轻量级且无缝集成，通过图标和命令快速操作；提供交互式提交历史查看界面；可在设置中自定义设备名称和提交消息前缀；操作可在命令面板中执行，还能设置快捷键。
4. **使用建议**：若想使用插件预设功能，直接点击侧边栏图标操作即可；若需个性化，可在设置里调整设备名和提交消息前缀；习惯快捷键操作的用户，可在设置的热键中为相关命令分配自定义快捷键。
