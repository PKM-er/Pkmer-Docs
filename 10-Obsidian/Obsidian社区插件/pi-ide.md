## 概述

### Pi IDE 插件总结
1. **主要功能**：通过 `pi-ide` 协议将 Obsidian 连接到 Pi Coding Agent，能让 Pi 获取当前文件、光标和选中文本信息，处理 Pi 的 `openDiff`，支持可选的自动接受模式，还能在启动时检查 Pi 端包并一键安装。
2. **适用场景**：适用于使用 Pi Coding Agent 且需要在 Obsidian 中进行代码编辑和协作的场景。
3. **核心特色**：将 Obsidian 作为 Pi 的 IDE 目标，实时更新选择、光标和文件变化信息；提供自动接受模式，提高信任环境下的工作效率；启动时自动检查并安装 Pi 端必要包。
4. **使用建议**：需安装 Obsidian 桌面版和 Pi Coding Agent，确保 `pi` 命令可用，并安装 Pi 端包 `npm:@ldelossa/pi-ide`。可通过本地开发或 BRAT 方式安装插件。在设置中，可按需开启自动接受编辑、启动通知等功能，默认不开启自动接受以保障安全。
