## 概述

**1. 主要功能**
该插件允许用户在 Obsidian 中创建基于纯 JSON 文件（`.kanban`）的看板，支持拖拽操作管理待办事项。它提供三种全局视图：艾森豪威尔矩阵（按紧急/重要程度分类任务）、已完成日志（按天分组展示所有完成卡片）以及技能雷达图（根据完成带标签的任务动态生成）。

**2. 适用场景**
适合需要可视化管理个人任务、项目进度或习惯养成的用户。特别适用于希望将任务数据本地化、便于 Git 版本控制及跨设备同步，且偏好通过游戏化机制提升执行动力的知识工作者。

**3. 核心特色**
*   **纯文件存储**：数据以明文 JSON 形式保存在库中，无隐藏数据库，可读性强且易于备份。
*   **优先级对决**：支持在列中通过两两对比的方式快速排序任务，提升决策效率。
*   **技能成长可视化**：完成带标签的任务可累积技能点，雷达图随之增长，实现“边做边升级”的游戏化体验。
*   **多语言支持**：提供英文和德文界面。

**4. 使用建议**
目前插件尚未进入官方社区列表，需通过 BRAT 或手动从 GitHub 安装。建议用户利用“优先级对决”功能整理杂乱任务，并善用标签系统，以便在“技能雷达图”中直观看到长期努力带来的成长轨迹。
