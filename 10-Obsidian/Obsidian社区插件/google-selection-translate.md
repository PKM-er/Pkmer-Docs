## 概述

### Google Selection Translate 插件总结
1. **主要功能**：在 Obsidian 笔记中选中文本，右侧栏会即时显示 Google 翻译结果。具备选中文本自动翻译、只读侧栏显示翻译、智能合并换行符、锁定翻译、一键复制翻译、翻译缓存及 API 密钥测试等功能。
2. **适用场景**：适用于阅读外文笔记、撰写双语内容、处理含大量外文的学术资料等场景，能快速获取翻译结果。
3. **核心特色**：无需按钮和复制粘贴，选中文本即可自动翻译，减少操作摩擦；侧栏仅显示翻译，保留原文位置；智能合并换行符，保证段落翻译完整性；有缓存机制，节省 API 配额。
4. **使用建议**：使用前先测试 Google API 密钥的连通性；若需查看之前选中文本的翻译，可利用翻译缓存功能；阅读或复制翻译时，可点击锁定按钮防止新选中文本覆盖当前翻译。
