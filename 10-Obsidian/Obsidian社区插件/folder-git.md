## 概述

**Folder Git** 是一款为 Obsidian 提供 VS Code 风格 Git 版本控制的插件，支持 GitHub 及 Forgejo/Gitea 平台。

1.  **主要功能**：实现“每文件夹独立仓库”管理，允许将 Vault 中的不同文件夹作为独立的 Git 仓库进行追踪。提供完整的源代码控制面板，支持文件暂存、提交、推送、拉取、同步及冲突解决，并具备彩色差异对比和历史记录查看功能。
2.  **适用场景**：适用于希望将笔记库的不同部分（如工作、个人、项目）独立备份到不同远程仓库的用户，或需要精细控制版本历史与权限管理的场景。
3.  **核心特色**：区别于全库单一仓库模式，支持多独立仓库并行管理；深度集成 GitHub/Forgejo，可在添加文件夹时直接创建远程仓库或组织；支持自动备份间隔设置及自定义提交模板，操作便捷（如快捷键提交）。
4.  **使用建议**：建议为不同性质的笔记文件夹分别配置独立的远程仓库，以隔离数据风险；利用自动备份功能定期同步，确保数据安全；注意该插件尚未经过官方人工审核，使用前建议自行备份重要数据。
