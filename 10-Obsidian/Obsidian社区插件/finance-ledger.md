## 概述

**Finance Ledger 插件中文总结**

1. **主要功能**
该插件将 hledger 会计日志可视化，提供可筛选的交易表格、余额与分类仪表盘。支持交易分类管理，并内置导入器，能自动同步生成日志、账户及合同笔记，实现与外部数据源的无缝对接。

2. **适用场景**
适用于使用 Obsidian 进行个人财务管理、记账或复式记账的用户。特别适合需要追踪多账户余额、分析支出分类，并希望通过 Markdown 笔记形式管理财务数据的场景。

3. **核心特色**
- **全栈集成**：最新版本已移除对 Python 的依赖，内置导入器可直接在 Obsidian 内完成数据同步。
- **智能保护**：仅更新自动生成的内容，保留用户手动添加的元数据（如初始余额、创建日期等），确保数据安全性。
- **交互优化**：提供防重复预览、重新导入按钮及交易筛选功能，提升数据管理效率。

4. **使用建议**
- 确保已安装 hledger 格式的数据源，或依赖插件内置导入器生成日志。
- 注意插件 ID 变更：2026年6月10日后 ID 由 `finance` 改为 `finance-ledger`，请检查配置。
- 虽然核心导入已内置，但部分高级报表（如维度笔记）仍建议通过终端运行 Python 脚本生成，以获得完整功能。
