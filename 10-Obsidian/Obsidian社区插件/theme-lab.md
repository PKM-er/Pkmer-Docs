## 概述

**Theme Lab** 是一款专为 Obsidian 主题开发者打造的内置工具，旨在替代“编辑-刷新-截图-目测”的低效循环。

**主要功能**：提供三大核心能力：1. **元素检查**：点击任意元素即可查看 DOM 路径、计算样式及所有匹配规则，并高亮显示实际生效的 CSS 规则，快速定位样式冲突；2. **截图矩阵**：自动捕获深色/浅色模式、阅读/编辑/源码视图及侧边栏状态的全组合截图，生成联系表；3. **质量报告**：一键生成 Lint 检查、对比度分析及 CSS 变量清单报告。

**适用场景**：适用于 Obsidian 主题作者、CSS 爱好者及需要调试界面样式的用户，特别适合在开发过程中实时预览和验证主题效果。

**核心特色**：无需离开应用即可完成从调试、预览到质量检查的全流程；通过可视化“获胜规则”解决“为什么我的 CSS 没生效”的痛点；支持 Shift 连续检查多元素，极大提升调试效率。

**使用建议**：建议主题开发者在编写 CSS 时配合“元素检查”功能实时验证选择器优先级；在发布前利用“截图矩阵”和“质量报告”确保跨视图兼容性及无障碍对比度标准。
