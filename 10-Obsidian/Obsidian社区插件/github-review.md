## 概述

### 插件名称
GitHub Review

### 主要功能
- 可在Obsidian内阅读、评论、批准或请求更改GitHub的问题和拉取请求。
- 从模板创建新问题，支持Markdown编辑和@提及自动补全。
- 舒适阅读规范文档，PR的Markdown文件、问题/PR正文及评论以Markdown形式呈现。
- 查看PR的完整更改集，Markdown文件渲染显示，其他文件以彩色差异显示。
- 直接进行评论、关闭问题或提交GitHub审查。
- 借助内置的stdio MCP服务器，让Claude客户端了解当前查看的内容。

### 适用场景
适用于需要在Obsidian中对GitHub上的Markdown规范/设计文档进行阅读和审查的场景。

### 核心特色
- 所有操作直接同步回GitHub，GitHub为唯一真实数据源，无本地存储。
- 评论和审查以令牌所有者身份进行，批准使用GitHub原生PR审查。
- 与Claude集成方便，无需手动设置端口、令牌和运行服务。

### 使用建议
在使用Claude功能时，可搭配Claudian或Claude Code CLI等客户端，直接询问相关问题以获取帮助。
