## 概述

**Better MD Diff** 是一款专为 Obsidian 设计的 Git 对比插件，旨在帮助用户在 Markdown 笔记中直观地查看、导航并恢复与 Git HEAD（最新提交）的差异。

**主要功能**：插件通过配对差异视图高亮显示文本变更，支持同步导航，并允许用户按代码块（hunk）确认并单独恢复特定修改。

**适用场景**：适用于使用 Git 进行版本管理的 Obsidian 桌面用户（需 Obsidian 1.8.0+ 及本地 Git），特别适合需要精细控制笔记历史版本、频繁进行内容修订或协作编辑的场景。

**核心特色**：
1. **精准差异展示**：红色代表旧内容，绿色代表新内容，并高亮具体变更单词，清晰直观。
2. **高效导航**：支持键盘上下键及点击行号快速定位变更，编辑器侧边栏显示增删改标志（绿+、蓝~、红-）。
3. **安全恢复**：支持按块确认恢复，防止误操作，且修复了空行导致的段落错位问题。

**使用建议**：建议在 Source 或 Live Preview 模式下编辑 Git 追踪的笔记，通过点击编辑器标志或 Ribbon 图标启动对比。恢复更改前务必预览确认，操作后可用 Ctrl/Cmd+Z 撤销。
