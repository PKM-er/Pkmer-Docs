## 概述

Mobile Timer for Clockify 允许你在 Obsidian 笔记中直接启动、停止或切换 Clockify 计时器，并实时显示当前运行时间及今日总时长。它解决了在手机上缺乏状态栏导致无法直观查看计时状态的问题，通过专门的计时面板和红色丝带按钮提供视觉反馈，让你无需离开笔记界面即可完成时间追踪操作。

典型场景包括在撰写文档时快速记录工作时间，或针对具体任务进行精准计时。例如，你可以将光标放在待办事项列表的某一行，执行“为此任务启动计时器”命令，系统会自动提取该行文本作为描述并启动计时；或者在笔记属性中设置默认项目，点击“为此笔记启动计时器”即可一键开始，极大简化了手动输入描述的繁琐流程。

相比同类插件，其特色在于深度整合笔记内容，支持从任务行直接提取描述，并具备离线队列功能（Pro 版），在网络中断时暂存操作并在恢复后自动同步。此外，Pro 版还支持在笔记中嵌入代码块生成按项目、日期或描述分类的工时报表，以及编辑或删除历史条目，使时间数据管理更加灵活高效。

使用前需注意，该插件为非官方插件，需在每台设备上单独配置 Clockify API 密钥，且密钥不会同步。核心功能免费，但项目选择器、报表生成、离线队列及条目编辑等高级功能需通过 GitHub Sponsors 赞助解锁。如果你不需要在笔记内直接操作计时器，或仅使用桌面端且已有其他状态栏插件满足需求，此插件可能并非必需。
