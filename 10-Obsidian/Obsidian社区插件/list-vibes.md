## 概述

**1. 主要功能**
List Vibes 是一款原生感十足的待办事项扩展插件。它将 Markdown 文件作为任务列表，一行即一个任务。支持为列表设置图标和颜色，提供原地重命名、拖拽排序、标题美化等功能。用户可在侧边栏或标签页中管理列表，并支持将列表文件直接以列表视图打开，而非纯 Markdown 编辑器。

**2. 适用场景**
适合追求高效、简洁且希望数据完全本地化同步的用户。特别适用于那些厌倦了传统待办应用无法同步、操作繁琐或不符合人体工学设计的人群。它是替代纯 Markdown 手动管理任务、又不想依赖外部数据库的理想选择。

**3. 核心特色**
*   **纯 Markdown 架构**：无数据库、无索引、无缓存。列表即文件，任务即行，直接编辑文件即可同步，透明且可靠。
*   **原生交互体验**：支持拖拽排序、双击重命名、图标/颜色自定义，操作流畅自然。
*   **灵活视图**：支持侧边栏或标签页模式，仅在指定文件夹内生效，不影响 Vault 其他部分的正常使用。

**4. 使用建议**
建议在 Vault 中创建一个专用文件夹存放列表文件。利用文件名前的 Emoji（如 `💼Work.md`）快速定义图标。若需查看原始格式，可通过菜单切换为 Markdown 视图。定期备份该文件夹即可确保数据安全。
