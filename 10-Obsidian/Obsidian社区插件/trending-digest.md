## 概述

### Trending Digest 插件总结
1. **主要功能**：多源趋势内容聚合器，抓取 25+ 个站点（如 GitHub、知乎等）的热门内容，用 AI 对每条内容按相关度、实用价值等评分 0 - 10，筛选后将精选日报自动写入 Obsidian Vault，生成带 frontmatter 的 Markdown 文件。
2. **适用场景**：适合关注多领域资讯、希望在 Obsidian 中整合热门信息的用户，如开发者、研究者、科技爱好者等。
3. **核心特色**：多数据源、无需 Twitter API Key、AI 智能评分、可按 20+ 细分领域筛选内容、支持定时和手动运行、同一天多次运行只新增不覆盖。
4. **使用建议**：手动安装需下载解压到指定目录并重启 Obsidian 后启用；也可从源码安装。配置时需在设置中打开该插件选项，并设置 Claude 兼容的 API 端点。
