## 概述

**Kavel AI Image Generator** 是一款让 Obsidian 用户直接在笔记中生成和编辑图片的插件，无需离开当前文档即可工作。

**主要功能**：支持通过文字描述在光标处生成图片并自动嵌入笔记；支持对库内现有图片进行一句话编辑（如修改天空颜色等），编辑后的副本会保存在原图附近。

**适用场景**：适合需要在写作、研究或项目笔记中快速插入示意图、地图、概念图的场景，也适用于对已有配图进行微调优化的需求。

**核心特色**：
1. **零门槛启动**：生成图片无需 API Key，使用 Kavel 免费层级即可运行（每日约2张，1K分辨率带水印）。
2. **灵活编辑**：付费用户可启用“一句话编辑”功能，支持多种主流模型（如 Nano Banana 2、GPT Image 2 等），且无每日限制、无水印。
3. **跨平台支持**：兼容桌面端和移动端，图片默认存入可配置的 `Kavel` 文件夹。

**使用建议**：
- 新手可直接使用免费层级体验生成功能，注意提示词应包含风格、光线和画面内容描述。
- 若需高频使用、去除水印或启用图片编辑功能，建议注册 Kavel 账号并填入 API Key 以解锁完整权限。
- 编辑功能需针对 PNG/JPG/WebP 格式图片操作，建议保留原图以便对比。
