## 概述

**ABAP Syntax Highlight** 是一款专为 Obsidian 打造的代码高亮插件，旨在提升 ABAP 代码的阅读与编辑体验。

1. **主要功能**：为 Markdown 中 ` ```abap ` 围栏代码块提供完整的语法高亮支持，涵盖 ABAP 关键字、字符串（含模板字符串）、注释、Pragma、数字及运算符。
2. **适用场景**：适用于 SAP ABAP 开发者在 Obsidian 中记录技术文档、编写代码片段或维护开发笔记时，需要清晰区分代码结构以提升可读性的场景。
3. **核心特色**：
   - **双视图支持**：同时在阅读视图和编辑视图（实时预览/源码模式）下生效。
   - **主题自适应**：利用 Obsidian CSS 变量，自动匹配当前主题，完美适配深色与浅色模式。
   - **轻量安全**：无网络请求、无遥测数据、无外部依赖，隐私友好且运行高效。
4. **使用建议**：用户可通过 Obsidian 社区插件市场直接搜索安装，或从 GitHub 下载文件手动部署至插件目录。安装后启用插件即可自动识别并高亮 ABAP 代码块，无需额外配置。
