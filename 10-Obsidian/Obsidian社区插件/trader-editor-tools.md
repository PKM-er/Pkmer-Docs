## 概述

Mengren Editor 旨在解决 Markdown 笔记中段落、代码块、引用及表格间距不一致导致的排版杂乱问题。它通过统一所有块级元素的垂直间距，确保正文、标题和特殊元素之间保持视觉上的均匀间隔。同时，插件提供了拖拽调整图片大小、添加文字颜色、高亮及下划线等增强功能，并支持语音朗读笔记内容，全程保留 Obsidian 原生 Markdown 编辑体验，不干扰常规输入操作。

典型场景包括整理长篇学习笔记或技术文档。例如，当你混合使用代码块、引用和列表时，插件能自动消除因主题样式叠加产生的多余空白，使页面紧凑整洁。在需要快速调整插图尺寸时，直接拖动图片角落即可按比例缩放，无需手动修改代码。此外，利用“听书”功能，你可以选中重点段落进行语音朗读，配合高亮显示和自动滚动，实现类似有声书的阅读体验，适合通勤或休息时回顾内容。

相比同类插件，Mengren Editor 的特色在于其精细的间距控制模型，不仅处理普通文本，还针对代码背景、Callout 框等“绘制块”进行了像素级对齐，确保视觉间隙完全一致。其拖拽移动块级元素的功能支持将标题连同其下属章节整体移动，且列表项移动时会自动适配新层级的缩进。此外，插件提供系统语音和百度翻译两种朗读引擎，系统语音离线可用，百度语音则提供更自然的中文发音，用户可根据网络环境灵活切换。

使用前需注意，插件界面主要为中文，且部分功能如“Tab 知识行”显示可能影响标准 Markdown 中 Tab 缩进代码的解析，若笔记中大量使用 Tab 编写代码，建议关闭该选项。它不适合需要严格保留原始 Markdown 源码格式、或对插件依赖网络服务（如百度语音）有安全顾虑的用户。插件不自动重排笔记，所有格式化操作均需手动触发并支持撤销，确保数据安全。
