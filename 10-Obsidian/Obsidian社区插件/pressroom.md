## 概述

**Pressroom 插件中文总结**

1. **主要功能**：将 Obsidian 中的单篇笔记发布至 GitHub 上托管的 Quartz 5 网站。支持右键一键发布，无需修改笔记 Frontmatter，并提供管理面板以批量更新、移动或删除已发布页面。

2. **适用场景**：适用于拥有 GitHub 仓库且已部署 Quartz 5 博客的个人用户。适合希望将特定笔记同步到线上，同时保持本地库其他内容私密、不被公开的场景。

3. **核心特色**：
   - **非侵入性**：发布时生成独立副本，绝不修改原始笔记内容或添加标记。
   - **多站点支持**：可将同一笔记发布到一个或多个不同的 Quartz 站点。
   - **隐私安全**：GitHub Token 存储在 Obsidian 安全存储中；建议保持仓库私有以保护库结构隐私。
   - **可视化管理**：通过面板清晰查看发布状态及变更。

4. **使用建议**：
   - 仅限桌面端使用。
   - 需预先配置具有“Contents: Read and write”权限的 GitHub 细粒度令牌。
   - 务必将 Quartz 站点仓库设为**私有**，防止通过 `.pressroom/manifest.json` 泄露本地文件夹结构。
   - 在设置中配置排除文件夹，避免误发布敏感笔记。
