## 概述

### Neat File Tree插件总结
1. **主要功能**：为Obsidian文件资源管理器提供优化，包括实现类似VSCode的粘性文件夹标题（滚动时父文件夹固定在顶部），以及按文件夹深度应用不同配色方案。
2. **适用场景**：适用于文件结构复杂、文件夹层级较深且内容繁多的Obsidian库，帮助用户更便捷地导航和管理文件。
3. **核心特色**：
    - 粘性文件夹标题让用户在展开多个文件夹时不会迷失位置。
    - 提供多种配色方案，可根据文件夹深度着色，顶级文件夹保持加粗突出显示。
    - 各功能可在插件设置中单独开关，还能调整行高以适配大字体界面。
    - 纯CSS实现，无DOM操作，不影响性能，能自动适配明暗和自定义主题。
4. **使用建议**：在Obsidian的社区插件中搜索“Neat File Tree”进行安装和启用。可根据个人喜好在设置里选择配色方案、开关功能及调整行高。
