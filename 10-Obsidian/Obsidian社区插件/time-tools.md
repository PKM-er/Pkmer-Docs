## 概述

**1. 主要功能**
Time Tools 插件包含两大核心模块：
*   **时间戳插入**：在光标处插入当前时间，并支持将已有时间文本转换为相对时间（如“3天前”）、Wiki链接或农历等格式。
*   **番茄钟计时器**：提供可拖动的计时器，支持按场景预设时长、正计时模式、会话日志记录及累计统计。

**2. 适用场景**
适用于需要高效记录时间点的笔记场景（如日记、会议记录），以及需要专注力管理、通过番茄工作法规划学习或工作时间的用户。

**3. 核心特色**
*   **双模合一**：单一插件集成时间戳与番茄钟，共享设置文件，通过标签页切换，管理便捷。
*   **灵活转换**：不仅限于插入时间，还能智能转换已写入的时间文本格式。
*   **场景化预设**：番茄钟支持针对不同场景（如深度工作、休息）设置不同的时长配置。
*   **数据追踪**：自动记录每次番茄钟会话，提供累计统计数据，帮助用户量化专注时长。

**4. 使用建议**
*   **安装注意**：若从旧版 `timestamp-inserter` 或 `pomodoro-plugin` 升级，请务必检查 `.obsidian/plugins/` 目录，删除 ID 冲突的旧文件夹，避免设置失效或命令冲突。
*   **配置备份**：升级前建议备份旧文件夹中的 `data.json` 以保留历史配置。
*   **文件夹命名**：确保插件文件夹名称与 ID `time-tools` 一致，以保证外部设置变更回调正常触发。
