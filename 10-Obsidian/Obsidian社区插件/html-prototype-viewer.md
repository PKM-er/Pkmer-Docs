## 概述

### HTML Prototype Viewer 插件总结
1. **主要功能**：可在隔离的 iframe 中预览本地 HTML 文件，支持原生打开 `.html` 和 `.htm` 文件，能切换设备宽度，具备实时重新加载功能，可将预览嵌入笔记，还能在系统浏览器中打开。
2. **适用场景**：适合存放设计原型、导出的工件或独立 HTML 原型文件并与笔记放在一起的场景。
3. **核心特色**：使用 iframe 加载文件，使 HTML 原型有独立的文档、样式表和脚本上下文，不会影响 Obsidian 界面，且 JavaScript 可正常运行；不依赖本地 Web 服务器，通过 Obsidian 资源 URL 解析文件，支持桌面和移动设备；界面支持英语和法语，随 Obsidian 语言设置切换。
4. **使用建议**：在文件资源管理器中点击文件即可打开预览；通过标签工具栏切换设备宽度；使用 `html-preview` 代码块将预览嵌入笔记，可使用命令“Insert a prototype preview in the note”生成代码框架。
