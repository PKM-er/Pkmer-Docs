## 概述

### “Publish on GitHub”插件总结
1. **主要功能**：可将标记特定标签（如`#public`）的笔记选择性发布到由 GitHub Pages 托管的 Jekyll 静态网站。能转换 Obsidian 特定的维基链接和图片为相对 Markdown 路径，构建 HTML 属性徽章，验证链接，自动执行 Git 提交和推送。
2. **适用场景**：适用于希望将 Obsidian 笔记选择性公开到 Jekyll 静态网站的用户，如知识分享者、博客作者等。
3. **核心特色**：支持选择性同步，仅复制含指定标签的笔记；自动转换链接和资产；扫描并提示断链；将 YAML 前置元数据转换为 HTML 徽章；兼容 WSL Git；生成详细的 Git 提交日志；可初始化美观的 Jekyll 模板，有侧边栏和自动目录。
4. **使用建议**：先确定好要公开的笔记标签，在配置时可根据自身系统选择合适的 Git 运行方式（Windows 或 WSL），使用前可参考示例网站熟悉效果。
