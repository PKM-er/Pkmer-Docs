## 概述

**1. 主要功能**
该插件在 Obsidian 中嵌入真实终端，支持在标签页或分屏中运行登录 Shell。它提供一键启动器，可直接在 Vault 文件夹中启动 Claude Code 会话，无需手动切换窗口或输入路径。

**2. 适用场景**
适用于需要在笔记旁直接执行脚本、查看 Git 状态或运行 AI 辅助工具的场景。特别适合希望减少在笔记软件与外部终端应用间频繁切换，追求工作流无缝衔接的用户。

**3. 核心特色**
- **原生集成**：终端作为普通面板存在，支持重命名，重载后自动恢复至原文件夹。
- **安全透明**：无遥测、无自动更新检查，仅在你按下按键时操作剪贴板，权限完全由用户掌控。
- **交互友好**：即使终端捕获键盘焦点，Obsidian 命令面板依然可用，避免操作受限。
- **平台限制**：目前仅支持 macOS 和 Linux，暂不支持 Windows。

**4. 使用建议**
安装前需明确终端拥有最高系统权限，可访问 Vault 外文件。若对安全性敏感或不需要在笔记内直接运行系统命令，建议不安装。使用时请确保了解所运行命令的后果，插件本身不限制任何操作，完全依赖用户自律。
