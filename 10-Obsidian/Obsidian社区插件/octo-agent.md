# Obsidian 插件：Octo Agent

> [!Note] 插件名片
> - 插件名称：Octo Agent
> - 插件作者：open-octo
> - 插件说明：把Octo Agent代码编写助手嵌入到你的仓库里。你的仓库会变成它的工作目录，让它具备读写文件、搜索、执行bash命令以及处理多步骤工作流程的能力。 - 此插件尚未经过Obsidian工作人员的人工审核。

## 概述

### Octo Agent插件总结
1. **主要功能**：将Octo Agent编码助手嵌入Obsidian库，可对库内文件进行读写、搜索操作，支持执行bash命令和多步骤工作流。具备内联编辑、斜杠命令与技能、@提及、指令模式、多标签与对话等功能。
2. **适用场景**：适用于需要在Obsidian中进行文件操作、代码编写及自动化工作流处理的场景，尤其适合开发者和技术人员。
3. **核心特色**：以库作为工作目录，操作便捷；支持多种交互方式，如热键内联编辑、斜杠命令、@提及等；具备多标签和对话历史功能。
4. **使用建议**：安装前需确保Octo Agent CLI/server已安装且可访问，Obsidian版本为v1.7.2+，仅支持桌面端。推荐从Obsidian社区插件安装，打开Obsidian，在社区插件中搜索“Octo Agent”进行安装和启用。
