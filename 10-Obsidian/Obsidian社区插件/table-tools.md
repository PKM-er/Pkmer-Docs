## 概述

**1. 主要功能**
Table Tools 插件为 Obsidian 中的 Markdown 表格提供三项增强：在表格旁自动添加行号；支持添加可编辑的标题（Caption）和脚注（Footnote）；以及一键复制表格为图片或纯 Markdown 格式。

**2. 适用场景**
适用于需要制作专业文档、报告或演示材料的用户。特别适合那些希望在不破坏原始 Markdown 结构的前提下，为表格增加视觉标识（行号、标题）或方便分享（复制为图片/文本）的场景。

**3. 核心特色**
*   **非侵入性**：行号绘制在表格外部，自动随增删行重新编号，不写入 Markdown 源码。
*   **原生兼容**：标题和脚注以 Obsidian 注释（`%% ... %%`）形式存储，在预览模式下隐藏，禁用插件后笔记仍保持有效 Markdown 格式。
*   **灵活导出**：支持按当前主题渲染并复制为 PNG 图片，或生成带格式说明的干净 Markdown 文本，方便跨平台分享。

**4. 使用建议**
安装后，点击表格上方的标题或下方的脚注区域即可编辑，按 `Enter` 保存。悬停表格右上角可看到复制按钮。若表格由其他插件动态生成，可使用命令面板中的“Process tables on this page”命令刷新。该插件无需复杂配置，即装即用，且对笔记源码零污染。
