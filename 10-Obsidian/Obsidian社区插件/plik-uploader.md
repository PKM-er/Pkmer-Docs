## 概述

**Plik Uploader** 是一款将 Obsidian 笔记或文件上传至自托管 Plik 服务器并生成分享链接的插件。

**主要功能**：支持上传当前笔记、任意文件或整个文件夹（自动打包为 Zip），并可将 Markdown 笔记直接渲染为 PDF 后上传。提供左侧边栏查看上传历史、复制链接及远程删除功能。

**适用场景**：适用于需要快速分享笔记内容、向外部协作方发送文档，或希望利用自托管服务器安全存储临时文件的用户。

**核心特色**：
1. **灵活分享**：支持设置有效期（TTL）、一次性链接及密码保护。
2. **便捷操作**：通过命令面板、右键菜单或侧边栏图标快速触发上传。
3. **远程管理**：可直接在 Obsidian 内删除服务器上的文件，无需访问 Web 界面。
4. **本地记录**：自动记录上传历史及过期状态，支持多语言自动检测。

**使用建议**：需先部署并运行 Plik 实例，并在插件设置中配置服务器 URL。若需管理存储空间，建议配置 API Token。PDF 导出功能仅限桌面端使用。
