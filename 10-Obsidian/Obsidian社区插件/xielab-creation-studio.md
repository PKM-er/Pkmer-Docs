## 概述

Creation Studio 是一款专为内容创作者设计的 Obsidian 插件，旨在通过六个联动视图解决从灵感捕捉到作品归档的全流程管理难题。它将仪表盘、创意库、制作看板、发布日历、作品库及复盘记录整合在单一 Markdown 笔记中，利用属性驱动视图更新。你只需维护一份笔记，即可在拖拽卡片切换制作阶段（如从写作到剪辑）或调整发布日程时，自动同步所有相关视图的状态，无需手动维护多份文档。

典型场景包括管理多平台内容发布与追踪创作进度。例如，当你完成一篇视频脚本并进入剪辑阶段时，只需在看板中拖动卡片，发布日历上的对应日期会自动更新状态；若需调整发布时间，直接拖动日历上的事件即可，且不会丢失当前的制作阶段信息。此外，你可以设定月度目标，并在复盘视图中记录实际数据与账号快照，缺失的数据会保持空白而非默认为零，确保统计的真实性和灵活性。

相比其他通用任务管理插件，Creation Studio 的核心特色在于其针对创作流程的深度定制与可选的 iCloud 日历单向同步。它允许将发布计划同步至 Mac 日历，方便在系统层面查看排期，但不会反向修改笔记内容。该插件完全本地运行，基础功能无需网络、Dataview 或其他社区插件支持，且明确区分演示数据与真实作品，确保统计数据的纯净性。

使用前需注意，该插件目前仅支持桌面端且界面为中文，无法自动发布内容或抓取平台数据，所有指标需手动录入。它不适合需要双向同步日历编辑、依赖移动端操作或希望插件直接对接社交媒体 API 的用户。若你主要使用移动端 Obsidian，或需要复杂的自动化发布流程，此插件可能无法满足需求。
