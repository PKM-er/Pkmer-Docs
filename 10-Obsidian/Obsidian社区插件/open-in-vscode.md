## 概述

**主要功能**
该插件允许用户在 Obsidian 中通过单一命令快速在 VS Code 中打开当前笔记、跳转至光标所在行，或将整个 Vault 作为文件夹打开。支持从命令面板、文件/编辑器右键菜单及侧边栏图标触发。

**适用场景**
适合习惯使用 VS Code 进行代码编辑、复杂 Markdown 处理或需要利用其强大插件生态的用户。当需要在 Obsidian 中管理笔记，同时依赖 VS Code 的专业开发环境时，此插件能实现无缝切换。

**核心特色**
1. **多入口触发**：支持命令面板、右键菜单及图标多种操作方式。
2. **跨平台自动检测**：自动识别 Windows、macOS 和 Linux 下的编辑器路径。
3. **编辑器可定制**：默认使用 VS Code，但可配置为 Cursor、Trae、Zed 或 Windsurf 等替代编辑器。
4. **非阻塞启动**：编辑器以分离进程启动，确保 Obsidian 保持响应流畅。

**使用建议**
若自动检测失败，请在设置中手动指定编辑器可执行文件路径。Windows 用户需确保路径指向正确的命令行入口点（如 `code.cmd`）。建议搭配 `markdown-open-typora-obsidian` 插件使用，以构建更完善的跨编辑器工作流。
