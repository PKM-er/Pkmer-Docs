## 概述

**Harry Toolkit** 是一款为作家设计的 Obsidian 个人工具包，将多个实用小工具集成于一体，所有数据均保存在本地库中，确保隐私与可读性。

**主要功能**：
1. **打字机式滚动**：光标固定屏幕位置，文本随滚动流动，支持热键控制，适合长文校对。
2. **发布日历**：提供文章排期、待办事项、截止日期提醒及笔记浏览功能。
3. **社交复制**：将笔记转换为保留空行的纯文本，方便直接粘贴至 Facebook 等平台。
4. **Threads 分析**：通过官方 API 只读获取个人 Threads 账号数据，生成可排序的分析仪表盘。

**适用场景**：适合需要管理内容发布计划、进行长文写作校对，以及监控社交媒体（特别是 Threads）表现的内容创作者和作家。

**核心特色**：
*   **模块化设计**：各功能可独立开关，未启用的功能不产生任何干扰。
*   **数据本地化**：数据以 Frontmatter、Markdown 或 JSON 形式存储，移除插件后数据依然可读。
*   **隐私安全**：除 Threads 分析需联网读取官方 API 外，其余功能完全离线运行，且绝不上传数据。

**使用建议**：建议在设置中仅启用所需功能以减少干扰；使用“社交复制”时注意检查格式兼容性；对于 Threads 分析，请确保已正确配置 API 权限。
