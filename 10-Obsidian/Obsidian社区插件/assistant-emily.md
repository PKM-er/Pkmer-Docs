## 概述

**插件名称**：Assistant Emily

**1. 主要功能**
这是一款基于 OpenAI 兼容 LLM 的智能 Markdown 辅助插件，核心功能包括：
*   **无损智能校对**：在保留原始格式的前提下修正语法与拼写错误。
*   **语境感知翻译**：结合上下文进行专业级精准翻译。
*   **排版规范化**：自动统一 Markdown 的字体与格式风格。
*   **自定义指令**：支持用户输入自然语言指令以执行特定任务。
*   **交互式 Diff 审查**：提供可视化差异对比，方便用户确认修改。

**2. 适用场景**
适用于需要处理大量 Markdown 文档的桌面端用户，特别是从事多语言写作、技术文档维护或学术笔记整理的场景。

**3. 核心特色**
*   **隐私安全**：100% 本地/直连处理，保障数据隐私。
*   **无损编辑**：严格保持 Markdown 结构不变，避免格式丢失。
*   **高度定制**：支持自然语言指令，灵活适配个人工作流。

**4. 使用建议**
*   仅支持 **Desktop** 版本（Obsidian v1.7.2+）。
*   需配置 OpenAI 兼容的 LLM 代理接口。
*   建议先通过 Diff 视图仔细审查 AI 生成的修改，再应用最终结果。
