## 概述

### 插件名称
Quick Editing

### 主要功能
提供快速的 Markdown 转换、智能粘贴、内部链接处理、文本清理、间距调整和空行编辑等功能。

### 适用场景
适用于需要高效处理 Markdown 文档的用户，如写作者、知识管理爱好者等。

### 核心特色
1. 包含四个独立可配置组：智能符号、格式刷、智能粘贴和全文档清理。
2. 支持语法感知的转换，有预览和撤销功能。
3. 基于剪贴板事件的富文本粘贴和 HTML 表格转换。
4. 可通过 Obsidian 链接 API 生成内部链接。
5. 具备可搜索的设置、单命令开关和多窗口支持。
6. 能一键移除图片链接且不删除附件。
7. 状态栏格式刷菜单直接显示配置的文本和高亮颜色。

### 使用建议
1. 在“设置→Quick Editing”中启用所需功能组。
2. 搜索命令列表来启用或禁用单个命令。
3. 在“设置→快捷键”中为常用命令分配快捷键。
4. 通过命令面板、快捷键或格式刷工具栏运行命令，全文档更改前会显示预估更改数量。
