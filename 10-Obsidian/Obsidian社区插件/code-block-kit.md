## 概述

**Code Block Kit** 是一款增强 Obsidian 代码块体验的插件，主要功能包括一键格式化、原地运行代码及在 VS Code 中打开。

**适用场景**：适合需要频繁编写、调试或整理代码片段的开发者、技术写作者及学生，特别是那些希望在笔记中直接验证逻辑或保持代码整洁的用户。

**核心特色**：
1. **全能格式化**：内置 Prettier，支持 JS/TS、JSON、CSS、HTML、Vue、Markdown 等主流语言，离线可用。
2. **原地执行**：支持直接运行 Python、JavaScript、TypeScript 和 Shell 代码块。
3. **智能编辑**：提供自动缩进、括号配对展开、智能注释切换及语法错误实时下划线提示。
4. **无缝集成**：在编辑和阅读视图均提供直观按钮，支持列表和引用块内的代码保持缩进格式。

**使用建议**：建议开启“Format current code block”命令以快速美化代码；利用智能编辑功能提升编码效率；对于复杂项目，可使用“Open in VS Code”将代码块无缝迁移至专业编辑器进行深度开发。
