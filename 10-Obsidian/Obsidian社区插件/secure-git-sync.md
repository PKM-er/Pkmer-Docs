## 概述

### Secure Git Sync插件总结
1. **主要功能**：用于Obsidian桌面，支持密码确认的Git同步，可选择对远程笔记快照加密，还能进行直接的局域网保险库同步。能复用现有`.git`仓库、添加新远程仓库，可加密存储远程笔记快照。
2. **适用场景**：适用于已用Git备份或迁移Obsidian保险库，但希望强化对私人笔记控制和本地优先工作流的用户。
3. **核心特色**：操作前需密码确认；新设置默认开启远程笔记快照加密；本地文件为明文；可导入现有远程仓库配置；支持多种远程仓库；有丰富的操作UI；支持局域网同步；有增量本地更改索引；加密同步更快；可选择同步后验证；对大型保险库有优化处理；支持分片加密清单。
4. **使用建议**：若已有本地`.git`仓库，可直接复用，按指引导入配置；启用加密功能保护隐私，局域网同步时确保设备在同一网络，按需选择同步设置。
