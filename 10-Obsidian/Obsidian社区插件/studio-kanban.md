## 概述

**1. 主要功能**
Kanban Studio 是一款基于 Markdown 的现代看板插件。它将笔记中的二级标题（`##`）映射为看板列，待办事项（`- [ ]`）映射为卡片。支持卡片拖拽排序、跨列移动，以及设置优先级、日期、负责人和标签。

**2. 适用场景**
适用于项目进度追踪、任务管理、个人待办清单及团队协作规划。特别适合需要直观可视化流程，同时希望保留数据纯文本兼容性的用户。

**3. 核心特色**
*   **纯 Markdown 数据**：数据即普通 Markdown 文件，卸载插件后数据无损，可无缝切换回源码视图。
*   **现代化交互**：提供深色模式、列表视图及缩略图展示，支持右键快速操作和撤销删除。
*   **智能识别**：带有特定属性的笔记自动以看板形式打开，支持中英双语界面。

**4. 使用建议**
*   新建看板可通过侧边栏图标、命令面板或文件夹右键菜单创建。
*   点击看板标题可直接重命名（优先修改 Frontmatter 中的 title，否则重命名文件）。
*   建议配合示例文件（如“云栖书店”案例）快速上手，熟悉列与卡片的对应关系。
